# 小配合

Seer Mod 的卡牌/遗物/能力配合思路。

## PP 体系

### 无为觉者 + PP 耗尽

- 无为觉者遗物让 PP=0 的卡牌仍可打出
- 配合高 PP 消耗卡牌（罗生门 ×3），即使 PP 耗尽也能继续输出

### PP 卡牌回收循环

- 部分机制会让消耗堆中的 PP 卡牌回收到弃牌堆
- 形成 PP 卡牌的循环利用

## 固定伤害体系

### 固定伤害 + 坚毅反弹

- [坚毅](/powers/resolve_power.md) 能力可反弹固定伤害
- 形成"打别人等于打自己"的局面

### 固定伤害免疫

- [免疫固定伤害](/powers/immune_fixed_damage_power.md)
- [回合免疫固伤](/powers/turn_immune_fixed_damage_power.md)
- [长效体力](/powers/long_lasting_hp_power.md)
- 这些能力都会拦截固定伤害能力系统

## 充能球体系

### 多源充能球

- 圣杯充能球、PP 充能球、多重充能球、火山、海洋、森林、塔、星辰、神谕
- 配合充能球栏位增加类卡牌，可形成多种充能球组合
