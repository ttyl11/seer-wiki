# 诅咒

<img src="/images/powers/curse_power.png" alt="诅咒" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **类型**: 减益（Debuff），列入[异常状态](/mechanics/abnormal-status.md)列表
- **叠加方式**: 叠加（Counter）
- **可见**: 是
- **允许负值**: 否
- **血条预测**: 是（仅怪物，紫色，3 点）

### 数值参数

| 参数 | 数值 |
|---|---|
| 攻击伤害降低 | 10% |
| 怪物随机伤害下限 | 3 |
| 怪物随机伤害上限 | 50 |

## 描述

攻击伤害降低<span style="color:#3aa675;font-weight:600">10</span>%。在玩家回合开始时获得一张[诅咒牌](/cards/curse/)。在你的回合结束时，若为怪物则受到<span style="color:#3aa675;font-weight:600">3</span>-<span style="color:#3aa675;font-weight:600">50</span>点随机伤害。在你的回合结束时减少1层。

## 详细机制

- **攻击伤害降低**：
  - 持有者造成的攻击伤害降低 10%（乘以 0.9）
  - 减伤幅度固定 10%，不随层数变化
- **玩家回合开始塞诅咒牌**：
  - 仅当持有者为玩家时触发
  - 从诅咒牌池中随机生成 1 张诅咒牌加入手牌
  - 该诅咒牌设为本回合免费（`SetToFreeThisTurn`）
- **怪物回合结束随机伤害**：
  - 仅当持有者为怪物时触发
  - 受 3-50 点随机不可格挡伤害，概率分布：
    - 50% 概率：3 点
    - 40% 概率：5 点
    - 9% 概率：8 点
    - 1% 概率：50 点
  - 期望伤害约 4.7 点/层
- **血条预测**：仅怪物显示（紫色，最小值 3 点）
- **回合结束减层**：持有者一方回合结束时，层数 -1

## 小贴士

- **双向惩罚**：玩家被诅咒会塞手牌，怪物被诅咒受随机伤害（1% 概率 50 点爆发）。对怪物是有效输出手段。
