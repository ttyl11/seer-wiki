# 万相乖离

> **归属**：玩家可施加
> **施加来源**：玩家获得——[无为觉者](/relics/legendary/inaction_awakener.md)（遗物）

<img src="/images/powers/universal_divergence_power.png" alt="万相乖离" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **类型**: 增益（Buff）
- **叠加方式**: 计数器（按层数叠加）
- **可见**: 是

mod 自定义能力。按层数解锁逐级增强效果：免疫减益、攻击伤害加成、以及在更高层数时于回合开始消耗 PP 牌触发治疗/清除/施加异常等效果。满层时死亡可复活（与「无为觉者」遗物联动）。
