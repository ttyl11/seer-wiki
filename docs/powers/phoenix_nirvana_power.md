# 凤之涅槃

> **归属**：怪物专属（玩家无法施加）
> **施加来源**：怪物自带——[菲尼克斯](/monsters/boss/phoenix_monster.md)

## 基本信息

- **类型**: 无类型（不参与增益/减益分类，不可被驱散/净化）
- **叠加方式**: 单例（不可叠加）
- **可见**: 是

## 描述

在其回合结束时，向你的抽牌堆中加入1张烬翎。自身死亡时最大生命值降为80%并满血复活，获得1层<span style="color:#d4a017;font-weight:600">缓冲</span>并再给予1张烬翎。其回合开始时，场上烬翎累计达20片时真正死亡。
