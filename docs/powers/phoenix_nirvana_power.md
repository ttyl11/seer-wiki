# 凤之涅槃

<img src="/images/powers/phoenix_nirvana_power.png" alt="凤之涅槃" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **叠加方式**: 按回合覆盖
- **可见**: 是

## 描述

在其回合结束时，向你的抽牌堆中加入1张烬翎。自身死亡时最大生命值降为80%并满血复活，获得1层<span style="color:#d4a017;font-weight:600">缓冲</span>并再给予1张烬翎。其回合开始时，场上烬翎累计达20片时真正死亡。
