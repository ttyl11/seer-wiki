# 北冥之刃

> **归属**：玩家可施加
> **施加来源**：玩家获得——[霍光](/relics/epic/huo_guang.md)（遗物）

## 基本信息

- **类型**: 增益（Buff）
- **叠加方式**: 单例（不可叠加）
- **可见**: 是

赛尔增益能力。持有期间，自身所有攻击必定暴击（强制[暴击](/powers/critical_strike_power.md)），且暴击伤害按 `CritDamageBoost` 百分比提升。
