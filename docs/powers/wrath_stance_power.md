# 愤怒姿态

<img src="/images/powers/wrath_stance_power.png" alt="愤怒姿态" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **类型**: 被动（不可消除）
- **叠加方式**: 不堆叠（单实例）
- **可见**: 是

## 描述

自身造成和受到的伤害翻倍。

## 详细机制

- **伤害翻倍范围**：仅对**攻击伤害**生效，非攻击伤害（固定伤害、异常状态持续伤害等）不翻倍。
- **双向翻倍**：白虎造成的攻击伤害 ×2，白虎受到的攻击伤害也 ×2。
- **乘法阶段**：在伤害计算的乘法修正阶段生效。

## 小贴士

- **双刃剑姿态**：白虎攻击力翻倍，但受到的伤害也翻倍——是输出也是破绽。
- **非攻击伤害不受影响**：固定伤害、中毒/烧伤等持续伤害不受翻倍影响，可以安全输出。
