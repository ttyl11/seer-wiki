# 金祖之龍

> **归属**：玩家可施加
> **施加来源**：玩家获得——[镇世·乔特鲁德](/relics/legendary/world_suppressor_jortrud.md)（遗物）

## 基本信息

- **类型**: 增益
- **来源**: [镇世·乔特鲁德](/relics/legendary/world_suppressor_jortrud.md)
- **叠加方式**: 不叠加（一次性）
- **可见**: 是

## 描述

免疫<span style="color:#d44;font-weight:600">臣服</span>异常状态。受到的伤害减少<span style="color:#3aa675;font-weight:600">30</span>%。<br/>自身死亡时，恢复到<span style="color:#d4a017;font-weight:600">最大生命</span>值的<span style="color:#3aa675;font-weight:600">30</span>%，但永久失去此能力。

## 数值

| 参数 | 数值 |
|---|---|
| 受到伤害减免 | 30%（攻击伤害） |
| 死亡复活生命 | 30% 最大生命 |
| 复活次数 | 1（一次性） |

## 小贴士

- **一次性复活**：致死时恢复到最大生命 30%，复活后该能力消失（减伤与复活均不再生效）。
- **跨战斗永久失去**：一旦本战斗中触发复活，后续战斗不再拥有此能力。
