# 钢傀守卫

<img src="/images/powers/steel_puppet_guard_power.png" alt="钢傀守卫" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **类型**: 无（不属于增益/减益，不可被清除）
- **叠加方式**: 单体（恒 1 层，不可叠加）
- **可见**: 是

## 描述

下回合开始时，随机无效化敌方一个非攻击[意图](/mechanics/intent.md)。

## 详细机制

- **获取方式**：[钢傀](/relics/epic/steel_puppet.md)持有者受到伤害（未被格挡的部分大于 0）后自动获得，恒 1 层——重复受伤不会叠加。
- **触发时点**：自己下回合开始时结算，此时敌人意图已生成，被无效化的是即将执行的动作。无论当回合有没有可无效化的意图，结算后本能力都会消失（过期作废）。
- **无效化目标池**：全体存活敌人当回合的所有非攻击意图（增益、格挡、施加异常、召唤等）合入一个池子随机选一个。纯攻击意图不在池内——攻击无法被守卫无效化。
- **敌人全攻击时空转**：所有敌人的意图都是攻击时池子为空，守卫直接消失，没有任何补偿。
- **不可清除**：不属于增益/减益，敌人的驱散/清除效果拿它没办法。
