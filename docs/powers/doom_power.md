# 灾厄



<img src="/images/powers/doom_power.png" alt="灾厄" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **类型**: 减益（Debuff）
- **叠加方式**: 递减（计数型）
- **可见**: 是
- **允许负值**: 否

## 描述

在敌人的回合结束时，如果其灾厄值等于或大于其生命，则其直接死亡。

## 详细机制

- **死亡判定**：持有者当前生命值 ≤ 灾厄层数时判定为死亡。
- **触发时机**：在持有者回合结束前，当满足以下条件时触发死亡：
  1. 战斗未结束
  2. 持有者在参与者列表中
  3. 持有者未死亡
  4. 持有者被判定为灾厄死亡
- **批量击杀**：一次性击杀所有同阵营的灾厄死亡生物。
  - 对每个生物播放灾厄动画。
  - 触发复活类能力的致死触发。
- **仅第一个触发**：同阵营中只有第一个灾厄生物触发击杀，避免重复。
- **特效**：播放特殊的灾厄覆盖动画和灾厄粒子。
- **层数颜色**：使用普通颜色（非减益的红色），与一般减益能力不同。
