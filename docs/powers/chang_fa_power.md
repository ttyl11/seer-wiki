# 常之罚

> **归属**：玩家可施加
> **施加来源**：玩家获得——[艾夏拉](/relics/rare/constancy.md)（遗物）

## 基本信息

- **类型**: 增益（Buff）
- **叠加方式**: 单例（不可叠加）
- **可见**: 是

本回合打出的第一张牌为攻击牌时，攻击伤害增加20%。为技能牌时，敌方回合内首次受到的攻击伤害降低20%。在你的回合结束时移除。
