# 失明

<img src="/images/powers/blind_power.png" alt="失明" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **类型**: 减益（Debuff），列入[异常状态](/mechanics/abnormal-status.md)列表
- **叠加方式**: 叠加（Counter）
- **可见**: 是
- **生效对象**: 玩家与怪物均生效

### 数值参数

| 参数 | 数值 |
|---|---|
| 自伤概率 | 50% |
| 非自伤时伤害倍率 | 50% |
| 自伤百分比 | 20% 原伤害 |

## 描述

攻击时，<span style="color:#3aa675;font-weight:600">50%</span>几率自伤<span style="color:#3aa675;font-weight:600">20%</span>原伤害，其余几率只造成<span style="color:#3aa675;font-weight:600">50%</span>伤害。在你的回合结束时减少1层。

## 详细机制

- **玩家与怪物均生效**：无论是玩家还是怪物持有失明，攻击时都触发判定——对怪物施加重构了"打不中还要挨自己一下"的惩罚（见[海天使](/relics/uncommon/sea_angel.md)）。
- **50% 概率自伤**：
  - 持有者攻击时，50% 概率自伤
  - 自伤量为原始伤害 × 20%（不可格挡的非攻击伤害）
  - 自伤时攻击伤害不降低（×1），但持有者自身受到 20% 反伤
- **50% 概率减伤**：
  - 另外 50% 概率不自伤，但攻击伤害只造成 50%（×0.5）
- **期望输出约 75%**：一半概率满伤 + 一半概率半伤 = 平均 75% 输出，另有每次攻击约 10% 原伤害的自伤反噬——攻击越高自伤越疼。
- **回合结束减层**：持有者一方回合结束时，层数 -1
- **RNG**：自伤判定多人模式两端一致

## 小贴士

- **对敌人施加重构是稳定削弱**：敌人持有失明期间，输出期望降到 75% 且每次攻击有 10% 自伤反弹——多段攻击型敌人（每次攻击都过一遍判定）收益比单次重击更稳。
