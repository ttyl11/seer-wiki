# 爵刻

> **归属**：玩家可施加
> **施加来源**：玩家获得——[爵刻·黑沃德](/relics/epic/jue_ke_blackward.md)（遗物）

## 基本信息

- **类型**: 增益（Buff）
- **叠加方式**: 计数器（按层数叠加）
- **可见**: 是

mod 自定义能力。回合开始时获得 1 层[先制](/powers/first_strike_power.md)；每当对敌人造成伤害时，对该敌人附加固定伤害、自身回复生命，并消耗 1 层爵刻。
