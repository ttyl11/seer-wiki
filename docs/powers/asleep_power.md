# 沉睡

> **归属**：怪物专属（玩家无法施加）
> **施加来源**：怪物自带——[狄修斯](/monsters/normal/dixius_monster.md)

<img src="/images/powers/asleep_power.png" alt="沉睡" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **类型**: 无类型（不参与增益/减益分类，不可被驱散/净化）
- **叠加方式**: 计数器（按层数叠加）
- **可见**: 是

## 描述

沉睡中的怪物在受到未被格挡的伤害时立即苏醒，或在层数归零（每回合结束时层数 -1）后苏醒。苏醒时会移除自身的[覆甲](/powers/plating_power.md)。
