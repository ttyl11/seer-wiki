# 凝视

> **归属**：怪物专属（玩家无法施加）
> **施加来源**：怪物施加给玩家——[墨鲁萨](/monsters/elite/medusa_minion_monster.md)

<img src="/images/powers/facing_power.png" alt="凝视" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **类型**: 减益（Debuff）
- **叠加方式**: 单例（不可叠加）
- **可见**: 是

## 描述

你的朝向会影响部分技能与怪物能力的效果。使用指定目标的卡牌或药水可以改变你的朝向。
