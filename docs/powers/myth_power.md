# 神话

> **归属**：怪物专属（玩家无法施加）
> **施加来源**：[群星的礼赠](/relics/starter/elemental_core.md)怪物被动池——遭遇怪物时按概率自带，概率随探索深度增长（神话是全池最稀有的能力之一）

<img src="/images/powers/myth_power.png" alt="神话" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **类型**: 增益（Buff）
- **叠加方式**: 单次（Single，无层数）
- **可见**: 是

## 描述

免疫所有<span style="color:#d44;font-weight:600">异常状态</span>。

## 详细机制

- **异常施加量归零**：任何[异常状态](/mechanics/abnormal-status.md)（全 <span style="color:#3aa675;font-weight:600">25</span> 种：睡眠、凝滞、烧伤、冰封、中毒、流血、冻伤、害怕、瘫痪、沉默、衰弱、狂暴、束缚、沸涌、石化、感染、超频、焚烬、失明、诅咒、臣服、寄生、麻痹、神游、易燃）要施加到持有者（怪物）身上时，施加量直接归 <span style="color:#3aa675;font-weight:600">0</span>——一个异常都挂不上。
- **只挡"异常状态"这一类**：以下效果**不属于**异常状态、照常生效——[固定伤害](/powers/fixed_damage_power.md)、力量/命中/速度/防御的降维 debuff、[曝](/powers/expose_power.md)等非异常类减益。
- **施加时拦截而非事后清除**：在异常进场前就把量改成 0，连"挂上再掉"的动画/闪光都不会有。

## 小贴士

- **异常流当场报废**：烧伤/中毒/流血/麻痹/石化这些体系遇到神话怪全部哑火——靠异常吃饭的卡组只能换直伤输出，别浪费行动去叠异常层数。
- **固伤是最优解**：[固定伤害](/powers/fixed_damage_power.md)不在异常列表里，神话怪照吃——固伤流打它没有任何折扣。
- **降维 debuff 照常生效**：力量/命中/速度/防御的直接降低不属于异常状态——削弱输出的手段依然可用（降它的攻击维度比硬叠异常靠谱得多）。
- **施加前拦截，没有窗口期**：与"挂上后每回合清除"的免疫不同（在异常进场前就把量归零）——**不存在先挂上异常再说的操作空间**，异常流别抱侥幸。
