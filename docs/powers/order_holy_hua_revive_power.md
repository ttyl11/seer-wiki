# 圣铸复活

> ℹ️ 此能力在游戏内不可见，无独立图标。
> **归属**：玩家可施加
> **施加来源**：玩家获得——[至序圣华](/relics/legendary/order_holy_hua.md)（遗物）

## 基本信息

- **类型**: 增益（Buff）
- **叠加方式**: 单例（不可叠加）
- **可见**: 否

## 描述

首次死亡时复活至<span style="color:#3aa675;font-weight:600">20</span>%生命。复活后立即失去此能力及圣铸计数能力。
