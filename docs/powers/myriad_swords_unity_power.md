# 万剑归一

> **归属**：玩家可施加
> **施加来源**：玩家获得——[万剑归一](/cards/character/myriad_swords_unity.md)（卡牌）

<img src="/images/powers/myriad_swords_unity_power.png" alt="万剑归一" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **类型**: 增益（Buff）
- **叠加方式**: 不叠加（单一）
- **可见**: 是

## 描述

在你的回合开始时，自动从你的消耗牌堆打出一张君王之剑。

## 关联

- 由卡牌**万剑归一**（`SeerMyriadSwordsUnity`）施加：获得 3 张免费的宝剑，之后每个回合开始时自动从消耗堆打出一张君王之剑（随机选取存活敌人作为目标）。
