# 万剑归一

<img src="/images/powers/myriad_swords_unity_power.png" alt="万剑归一" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **类型**: 增益（Buff）
- **叠加方式**: 不叠加（单一）
- **可见**: 是

## 描述

在你的回合开始时，自动从你的消耗牌堆打出一张宝剑。

## 关联

- 由卡牌**万剑归一**（`SeerMyriadSwordsUnity`）施加：获得若干张免费的宝剑，之后每个回合开始时自动从消耗牌堆打出一张宝剑。
