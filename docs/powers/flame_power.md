# 火苗

> **归属**：玩家可施加
> **施加来源**：玩家获得——[火种](/powers/spark_power.md)（能力联动）

## 基本信息

- **类型**: 增益（Buff）
- **叠加方式**: 叠加
- **可见**: 是

## 描述

回合结束时<span style="color:#3aa675;font-weight:600">10%</span>概率转化为<span style="color:#d4a017;font-weight:600">烈焰</span>，未转化的消失。转化时对所有敌人施加等量种<span style="color:#d44;font-weight:600">异常状态</span>。
