# 神羽

> **归属**：玩家可施加
> **施加来源**：玩家获得——[皮神](/relics/epic/pi_shen.md)（遗物）

<img src="/images/powers/divine_feather_power.png" alt="神羽" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **类型**: 增益（Buff）
- **叠加方式**: 计数器（按层数叠加）
- **可见**: 是

皮神（SeerPiShen）的核心能力，战斗开始时按神羽数量施加层数；每回合结束时若生命低于阈值，消耗1层将生命回复至一定比例。
