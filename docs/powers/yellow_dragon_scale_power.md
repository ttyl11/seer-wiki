# 黄色龙鳞

<img src="/images/powers/yellow_dragon_scale_power.png" alt="黄色龙鳞" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **类型**: 增益
- **来源**: [武心婵](/relics/legendary/wu_xin_chan.md)
- **叠加方式**: 不叠加（触发即消失）
- **可见**: 是

## 描述

免疫<span style="color:#d44;font-weight:600">异常状态</span>。触发免疫时消除对手基础属性提升，然后自身消失。

## 数值

| 参数 | 数值 |
|---|---|
| 免疫类型 | 异常状态 |
| 触发后效果 | 消除对手基础属性提升 |
| 基础属性范围 | 力量、敏捷、命中、防御、速度 |
| 持续 | 触发后消失 |

## 小贴士

- **异常免疫**：免疫所有异常状态（烧伤、中毒、冰封、流血、麻痹、睡眠、失明、害怕、沉默等）。
- **反击削属性**：触发免疫时消除对手力量、敏捷、命中、防御、速度的提升（正向部分归零）。
