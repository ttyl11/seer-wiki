# 闪光漩涡

> **归属**：怪物专属（玩家无法施加）
> **施加来源**：怪物施加给玩家——[史莱姆国王](/monsters/normal/slime_king_monster.md)、[史莱姆王子](/monsters/normal/slime_prince_monster.md)

## 基本信息

- **类型**: 减益（Debuff）
- **叠加方式**: 单例（不可叠加）
- **可见**: 是

## 描述

每回合结束时，若你的四个牌堆都有状态牌，战斗结束后向你的牌组加入一张粘液。
