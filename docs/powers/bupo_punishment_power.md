# 不破诛罚

> **归属**：玩家可施加
> **施加来源**：玩家获得——[不破帝·南霜](/relics/epic/bupo_emperor_nanshuang.md)（遗物）

## 基本信息

- **类型**: 增益
- **叠加方式**: 单例（不可叠加）
- **可见**: 是

### 数值参数

| 参数 | 数值 |
|---|---|
| 能量获取 | 1 |
| 抽牌数量 | 2 |
| 格挡数值 | 20 |

## 描述

免疫<span style="color:#d44;font-weight:600">debuff</span>。在你的回合开始时，获得<span style="color:#3aa675;font-weight:600">1</span><span style="color:#d4a017;font-weight:600">能量</span>，抽<span style="color:#3aa675;font-weight:600">2</span>张牌，所有生物获得<span style="color:#3aa675;font-weight:600">20</span><span style="color:#d4a017;font-weight:600">格挡</span>。在你的回合结束时移除。
