# 幻灵破碎

> **归属**：怪物专属（玩家无法施加）
> **施加来源**：怪物施加给玩家——[暴君史莱姆](/monsters/normal/tyrant_slime_monster.md)

## 基本信息

- **类型**: 减益（Debuff）
- **叠加方式**: 计数器（按层数叠加）
- **可见**: 是

## 描述

每当有状态牌进入你的消耗牌堆时，扣除1点最大生命。
