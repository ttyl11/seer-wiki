# 脂肪护盾

> **归属**：怪物专属（玩家无法施加）
> **施加来源**：怪物自带——[斗魔旺乔](/monsters/elite/dou_mo_wang_qiao_monster.md)

## 基本信息

- **类型**: 增益（Buff）
- **叠加方式**: 回合计数器（按层数叠加，每回合 -1）
- **可见**: 是

## 描述

自身每次受到攻击时，获得2层斗气。持续<span style="color:#3aa675;font-weight:600">层数</span>回合。
