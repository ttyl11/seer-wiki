# 不灭之血

> **归属**：怪物专属（玩家无法施加）
> **施加来源**：怪物自带——[泰勒斯](/monsters/normal/tailesi_monster.md)

## 基本信息

- **类型**: 增益（Buff）
- **叠加方式**: 计数器（按层数叠加）
- **可见**: 是

## 描述

首次致死时复活并显示无穷生命，复活回合强制使用泰勒斯猜想后自杀。
