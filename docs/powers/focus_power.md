# 集中

<img src="/images/powers/focus_power.png" alt="集中" style="max-width:120px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **类型**: 增益（Buff）
- **来源**: 原版能力

## 描述

提升充能球的效力。

## 详细机制

- **效果**：每层集中提升所有充能球的被动数值和激发数值
- **影响范围**：所有充能球（包括原版和 mod 充能球）
- **mod 充能球继承**：mod 充能球（如[森林](/orbs/forest_orb.md)）同样受集中影响
