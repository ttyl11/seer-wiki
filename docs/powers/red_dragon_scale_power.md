# 红色龙鳞

<img src="/images/powers/red_dragon_scale_power.png" alt="红色龙鳞" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **类型**: 增益
- **来源**: [武心婵](/relics/legendary/wu_xin_chan.md)
- **叠加方式**: 不叠加（触发即消失）
- **可见**: 是

## 描述

免疫攻击伤害与<span style="color:#d4a017;font-weight:600">固定伤害</span>。触发免疫时消除对手非基础属性提升的<span style="color:#d4a017;font-weight:600">buff</span>，然后自身消失。

## 数值

| 参数 | 数值 |
|---|---|
| 免疫类型 | 攻击伤害、固定伤害 |
| 触发后效果 | 消除对手非基础属性 buff |
| 持续 | 触发后消失 |

## 小贴士

- **双伤害免疫**：免疫攻击伤害与[固定伤害](/powers/fixed_damage_power.md)两类主要伤害来源。
- **反击扒 buff**：触发免疫时消除对手所有非基础属性提升的 buff（力量、敏捷、命中、防御、速度这类基础属性除外）。
