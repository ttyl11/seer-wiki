# 星璨舞台

<img src="/images/powers/star_stage_power.png" alt="星璨舞台" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **类型**: 增益（Buff）
- **叠加方式**: 计数（层数递减）
- **可见**: 是

## 描述

造成伤害提升<span style="color:#3aa675;font-weight:600">25</span>%。在你的回合结束时，恢复<span style="color:#3aa675;font-weight:600">3</span>张随机卡牌<span style="color:#3aa675;font-weight:600">1</span>点[PP](/mechanics/pp-system.md)并减少1层。

## 数值参数

| 参数 | 数值 |
|---|---|
| 伤害提升百分比 | 25 |
| 恢复卡牌数 | 3 |
| 每次恢复PP | 1 |

## 关联

- 由卡牌**欢梦芳逝**（`SeerPhantomDreamFade`）施加：下场战斗开启灵籁泳馆和星璨舞台若干回合。
