# 神灵之触

> ℹ️ 此能力在游戏内不可见，无独立图标。

## 基本信息

- **类型**: 增益（Buff）
- **叠加方式**: 单次（不叠加）
- **可见**: 否

## 描述

每打出一张攻击牌，[神灵之触](/cards/ancient/divine_touch.md)卡牌自动从任意地方（手牌、抽牌堆、弃牌堆、消耗堆）打出。神灵之触自身被打出时不重复触发。

## 详细机制

- **触发条件**：每打出一张牌时，当满足以下所有条件时触发：
  1. 拥有者存活
  2. 是拥有者打出的牌
  3. 是攻击牌
  4. 不是神灵之触自身（防递归）
- **查找神灵之触**：从所有战斗牌堆（手牌、抽牌堆、弃牌堆、消耗堆、打出堆）中查找神灵之触卡牌。
- **自动打出**：遍历找到的神灵之触卡牌：
  1. 若拥有者死亡则停止
  2. 若神灵之触 PP ≤ 0 则跳过（只要它有 PP 才自动打出）
  3. 自动打出，走标准流程，保证多人同步
- **无视限制**：神灵之触的自动打出只要 PP > 0 就允许，无视[懒惰](/powers/sloth_power.md)、[魂缚锁链](/powers/chains_of_binding_power.md)、[烟雾弥漫](/powers/smoggy_power.md)等能力的限制。
