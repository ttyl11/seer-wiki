# 龙威

> **归属**：怪物专属（玩家无法施加）
> **施加来源**：怪物自带——[哈莫雷特](/monsters/elite/hamlet_monster.md)

<img src="/images/powers/dragon_majesty_power.png" alt="龙威" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **类型**: 无类型（不参与增益/减益分类，不可被驱散/净化）
- **叠加方式**: 单例（不可叠加）
- **可见**: 是

## 描述

战斗开始时，自身获得等量于敌人牌组中「龙」牌数量的全属性加成。你打出的牌与上一张类型不同时，会重放一次；类型相同时此牌无效。
