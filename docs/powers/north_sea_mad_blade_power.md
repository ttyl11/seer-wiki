# 北冥狂刃

赛尔增益能力。[北冥之刃](/powers/north_sea_blade_power.md)的升级形态。自身所有攻击必定[暴击](/powers/critical_strike_power.md)，暴击伤害按 `CritDamageBoost` 百分比提升，且暴击后附加等量[固定伤害](/powers/fixed_damage_power.md)。
