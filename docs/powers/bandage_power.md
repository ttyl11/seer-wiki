# 自由之魂

> **归属**：怪物专属（玩家无法施加）
> **施加来源**：怪物自带——[哈耶克](/monsters/elite/hayek_monster.md)

<img src="/images/powers/bandage_power.png" alt="自由之魂" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **类型**: 无类型（不参与增益/减益分类，不可被驱散/净化）
- **叠加方式**: 递减
- **可见**: 是

## 描述

在其回合开始时消耗1层绷带，使你随机一张手牌获得绷带缠绕。绷带缠绕：耗能+1，打出后消失。
