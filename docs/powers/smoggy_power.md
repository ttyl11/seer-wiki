# 烟雾弥漫

<img src="/images/powers/smoggy_power.png" alt="烟雾弥漫" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **类型**: 减益（Debuff）
- **叠加方式**: 单例（不叠加）
- **可见**: 是
- **允许负值**: 否

## 描述

每回合你只能打出<span style="color:#3aa675;font-weight:600">1</span>张技能牌。

## 详细机制

- **技能牌限制**：若卡牌拥有者是持有者的玩家且卡牌带有烟雾污痕，则不能打出。
  - 即每回合只能打出 <span style="color:#3aa675;font-weight:600">1</span> 张技能牌（第一张打出的技能牌会赋予其他所有技能牌烟雾污痕）。
- **打出后施加烟雾**：打出的卡牌若是持有者的技能牌，对所有其他技能牌施加烟雾污痕。
- **新进入战斗的卡牌**：若本回合已打出过技能牌，对新进入战斗的技能牌也施加烟雾污痕。
- **回合结束清除**：拥有者一方回合结束时，清除持有者所有卡牌上的烟雾污痕。
- **仅限技能牌**：只影响技能牌，不影响攻击牌、能力牌等。
