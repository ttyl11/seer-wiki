# 二律背反

> **归属**：玩家可施加
> **施加来源**：玩家获得——[二律背反](/cards/character/antinomy.md)（卡牌）

## 基本信息

- **类型**: 增益（Buff）
- **叠加方式**: 单例（不可叠加）
- **可见**: 是

## 描述

下一次对手的攻击不是暴击则免疫之。

## 详细机制

- **免疫条件**：
  - 目标必须是自身
  - 伤害来源必须来自对方（敌方攻击）
  - 伤害来源**没有暴击**（无暴击能力，或本次攻击未暴击）
  - 满足以上条件时，伤害完全无效化
- **暴击穿透**：暴击伤害不受二律背反影响，照常生效。
- **被攻击后消失**：当本方受到对方攻击且拥有者是被命中目标之一时，移除自身。即无论是否暴击，被攻击一次后该能力即消失。
- **视觉效果**：能力生效时会闪烁提示。
- **无层数设计**：无层数，效果只看"有无"。
