# 空元·镀

<img src="/images/powers/void_plating_power.png" alt="空元·镀" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

赛尔增益能力（计数型）。持有期间，自身下 N 次受到的[异常状态](/mechanics/abnormal-status.md)被免疫（N = 层数），每成功免疫一次层数减 <span style="color:#3aa675;font-weight:600">1</span>，归零后自动移除。
