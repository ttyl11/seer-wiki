# 播种

<img src="/images/enchantments/sown.png" alt="播种" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **类型**: 原版附魔
- **可附魔牌类型**: 攻击 / 技能 / 能力
- **显示数量**: 否
- **来源**: 原版

### 数值参数

| 参数 | 数值 |
|---|---|
| 获得能量 | 由附魔等级决定 |

## 描述

你在每场战斗中第一次打出这张牌时，获得若干点[<span style="color:#d4a017;font-weight:600">能量</span>](/mechanics/energy.md)。

## 详细机制

- **首次打出回能**：每场战斗第一次打出此牌时，获得等同于附魔等级的能量，随后本场战斗不再触发。
- **每场战斗重置**：状态在每个战斗开始时重置，因此每场战斗均可触发一次。

## 小贴士

- **每场战斗首打回能**：播种每场战斗首次打出回 Amount 能量，相当于"打出此牌不耗能还+能量"，是稳定的能量来源。
- **适合0费牌**：附在 0 费牌上首打回 Amount 能量净赚能量，是开局爆发的关键附魔。
