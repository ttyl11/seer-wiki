# 册

<img src="/images/enchantments/seer_five_tone_book.png" alt="册" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **类型**: 五音附魔
- **可附魔牌类型**: 攻击 / 技能 / 能力
- **显示数量**: 否

## 描述

打出后，减少对手 <span style="color:#3aa675;font-weight:600">10%</span> 当前生命，自身恢复等量生命。

## 详细机制

- **打出时触发**：当被附魔的卡牌打出时，先确定目标对手，再造成伤害并恢复等量生命。
- **目标选择**：
  - 优先使用牌的目标
  - 若目标为空、与自身同阵营或已死亡，则从可命中且未死亡的敌人中随机选一个
- **伤害计算**：目标当前生命的 <span style="color:#3aa675;font-weight:600">10%</span>（向下取整）
- **造成伤害**：造成非攻击伤害，不受增伤/易伤影响
- **恢复生命**：恢复等同于实际造成伤害的生命值

## 小贴士

- **百分比伤害+吸血**：册对目标造成 10% 当前生命的非攻击伤害并恢复等量生命，是少有的百分比伤害+吸血组合附魔。
- **高血敌人收益最大**：10% 当前生命对高血敌人伤害更高（100 血→10 伤，200 血→20 伤），适合附在群攻牌上对多个高血敌人同时削血。
