# 蛇行

<img src="/images/enchantments/slither.png" alt="蛇行" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **类型**: 原版附魔
- **可附魔牌类型**: 非不可打出、非 X 耗能的牌
- **显示数量**: 否
- **来源**: 原版

### 数值参数

| 参数 | 数值 |
|---|---|
| 耗能随机范围 | 0 ~ 3 |

## 描述

当你抽到这张牌时，使其费用在<span style="color:#3aa675;font-weight:600">0</span>到<span style="color:#3aa675;font-weight:600">3</span>之间随机变化。

## 详细机制

- **抽牌时随机耗能**：抽到此牌且其位于手牌时，本场战斗内将其耗能设为 0~3 的随机值。
- **附魔限制**：不可附魔于不可打出或 X 耗能的牌。

## 小贴士

- **25%概率0费**：蛇行 0~3 随机，0 费概率 25%，适合附在高费牌上博 0 费收益，3 费时可能反亏。
- **每次抽到都重抽**：每次抽到此牌都重新随机耗能，多次抽到可能多次降价，配合抽牌效果可多次触发。
