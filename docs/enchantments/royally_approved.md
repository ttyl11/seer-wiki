# 王室认证

<img src="/images/enchantments/royally_approved.png" alt="王室认证" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **类型**: 原版附魔
- **可附魔牌类型**: 技能 / 能力
- **显示数量**: 否
- **来源**: 原版

### 数值参数

无

## 描述

这张牌拥有[<span style="color:#d4a017;font-weight:600">固有</span>](/mechanics/innate.md)和[<span style="color:#d4a017;font-weight:600">保留</span>](/mechanics/retain.md)。

## 详细机制

- **获得关键词**：附魔时为卡牌添加固有和保留关键词。
- **附魔限制**：仅可附魔于技能牌或能力牌。

## 小贴士

- **双关键词最强稳定性**：王室认证同时提供固有+保留，固有保证首回合抽到、保留保证不弃——是稳定性最高的附魔。
- **适合关键能力牌**：附在关键能力牌（如增益能力）上，首回合必抽到、不打则保留到下回合，保证关键牌不卡手。

- [保留](/mechanics/retain.md)：附魔后获得保留
