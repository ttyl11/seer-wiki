# 沉眠精华

<img src="/images/enchantments/slumbering_essence.png" alt="沉眠精华" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **类型**: 原版附魔
- **可附魔牌类型**: 攻击 / 技能 / 能力
- **显示数量**: 否
- **来源**: 原版

### 数值参数

| 参数 | 数值 |
|---|---|
| 耗能降低 | -1（直到打出） |

## 描述

回合结束时，如果这张牌在你的手牌中，则将其费用降低<span style="color:#3aa675;font-weight:600">1</span>点，直到其被打出。

## 详细机制

- **回合结束减耗能**：回合结束结算时，若此牌仍在手牌中，则其耗能 -1，该减免持续到此牌被打出为止。
- **多次叠加**：每回合结束只要仍在手牌就会再次 -1，可逐回合累积降低。

## 小贴士

- **留牌减费累积**：沉眠精华让留手的牌每回合 -1 费，配合[保留](/mechanics/retain.md)关键词可无限累积减费，几回合后可降到 0 费。
- **适合高费能力牌**：附在高费能力牌上，留几回合后降到 0 费再打出，是高费牌的减费手段。
