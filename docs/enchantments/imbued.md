# 注能

<img src="/images/enchantments/imbued.png" alt="注能" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **类型**: 原版附魔（mod 重写）
- **可附魔牌类型**: 攻击 / 技能 / 能力（mod 扩展；原版仅技能）
- **显示数量**: 否
- **抽牌堆底部起始**: 是
- **来源**: 原版

### 数值参数

无

## 描述

这张牌在每场战斗开始时自动打出。

## 详细机制

- **抽牌堆底部**：被附魔的卡牌在战斗开始时放置于抽牌堆底部，而非随机洗入。
- **第 1 回合自动打出**：当所属玩家进入自动预打出阶段且当前为第 1 回合时，自动打出此牌。
- **附魔限制**：mod 重写版可附魔于攻击 / 技能 / 能力牌（原版 `Imbued` 仅限技能牌，mod 扩展为 CardType 1-3）。

## 小贴士

- **免费首回合触发**：第 1 回合自动打出，不消耗[能量](/mechanics/energy.md)、不占用手牌——适合附在开场增益牌或防御牌上，开场即生效。
- **注意目标型牌**：自动打出时无法手动选目标——需要选敌的牌会从可命中敌人中**随机**选一个结算，附在关键单体牌上时需留意目标不可控。
