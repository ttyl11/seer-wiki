# 特兹卡塔拉的余烬

<img src="/images/enchantments/tezcataras_ember.png" alt="特兹卡塔拉的余烬" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **类型**: 原版附魔
- **可附魔牌类型**: 攻击 / 技能 / 能力
- **显示数量**: 否
- **来源**: 原版

### 数值参数

| 参数 | 数值 |
|---|---|
| Damage（额外伤害） | 3 |
| 耗能 | 0 |

## 描述

费用为<span style="color:#3aa675;font-weight:600">0</span>，造成若干点额外伤害，且获得[<span style="color:#d4a017;font-weight:600">永恒</span>](/mechanics/eternal.md)。

## 详细机制

- **耗能归零**：附魔时将卡牌耗能降至 0。
- **获得永恒**：附魔时为卡牌添加永恒关键词。
- **额外伤害**：对已充能攻击（powered attack）额外造成 3 点伤害；非充能攻击不生效。

## 小贴士

- **0费+永恒+3伤**：特兹卡塔拉的余烬是综合型附魔——0 费让卡牌免费打、永恒让卡牌每次洗入抽牌堆都保留、+3 伤提升输出，三效合一。
- **适合高伤攻击**：附在高伤攻击上，0 费免费打+永恒反复用+3 伤加成，是攻击牌的强力附魔。
