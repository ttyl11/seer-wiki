## 描述

这张牌能在[<span style="color:#d4a017;font-weight:600">休息处</span>](#)被复制。

## 详细机制

- **被动标记**：该附魔本身不触发任何效果，仅作为标记，供休息处的复制选项查找可复制的卡牌时引用。

## 小贴士

- **休息处复制**：克隆的唯一作用是让卡牌在休息处可被复制（克隆选项查找带此附魔的牌），是跨战斗强化卡组的手段。
- **附魔本身无战斗效果**：克隆在战斗中不触发任何效果，纯粹是休息处复制标记——附在关键卡牌上让休息处可复制强化。
