# ♊ 双极药水

## 基本信息

- **分类**: 属性与火焰
- **稀有度**: 普通
- **使用时机**: 战斗内
- **目标**: 自身

## 描述

使自身的[全属性](/mechanics/all_attributes.md)翻倍。

## 详细机制

- **翻倍范围**：对自身的[力量](/powers/strength_power.md)、[速度](/powers/speed_power.md)、[命中](/powers/accuracy_power.md)、[防御](/powers/defense_power.md)四项属性分别翻倍——只翻倍**正值**属性，负值属性不变。
- **翻倍方式**：读取当前正值属性，再施加等量正值实现翻倍。例如力量 3 → 再 +3 = 6。
- **不改变负值**：若某属性为负（如力量 -2），不触发翻倍，保持 -2。
- **一次性结算**：使用时立即结算，不施加持续 Power。
- **悬浮提示**：附带力量/速度/命中/防御 4 个能力提示。

## 小贴士

- **爆发倍增器**：先叠加正值属性（如[绿火](green_fire_potion.md)）再喝双极，翻倍收益最大化；力量 5 → 10 的瞬间爆发可秒杀敌人。
- **只翻正值**：负属性不受影响，无法用来「翻倍负值再转正」，配合[乾坤](reverse_potion.md)应先转正再翻倍。
