# 🔥 焚天药水

## 基本信息

- **分类**: 异常状态
- **稀有度**: 罕见
- **使用时机**: 战斗内
- **目标**: 全体敌人

### 数值参数

| 参数 | 数值 |
|---|---|
| 烧伤层数 | 99 |

## 描述

对所有敌人施加<span style="color:#3aa675;font-weight:600">99</span>层[烧伤](/powers/burn_power.md)。

## 详细机制

- **目标范围**：对所有敌人逐一施加，无需选目标。
- **施加效果**：对每个敌人施加 99 层[烧伤](/powers/burn_power.md)。
- **烧伤机制**：烧伤是 25 种[异常状态](/mechanics/abnormal-status.md)之一，每回合开始时受到 3 点不可格挡伤害并降 1 点攻击伤害，然后层数 -1。层数越多持续越久（99 层 = 99 回合的持续伤害）。
- **99 层≈秒杀**：99 层烧伤每回合固定 3 点伤害，累计总伤极高，多数非 Boss 敌人会在数回合内死亡。
- **悬浮提示**：附带[烧伤](/powers/burn_power.md)能力提示。

## 小贴士

- **群体清场核弹**：99 层烧伤对全体敌人施加，多敌人场景一轮清场，是罕见药水中的强力输出。
- **Boss 战也有效**：99 层烧伤即使对 Boss 也能造成可观伤害，但 Boss 可能有异常状态免疫/清除机制。
