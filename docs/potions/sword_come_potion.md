# ⚔️ 剑来药水

## 基本信息

- **分类**: 资源与召唤
- **稀有度**: 普通
- **使用时机**: 战斗内
- **目标**: 自身

### 数值参数

| 参数 | 数值 |
|---|---|
| 铸造伤害加值 | 20 |

## 描述

[铸造](/mechanics/forge.md)<span style="color:#3aa675;font-weight:600">20</span>，并将所有铸造的剑刃升级。

## 详细机制

- **铸造的本质**：[铸造](/mechanics/forge.md) N = 为你**所有的君王之剑伤害 +N**（包括手牌/弃牌堆/抽牌堆甚至消耗堆里的每一张），不是生成 N 把剑。
- **无剑先生成**：若当前没有任何君王之剑，先自动生成 1 张加入手牌，再执行 +20 伤害。
- **全部升级**：铸造后，将所有**未消耗**且未升级的君王之剑升级——包括使用药水前就已经在手的旧剑刃，不只是本次生成的。
- **升级收益放大**：君王之剑的伤害会随铸造累积，这张药水相当于"群体升级 + 全剑 +20 伤害"的双重强化。
- **悬浮提示**：附带铸造提示。

## 小贴士

- **铸造流的核心爆发**：+20 伤害作用于所有君王之剑，手里剑越多收益越高；先靠卡牌攒出多把君王之剑再用，一次 +20×剑数。
- **白嫖群体升级**：升级判定覆盖所有未消耗的君王之剑——配合能复制/保留剑刃的卡牌，等于全场剑刃集体升级。
- **对比王之勇气**：原版王之勇气只铸造不加升级，剑来药水多了群体升级，爆发上限更高。
