# 🤝 借势药水

## 基本信息

- **分类**: 资源与召唤
- **稀有度**: 稀有
- **使用时机**: 战斗内
- **目标**: 自身

### 数值参数

| 参数 | 数值 |
|---|---|
| 选牌次数 | 3 |
| 每次候选数 | 3 |

## 风味文字

<span style="color:#d44;font-weight:600">借他人之力，化为己用。</span>

## 描述

从 5 个角色牌池中，每次选择<span style="color:#3aa675;font-weight:600">3</span>张中选 1 张，共选择<span style="color:#3aa675;font-weight:600">3</span>张牌加入你的[手牌](/mechanics/hand.md)。

## 详细机制

- **5 角色牌池**：从原版 5 个角色牌池中抽取候选牌——铁甲战士、静默猎手、故障机器人、亡灵契约师、储君。
- **选牌流程**：从 5 个牌池的并集中生成 3 张互不重复的候选牌，弹出选牌界面，玩家选 1 张加入手牌。
- **重复 3 次**：上述流程重复 3 次，共选 3 张牌入手牌；每轮候选重新随机生成。
- **RNG 同步**：候选牌生成使用 CombatCardGeneration Rng，多人两端一致。
- **加入手牌底部**：选中的牌加入手牌底部（最后位置），已有手牌的出牌顺序不受影响。
## 小贴士

- **跨角色选牌**：可拿到原版 5 个角色的强力卡（跨体系补强），任何角色都能用，是稀有药水中的资源神器。
- **3 张即时上手**：选出的牌直接入手牌（非抽牌堆），当回合即可使用，适合关键回合补输出/防御。
