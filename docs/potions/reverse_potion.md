# 🔄 乾坤药水

## 基本信息

- **分类**: 属性与火焰
- **稀有度**: 普通
- **使用时机**: 战斗内
- **目标**: 自身

## 描述

若自身的[全属性](/mechanics/all_attributes.md)为负，将其变为等量正值。若对手的全属性为正，将其变为等量负值。

## 详细机制

- **自身负转正**：遍历自身的[力量](/powers/strength_power.md)、[速度](/powers/speed_power.md)、[命中](/powers/accuracy_power.md)、[防御](/powers/defense_power.md)，若某属性为负值，施加两倍绝对值的正值——即先抵消负值再叠加等量正值，最终结果为绝对值。
- **敌方正转负**：对所有敌人，对其正属性施加两倍绝对值的负值，最终结果为负绝对值。
- **双向同时生效**：自身负转正 + 敌方正转负在一次使用中同时结算。
- **不影响零值**：属性为 0 时不触发任何变化。
- **悬浮提示**：附带速度/命中/防御/力量 4 个能力提示。

## 小贴士

- **逆转劣势神器**：被敌人堆叠负属性时，乾坤瞬间把 -3 力量变成 +3，同时把敌人的 +3 力量变成 -3，攻守逆转 6 点差距。
- **配合双极**：先用乾坤把自身负属性转正，再用[双极](twin_potion.md)翻倍，最大化收益。
