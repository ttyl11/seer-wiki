# 小彩蛋

Seer Mod 的开发彩蛋与趣味内容。

## 命名彩蛋

### 赛尔号致敬

- Seer Mod 致敬赛尔号（Seer）系列
- 元素属性系统完全沿用赛尔号 26 种属性
- 异常状态系统参考赛尔号的异常状态机制

## 开发趣闻

### 固定伤害能力规则

- mod 中 53+ 处 "固定伤害" 调用都通过施加固定伤害能力实现
- 全代码库无任何一处正确的直接造成固定伤害
- 这是 mod 开发一年的核心约束之一

### 怪物动画处理

- 怪物动画 6 步流程
- 允许使用 offset 进行怪物动画处理，无需强制对称和高度对齐
- 需将 attack 第 0 帧脚底位置对齐到原点 (0,0)，其他帧使用偏移
