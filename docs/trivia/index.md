# 小知识

Seer Mod 的隐藏机制、冷知识、开发趣闻。

## 凝滞是增益不是减益

- 凝滞是增益类型，但列入异常状态列表
- 这意味着凝滞不会被 "消除减益" 类效果清除

## PP 自动循环

- 部分遗物机制会让消耗堆中的 PP 卡牌在己方回合开始前移回弃牌堆
- 形成"休息-再战"循环，让卡牌可以重复使用

## 固定伤害是能力不是伤害类型

- mod 中 "固定伤害" 通过施加固定伤害能力（减益类型）实现
- 目标下回合开始时自动受到伤害
- 走完整能力系统（免疫/反弹/血条预测）
- 绝对不直接造成直接伤害

## 无为觉者

- 拥有「无为觉者」遗物时，PP=0 的卡牌仍可打出
- 这让 PP 耗尽的卡牌不会完全废掉

## 怪物开局被动能力必须是不可消除类型

- 所有怪物开局自带的被动能力，必须设置为不可消除类型
- 若设为增益/减益类型，会被 "消除增益/减益" 类效果误清导致 bug

## 遗物绝对不能出现悬浮框

- 遗物出现悬浮框会导致程序卡死
- 相关代码必须移除
