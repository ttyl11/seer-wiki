# 混沌化身

混沌化身是 Seer Mod 独有的能量替代机制。持有此能力时，能量不足仍可打出卡牌，差额由最大生命值抵扣。

::: tip Mod 扩展了什么
- 原版能量不足时无法打出卡牌，混沌化身打破这一限制
- 差额用最大生命值抵扣，而非当前生命值——直接降低生命上限
- 有最低保护：不会因抵扣而将最大生命值降到 0
:::

---

## 基本信息

| 属性 | 值 |
| --- | --- |
| 能力类型 | Power（不属于 Buff/Debuff，不会被清除） |
| 触发条件 | 能量不足时打出卡牌 |
| 抵扣方式 | 扣除最大生命值 |
| 抵扣比例 | 1 点能量 = 1 点最大生命值 |
| 最低保护 | 最大生命值不会低于 1 |

---

## 触发规则

### 能量不足判定

- 原版打出卡牌时会检查能量是否足够，不足则拒绝打出
- 混沌化身拦截此检查：当能量不足时，仍允许打出卡牌
- **不限制能量必须为 0**：支持任意能量不足情况（如 1 能量打 3 费牌）

### 费用计算

打出卡牌时，混沌化身会记录：
1. **打出前能量**：卡牌打出前的当前能量值
2. **卡牌最终费用**：经过所有费用修改后的最终费用（如耗能翻倍、减费等）

### 抵扣计算

- **超额部分** = 卡牌最终费用 - 打出前能量
- **实际扣除** = min(超额部分, 最大生命值 - 1)
- 通过扣除最大生命值来抵扣超额部分

::: tip 费用修改的兼容性
混沌化身在打出前会通过钩子链计算含修改的最终费用。如果卡牌费用被翻倍（如某些能力效果），抵扣也会按翻倍后的费用计算。
:::

## 原版能量扣除流程

理解混沌化身需要了解原版的能量扣除流程：

1. 玩家打出卡牌时，原版扣除能量
2. 原版实际只扣除"费用"和"当前能量"中的较小值——能量归零，不会变成负数
3. 超额部分（费用 > 当前能量）在原版会导致无法打出
4. 混沌化身允许打出后，超额部分在卡牌打出后用最大生命值抵扣

## 战略意义

### 高费卡牌提前打出

- 混沌化身让你在能量不足时仍能打出高费卡牌
- 适合在关键时刻打出决定性卡牌（如斩杀牌、清场牌）
- 代价是降低最大生命值，需要权衡生存能力

### 最大生命值管理的风险

- 抵扣的是最大生命值，不是当前生命值
- 最大生命值降低后，当前生命值不会立即变化，但上限降低了
- 如果当前生命值高于新的最大生命值，会被截断
- 多次使用会持续降低生存能力

### 最低保护

- 最大生命值不会因抵扣而降到 0
- 最低保留 1 点最大生命值
- 但 1 点最大生命值意味着极度脆弱，需要谨慎使用

## 与其它系统的关联

### 与能量系统的关系

混沌化身是对原版能量系统的扩展，不替代能量系统：
- 有能量时正常消耗能量
- 能量不足时才触发最大生命值抵扣
- 两者互补，不冲突

### 与 PP 系统的关系

[PP 系统](./pp-system)是赛尔卡的次级资源，独立于能量。混沌化身只影响能量不足的情况，不影响 PP 消耗：
- 打出 PP 卡牌时，PP 照常消耗
- 能量不足时，差额用最大生命值抵扣
- PP 和最大生命值抵扣互不干扰
