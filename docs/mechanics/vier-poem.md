# 薇尔诗

薇尔诗是 Seer Mod 的自定义卡牌关键词，根据打出牌在手牌中的位置关系，为本场战斗提供三种不同的免疫效果。它是一个基于手牌位置的位置型防御机制。

::: tip Mod 扩展了什么
- 原版没有"手牌位置触发"型关键词，薇尔诗是 Mod 独创的位置型免疫机制
- 三种位置关系（相邻/隔位/首末位）对应三种不同免疫，覆盖全属性下降、异常状态、固定伤害
- 免疫效果持续整场战斗，每种免疫只施加一次
:::

## 三种位置关系与免疫

薇尔诗的触发基于**打出牌与薇尔诗牌在手牌中的位置关系**。位置判定使用打出前的手牌快照，避免打出过程中手牌变化导致位置错乱。

### ①相邻 → 免疫全属性下降

- **触发条件**：打出牌与薇尔诗牌在手牌中相邻（距离 = 1）
- **免疫效果**：本场战斗免疫全属性下降
- **覆盖范围**：力量、防御、命中、速度等所有属性的降低效果

### ②隔位 → 免疫异常状态

- **触发条件**：打出牌与薇尔诗牌在手牌中隔一位（距离 = 2）
- **免疫效果**：本场战斗免疫异常状态
- **覆盖范围**：所有 25 种 Mod 异常状态（衰弱、沉默、狂暴、中毒等）

### ③首末位 → 免疫固定伤害

- **触发条件**：打出牌位于手牌首位或末位（与薇尔诗牌位置无关，只要手牌中有薇尔诗牌即可）
- **免疫效果**：本场战斗免疫固定伤害
- **覆盖范围**：所有固定伤害（延迟到下回合结算的 Debuff 伤害）

::: warning 首末位的特殊性
首末位判定**不需要**打出牌与薇尔诗牌相邻或隔位。只要手牌中存在薇尔诗牌，打出首末位的任何牌都能触发免疫固定伤害。这是最容易触发的条件。
:::

## 免疫施加规则

### 唯一性

每种免疫能力只施加一次：
- 若已有"免疫全属性下降"能力，再次触发相邻条件不会重复施加
- 若已有"免疫异常状态"能力，再次触发隔位条件不会重复施加
- 若已有"免疫固定伤害"能力，再次触发首末位条件不会重复施加

### 持续时间

- 所有免疫效果持续到**本场战斗结束**
- 战斗结束后免疫清除，下场战斗需要重新触发

### 手牌快照

位置判定使用打出前的手牌快照：
- 快照在卡牌打出流程的最开始（打出包装器执行之前）抓取
- 快照记录此时手牌中所有卡牌的顺序和位置
- 即使打出过程中手牌发生变化（如抽牌、弃牌），仍按快照位置判定

::: tip 为什么需要手牌快照
卡牌打出时，它会从手牌中移除。如果不用快照，打出后手牌位置会变化，薇尔诗牌的位置也会偏移，导致判定错误。手牌快照确保位置判定基于打出前的真实手牌状态。
:::

## 薇尔诗牌的分配

薇尔诗关键词不是卡牌固有的，而是通过"薇尔诗"遗物动态分配的：

### 效果一：拾起赋薇

- 获得遗物时，随机为牌组中 4 张卡牌附加"薇"关键词（非"薇尔诗"）
- "薇"关键词让相邻的非"薇"卡牌自动打出

### 效果二：一次复活

- 死亡时复活一次，复活时击晕所有对手

### 效果三：首回合中间牌赋薇尔诗

- 每场战斗第 1 回合抽牌后，将手牌中间位置的卡牌附加"薇尔诗"关键词
- 手牌数为奇数时取正中位置
- 手牌数为偶数时取中间左右两张中随机一张

::: tip 薇尔诗牌的位置
薇尔诗牌每场战斗固定分配到手牌中间位置。这意味着：
- 中间位置往左/右相邻的牌触发"免疫全属性下降"
- 中间位置往左/右隔一位的牌触发"免疫异常状态"
- 手牌最左和最右的牌触发"免疫固定伤害"
:::

## 战略要点

### 三种免疫的覆盖

薇尔诗一场战斗最多获得三种免疫：
- **免疫全属性下降**：克制降属性型敌人
- **免疫异常状态**：克制异常状态型敌人（25 种异常全免）
- **免疫固定伤害**：克制固定伤害型敌人

三种免疫一旦全部触发，防御面极为全面。

### 出牌顺序规划

由于位置判定基于手牌快照，出牌顺序决定了能触发哪些免疫：
- 想触发"免疫全属性下降"→ 在薇尔诗牌旁边出牌
- 想触发"免疫异常状态"→ 在薇尔诗牌隔一位出牌
- 想触发"免疫固定伤害"→ 先出首末位的牌

### 与"薇"关键词的配合

薇尔诗遗物同时分配"薇"关键词，"薇"让相邻牌自动打出。自动打出的牌同样会触发薇尔诗的位置判定——可以用来免费触发免疫效果。
