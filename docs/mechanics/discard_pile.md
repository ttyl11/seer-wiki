# 弃牌堆

> 原版状态

## 基本信息

- **类型**: 状态（非能力，不占用 Power 槽位）

## 描述

如果你的抽牌堆为空，则弃牌堆会被洗入抽牌堆。

## 详细机制

- **不是 Power**：弃牌堆是战斗中的牌堆之一，不占用 Power 槽位。
- **弃牌来源**：打出的卡牌、回合结束时弃掉的手牌、被其他效果弃掉的卡牌都会进入弃牌堆。
- **洗牌触发**：当抽牌堆为空且需要抽牌时，弃牌堆中的所有卡牌会被洗入抽牌堆。
- **查看方式**：点击弃牌堆图标可查看其中的卡牌。
- **与消耗牌堆的区别**：
  - 弃牌堆中的卡牌在抽牌堆空时会洗回抽牌堆，可再次使用
  - 消耗牌堆中的卡牌不会洗回，战斗结束前无法再次使用
