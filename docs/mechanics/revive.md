# 复活机制

至序圣华遗物的复活效果在死亡检查的最后阶段执行，确保复活逻辑优先于其他死亡处理。

## 复活流程

### 首次死亡

1. 检查是否已复活过（未复活则允许复活）
2. 回复到最大生命值的 20%
3. 标记为本局已复活
4. 永久失去圣铸与复活能力

### 复活后变化

复活后，至序圣华的效果改为：

- **失去**：圣铸能力、复活能力
- **获得**：每场战斗开始时消耗所有攻击牌并清空其 PP，每清空 1 点 PP 铸造 1
