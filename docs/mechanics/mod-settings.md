# Mod 配置系统

Seer Mod 提供了 **9 项配置**，允许玩家自定义游戏体验。配置分为两类：**跑局内同步配置**（影响游戏逻辑，多人游戏中由主机同步给所有客机）和**纯客户端配置**（仅影响本地渲染/UI，不同步）。

::: tip 配置入口
配置保存在 `user://mod_configs/seer.cfg` 文件中，可通过 Mod 设置界面修改。修改后需开新局才生效（同步配置在大厅阶段由主机发布）。
:::

---

## 跑局内同步配置（7 项）

这些配置影响游戏逻辑和多人同步状态，在多人游戏中**以主机配置为准**，跑局开始时同步给所有客机。

| 配置项 | 默认值 | 说明 |
|---|---|---|
| 怪物能力概率倍率 | 1.0 | 怪物拥有特殊能力的概率倍率。0 = 关闭怪物能力 |
| 赛尔牌出现概率 | 45% | 其他角色卡池中出现赛尔牌的概率（0-100%） |
| 商店遗物加价 | 50 | 商店中赛尔遗物价格增加值（-100 ~ 100） |
| 怪物比例调整 | 关闭 | 是否启用原版/赛尔怪物出现比例调整 |
| 怪物赛尔占比 | 50% | 怪物中赛尔（mod）占比目标（0-70%，仅启用时生效） |
| 事件比例调整 | 关闭 | 是否启用原版/赛尔事件出现比例调整 |
| 事件赛尔占比 | 50% | 事件中赛尔（mod）占比目标（0-70%，仅启用时生效） |

### 怪物/事件比例调整

比例调整用于控制原版内容与 Mod 内容的出现频率。关闭时按各自数量自然比例分配（原版行为）；开启后可指定 Mod 内容的占比目标。

::: warning 占比上限
怪物和事件的赛尔占比最高为 **70%**，无法设为 100%。这确保原版内容仍有出现机会，避免 Mod 内容完全淹没原版体验。
:::

**确定性算法**：比例调整使用确定性哈希（基于章节 ID 和元素 ID 排序、均匀插入），**不消耗任何运行时随机数**。这保证了多端一致性——主机和客机即使在不同步随机种子的情况下，也能得出完全相同的过滤结果。

## 纯客户端配置（2 项）

这些配置仅影响本地渲染或 UI 显示，不影响游戏逻辑，**无需多人同步**，每位玩家可独立设置。

| 配置项 | 默认值 | 说明 |
|---|---|---|
| FTUE 弹窗 | 关闭 | 是否显示 Mod 介绍弹窗。默认关闭，避免老玩家每局被弹窗打扰 |
| 怪物动画 | 开启 | 是否启用 Mod 怪物的非待机动画。关闭后只保留待机第一帧，适合低端设备 |

::: tip 性能优化
如果在低端设备上遇到卡顿，可尝试关闭"怪物动画"。关闭后 Mod 怪物将只显示待机状态的静态帧，减少动画渲染开销，但不影响任何游戏逻辑和战斗效果。
:::

---

::: details 多人同步机制详解
在多人游戏中，同步配置的传递流程如下：

1. **大厅阶段**：主机（或单人模式）的本地配置通过大厅暂存机制写入
2. **开始跑局**：配置随开始消息一同发送给所有客机
3. **跑局内**：所有玩家读取主机同步的配置值，而非各自本地配置

::: warning 客机限制
客机玩家在多人游戏中**无法修改跑局内同步配置**——即使客机修改了本地配置文件，跑局内仍使用主机同步的值。客机的配置仅在单人模式或自己作为主机时生效。
:::
:::
