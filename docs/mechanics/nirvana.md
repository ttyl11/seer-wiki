# 寂灭

> mod 关键词

## 基本信息

- **类型**: mod 卡牌关键词
- **来源**: mod 自定义关键词

## 描述

打出时，本场战斗结束后从你的牌组中移除此牌。

## 详细机制

- **触发时机**：在卡牌打出时记录（不依赖打牌后钩子，避免终结对手的牌因战斗已结束而漏记录）。
- **记录方式**：按玩家分别记录已打出的寂灭牌，确保多玩家数据隔离。
- **移除时机**：战斗结束时，从各玩家牌组中移除已记录的寂灭牌。
- **多人隔离**：按玩家分别记录，避免跨玩家共享导致误删队友同 ID 卡。
- **与遗物联动**：若玩家拥有罕见帕尔遗物，移除寂灭牌时会触发对应回调。
- **禁用机制**：部分遗物（如贪欲晶动仪）获得的寂灭牌会被禁用寂灭效果，打出后不会从牌组移除。
