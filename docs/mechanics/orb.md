# 充能球

充能球是原版就有的战斗资源系统，Seer Mod 在原版 5 种充能球基础上**新增了 9 种自定义充能球**，并扩展了集中影响规则。

::: tip Mod 扩展了什么
- 原版 5 种：闪电、冰霜、黑暗、等离子、玻璃（玻璃只能由玻璃工艺、旋转工艺、折射这类特定卡牌定向生成，不在随机充能球池里）
- Mod 新增 9 种：星星、高塔、森林、海洋、神谕、PP、火山、圣杯、多用（全部参与随机充能球池）
- Mod 扩展了集中影响规则——不是所有充能球都吃集中
:::

---

## 基本机制

### 生成与激发

- **生成**：通过卡牌或能力将充能球放入栏位（默认 3 个，可被遗物/能力增加）
- **栏位已满**：生成新充能球时，自动激发最早的充能球（第一个栏位）
- **被动**：在特定时机自动触发（回合开始/回合结束）
- **激发**：被激发时触发激发效果，然后消失

### 被动与激发的触发时机

不同充能球的被动触发时机不同：

| 时机 | 说明 |
| --- | --- |
| 回合开始时 | 产能量、产辉星、获得格挡、恢复 PP/生命等 |
| 回合结束时 | 造成伤害、施加异常、获得覆甲等 |

## 集中影响规则

**集中**能力可以提升充能球的被动数值和激发数值，但**不是所有充能球都吃集中**：

### 吃集中的充能球

| 充能球 | 受集中影响的部分 |
| --- | --- |
| 闪电 | 被动 + 激发 |
| 冰霜 | 被动 + 激发 |
| 黑暗 | 被动（激发通过被动累加间接受益） |
| 玻璃 | 被动 + 激发 |
| 星星 | 被动（激发不受影响） |
| 高塔 | 被动 + 激发 |
| 森林 | 被动 + 激发 |
| 海洋 | 被动 + 激发 |
| 火山 | 被动 + 激发 |
| PP | 被动 + 激发 |
| 圣杯 | 被动 + 激发（恢复比例随集中提升） |
| 多用 | 被动（激发不受影响） |

### 不吃集中的充能球

| 充能球 | 不受集中影响的原因 |
| --- | --- |
| 等离子 | 硬编码固定产能量（被动 1 点，激发 2 点） |
| 神谕 | 随机提升属性，数值固定 |

::: warning 黑暗充能球的特殊性
黑暗充能球的激发伤害不直接吃集中，但被动会累加激发值——而被动吃集中，所以集中能间接提升黑暗充能球的最终激发伤害。
:::

## Mod 新增充能球

### 星星

- **被动**：回合开始时获得辉星
- **激发**：添加一张随机储君卡牌到手牌

### 高塔

- **被动**：回合开始时获得覆甲
- **激发**：获得覆甲

### 森林

- **被动**：回合结束时对随机对手施加中毒
- **激发**：对所有对手施加感染

### 海洋

- **被动**：回合结束时对随机对手施加冻伤
- **激发**：对所有对手施加冰封

### 火山

- **被动**：回合结束时对随机对手施加烧伤
- **激发**：对所有对手施加焚烬

### 神谕

- **被动**：回合开始时随机提升力量、防御、命中或速度
- **激发**：随机为一张手牌施加随机附魔
- **不吃集中**

### PP

- **被动**：回合开始时随机分配 PP 给未满的 PP 卡牌
- **激发**：随机分配 PP 给未满的 PP 卡牌

### 圣杯

- **被动**：每两回合恢复生命
- **激发**：恢复已损失生命值的 10%（每层集中 +5%）

### 多用

- **被动**：回合结束时铸造 + 召唤
- **激发**：随机为一张手牌赋予奇巧，一张赋予消耗，一张赋予虚无

## 充能球伤害的特性

Mod 充能球造成的伤害有以下特性：

- **不吃力量/虚弱/易伤**——充能球伤害是 Unpowered 的
- **可被格挡**——充能球伤害没有 Unblockable 标记
- **不吃元素克制**——元素克制只影响攻击伤害
- **可触发"每次造成伤害"类效果**（如雷雨天加闪电球）
