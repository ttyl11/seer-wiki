# 销毁牌堆

销毁牌堆是 Seer Mod 通过 RitsuLib 注册的**自定义战斗内牌堆**，用于隔离本场战斗中不再使用的卡牌。它独立于抽牌堆、弃牌堆、消耗堆和真神牌堆，仅在当前战斗中存在，战斗结束时自动清空。战斗界面中，销毁牌堆按钮显示在消耗牌堆按钮正上方，真神牌堆按钮则在销毁牌堆上方。

---

## 基本信息

| 属性 | 值 |
| --- | --- |
| 注册 ID | `SEER_CARDPILE_DESTROYED_PILE` |
| 持久化范围 | 战斗内（CombatOnly） |
| 最大容量 | 无限制 |
| UI 位置 | 消耗牌堆按钮正上方（真神牌堆在其上方） |
| 可见性 | 牌堆有牌时才显示按钮 |

---

## 卡牌的进入与离开

### 进入销毁牌堆

- 部分卡牌效果会将消耗堆中的卡牌移动到销毁牌堆
- 卡牌从消耗堆完整迁移，保留所有状态（升级、附魔、计数器等）

### 离开销毁牌堆

- **战斗结束**：销毁牌堆随 CombatState 一同清理，其中的卡牌全部消失
- **不可取回**：销毁牌堆中的卡牌在当前战斗中无法再被取回或打出

::: tip 为什么需要销毁牌堆
直接将卡牌移出战斗可能让部分依赖牌堆状态的逻辑出错。移动到销毁牌堆保留了卡牌的战斗状态归属，同时让它不参与常规牌堆交互，是一种更安全的隔离方式。
:::

## 与其它牌堆的关系

| 牌堆 | 作用域 | 用途 |
| --- | --- | --- |
| 抽牌堆 | 战斗内 | 待抽的牌 |
| 弃牌堆 | 战斗内 | 已打出的非保留牌 |
| 消耗堆 | 战斗内 | 已消耗的牌 |
| 手牌 | 战斗内 | 当前可打出的牌 |
| 真神牌堆 | 跨战斗 | 存放真神牌，用一张少一张 |
| 销毁牌堆 | 战斗内 | 隔离本场战斗不再使用的卡牌，战斗结束清空 |
