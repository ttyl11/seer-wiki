# 诅咒卡系统

Seer Mod 引入了 **17 张自定义诅咒卡**，构成一个独立的诅咒子系统。与原版诅咒牌不同，Mod 的诅咒卡大多**不需要打出**——它们只要留在手牌中就会持续产生负面效果，迫使玩家尽快处理或承受代价。

::: tip 与原版诅咒牌的区别
原版诅咒牌（如沮丧、寄生）通常只是占用手牌位、不可打出。Mod 的诅咒卡则**主动惩罚**持有者：有的每回合造成伤害，有的封锁 PP 卡牌，有的甚至强制结束回合。它们是双刃剑——部分诅咒卡打出后反而能产生正面效果。
:::

---

## 基本特性

所有 Mod 诅咒卡共享以下基础属性：

| 属性 | 值 | 说明 |
|---|---|---|
| 不可升级 | 是 | 升级等级上限为 0 |
| 卡牌类型 | 诅咒 | 与原版诅咒牌类型相同 |
| 稀有度 | 诅咒 | 专属稀有度 |
| 目标 | 无目标 | 大多数不可主动打出 |
| 卡牌池 | 诅咒卡池 | 独立卡池，不混入常规卡池 |

## 七罪系列

七张以"七宗罪"为主题的诅咒卡，每张都有独特的手牌惩罚机制：

| 诅咒 | 效果 |
|---|---|
| **嫉妒** | 一定场战斗后从牌组移除。回合结束时若在手牌中，战斗结束随机添加一张打击或防御牌（每场战斗最多一张） |
| **暴食** | 进入手牌时获得最大生命值。回合结束时若在手牌中，下回合加入数张随机诅咒 |
| **贪婪** | 回合结束时若在手牌中，获得金币并受到当前金币数一定比例的伤害。打出时扣除等于最大生命值的金币 |
| **色欲** | 抽到时，场上每有一个敌人受到伤害（女王为更高伤害） |
| **傲慢** | 在你的回合结束时，若此牌在你手牌中，受到伤害 |
| **懒惰** | 此牌在手牌中时，你造成的攻击伤害为 0 |
| **暴怒** | 此牌在手牌中时必须先打出。打出后对所有生物造成伤害 |

::: warning 七罪策略
七罪卡大多有"在手牌中时"的持续惩罚，但部分（如暴怒、贪婪）打出后也有代价。关键在于权衡持有惩罚与打出代价哪个更小。懒惰和暴食若不及时处理，会让战斗迅速失控。
:::

## 其他诅咒卡

除七罪外，Mod 还有 10 张主题各异的诅咒卡：

| 诅咒 | 效果 |
|---|---|
| **借鉴** | 回合结束时若在手牌中，下回合加入一张随机其他角色的牌（费用 +1），且必须先打出该牌 |
| **冲锋** | 此牌在手牌中时，若一回合造成的伤害未超过阈值，回合结束时受到伤害 |
| **云玩家** | 此牌在手牌中时，所有 PP 卡牌无法打出。打出后解除封锁 |
| **拖50** | 回合结束时若在手牌中，受到等同于当前回合数 × 固定值的伤害 |
| **保底** | 抽到时有概率受到伤害。战斗结束有概率获得一张随机稀有牌 |
| **氪金** | 加入手牌时失去当前金币的一定比例。打出时自身附加 99 层易伤和虚弱 |
| **涨价** | 抽到时所有手牌费用增加，打出任何牌后移除。打出后下回合所有手牌费用增加 |
| **老鼠药** | 此牌在手牌中时，使用药水失去最大生命值 |
| **羞耻** | 无法打出的诅咒卡，无描述文本，会一直留在手牌中 |
| **开龟** | 此牌在手牌中时，每回合当你造成大于等于阈值伤害时，强制结束你的回合 |

---

::: details 触发模式详解
诅咒卡的效果触发遵循几种典型模式：

**1. 手牌驻留惩罚** —— 最常见的模式，诅咒卡在手牌中时持续生效。如懒惰（攻击伤害为 0）、云玩家（封锁 PP 卡牌）、老鼠药（用药扣血）等。这类诅咒卡需要通过打出、消耗或弃牌来解除惩罚。

**2. 回合结束触发** —— 部分诅咒卡在回合结束时检查是否在手牌中，若在则触发惩罚。如傲慢（受到伤害）、暴食（加入诅咒）、拖50（按回合数伤害）等。

**3. 抽到时触发** —— 部分诅咒卡在抽到瞬间触发效果。如色欲（对敌人造成伤害）、涨价（手牌费用增加）、保底（概率受到伤害）等。

**4. 打出后双刃** —— 部分诅咒卡可以打出，但打出后有代价。如暴怒（对全生物造成伤害）、氪金（附加 99 层易伤和虚弱）、贪婪（扣除金币）等。
:::

::: details 处理诅咒卡的方式
- **打出**：部分诅咒卡可打出，但通常有代价
- **消耗**：通过消耗机制将诅咒卡移入消耗堆
- **弃牌**：通过弃牌机制移除
- **转化**：部分卡牌或遗物可将诅咒卡转化为其他牌
- **等待移除**：如嫉妒会在一定场战斗后自动从牌组移除

::: tip 与其他系统的联动
诅咒卡与 Mod 的多个系统有联动：[湮灭](./annihilation)机制中的邪诲/圣诰可配对造成伤害；部分遗物会在获得诅咒时触发效果；[空元之诗](./void-poem)的渍效果可给敌人施加诅咒。
:::
:::
