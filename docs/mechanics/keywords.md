# 关键词

Seer Mod 在原版 7 个关键词（消耗、虚无、保留、固有、不能被打出、永恒、奇巧）基础上，新增了 **20 个自定义关键词**。这些关键词是赛尔卡的核心机制标识。

::: tip 关键词的两种类型
- **动态关键词**：根据卡牌当前 PP 状态自动添加/移除（PP 充足时有，PP 归 0 后消失）
- **静态关键词**：卡牌类直接声明，不受 PP 状态影响
:::

---

## Mod 新增关键词清单

### 打出时触发型

| 关键词 | 效果 |
| --- | --- |
| **碎心** | 打出时，失去 2 点最大生命值 |
| **悼** | 打出时，下个回合由瓦库代替你行动 |
| **寂灭** | 打出时，本场战斗结束后从你的牌组中移除此牌 |
| **化墟** | 打出时，向你的弃牌堆中加入一张随机状态牌 |
| **陨** | 打出后，此牌转化为"圣逝" |
| **芜生** | 打出后，此牌转化为"芜" |
| **缢形** | 打出时，本场战斗中你无法再获得任何增益 |
| **异变** | 打出时，对自己施加随机 1 种异常状态，持续 2 回合 |
| **毁灭** | 打出时，将你的消耗堆中的所有牌移动到销毁牌堆 |
| **邪恶** | 打出时，本场战斗结束后向你的牌组中添加一张此牌的复制品。每张牌的这个词条每场战斗只触发一次 |
| **炼狱** | 此牌伤害翻倍。打出时，对自己施加随机 1 种异常状态，持续 5 回合 |

### 持续效果型

| 关键词 | 效果 |
| --- | --- |
| **回响** | 每回合开始时，此牌从任意位置加入你的手牌 |
| **饮血** | 此牌造成的伤害回复你 20% 的生命值 |

### 触发条件型

| 关键词 | 效果 |
| --- | --- |
| **薇** | 非"薇"的相邻的牌被打出时，此牌自动打出 |
| **戏法** | 打出时，若弃牌堆有牌，随机从弃牌堆抽一张牌到手中 |

### 子系统型（有独立机制页）

| 关键词 | 效果 | 详见 |
| --- | --- | --- |
| **真神** | 此牌只能被自动打出 | [真神牌堆](./true-god-pile) |
| **湮灭** | 打出后，对所有敌人，"邪诲"与"圣诰"每配对一组，造成 8 点伤害。剩余层数保留 | [湮灭](./annihilation) |
| **薇尔诗** | 相邻牌打出后免疫全属性下降；隔位牌打出后免疫异常状态；手牌中有此牌时首末位牌打出后免疫固定伤害 | [薇尔诗](./vier-poem) |
| **预见** | 查看牌堆顶 N 张牌，可丢弃其中任意数量 | [预见](./scry) |
| **空元之诗** | 打出时若自身有空妄诗章，扣除一篇，随机触发渍/镀/柱/烙/均五种效果（每打出一次多触发一种） | [空元之诗](./void-poem) |

## 动态关键词 vs 静态关键词

### 动态关键词（14 个）

以下关键词在 PP 卡牌上根据 PP 状态动态添加/移除：

碎心、悼、寂灭、化墟、陨、芜生、缢形、异变、回响、饮血、毁灭、邪恶、炼狱、薇

::: tip 动态机制
部分 PP 卡在 PP 充足时拥有某个动态关键词，PP 归 0 后该关键词消失。状态变化时自动重新应用对应关键词。
:::

### 静态关键词（6 个）

卡牌类直接声明，不受 PP 状态影响：

戏法、薇尔诗、预见、空元之诗、真神、湮灭

## 触发时序

关键词的触发时机分布在卡牌打出流程的不同阶段：

| 时机 | 触发的关键词 |
| --- | --- |
| 回合开始（抽牌前） | 回响（加入手牌） |
| 卡牌打出时 | 碎心、悼、寂灭、化墟、缢形、异变、毁灭、邪恶、炼狱、戏法 |
| 卡牌打出后 | 陨、芜生、湮灭、空元之诗 |
| 相邻牌打出时 | 薇（自动打出） |
| 相邻/隔位/首末位牌打出后 | 薇尔诗（免疫效果） |
| 战斗结束后 | 寂灭（移除牌组）、邪恶（添加复制品） |
