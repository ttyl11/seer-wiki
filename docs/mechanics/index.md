# 核心机制总览

Seer Mod 在原版《杀戮尖塔2》基础上引入了大量独有机制。本页是所有核心机制的入口，按类型分组索引。

::: tip 阅读建议
第一次接触本 Mod 的玩家，建议先读 [PP 系统](./pp-system)、[固定伤害](./fixed-damage)、[元素克制](./element-affinity)、[异常状态](./abnormal-status)、[关键词](./keywords) 这五篇——它们是理解 Seer Mod 战斗的基础。
:::

---

## 一、Mod 独有核心系统

原版完全没有的全新规则系统。

| 机制 | 简介 |
| --- | --- |
| [PP 系统](./pp-system) | 每张赛尔卡专属的次级资源池，独立于能量 |
| [固定伤害](./fixed-damage) | 延迟结算的特殊伤害，下回合开始才掉血，可被免疫/反弹 |
| [元素克制](./element-affinity) | 26 种元素构成的赛尔号式克制表，只影响攻击伤害 |
| [异常状态](./abnormal-status) | 25 种独有异常（衰弱、沉默、狂暴等），区别于原版虚弱/易伤 |
| [永久属性](./permanent-bonus) | 通过抽奖获得的跨战斗持久化属性，30+ 种 |
| [赛尔豆与泰坦之灵](./currency) | Mod 独有的双货币系统，用于精英商店和泰坦商店 |
| [唱词系统](./chant) | 四种唱词（舍麦什/霍尔希德/拉/莎木斯），被动触发体系 |
| [暴击](./critical-strike) | 12.5% 基础概率、1.5 倍伤害，不被清除 |
| [诅咒卡系统](./curse-system) | 17 张自定义诅咒卡（七罪系列等），手牌驻留即惩罚 |
| [Mod 配置系统](./mod-settings) | 9 项可配置选项（怪物比例/赛尔牌概率/动画等），含多人同步 |

## 二、Mod 改造的原版系统

原版已有、Mod 进行了大幅扩展或改写规则的系统。

| 机制 | 简介 |
| --- | --- |
| [关键词](./keywords) | 原版 7 个 + Mod 新增 20 个（碎心/悼/寂灭/真神/湮灭等） |
| [充能球](./orb) | 原版 6 种 + Mod 新增 9 种自定义球 |
| [附魔](./enchantment) | 状态宝石（22 种异常）+ 特殊附魔（注能/星皇之怒/五音系列等） |
| [意图](./intent) | Mod 新增意图类型（无效化/同生共死/解析/动态多段） |
| [角色卡牌标签](./card-tags) | 5 种原版角色的 CardTag，实现"仅对某角色生效" |

## 三、Mod 独有的关键词衍生子系统

由 Mod 新增关键词触发的独立小系统，规则复杂，单独成篇。

| 机制 | 关键词 | 简介 |
| --- | --- | --- |
| [真神牌堆](./true-god-pile) | 真神 | 只能被自动打出的特殊牌堆 |
| [湮灭](./annihilation) | 湮灭 | 邪诲×圣诰配对触发伤害 |
| [空元之诗](./void-poem) | 空元之诗 | 渍/镀/柱/烙/均 五种随机效果 |
| [薇尔诗](./vier-poem) | 薇尔诗 | 基于手牌位置的免疫（相邻/隔位/首末位） |
| [预见](./scry) | 预见 | 查看牌堆顶 N 张牌并选择性弃牌 |

## 四、Mod 独有的战斗机制

由补丁或能力实现的独立战斗规则。

| 机制 | 简介 |
| --- | --- |
| [消逝](./vanish) | 怪物死亡时跳过复活和亡语，并传染 Debuff 给队友 |
| [混沌化身](./chaos-incarnation) | 能量不足时可用最大生命值抵扣打出卡牌 |
| [手牌快照](./hand-snapshot) | 卡牌打出时记录手牌状态，供"本回合打出的每张牌"类效果使用 |
| [龙威](./dragon-majesty) | 哈莫雷特被动：敌人打出与上一张不同类型的牌则重放，相同则无效 |

## 附：原版机制（仅作入口）

以下机制原版已有，Mod 未改写核心规则，仅在个别卡牌/遗物中引用。详情请参考原版游戏内的提示。

- 能量、格挡、手牌、抽牌堆、弃牌堆、消耗堆
- 消耗、虚无、保留、固有、不能被打出、永恒、奇巧
- 铸造、召唤、辉星、激发、集中、充能
- 击晕、斩杀、生成、转化、回放
- 复活机制（Mod 在此基础上扩展了多种复活能力）
