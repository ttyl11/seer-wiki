# PP 系统

PP（Power Point）是 Seer Mod 最核心的卡牌机制。每张赛尔卡除了像原版卡牌那样消耗能量外，还自带一个独立的 PP 资源池——**PP 归 0 的赛尔卡无法主动打出**。这使得赛尔卡比普通卡牌多了一层"使用次数"的管理。

::: tip 与原版能量的区别
能量是回合制资源（每回合回满），PP 是卡牌制资源（每张卡各自的池子）。一张卡的 PP 用完了，即使你还有能量也打不出它——这模拟了赛尔号游戏中"技能 PP"的设定。
:::

---

## 基本字段

每张赛尔 PP 卡包含两个 PP 字段：

- **当前 PP**：当前还能打出的次数
- **最大 PP**：该卡 PP 池的上限，也是打出一次所需的基础消耗（通常为 1）

## 打出消耗规则

### 基础消耗

- 每次主动打出消耗 **1 点 PP**（最大 PP 的基础值）
- **最大 PP 为 0 的赛尔卡不消耗 PP**——这类卡可以无限打出
- **自动打出同样消耗 PP**——无论"薇"、"悼"、附魔触发、还是其它自动打出效果，都走标准 PP 消耗流程。PP 归 0 的赛尔卡同样无法被自动打出

### 免耗情形

以下效果存在时，打出赛尔卡不消耗 PP：

| 效果 | 来源 |
| --- | --- |
| Boss 免费效果 | 部分怪物自带的能力 |
| 龙语·无匹 | 哈莫雷特系列能力 |

### PP 消耗修正

部分怪物能力会改变玩家赛尔卡的 PP 消耗：

| 能力 | 效果 | 来源 |
| --- | --- | --- |
| 侵蚀一 | PP 消耗 ×2 | 怪物能力 |
| 侵蚀二 | PP 消耗 +N（N 随能力层数提升） | 怪物能力 |
| 罗生门 | PP 消耗 ×3，持续 5 回合 | 怪物能力 |

::: warning 罗生门是硬封锁
罗生门让 PP 消耗变为 3 倍——大多数赛尔卡的最大 PP 只有 1-2，触发后等于直接无法打出。需要优先解除。
:::

## 可打出判定

| 条件 | 可否打出 |
| --- | --- |
| 最大 PP ≤ 0 | 可打（不消耗 PP） |
| 当前 PP > 0 | 可打 |
| 拥有「无为觉者」遗物，且当前 PP = 0 | **可打**（遗物允许 PP=0 时仍打出） |
| 当前 PP = 0，且无上述遗物 | 不可打 |

## PP 保护机制

PP 保护能力存在时，PP 不会被外部效果减少——只能通过"打出卡牌"这一标准流程消耗。

这保证了 PP 是一个"卡牌使用次数"资源，不会被怪物的偷取/破坏效果清空。

## PP 自动循环

每回合开始和结束时，赛尔 PP 卡会在牌堆间自动流转，形成"休息-再战"循环：

- **回合结束时**：抽牌堆、弃牌堆、手牌中 PP ≤ 0 的赛尔 PP 卡移入消耗堆
- **己方回合开始前**：消耗堆中 PP > 0 的赛尔 PP 卡移回弃牌堆

这意味着 PP 耗尽的卡会暂时离开战斗牌堆休息，等不到它们再次进入手牌。

## PP 恢复途径

PP 主要通过以下途径恢复：

- **PP 充能球**：被动/激发时随机分配 PP 给未满的赛尔卡
- **仐（五音之一）附魔**：打出后所有 PP 恢复 1 点
- **霍尔希德唱词**：自身造成伤害后恢复所有 PP 牌的 PP 值
- **部分药水/遗物**：直接恢复 PP

## 克隆与复制

卡牌被克隆（如复制、生成衍生牌）时，**PP 重置为最大值**，不继承原卡的 PP。

这意味着"复制一张赛尔卡"等于获得一张满 PP 的新卡，是重要的 PP 续航手段。

## 与动态关键词的关系

赛尔 PP 卡支持一组"动态关键词"——根据卡牌当前 PP 状态自动添加或移除。例如：

- 部分 PP 卡在 PP 充足时拥有某个关键词，PP 归 0 后关键词消失
- 状态变化时自动重新应用对应关键词

涉及的关键词包括：碎心、悼、寂灭、化墟、陨、芜生、缢形、异变、回响、饮血、毁灭、邪恶、炼狱、薇等。
