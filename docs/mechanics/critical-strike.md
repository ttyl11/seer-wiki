# 暴击

暴击是 Seer Mod 独有的伤害放大机制。与原版的"力量/易伤"等增伤不同，暴击是**概率触发的固定倍率放大**，且有独立的锁定和强制触发机制。

::: tip 暴击 vs 力量
力量是"每次攻击 +N"的加法增伤；暴击是"概率 ×1.5"的乘法增伤。暴击不吃力量/虚弱/易伤修正，是独立的伤害放大层。
:::

---

## 基础规则

| 参数 | 默认值 |
| --- | --- |
| 暴击概率 | 12.5% |
| 暴击倍率 | ×1.5 |
| 能力类型 | 中性（不是 Buff 也不是 Debuff） |

### 关键特性

- **不被清除**：暴击能力是中性类型，不会被消除 Buff/Debuff 类效果清除
- **只影响攻击伤害**：暴击只修正攻击伤害，不影响持续伤害、固定伤害、充能球伤害等
- **乘法结算**：暴击在伤害计算的乘法阶段生效，与力量（加法）、虚弱/易伤（乘法）等独立计算

## 触发流程

1. **攻击前**：掷骰判定本次攻击是否暴击
2. **伤害计算**（乘法伤害修正阶段）：若判定为暴击，伤害 ×1.5
3. **攻击后**：重置暴击标记，准备下次判定

::: tip 判定时机
暴击判定在攻击前完成，一旦判定本次攻击为暴击，则该次攻击的所有伤害段都享受 ×1.5 倍率。
:::

---

## 暴击锁定机制

部分能力可以**锁定暴击**——绕过概率判定，直接确定暴击结果：

| 能力 | 效果 |
| --- | --- |
| 要害一 | 50% 概率暴击（覆盖基础 12.5%） |
| 要害二 | 100% 暴击（必定暴击） |
| 要害一·叠层 | 50% 概率暴击（覆盖基础概率） |
| 要害二·叠层 | 100% 暴击（必定暴击） |

::: warning 锁定优先级
要害系列能力存在时，**完全覆盖**基础 12.5% 概率——要害一固定 50%，要害二固定 100%。不会先掷基础概率再掷要害概率。
:::

## 强制暴击

部分效果可以**强制下次攻击暴击**：

- **精神同步**（怪物招式）：首次使用下次攻击 50% 暴击，再次使用 100% 暴击，三次以上伤害翻倍
- **冲天霸气**（怪物招式）：进入愤怒姿态，下两次攻击必定致命一击
- **不灭斗气**（怪物招式）：下次攻击必定暴击
- **圣光气**（谱尼招式）：下次攻击必定暴击
- **灭魂天葬击**（怪物招式）：下次攻击必定暴击

## 暴击与异常状态交互

### 沸涌

沸涌异常状态会**改变暴击倍率**：

- 持有沸涌的目标受到暴击时，暴击倍率从 ×1.5 提升至 **×2.0**
- 这是对暴击流的一种反制——沸涌让暴击更痛，但沸涌本身有"攻击伤害至少为下限值"的减伤效果

### 雷雨天

雷雨天能力让自身攻击**必定暴击**，但每次造成伤害（含自伤）后闪电充能球 +1。

---

## 暴击与秒杀

部分能力在暴击基础上还有**秒杀**机制：

### 魔王咒怨

- 攻击伤害增加、伤害减免
- 攻击技能有概率秒杀对面
- 秒杀会**传染同 HP 敌人**——如果场上有多个 HP 相同的敌人，秒杀一个会连带秒杀其它同 HP 的
- 达到阈值层数时自身免疫异常状态
