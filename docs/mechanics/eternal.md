# 永恒

> 原版关键词

## 基本信息

- **类型**: 卡牌关键词
- **枚举值**: 7

## 描述

无法从你的牌组中移除或变化。

## 详细机制

- **不可移除**：带有"永恒"关键词的卡牌无法通过任何效果从牌组中移除（如休息处的"移除卡牌"服务、卡牌消耗后的永久移除等）。
- **不可变化**：带有"永恒"关键词的卡牌无法被"变化"效果转变为其他卡牌。
- **战斗中仍可消耗**：在战斗中，永恒卡牌仍可被消耗（进入消耗堆），但战斗结束后会恢复到牌组。
- **自动添加描述**：卡牌带有此关键词时，描述中会自动显示"永恒"文本。
