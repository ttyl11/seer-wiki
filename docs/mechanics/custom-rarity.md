# 自定义遗物稀有度

自定义遗物稀有度是 Seer Mod 为遗物新增的稀有度类型。原版只有普通、罕见、稀有、先古四种稀有度，Mod 新增了史诗和传说两种，并接管原版 UI 显示。

::: tip Mod 扩展了什么
- 原版只有 4 种遗物稀有度，Mod 新增了史诗（紫色）和传说（红橙色）2 种
- 因 C# 枚举无法运行时扩展，采用"自定义字段 + 补丁接管 UI"方案
- 自定义稀有度遗物不在原版商店交易，仅在精英商店出售
:::

---

## 两种自定义稀有度

| 稀有度 | 颜色 | 视觉回退 | 排序 | 精英商店售价 |
| --- | --- | --- | --- | --- |
| 史诗 | 紫色描边（`#994DFF`） | 稀有 | 100 | 1600 |
| 传说 | 红橙描边（`#FF4D1A`） | 先古 | 110 | 2500 |

### 视觉回退

由于原版 UI 系统基于枚举值渲染，自定义稀有度需要一个"视觉回退"到原版稀有度：
- **史诗** → 视觉回退到"稀有"（Rare），但描边颜色覆盖为紫色
- **传说** → 视觉回退到"先古"（Ancient），但描边颜色覆盖为红橙色

### 排序

- 史诗排序值 100，传说排序值 110
- 在遗物图鉴中，自定义稀有度遗物排在原版稀有度之后

## 遗物接入方式

### 声明自定义稀有度

遗物通过重写两个属性来声明自定义稀有度：

1. **自定义稀有度属性**：返回"史诗"或"传说"
2. **原版稀有度属性**：返回"先古"（让原版掉落池过滤掉，避免污染正常掉落池）

### 使用自定义稀有度的遗物

以下遗物使用了自定义稀有度（部分列举）：

| 遗物 | 稀有度 |
| --- | --- |
| 全父奥丁 | 史诗 |
| 天启帝 | 史诗 |
| 混沌魔王 | 史诗 |
| 宇宙帝 | 史诗 |
| 圣诰邪魇夜 | 史诗 |
| 无为觉者 | 史诗 |
| 空元行者 | 史诗 |

::: tip 为什么用 Ancient 作为 Rarity
将原版稀有度设为"先古"有两个目的：
1. 让原版的随机掉落池过滤掉这些遗物，避免在正常游戏流程中掉落
2. 让遗物在原版图鉴中归类到先古分类，再由 Mod 补丁追加史诗和传说子分类
:::

## UI 接管

Mod 通过多个补丁接管原版 UI，确保自定义稀有度正确显示：

### 检视界面

- **补丁目标**：遗物检视界面的更新方法
- **接管内容**：设置自定义稀有度标签文字、颜色、帧的 HSV 着色器参数
- **颜色回退**：未定义颜色时回退到视觉回退稀有度的原版 HSV

### 描边颜色

- **补丁目标**：遗物节点的重载方法
- **接管内容**：给遗物描边的纹理染色为自定义颜色

### 交易限制

- **补丁目标**：遗物可交易性检查
- **接管内容**：自定义稀有度遗物不可交易
- **原因**：自定义稀有度遗物仅在精英商店出售，不应在原版商店交易

### 图鉴分类

- **补丁目标**：遗物图鉴的分类加载方法
- **接管内容**：
  1. 从原版分类中移除自定义稀有度遗物（避免重复显示）
  2. 在先古分类后追加 Epic 和 Legendary 两个独立子分类
  3. 使用反射调用原版的子分类创建方法
  4. 设置线程本地标志防止注入的遗物被过滤

## 与精英商店的关系

自定义稀有度遗物仅在精英商店出售：

- **获取方式**：通过[赛尔豆](./currency)在精英商店购买
- **不可交易**：不能在原版商店出售或交换
- **不可掉落**：不在正常游戏流程的遗物掉落池中

---

## 与遗物宝库的关系

群星的礼赠的[遗物宝库](./relic-right-click)包含史诗和传说稀有度的遗物：
- 2 个史诗遗物（HP 倍率 1.4）
- 1 个传说遗物（HP 倍率 1.8）
- 这是除了精英商店外，获取自定义稀有度遗物的另一途径
