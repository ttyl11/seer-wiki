# 游戏流程改造

Seer Mod 对杀戮尖塔2 的游戏流程进行了全面改造，包括子地图系统、遭遇战比例调整、起始遗物注入、Neow 选项扩展、强制解锁 Neow 纪元五大方面。

::: tip Mod 扩展了什么
- 新增子地图系统：独立的 6 节点精英战子地图
- 遭遇战比例调整：Mod 怪物与原版怪物的遭遇比例自动平衡
- 起始遗物注入：所有角色开局获得元素核心
- Neow 选项扩展：为每个古代存在追加 Mod 遗物选项
- 强制解锁 Neow 纪元：无需完成前置进度即可访问 Neow
:::

---

## 子地图系统

### 概述

子地图是 Mod 独有的独立地图区域，玩家通过特定条件进入，完成后返回原地图。子地图是一个 6 节点单列结构，专注于精英战。

### 子地图布局

| 层 | 节点类型 | 说明 |
| --- | --- | --- |
| 0 | 先古 | 起点 |
| 1 | 未知 | 问号事件 |
| 2 | 精英 | 精英战 |
| 3 | 休息点 | 恢复 |
| 4 | 精英 | 精英战 |
| 5 | 商店 | 购物 |
| 6 | 精英 | 终点（访问后触发返回） |
| 7 | Boss | 隐藏（不直接访问） |

### 进入与返回

- **进入**：通过同步 Action 进入子地图，保存原地图状态（地图、已访问坐标、楼层、当前坐标）
- **地图生成**：使用稳定种子（RNG 种子的异或变换）创建确定性子地图
- **嵌套支持**：子地图可以嵌套（继承旧 session 的原地图状态）
- **返回**：访问终点（第 6 层精英）后触发返回，恢复原地图状态
- **存档恢复**：支持从存档恢复子地图状态（终点已访问→恢复原版地图；未访问→重建 session 继续）

::: tip 子地图的战略意义
子地图是一个高风险高回报的区域：3 场精英战 + 1 个商店 + 1 个休息点 + 1 个问号。适合需要大量精英遗物的构筑，但生存压力极大。
:::

## 遭遇战比例调整

### 比例自动平衡

Mod 的怪物和事件与原版混合时，通过补丁自动调整比例：

- **按房间类型分组**：怪物房、精英房、Boss 房分别处理
- **目标比例**：Mod 条目数量 = 原版条目数量 × 比例 / (1 - 比例)
- **多余移除**：超出目标的 Mod 条目按条目 ID 排序移除（确定性，确保多人同步）
- **不足保留**：不足目标数量时保留全部 Mod 条目

### 事件均匀交错

- 重建事件列表，使用 Bresenham 算法均匀交错原版和 Mod 事件
- 确保两类事件在地图上均匀分布，避免聚集

### 存档修复

- 若存档中 Boss 房间为 null，用占位遇敌修复
- 让原版方法重新随机生成 Boss

## 起始遗物注入

### 元素核心作为起始遗物

- **补丁目标**：游戏数据库初始化
- **注入方式**：遍历所有角色模型（含 Mod 角色），为每个角色注册元素核心为起始遗物
- **效果**：所有角色开局自动获得元素核心

::: tip 元素核心的普适性
元素核心是所有角色的通用起始遗物，提供[遗物宝库](./relic-right-click)右键功能。这意味着无论选择哪个角色，都能通过右键元素核心获取 30 选 1 的遗物。
:::

## Neow 选项扩展

### 选项池扩展

Mod 为 Neow（以及其它古代存在）的选项池追加了 27+ 个 Mod 遗物选项：

| 古代存在 | 追加选项数 |
| --- | --- |
| Neow | 27（15 普通 + 12 先古塔罗） |
| Darv | 5 |
| Vakuu | 9 |
| Pael | 5 |
| Tanx | 5 |
| Tezcatara | 5 |
| Orobas | 10 |
| Nonupeipe | 6 |

### 选项抽取接管

- **补丁目标**：Neow 初始选项生成
- **接管方式**：Postfix 完全替换原版抽取结果
- **抽取流程**：
  1. 过滤已锁定选项
  2. 过滤不允许的遗物
  3. Fisher-Yates 洗牌（消耗古代事件的 RNG）
  4. 取前 4 个作为初始选项
  5. 对尘封之书选项进行先古牌初始化确保非空

### 尘封之书特殊处理

- 尘封之书选项需要确保先古牌不为空
- 调用先古牌初始化方法进行多级回退查找
- 详见 [卡牌池扩展](./card-pool-extension)

## 强制解锁 Neow 纪元

### 概述

原版需要完成前置进度才能解锁 Neow 纪元。Mod 通过补丁强制解锁，让玩家无需前置进度即可访问 Neow。

### 实现

- **补丁目标**：存档管理器的解锁状态生成
- **补丁类型**：Prefix
- **逻辑**：检查是否已有 Neow 纪元但未显示，若是则强制解锁显示

## 整体流程

综合以上改造，Seer Mod 的游戏流程为：

1. **游戏开始**：强制解锁 Neow 纪元，所有角色获得元素核心为起始遗物
2. **Neow 事件**：选项池包含 27+ 个 Mod 遗物选项，4 选 1
3. **地图探索**：遭遇战比例自动平衡，Mod 与原版怪物/事件均匀分布
4. **子地图**：通过特定条件进入精英战子地图，6 节点探索后返回
5. **精英商店**：使用赛尔豆抽取永久属性，购买自定义稀有度遗物
