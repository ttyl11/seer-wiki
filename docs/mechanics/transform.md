# 转化

> 原版卡牌机制

## 描述

转化是将一张卡牌变为另一张卡牌的机制。转化后，原卡被替换为新卡，新卡保留原卡所在的牌组位置与归属——转化不会把卡牌移动到其它牌堆，也不会改变它属于谁。

## 详细机制

### 转化类型

| 类型 | 说明 |
| --- | --- |
| 指定转化 | 变为某张确定的卡牌（如"生命"固定变为"光荣之梦"） |
| 随机转化 | 从卡池中随机选取一张卡作为转化结果 |

### 哪些卡能被转化

- 并非所有卡都能被转化：部分诅咒牌、状态牌等无法被转化
- 转化产生的新卡通常仍可被再次转化

### 转化流程

1. 原卡从所在牌堆消失
2. 新卡出现在原卡的位置，继承其归属
3. 播放转化动画提示

## Mod 中的转化应用

### 起源流转遗物

[起源流转](/relics/starter/origin_shift)（谱尼初始遗物）每经过 7 个战斗房间（精英算 2 次，Boss 算 3 次），随机将 1 张基础牌转化为对应的先古任务牌：

| 基础牌 | 转化为 |
| --- | --- |
| 生命 | 光荣之梦 |
| 虚无 | 圣灵悲魂曲 |
| 轮回 | 神圣复苏 |
| 元素 | 神灵之触 |
| 能量 | 神圣启示歌 |
| 永恒 | 圣光吟诵 |
| 圣洁 | 璨灵圣光 |

- **随机选取**：多人模式两端结果一致
- **只转化基础牌**：从牌组中筛选可转化的基础牌，随机选一张转化

### 尘封之书

尘封之书的先古牌获取也涉及转化机制，详见 [卡牌池扩展](./card-pool-extension)。
