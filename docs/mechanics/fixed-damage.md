# 固定伤害

固定伤害是 Seer Mod 独有的"延迟结算"伤害模型。与原版直接掉血的伤害不同，固定伤害**先以 Debuff 形式施加在目标身上，等到该目标下回合开始时才真正掉血**。

::: warning 最容易踩坑的机制
固定伤害不是"立即造成伤害"，而是"先挂一个 Debuff，下回合开始才扣血"。这个延迟结算机制让固定伤害可以**被免疫**、**被反弹**、**被血条预判显示**——这些是普通伤害做不到的。
:::

---

## 运作流程

1. **施加阶段**：源效果（卡牌、怪物招式、能力）对目标施加"固定伤害"Debuff，层数等于伤害值
2. **等待阶段**：Debuff 停留在目标身上，血条上以特殊颜色（粉橙色）显示预扣血段
3. **结算阶段**：目标下回合开始时，受到等于层数的固定伤害，然后 Debuff 移除

## 重要特性

### 不走常规伤害流程

固定伤害结算时：

- **不受力量/虚弱/易伤影响**——这些只修正攻击伤害
- **不受元素克制影响**——克制只修正攻击伤害
- **不受格挡影响**——固定伤害直接扣血，不吃格挡
- **可被部分特殊效果减免**（如长效体力）

### 血条预判显示

固定伤害 Debuff 持续期间，目标血条会显示一个**粉橙色的预扣血段**，让玩家能直观看到"下回合将要掉多少血"。这是固定伤害独有的视觉反馈。

### 配对触发机制

部分效果以"附加固定伤害"形式出现——例如怪物招式造成攻击伤害后**附加 N 点固定伤害**。这 N 点不是立即扣血，而是给目标挂上 N 层固定伤害 Debuff，下回合才开始结算。

---

## 免疫源

以下能力存在时，目标**完全免疫固定伤害**（Debuff 施加后立即移除，不造成伤害）：

| 能力 | 说明 |
| --- | --- |
| 免疫固定伤害 | 永久免疫，直到该能力被移除 |
| 回合免疫固伤 | 免疫 N 回合，每回合结束时层数 -1 |
| 长效体力 | 每回合开始恢复 2 点体力并免疫固定伤害，每回合 -1 层 |

## 反弹机制

**坚毅**能力存在时，目标不仅免疫固定伤害，还会**把免疫的固定伤害全额转移给所有对手**——相当于把"我要掉的固定伤害"变成"对面所有人掉的固定伤害"。

这是一个极强的反制手段，能将敌人的固定伤害输出转化为己方输出。

## 常见来源

### 玩家侧

- **千里击涛**等卡牌直接施加固定伤害
- **薇尔诗**关键词的"柱"效果：每个敌人意图数 ×3 点固定伤害（随机分配）
- **空元之诗**关键词的"均"效果：对随机敌人造成自身与体力之差 50% 的固定伤害
- **龙胆**能力：使用牌时对随机敌人造成 1 点固定伤害

### 怪物侧

- **比比鼠·电火花**：造成攻击伤害并附加固定伤害
- **流星雨**：造成攻击伤害并附加 10 点固定伤害
- **沙暴铁碎阵**：造成攻击伤害并附加等于自身防御层数的固定伤害
- **石化操控**：玩家下回合结束时清除格挡并转化为等量固定伤害
- **墨杜萨系列**：多个招式附带固定伤害

::: tip 应对策略
面对大量固定伤害的敌人，优先获取"免疫固定伤害"或"坚毅"能力。否则血条上的粉橙色预扣血段会越叠越多，下回合直接暴毙。
:::

---

## 为什么 Mod 要这样设计

固定伤害的"延迟结算 + 可免疫 + 可反弹"模型，让 Mod 能模拟赛尔号原版中"固定伤害技能"的几个特点：

1. **无视防御**：固定伤害不吃格挡/力量/虚弱，模拟了原版"固伤穿盾"的特性
2. **可被反制**：通过免疫/反弹能力，给玩家"针对固伤流"的应对空间
3. **可预判**：血条预扣血段让玩家能提前规划，而不是被突然秒杀
4. **配对触发**：作为攻击伤害的"附加"出现，模拟原版技能的"附带固伤"效果
