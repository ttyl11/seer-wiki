# 消逝

消逝是 Seer Mod 独有的怪物死亡机制。当满足特定条件时，怪物死亡时**跳过所有复活和亡语效果**，并将身上的全部 Debuff 传染给存活队友。

::: tip Mod 扩展了什么
- 原版怪物死亡时会触发 ShouldDie/AfterDeath 钩子链，允许复活和亡语
- 消逝直接跳过这些钩子，让怪物"真正死亡"——无法被任何复活效果挽救
- 消逝还会传染 Debuff 给队友，形成连锁削弱效果
:::

---

## 触发条件

消逝在以下任一条件满足时触发：

### 条件一：曝状态

- 怪物持有"曝"异常状态时死亡 → 触发消逝
- 曝状态的效果：不可计数，持有此状态的敌怪所对应的所有幻扰施加异常状态成功概率下降 50%，且此敌怪死亡后直接消逝

### 条件二：空元行者遗物

- 敌方玩家持有"空元行者"遗物时，对方怪物死亡 → 触发消逝
- 空元行者遗物让所有敌方怪物死亡时都消逝

---

## 消逝的效果

### 跳过复活

- 消逝直接跳过所有死亡阶段监听者（含早期判定与晚期判定）
- 任何复活效果（如不死之身、复活能力等）都无法挽救消逝的怪物
- 怪物立即死亡，无任何挽救机会

### 跳过亡语

- 消逝跳过所有死亡后亡语钩子
- 怪物的死亡触发效果（如亡语伤害、死亡时召唤等）不会执行
- 但空元行者遗物的诗章 +1 效果会被手动补回（因为消逝跳过了原版遗物的死亡后监听）

### 传染 Debuff

- 消逝的怪物身上的所有 Debuff 状态会传染给存活的队友
- 每种 Debuff 以原层数传染
- 通过施加能力的方式传染，可被异常免疫效果抵挡

::: warning 传染范围
只有减益（Debuff）类型的状态会被传染。增益型状态和特殊类型状态不会传染。传染时快照收集所有减益状态（避免迭代中修改集合），然后逐一施加给每个存活队友。
:::

---

## 消逝的流程

1. **触发判定**：怪物 ShouldDie 返回 true 时，检查是否满足消逝条件
2. **阻止复活**：设置 preventer = null、result = true，跳过所有 ShouldDie 监听
3. **跳过亡语**：跳过所有 AfterDeath 钩子，仅执行消逝逻辑
4. **传染 Debuff**：快照收集怪物身上所有 Debuff，施加给每个存活队友
5. **补回遗物效果**：若由空元行者触发，手动调用遗物的 OnEnemyVanished（诗章 +1 + 最大生命 3%）

## 战略意义

### 克制复活型敌人

- 部分怪物有复活能力（如不死之身），消逝可以直接跳过复活
- 曝状态是施加消逝的手段之一，适合对付高难度复活型 Boss
- 空元行者遗物让所有敌方怪物都消逝，是终极反复活手段

### Debuff 传染连锁

- 消逝传染 Debuff 给队友，可以形成连锁削弱
- 对身上堆满 Debuff 的怪物触发消逝，效果最佳
- 适合配合多 Debuff 施加型卡牌使用

### 跳过亡语的风险

- 部分怪物的亡语是有益的（如死亡时掉落物品），消逝会跳过这些效果
- 需要权衡：跳过亡语的代价 vs 阻止复活和传染 Debuff 的收益
