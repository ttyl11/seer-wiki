# 异常状态

Seer Mod 引入了 **25 种独有异常状态**，模拟赛尔号原版的异常机制。这些异常状态与原版尖塔的虚弱/易伤/缩小等 Debuff **完全独立**——它们有独立的施加途径、衰减规则和免疫机制。

::: tip 与原版 Debuff 的区别
原版的虚弱/易伤/缩小等是通用 Debuff；Seer Mod 的异常状态是独立体系，有专门的"异常免疫"能力（不免疫原版 Debuff，反之亦然）。一个生物可以同时拥有原版 Debuff 和 Seer 异常状态。
:::

## 异常状态清单

### 减伤类（降低攻击伤害）

| 异常 | 核心效果 | 衰减 |
| --- | --- | --- |
| **睡眠** | 攻击伤害降低 **50%**；受到未被格挡的伤害时立即移除 | 回合末 -1 |
| **害怕** | 攻击伤害降低 **30%** | 回合末 -1 |
| **狂暴** | 每层使攻击伤害**增加 25%**（反向增益，Buff 类型） | 回合末 -1 |
| **沸涌** | 受到的攻击伤害**至少为 5**；受到暴击时暴击倍率提升至 **×2**（先反算暴击前伤害，取最大值后再 ×2） | 回合末 -1 |
| **失明** | 攻击时 **50%** 概率自伤（原伤害的 **20%**），**50%** 概率伤害减半（**×50%**） | 回合末 -1 |
| **衰弱** | 每层使**受到的**攻击伤害增加 **25%**（增伤方向，与原版易伤类似但独立） | 回合末 -1 |
| **瘫痪** | 攻击伤害降低 **10%**；回合开始时若上回合未造成伤害，获得虚弱/易伤/缩小各 1 层 | 回合末 -1 |
| **麻痹** | 攻击伤害降低 **10%**；回合开始时获得 1 层易伤 | 回合末 -1 |
| **感染** | 攻击伤害降低 **20%**；回合末获得 **2** 层中毒 | 回合末 -1 |

### 转化类（一种异常转化为另一种）

| 异常 | 核心效果 | 衰减 |
| --- | --- | --- |
| **冰封** | 攻击伤害降低 **20%**；回合结束时移除并转化为 **2** 层冻伤 | 回合末移除并转化 |
| **神游** | 攻击伤害降低 **20%**；回合末获得 **2** 层睡眠 | 回合末 -1 |
| **焚烬** | 攻击伤害降低 **20%**；回合末获得 **2** 层烧伤 | 回合末 -1 |
| **易燃** | 造成攻击伤害降低 **20%**；受到攻击时获得 **2** 层烧伤 | 回合末 -1 |

### 固定伤害类（回合开始扣血）

| 异常 | 核心效果 | 衰减 |
| --- | --- | --- |
| **烧伤** | 回合开始受 **3** 点固定伤害，攻击伤害降低 **1** 点 | 回合开始结算后 -1 |
| **冻伤** | 回合开始受 **5** 点固定伤害 | 回合开始结算后 -1 |
| **中毒** | 回合开始受 **1 + 层数÷2** 点伤害 | 回合开始结算后 -1 |
| **流血** | 回合结束受等于层数的伤害；受未格挡伤害时 +1 层 | 回合末结算伤害后 -1 |
| **寄生** | 回合开始受 **2** 点伤害，所有对手回复 **2** 点生命 | 回合开始结算后 -1 |

### 特殊机制类

| 异常 | 核心效果 | 衰减 |
| --- | --- | --- |
| **沉默** | 若单次伤害超过 **30** 则降至 0；回合末对非玩家造成 1 点伤害 | 回合末 -1 |
| **束缚** | 存在时自身无法获取先制 | 回合末 -1 |
| **石化** | 攻击伤害降低 **70%**；本应造成的伤害 **70%** 转化为自身格挡 | 回合末 -1 |
| **超频** | 回合开始获得 1 层先制；移除时获得 **2** 层瘫痪 | 触发后 -1 |
| **诅咒** | 攻击伤害降低 **10%**；回合开始获得一张诅咒牌；回合结束受 **3-50** 点随机伤害 | 回合末 -1 |
| **臣服** | 攻击伤害降低 **70%**；移除时玩家获得 **2** 张随从牌、怪物获得 **3** 层力量 | 回合末 -1 |

### 特殊：凝滞（增益型异常）

凝滞是唯一的**增益类型**异常状态：

- 免疫所有其它异常状态（但不免疫自身减层）
- **怪物持有时**：回合开始随机无效化一个非攻击意图
- **玩家持有时**：无法额外抽牌（正常抽牌阶段不受影响）
- 回合末 -1

## 衰减规则汇总

异常状态的衰减时机并不统一：

| 衰减时机 | 涉及异常 |
| --- | --- |
| 回合开始结算后 -1 | 烧伤、冻伤、中毒、寄生 |
| 回合末 -1 | 睡眠、害怕、狂暴、沸涌、失明、衰弱、瘫痪、麻痹、感染、沉默、束缚、石化、诅咒、臣服、神游、焚烬、易燃、凝滞 |
| 回合末结算伤害后 -1 | 流血（先受等层数伤害，存活则 -1） |
| 回合开始触发后 -1 | 超频（N 层 = N 个回合开始各触发一次先制，减到 0 移除时给 2 层瘫痪） |
| 一次性移除 | 冰封（回合末移除并转化为 2 层冻伤）、睡眠（受未格挡伤害时立即移除） |

## 异常免疫

以下能力可免疫 Seer 异常状态。注意各能力的**免疫范围和消耗方式差别很大**：

| 能力 | 免疫范围 | 机制 |
| --- | --- | --- |
| [异常免疫](/powers/debuff_immune_power.md) | Seer 异常状态 | 免疫 N 回合（N=层数）；对方回合结束时 -1，不按次数消耗 |
| [异常免疫·反弹](/powers/debuff_immune_reflect_power.md) | Seer 异常状态 | 同上，且免疫时把该异常反弹给所有敌人 |
| [永久异常免疫](/powers/permanent_debuff_immune_power.md) | Seer 异常状态 + 所有原版 Debuff | 永久生效，无层数 |
| [免疫](/powers/immunity_power.md) | Seer 异常状态 + 所有原版 Debuff | 预留能力，当前无获取途径 |
| [次数免疫](/powers/void_plating_power.md) | Seer 异常状态 | 免疫下 N 次异常，每次成功免疫后 -1 层 |
| [支援庇护](/powers/support_immune_count_power.md) | Seer 异常状态 | 受到异常时免疫该次异常并消耗 1 层 |
| [未来奇点](/powers/future_singularity_power.md) | Seer 异常状态 + 所有原版 Debuff | 免疫时消耗 1 层；另有按层数解锁的附带效果 |
| [凝滞](/powers/stasis_power.md) | 其它 Seer 异常状态 | 自身就是一种异常状态；自己回合结束时 -1 |
| [神话](/powers/myth_power.md) | 所有 Seer 异常状态 | 永久生效，无层数（部分怪物自带） |
| [圣谕形态](/powers/divine_form_power.md) | 固定伤害 + Seer 异常状态 | 另有圣诰/邪诲附加效果 |
| [龙胆](/powers/dragon_whisker_power.md) | Seer 异常状态 | 每层：使用牌时对随机敌人造成 1 点固定伤害；受到异常时消耗 1 层抵消 |
| [白色龙鳞](/powers/white_dragon_scale_power.md) | 攻击伤害 / 固定伤害 / 异常 / 属性下降 | 每层免疫一次（各类附带反制效果）；对方回合结束时 -1 |
| [黄色龙鳞](/powers/yellow_dragon_scale_power.md) | Seer 异常状态 | 触发免疫时消除对手基础属性提升，然后自身消失 |
| [罗生门](/powers/rashomon_power.md) | Seer 异常状态 | 5 层；敌方打出 PP 牌时 PP 消耗变为 **3 倍**；对方回合结束时 -1 |
| [传说结界](/powers/legendary_barrier_power.md) | 属性下降（力量/防御/命中/速度/先制） | 详见下方说明 |

::: warning 部分遗物也提供异常免疫
「蓓丽安特」「皮神」（Boss 战）等遗物同样会拦截异常状态的施加，详见各遗物页面。
:::

### 传说结界的特殊行为

传说结界（史莱姆国王招式"传说结界"、暴君史莱姆招式"绝望结界"施加，两者是同一种能力）的实际效果：

- **免疫能力下降**：力量、防御、命中、速度、先制无法被降低（负向修改归零）
- **锁死五种状态**：虚弱、易伤、烧伤、冻伤、中毒的**衰减和移除被拦截**——一旦挂上就永不掉层。例如给它挂上烧伤后，烧伤每回合结算 3 点固定伤害且永久生效，反而是玩家的输出机会
- **冰封特殊**：冰封的"回合末移除并转化为 2 层冻伤"照常触发（移除不走拦截路径），但转化出来的冻伤会被锁死——先上冰封再等它转化，是面对结界怪物的隐藏连招
- 注意：上述状态的**新施加并不被阻挡**（能力描述文本"免疫异常状态"与实际实现存在偏差，以实际行为为准）；其余 19 种异常状态完全不受结界影响

## 施加途径

### 卡牌/怪物招式

- 直接施加异常状态的招式（如比比鼠电火花→烧伤）
- **异变**关键词：打出时对自己施加随机 1 种异常，持续 2 回合
- **炼狱**关键词：伤害翻倍，打出时对自己施加随机 1 种异常，持续 5 回合
- 部分怪物招式附加异常（墨杜萨石化系列、奇幻之粉的多异常等）

### 状态宝石附魔

22 种异常状态都有对应的"状态宝石"附魔——给卡牌附魔后，打出时对目标施加对应异常 N 回合。详见 [附魔机制](./enchantment)。

### 充能球

- 森林充能球：被动施加中毒，激发施加感染
- 海洋充能球：被动施加冻伤，激发施加冰封
- 火山充能球：被动施加烧伤，激发施加焚烬
