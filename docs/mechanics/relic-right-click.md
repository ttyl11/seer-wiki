# 遗物右键点击

遗物右键点击是 Seer Mod 为部分遗物添加的交互机制。原版遗物只能左键查看信息，Mod 通过自定义接口和补丁让部分遗物支持右键触发特殊效果。

::: tip Mod 扩展了什么
- 原版遗物只有左键查看功能，Mod 新增了右键触发功能
- 通过自定义可点击遗物接口声明遗物可点击
- 右键效果通过多人同步 Action 确保...一致
:::

---

## 基本机制

### 接口契约

支持右键的遗物实现可点击接口，声明两个方法：
- **左键点击**：左键点击效果（原版已有，通常为查看信息）
- **右键点击**：右键点击效果（Mod 新增）

### 默认按键

- 默认使用**右键**触发
- 通过 Godot 的界面输入信号捕获鼠标输入
- 当检测到右键按下且事件来源为遗物类型时，分发到右键点击处理

### 多人同步

- 右键点击通过专用同步动作进行多人同步
- 使用动作队列同步器入队
- 确保多端同时触发右键效果

## 支持右键的遗物

### 元素核心（遗物宝库）

目前唯一实现右键功能的遗物是**元素核心**：

- **触发位置**：局外（非战斗中）
- **触发条件**：尚未从宝库中选择遗物时（只能触发一次）
- **效果**：弹出遗物选择界面，展示 30 个遗物供玩家选择
- **遗物构成**：14 普通 + 8 罕见 + 5 稀有 + 2 史诗 + 1 传说
- **HP 倍率**：不同稀有度的遗物对应不同的最大生命值倍率

| 稀有度 | HP 倍率 | 数量 |
| --- | --- | --- |
| 普通 | 0.8 | 14 |
| 罕见 | 1.0 | 8 |
| 稀有 | 1.2 | 5 |
| 史诗 | 1.5 | 2 |
| 传说 | 1.8 | 1 |

::: tip 遗物宝库的战略意义
元素核心的右键宝库是 Mod 独有的遗物获取途径。30 选 1 的宝库让玩家可以根据当前构筑选择最合适的遗物。传说稀有度的遗物 HP 倍率高达 1.8，是最强的选择。
:::

### 怪物能力配置

选择遗物后，游戏还会根据所选稀有度，按概率给怪物配置各种额外能力（共 63 种），稀有度越高，怪物获得的能力越强、越多。能力系列包括：

| 系列 | 代表能力 | 效果 |
| --- | --- | --- |
| 强体系列 | 强体一/二/三 | 提升怪物属性 |
| 侵蚀系列 | 侵蚀一/二 | 增加玩家赛尔卡 PP 消耗 |
| 城守系列 | 城守一/二/三 | 提升怪物防御 |
| 吸血系列 | 吸血一/二/三 | 怪物攻击回血 |
| 复活系列 | 复活一/二/三 | 怪物死亡后复活 |
| 要害系列 | 要害一/二/三 | 提升怪物暴击 |
| 迅捷系列 | 迅捷一/二 | 提升怪物速度 |
| 生命气息系列 | 生命气息一/二/三 | 怪物回血 |
| 其它 | 暗滞、吸魂、逆转吞噬、神话、硬化、决心、格挡系列 | 各类特殊能力 |

::: warning 高稀有度 = 高难度
选择传说遗物不仅让敌人血量 +80%，还会让怪物获得更多更强的额外能力。这是"选强敌换强遗物"的风险/收益权衡——遗物越强，战斗越难。
:::

## 真神牌堆的右键

真神牌堆也支持右键交互，但使用的是独立的补丁机制（非可点击遗物接口）：

- **触发位置**：真神牌堆界面中
- **触发方式**：右键点击牌堆中的卡牌
- **效果**：将卡牌从真神牌堆移到当前战斗手牌
- **同步方式**：通过专用同步动作同步

详见 [真神牌堆](./true-god-pile)。

## 技术实现

### 补丁接入

- 补丁目标：遗物节点设置模型时
- 接入方式：若遗物实现了可点击接口，则连接界面输入信号到处理方法
- 信号处理：处理方法检测鼠标按键，右键时分发到右键点击处理

### 与原版的兼容性

- 不修改原版遗物的行为
- 只有实现了可点击遗物接口的 Mod 遗物才支持右键
- 原版遗物不受影响
