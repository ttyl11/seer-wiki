# 生成

> 原版状态

## 基本信息

- **类型**: 原版状态
- **本地化来源**: `static_hover_tips.json`

## 描述

生成充能球会将其放入你的第一个空着的充能球栏位。如果栏位已满，则你的第一个充能球将会被自动[激发](/mechanics/evoke.md)，腾出栏位。

## 详细机制

- **充能球栏位**：玩家拥有固定数量的充能球栏位（默认 3 个，可被遗物/能力增加）
- **生成流程**：将充能球放入第一个空栏位
- **栏位已满时**：自动激发最早放入的充能球（第一个栏位），触发其激发效果，然后放入新生成的充能球

## 相关机制

- [激发](/mechanics/evoke.md)（栏位已满时自动激发）
- [充能球](/mechanics/orb.md)（生成的对象）
