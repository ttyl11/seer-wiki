# 重放

> 原版状态

## 基本信息

- **类型**: 原版状态
- **枚举值**: 动态重放（=14）/ 静态重放（=15）
- **本地化来源**: static_hover_tips.json

## 描述

- **重放（动态）**：将这张牌额外打出<span style="color:#3aa675;font-weight:600">X</span>次（X 为动态变量，由来源决定）。
- **重放（静态）**：将这张牌额外打出一次。

## 详细机制

- **重放（Replay）**：带有重放状态的卡牌在打出后，会额外被重新打出指定次数。
- **动态重放**：重放次数可被能力或附魔修改。
- **静态重放（ReplayStatic）**：固定重放一次，不受变量影响。
- **触发时机**：卡牌打出后，根据重放次数自动重新打出。
