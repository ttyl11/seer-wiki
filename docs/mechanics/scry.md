# 预见

预见是 Seer Mod 的自定义卡牌关键词，打出时查看抽牌堆顶 N 张牌，可选择丢弃其中任意数量。它是 Mod 独有的牌堆操控机制，帮助玩家优化牌堆顺序。

::: tip Mod 扩展了什么
- 原版有"预见"（Scry）机制但仅限个别卡牌，Mod 将其注册为通用关键词，可附加到任意卡牌
- 预见在卡牌打出时、主效果之前触发，可以先行清理牌堆顶不需要的牌
- 预见数值通过卡牌动态变量配置，升级可提升预见数量
:::

---

## 基本信息

| 属性 | 值 |
| --- | --- |
| 类型 | Mod 卡牌关键词（静态关键词，不走 flag 系统） |
| 触发时机 | 卡牌打出时，在主效果之前 |
| 查看目标 | 抽牌堆顶 N 张 |
| N 的来源 | 卡牌的预见数值 |
| 操作选项 | 丢弃其中任意数量，或全部保留 |

---

## 触发流程

1. **取牌堆顶 N 张**：从抽牌堆顶部取出 N 张牌（N = 预见数值）
2. **弹出选择面板**：展示这 N 张牌的卡牌选择界面
3. **玩家选择丢弃**：玩家可选中任意数量的牌进行丢弃
4. **丢弃处理**：选中的牌进入弃牌堆
5. **保留处理**：未选中的牌保留在抽牌堆顶，顺序不变

::: tip 预见 vs 抽牌
预见只是"查看"牌堆顶的牌，不会将牌加入手牌。你可以选择丢弃其中的牌来优化牌堆顺序，但不选的牌仍在抽牌堆顶——下一回合抽牌时仍会抽到。
:::

---

## 预见数值

预见数值（N）来自卡牌的动态变量配置，不同卡牌的预见数值不同：

| 卡牌 | 预见数值 | 说明 |
| --- | --- | --- |
| 拨乱反正 | 1 | 查看顶 1 张 |
| 虚无 | 2 | 查看顶 2 张 |
| 无尽执念 | 3 | 查看顶 3 张 |
| 多重时间线 | 0 → 1 | 基础 0，升级后 1 |

- **预见数值为 0**：不会触发预见效果（无牌可看）
- **升级提升**：部分卡牌升级后预见数值 +1
- **遗物触发**：部分遗物（如诸葛遗物）也可直接调用预见命令

## 预见的战略价值

### 牌堆顺序优化

- 预见让你提前看到牌堆顶的牌，丢弃不需要的牌
- 保留的牌顺序不变，可以精确规划下回合的抽牌
- 适合配合"保留"型卡牌或特定顺序触发型卡牌

### 弃牌堆操控

- 丢弃的牌进入弃牌堆，可被"从弃牌堆抽牌"类效果利用
- 配合"戏法"关键词（从弃牌堆随机抽一张），可以变废为宝
- 配合消耗堆相关效果，可以加速特定牌的回收

### 信息优势

- 预见提供牌堆信息，帮助判断接下来的战斗节奏
- 知道下回合会抽到什么牌，可以更好地规划当前回合的出牌

## 预见与其它机制的配合

### 与"保留"关键词

保留型卡牌每回合留在手牌中不弃掉。预见可以帮你保留关键牌的同时，清理牌堆顶的干扰牌。

### 与"回响"关键词

回响牌每回合开始加入手牌。预见可以清理牌堆顶的低价值牌，确保回响牌之外的好牌也能被抽到。

### 与抽牌堆操控

预见本身不改变牌堆顺序（只丢弃或保留），但配合其他牌堆操控手段（如放回牌堆顶、洗牌等），可以实现更精确的牌堆管理。
