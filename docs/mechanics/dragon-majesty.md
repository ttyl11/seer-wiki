# 龙威

龙威是 Seer Mod 中哈莫雷特持有的核心被动能力，包含三段机制：开局按牌组中龙牌数量加全属性、打出与上一张不同类型的牌则重放、相同则无效。

::: tip Mod 扩展了什么
- 原版没有"类型匹配重放/无效"型能力，龙威是 Mod 独创的出牌限制机制
- 龙威同时具备开局属性加成和出牌类型匹配两段效果
- 配合回避招式可恢复到历史峰值属性，形成"打不死的龙"体验
:::

---

## 基本信息

| 属性 | 值 |
| --- | --- |
| 能力类型 | Power（不属于 Buff/Debuff，不会被清除） |
| 持有者 | 哈莫雷特（第三层精英怪） |
| 触发对象 | 玩家打出的牌 |
| 核心机制 | 类型匹配重放/无效 + 开局属性加成 |

---

## 三段机制

### 第一段：开局属性加成

- **触发时机**：战斗开始时
- **加成计算**：统计玩家牌组中"龙"牌的数量，对自身施加等量的力量、防御、命中、速度
- **龙牌判定**：卡牌类名包含 `"Dragon"` 或 `"龙"` 即为龙牌
- **属性累积**：与[角色卡牌标签](./card-tags)中的龙标签配合

::: tip 龙牌越多越强
玩家牌组中龙牌越多，哈莫雷特开局的全属性加成越高。如果牌组中有 10 张龙牌，哈莫雷特开局获得 10 点力量 + 10 点防御 + 10 点命中 + 10 点速度——极为强大。
:::

### 第二段：类型匹配——不同则重放

- **触发时机**：玩家打出牌时
- **判定条件**：打出的牌与上一张打出的牌**类型不同**（攻击 vs 技能 vs 能力）
- **效果**：此牌重放一次（打出两次）
- **第一张牌**：无上一张类型记录，正常打出

### 第三段：类型匹配——相同则无效

- **触发时机**：玩家打出牌时
- **判定条件**：打出的牌与上一张打出的牌**类型相同**
- **效果**：此牌无效（跳过打出效果，相当于没打出）
- **类型记录**：无论有效还是无效，都会更新"上一张牌类型"

::: warning 类型匹配的节奏
龙威迫使玩家交替出不同类型的牌：
- 攻击 → 技能 → 攻击 → 技能 → ...（每张都重放，输出翻倍）
- 攻击 → 攻击 → ...（第二张无效，输出减半）
- 能力牌通常只能打出一张（第二张相同类型会无效）

能力牌（Power）打出后持续到战斗结束，无法"重放"。如果第一张是能力牌，第二张也是能力牌，第二张会无效。
:::

## 历史峰值属性

龙威还维护一个**历史峰值属性**记录：

- **记录时机**：每回合开始和回合结束时
- **记录内容**：取力量、防御、命中、速度四种属性的最大值
- **用途**：配合哈莫雷特的"回避"招式，可恢复到历史峰值属性

### 回避招式

哈莫雷特的"回避"招式：
1. 获得 1 层缓冲
2. 从龙威能力读取历史峰值属性
3. 将当前属性恢复到历史峰值

这意味着即使玩家削弱了哈莫雷特的属性，它也可以通过回避恢复到巅峰状态。

---

## 哈莫雷特的其它招式

龙威只是哈莫雷特的五个招式之一：

| 招式 | 效果 |
| --- | --- |
| 龙威 | 被动能力（开局施加，持续整场战斗） |
| 龙王灭碎阵 | 20 伤害 + 给玩家手牌加 5 张碎屑 |
| 龙之意志 | 翻倍自身四种正向属性 |
| 龙王波 | 7 伤害 × 2，附加龙王波能力 |
| 回避 | 1 层缓冲 + 恢复到历史峰值属性 |

## 战略要点

### 应对类型匹配

- **交替出牌**：攻击 → 技能 → 攻击 → 技能，每张都重放，输出最大化
- **避免连续同类型**：连续出同类型牌会导致后续牌无效
- **能力牌时机**：能力牌最好在类型切换时打出（如攻击 → 能力 → 技能）

### 削弱龙牌数量

- 龙威的开局属性加成取决于牌组中龙牌数量
- 减少牌组中的龙牌可以降低哈莫雷特的开局属性
- 但龙牌本身可能很强力，需要权衡

### 应对回避

- 回避让哈莫雷特恢复到历史峰值属性
- 需要在回避后再次削弱属性
- 或通过固定伤害、异常状态等不依赖属性差的手段输出

### 龙王波的威胁

- 龙王波造成 7 伤害 × 2 段，并附加龙王波能力
- 龙王波能力会持续造成伤害
- 需要优先清除龙王波能力或通过格挡抵消
