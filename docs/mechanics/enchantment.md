# 附魔

附魔是附加到卡牌上的特殊修饰，使卡牌在打出时触发额外效果。一张卡牌只能拥有一个附魔。Seer Mod 在原版附魔系统基础上，新增了**状态宝石**和**特殊附魔**两大类。

::: tip Mod 扩展了什么
- **状态宝石**（22 种）：打出时对目标施加对应异常状态 N 回合
- **特殊附魔**（9 种）：注能、冷却时间、星皇之怒、永耀、五音系列（仐囙乂册卩）
:::

---

## 状态宝石

状态宝石是一类统一规则的附魔——**打出时对目标施加对应异常状态 N 回合**。N 的数值随附魔等级提升。

::: warning 自身施加的宝石
**狂暴宝石**和**超频宝石**是对**自身**施加异常状态，而非目标。这是因为狂暴和超频本质上是增益型异常。
:::

### 状态宝石的统一规则

- **持续回合数**：统一为 3 回合（N = 3）
- **施加时机**：打出时
- **目标**：默认对目标施加（狂暴/超频对自身）
- **可被异常免疫**：目标有异常免疫时，施加无效

## 特殊附魔

特殊附魔有各自独立的规则，不遵循状态宝石的统一模式。

### 注能

- **效果**：这张牌在每场战斗开始时自动打出
- **定位**：让关键起手牌每战自动触发，节省手牌

### 冷却时间

- **效果**：这张牌获得"重放"+N，然后消耗
- **定位**：让一次性卡牌可以多次使用，但每次使用后进入消耗

### 星皇之怒

- **效果**：第一次打出此牌后，此牌获得"重放"+N
- **定位**：让卡牌首打后自动重放 N 次，形成爆发

### 永耀

- **效果**：此类牌拥有"保留"关键词，但所有"永耀"牌每回合只能打出一张
- **定位**：永耀牌可以保留在手牌中，但每回合只能用一张——适合作为"保底输出"

### 五音系列

五音系列是 5 个单字命名的附魔，打出后触发各自效果：

| 附魔 | 效果 |
| --- | --- |
| **仐** | 打出后，自身先制 +1 |
| **囙** | 打出后，自身所有 PP 恢复 1 点 |
| **乂** | 打出后，解除自身所有异常状态 |
| **册** | 打出后，减少对手 10% 当前生命，自身恢复等量生命 |
| **卩** | 打出后，若以此牌击败对手，自身最大生命 -20，造成的攻击伤害永久 +10%，受到的伤害永久 -10%（可叠加） |

::: tip 卩的成长性
卩是唯一有"永久成长"效果的附魔——击败对手后永久增伤减伤。适合作为 Boss 击杀流的核心。
:::

## 附魔的施加途径

- **神谕充能球**：激发时随机为一张手牌施加随机附魔
- **部分卡牌/遗物**：直接施加特定附魔
- **事件/商店**：部分事件/商店提供附魔服务

## 附魔与卡牌类型的兼容性

部分卡牌类型对附魔有特殊限制：

- **诅咒/状态牌**：部分附魔可能无法施加（需检查兼容性）
- **衍生牌**：通常可以附魔
- **任务牌**：视具体附魔而定
