# 湮灭

湮灭是 Seer Mod 的自定义卡牌关键词，打出后对所有敌人结算"邪诲"与"圣诰"的配对伤害。它是一个独立的伤害子系统，不消耗层数，剩余保留。

::: tip Mod 扩展了什么
- 原版没有"配对结算"型关键词，湮灭是 Mod 独创的配对伤害机制
- 邪诲与圣诰是两种配套的 Debuff，缺一不可，配对后才触发伤害
- 伤害不消耗层数，剩余保留——可以多次触发
:::

---

## 基本信息

| 属性 | 值 |
| --- | --- |
| 类型 | Mod 卡牌关键词（静态关键词，不走 flag 系统） |
| 触发时机 | 卡牌打出后 |
| 伤害类型 | 非攻击伤害（Unpowered），不受力量/虚弱/易伤影响 |
| 每组伤害 | 8 点 |
| 层数消耗 | 不消耗，剩余保留 |

---

## 触发规则

### 配对机制

湮灭的核心是**邪诲与圣诰的配对**：

- 对每个敌人分别检查其身上的**邪诲**层数和**圣诰**层数
- 配对数 = `min(邪诲层数, 圣诰层数)`
- 缺一不可：若敌人身上只有邪诲没有圣诰（或反之），不会触发任何伤害
- 每组配对造成 8 点伤害
- 总伤害 = `配对数 × 8`

### 结算方式

- **逐组结算**：伤害一组一组触发，每组单独结算
- **中途死亡停止**：若敌人在结算过程中死亡，立即停止对该敌人的后续伤害
- **非攻击伤害**：使用 Unpowered 伤害类型，不受力量加成、不受虚弱削减、不受易伤放大
- **层数不消耗**：结算后邪诲和圣诰的层数均保留，下次湮灭仍可配对

::: warning 与固定伤害的区别
湮灭造成的伤害是**非攻击伤害（Unpowered）**，不是[固定伤害](./fixed-damage)。固定伤害是延迟到下回合结算的 Debuff 能力，而湮灭是打出时立即结算的直接伤害。两者机制完全不同。
:::

## 邪诲

邪诲是湮灭配对所需的两种 Debuff 之一。

| 属性 | 值 |
| --- | --- |
| 状态类型 | Debuff |
| 叠加方式 | 计数器（Counter） |
| 核心效果 | 持有者受到攻击时，伤害来源恢复相当于伤害 20% 的体力 |
| 衰减条件 | 受到的伤害低于此状态层数的 50% 时，减少一层 |

### 邪诲的施加来源

| 来源 | 施加方式 |
| --- | --- |
| 邪魇形态 | 攻击造成伤害时，对目标施加 1 层邪诲 |
| 圣谕形态 | 受到攻击伤害时，对攻击者施加 1 层邪诲 |
| 净世新生 | 恢复生命时，对所有敌人施加 3 层邪诲 |

---

## 圣诰

圣诰是湮灭配对所需的另一种 Debuff。

| 属性 | 值 |
| --- | --- |
| 状态类型 | Debuff |
| 叠加方式 | 计数器（Counter） |
| 核心效果 | 持有者受到攻击时，60% 概率施加疲惫 2 回合 |
| 衰减条件 | 受到的伤害低于此状态层数的 50% 时，减少一层 |

### 圣诰的施加来源

| 来源 | 施加方式 |
| --- | --- |
| 圣谕形态 | 造成攻击伤害时，对目标施加 1 层圣诰 |
| 邪魇形态 | 受到敌人伤害时，对伤害来源施加 1 层圣诰 |
| 神明送葬 | 受到伤害时，对所有敌人施加 3 层圣诰 |

---

## 配对入口：圣谕形态与邪魇形态

圣谕形态和邪魇形态是湮灭配对的主要入口，它们可以同时施加邪诲和圣诰：

### 圣谕形态

- 免疫固定伤害和异常状态
- 造成攻击伤害时，为对手附加 1 层圣诰
- 受到攻击伤害时，为攻击者附加 1 层邪诲

### 邪魇形态

- 攻击造成伤害时，对目标施加 1 层邪诲
- 受到敌人伤害时，对伤害来源施加 1 层圣诰

::: tip 配对策略
要触发湮灭，敌人需要同时拥有邪诲和圣诰。最直接的方式是让敌人持有圣谕形态或邪魇形态——这两种形态在攻防两端都会施加配套的邪诲/圣诰，自然形成配对。
:::

## 战略要点

### 高伤害潜力

由于层数不消耗，多次打出湮灭牌可以反复利用已积累的邪诲/圣诰：
- 敌人身上有 5 层邪诲 + 5 层圣诰 → 每次湮灭造成 40 点伤害
- 第二次湮灭仍造成 40 点伤害（层数未消耗）
- 适合作为持续输出手段

### 非攻击伤害优势

湮灭的伤害是 Unpowered 类型：
- 不受力量削减（对有虚弱/力量降低的玩家有利）
- 不受易伤放大（无法通过易伤增伤）
- 不受格挡减免（可被格挡，但伤害类型特殊）

### 配对前提

湮灭的伤害完全依赖邪诲和圣诰的配对：
- 只施加邪诲不施加圣诰（或反之）不会触发任何伤害
- 需要先通过其他手段在敌人身上积累两种 Debuff
- 圣谕形态/邪魇形态是最稳定的配对来源
