# 元素克制

Seer Mod 引入了赛尔号原版的元素克制系统。**26 种元素**构成完整的克制表，影响攻击伤害的最终结算。

::: tip 这是赛尔号的灵魂
如果你玩过赛尔号，这套元素克制关系你应该很熟悉——草克水、水克火、火克草……Seer Mod 完整还原了这套体系，让每场战斗都有"选对属性"的策略层。
:::

## 克制倍率

元素克制只影响**攻击伤害**的乘法结算，三种倍率：

| 关系 | 倍率 | 说明 |
| --- | --- | --- |
| 克制对方 | **×1.5** | 攻击伤害提升 50% |
| 被对方克制 | **×0.75** | 攻击伤害降低 25% |
| 中性 | **×1.0** | 无克制关系时不修正 |

::: warning 龙系是双向特例
龙系的克制表与其它 25 种元素不同，**只对龙系自身生效**——即只有"龙系作为攻击方"时才查阅此表：

- 龙系**克制**（×1.5）：冰、龙、圣灵、邪灵
- 龙系**被克**（×0.5）：草、水、火、电、远古、虫

其它 25 种元素攻击龙系目标时，**走该攻击方元素自身的克制表**，不存在"任何元素打龙系都减半"的规则。例如草系攻击龙系走草系自身的克制表（默认 ×1.0，因为草系表为空）。
:::

::: warning 只影响攻击伤害
元素克制**只作用于攻击伤害**（卡牌/怪物招式造成的伤害）。以下伤害类型**不受元素克制影响**：

- 异常状态的持续伤害（中毒、烧伤、冻伤等回合结算伤害）
- 固定伤害
- 充能球伤害
- 荆棘、反伤等被动伤害
- 生命流失效果
:::

## 属性分配机制

战斗开始时，每个生物会获得随机元素属性：

- **玩家**：每场战斗随机分配一种元素
- **敌人**：每场战斗随机分配一种元素
- 元素属性以"元素能力"形式存在，是**中性属性**（不是 Buff 也不是 Debuff），不会被消除 Buff/Debuff 类效果清除

## 克制表查询

每个元素对应一个"元素能力"，该能力内置了对其它 25 种元素的克制倍率表。例如：

- **远古** 克制：草、飞行、神秘、龙、虚空（×1.5）
- **远古** 被克：机械、冰、王、轮回（×0.75）
- **虫** 克制：草、地面、战斗、混沌、虫（×1.5）
- **虫** 被克：水、火、冰、光（×0.75）

完整的 26×26 克制表可在游戏内通过元素能力的悬浮提示查看，或参考赛尔号原版克制关系。

## 战略意义

- **选对属性打**：克制时伤害 ×1.5，是重要的输出提升手段
- **避开被克目标**：被克时伤害 ×0.75，相当于浪费了 1/4 伤害
- **龙系是双刃剑**：龙系攻击方克冰/龙/圣灵/邪灵（×1.5），但被草/水/火/电/远古/虫克（×0.5）；其它元素打龙系走各自克制表（多为 ×1.0）
- **元素是随机的**：每场战斗的元素分配不同，需要根据当局属性调整策略

## 局外宝库与怪物能力配置

群星的礼赠的右键宝库和对应的怪物能力配置详见 [遗物右键点击](./relic-right-click)。选择的遗物稀有度只影响敌人最大生命值；怪物额外能力（强体/侵蚀/城守/吸血/复活等 63 种）的概率随探索房间数累积，与宝库选择无关。
