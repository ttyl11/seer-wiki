# 消耗

> 原版关键词

## 基本信息

- **类型**: 卡牌关键词
- **枚举值**: 1

## 描述

在战斗结束前移除。

## 详细机制

- **打出时消耗**：带有"消耗"关键词的卡牌在被打出后，会从手牌移到消耗堆，而不是弃牌堆。
- **战斗结束恢复**：战斗结束后，消耗堆中的卡牌会恢复到牌组中，不会永久丢失。
- **消耗堆查看**：战斗中可以点击消耗堆图标查看已被消耗的卡牌。
- **自动添加描述**：卡牌带有此关键词时，描述中会自动显示"消耗"文本。
