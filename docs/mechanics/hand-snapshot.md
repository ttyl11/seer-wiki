# 手牌快照

手牌快照是 Seer Mod 的底层基础设施机制，在卡牌打出时记录手牌状态，供"根据手牌位置触发效果"的关键词使用。它本身不是玩家可见的机制，但支撑了薇尔诗等关键词的正常运作。

::: tip Mod 扩展了什么
- 原版没有"手牌快照"机制，打出牌后手牌立即变化，无法回溯打出前的状态
- Mod 通过补丁在卡牌打出前抓取手牌快照，让位置型关键词能正确判定
- 快照使用弱引用表关联卡牌实例，随卡牌 GC 自动清理
:::

---

## 为什么需要手牌快照

### 问题背景

卡牌打出时，它会立即从手牌中移除。如果效果需要根据"打出牌在手牌中的位置"来触发，打出后手牌已经变化，位置信息丢失。

### 解决方案

在卡牌打出流程的**最开始**（打出包装器执行之前）抓取手牌快照：
- 快照记录此时手牌中所有卡牌的完整列表和顺序
- 后续的位置判定使用快照，而非实时手牌
- 确保位置判定基于打出前的真实手牌状态

---

## 快照的工作流程

### 1. 抓取快照

- **时机**：卡牌打出流程的最开始（打出包装器执行之前）
- **内容**：当前手牌中所有卡牌的列表副本
- **关联**：使用弱引用表将卡牌实例与快照关联，随卡牌回收自动清理

### 2. 查询快照

- **接口**：通过查询接口获取打出牌关联的手牌快照
- **返回**：打出牌关联的手牌快照（打出前的手牌状态）
- **使用方**：薇尔诗等位置型关键词的效果管理器

### 3. 位置判定

使用快照中的手牌列表计算位置关系：
- 取出打出牌在手牌中的位置序号
- 记录打出前的手牌总数量
- 遍历快照中的手牌查找特定关键词的卡牌（如薇尔诗牌）
- 计算其余牌与打出牌的位置距离（取绝对值）

---

## 使用快照的关键词

### 薇尔诗

薇尔诗关键词的三种位置免疫完全依赖手牌快照：

- **相邻（距离 = 1）**：打出牌与薇尔诗牌在快照中相邻 → 免疫全属性下降
- **隔位（距离 = 2）**：打出牌与薇尔诗牌在快照中隔一位 → 免疫异常状态
- **首末位**：打出牌在快照中位于首位或末位 → 免疫固定伤害

详见 [薇尔诗](./vier-poem)。

### 薇（相邻自动打出）

薇关键词的相邻判定也优先使用手牌快照：
- 检查打出牌在快照中的相邻位置是否有"薇"牌
- 若快照不可用，回退到当前手牌

---

## 快照的内存管理

- **弱引用关联**：使用弱引用表关联卡牌实例与快照
- **自动清理**：卡牌实例被系统回收时，关联的快照自动清理
- **无内存泄漏**：不需要手动清理快照

---

## 战略意义（间接）

手牌快照本身不是玩家可直接利用的机制，但它确保了位置型关键词的可靠性：

- **薇尔诗的稳定性**：快照保证薇尔诗的位置判定不受打出过程中手牌变化的影响
- **出牌顺序的意义**：由于快照记录的是打出前的手牌状态，玩家的出牌顺序规划是有意义的——先出什么牌、后出什么牌，会影响位置判定
- **配合手牌操控**：通过抽牌、弃牌等手段调整手牌顺序，可以精确控制薇尔诗的位置触发
