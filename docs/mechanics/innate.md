# 固有

> 原版关键词

## 基本信息

- **类型**: 卡牌关键词
- **枚举值**: 3

## 描述

每场战斗开始时这张牌会出现在你的[手牌](/mechanics/hand.md)。

## 详细机制

- **战斗开始触发**：每场战斗开始时，带有"固有"关键词的卡牌会自动从抽牌堆移到手牌。
- **多张固有**：如果牌组中有多张固有牌，它们都会在战斗开始时出现在手牌。固有牌的数量受手牌上限限制。
- **与抽牌独立**：固有牌的抽取不占用每回合 5 张的正常抽牌数。
- **自动添加描述**：卡牌带有此关键词时，描述中会自动显示"固有"文本。
