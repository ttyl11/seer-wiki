# 虚无

> 原版关键词

## 基本信息

- **类型**: 卡牌关键词
- **枚举值**: 2

## 描述

如果这张牌在这个回合结束时留在你的[手牌](/mechanics/hand.md)中，则将其[消耗](/mechanics/exhaust.md)。

## 详细机制

- **回合结束触发**：在回合结束阶段，如果带有"虚无"关键词的卡牌仍在手牌中，则自动消耗该牌。
- **与保留互斥**：如果卡牌同时带有"保留"关键词，"保留"优先，卡牌不会被消耗。
- **自动添加描述**：卡牌带有此关键词时，描述中会自动显示"虚无"文本。
- **打出不消耗**：虚无只在没有被打出时触发，如果打出了该牌则按牌的效果处理。
