# 空元之诗

空元之诗是 Seer Mod 的自定义卡牌关键词，打出时消耗"空妄诗章"，随机触发渍、镀、柱、烙、均五种效果之一。每多打出一次，触发效果种类递增——第 1 次触发 1 种，第 2 次触发 2 种，以此类推。

::: tip Mod 扩展了什么
- 原版没有"递增触发"型关键词，空元之诗是 Mod 独创的累积触发机制
- 空妄诗章是关键词配套的专属计数资源，通过击杀敌人积累
- 五种效果覆盖伤害、防御、恢复、控制多个维度，随机性带来不确定性
:::

---

## 基本信息

| 属性 | 值 |
| --- | --- |
| 类型 | Mod 卡牌关键词（静态关键词，不走 flag 系统） |
| 触发时机 | 卡牌打出后 |
| 前置条件 | 自身持有空妄诗章（诗章 > 0） |
| 计数资源 | 空妄诗章 |
| 效果种类 | 5 种（渍/镀/柱/烙/均） |

## 空妄诗章

空妄诗章是空元之诗关键词的专属计数资源，每打出一次空元之诗牌消耗一篇。

### 获取方式

- **击杀敌人**：敌方怪物死亡或消逝时，空妄诗章 +1，同时获得该怪物最大生命 3% 的最大生命值
- **复活免费**：持有者死亡复活后，下一次打出空元之诗不消耗诗章

### 消耗规则

- 每打出一次空元之诗牌，扣除一篇空妄诗章
- 诗章为 0 时，打出空元之诗牌不会触发任何效果
- 复活后的第一次打出免费（不消耗诗章）

## 五种效果

空元之诗打出时，从五种效果中随机选取触发。选取方式为：将 5 种效果的索引洗牌后取前 N 个（N = 本次是第几次打出）。

### ①渍

- **效果**：所有敌人诅咒 3 回合
- **定位**：群体控制，让敌人无法出牌
- **目标**：所有敌人

### ②镀

- **效果**：免疫下两次异常状态
- **定位**：防御型效果，保护自身免受异常状态干扰
- **目标**：自身
- **机制**：施加 2 层免疫异常状态的能力，每次被施加异常状态时消耗 1 层

### ③柱

- **效果**：每个敌人意图数 × 3 点固定伤害（随机分配）
- **定位**：意图越多伤害越高，克制多段攻击型敌人
- **目标**：随机敌人
- **伤害类型**：固定伤害（延迟到目标下回合开始结算）

::: warning 注意
③柱造成的固定伤害严格遵循 Mod 的固定伤害规则——通过施加固定伤害能力实现，目标下回合开始时才受到伤害，可被免疫固定伤害效果抵挡。
:::

### ④烙

- **效果**：每剩余 1 PP 恢复 3 生命
- **定位**：恢复型效果，PP 越多恢复越多
- **目标**：自身
- **前提**：打出牌需为 PP 卡牌，且当前有剩余 PP

### ⑤均

- **效果**：对随机敌人造成自身与其体力之差 50% 的固定伤害
- **定位**：斩杀型效果，自身血量越高于敌人，伤害越高
- **目标**：随机敌人
- **伤害类型**：固定伤害（延迟结算）
- **计算公式**：`伤害 = (自身当前生命 - 目标当前生命) × 50%`

::: tip ⑤均的使用技巧
⑤均在自身满血、敌人残血时伤害最高。例如自身 100 血、敌人 20 血时，造成 40 点固定伤害。适合在战斗后期收割残血敌人。
:::

## 递增触发机制

空元之诗的触发种类随打出次数递增：

| 打出次数 | 触发效果数 | 说明 |
| --- | --- | --- |
| 第 1 次 | 1 种 | 随机触发 5 种效果中的 1 种 |
| 第 2 次 | 2 种 | 随机触发 5 种效果中的 2 种 |
| 第 3 次 | 3 种 | 随机触发 5 种效果中的 3 种 |
| 第 4 次 | 4 种 | 随机触发 5 种效果中的 4 种 |
| 第 5 次及以上 | 5 种 | 触发全部 5 种效果 |

- **触发计数**：每场战斗独立计算，从 0 开始累计
- **随机选取**：每次打出时，将 5 种效果的索引洗牌，取前 N 个依次触发
- **多人同步**：洗牌使用同步 RNG，确保多端结果一致

## 空元之诗牌的分配

空元之诗关键词不是卡牌固有的，而是通过"空元行者"遗物动态分配的：

1. **战斗开始时**：遗物根据空妄诗章数量，从牌组中随机选取等量的卡牌，为它们附加空元之诗关键词
2. **选取方式**：Fisher-Yates 部分洗牌，确保多端同步
3. **持续到战斗结束**：附加的关键词在整场战斗中持续有效

::: tip 空元行者遗物
空元之诗关键词的载体是"空元行者"遗物。该遗物有四大效果：空元之铭、空元之录、空元之渎、空元之诗。其中空元之录负责积累空妄诗章（击杀敌人 +1），空元之诗负责在战斗中分配关键词和触发效果。
:::

## 战略要点

### 诗章积累

- 空妄诗章通过击杀敌人积累，前期需要尽快击杀小怪积攒诗章
- 诗章越多，战斗中分配的空元之诗牌越多，触发机会越大
- 复活后的免费触发是宝贵机会，要善加利用

### 递增爆发的节奏

- 前几次打出只触发 1-2 种效果，伤害有限
- 第 5 次以后触发全部 5 种效果，是爆发点
- 需要配合多打牌手段（如重放、回响）快速累积打出次数

### 效果随机性

- 每次触发的效果种类随机，无法指定
- ③柱和⑤均造成的固定伤害可被免疫固定伤害效果抵挡
- ④烙的恢复量取决于剩余 PP，需配合 PP 管理手段
