# 饮血

> mod 关键词

## 基本信息

- **类型**: mod 卡牌关键词
- **来源**: mod 自定义关键词

## 描述

此牌造成的伤害回复你 <span style="color:#3aa675;font-weight:600">20</span>% 的生命值。

## 详细机制

- **触发时机**：在造成伤害后触发，检查伤害来源卡牌是否带有饮血关键词。
- **触发条件**：
  1. 伤害来源存在且为攻击伤害
  2. 实际造成伤害大于 0
  3. 伤害来源是卡牌拥有者自身
  4. 卡牌带有饮血关键词
- **回复量**：实际伤害的 20%（向下取整，至少 1 才回复）。
- **回复方式**：回复伤害来源的生命值。
- **即时触发**：在伤害造成时立即触发，不需要等待卡牌打出完毕。即使伤害终结了对手，饮血效果仍会触发。
