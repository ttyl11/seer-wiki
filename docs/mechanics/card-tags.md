# 角色卡牌标签

角色卡牌标签是 Seer Mod 通过 RitsuLib 注册的自定义 CardTag 系统，为 5 种原版角色分别定义专属标签，实现"仅对某角色生效"的卡牌过滤机制。

::: tip Mod 扩展了什么
- 原版有 CardTag 系统但种类有限，Mod 注册了 5 个角色专属 CardTag
- 通过标签过滤，实现卡牌"仅对某角色生效"的效果
- 标签 ID 使用 XxHash32 确定性生成，多端天然一致无需网络同步
:::

---

## 5 种角色标签

Mod 为杀戮尖塔2 的 5 种原版角色分别注册了专属 CardTag：

| 标签名 | 对应角色 |
| --- | --- |
| Ironclad | 铁甲战士 |
| Silent | 静默猎手 |
| Defect | 缺陷机器人 |
| Regent | 摄政者 |
| Necrobinder | 死灵术士 |

::: warning 角色名称说明
杀戮尖塔2 的角色在代码中命名为 Ironclad/Silent/Defect/Regent/Necrobinder，对应原版的铁甲战士/静默猎手/缺陷机器人/摄政者/死灵术士。Mod 沿用这套命名体系。
:::

## 标签注册机制

### 确定性 ID 生成

- 标签的数值 ID 通过确定性哈希算法生成
- 同一个限定 ID 在所有端上生成相同的数值
- 无需网络同步，多端天然一致

### 注册方式

通过 RitsuLib 的卡牌标签注册系统注册，使用特性声明。

---

## 卡牌打标签

卡牌通过声明标签属性来附加角色归属标签：

- 一张卡牌可以拥有多个角色标签（但通常只属于一个角色）
- 标签在卡牌类定义时静态绑定，运行时不可变
- 通过检查卡牌标签集合中是否包含特定角色标签来判断

### 已使用角色标签的卡牌示例

| 角色标签 | 卡牌示例 |
| --- | --- |
| Ironclad | 天威、千劫 |
| Silent | 邪咒逐、洪龙出、森罗万物、圣山碎、寂律、汪海天 |
| Defect | 狂码、圣雷斩、纯能 |
| Regent | 赐天星、圣眼斩 |
| Necrobinder | 暗湮灭、百鬼、亡律、亡暴 |

## "仅对某角色生效"的过滤

### 按角色查标签

通过玩家角色 ID 映射到对应的标签，然后检查卡牌是否拥有该标签：

- 玩家角色为铁甲战士 → 返回 Ironclad 标签
- 玩家角色为静默猎手 → 返回 Silent 标签
- 以此类推

### 按标签过滤卡牌

通过检查卡牌是否拥有特定角色标签，实现"仅对某角色生效"的效果：

- 只有铁甲战士角色才能使用的卡牌 → 检查是否拥有 Ironclad 标签
- 只有静默猎手角色才能触发的效果 → 检查是否拥有 Silent 标签
- 以此类推

## 其它标签

### 龙标签

除角色标签外，Mod 还注册了一个"龙"标签，用于识别龙系卡牌：
- 类名包含"Dragon"或"龙"的卡牌自动拥有龙标签
- 龙标签用于[龙威](./dragon-majesty)能力的开局属性加成计算

### 原版标签

Mod 也使用原版的 CardTag 系统：
- 打击牌标签（Strike）
- 防御牌标签（Defend）
- 部分遗物和卡牌效果通过原版标签过滤

## 战略意义

### 角色专属卡牌

角色标签让 Mod 可以为每个角色设计专属卡牌，只有该角色才能使用或触发效果。这增加了角色差异化，让每个角色的构筑策略更加独特。

### 跨角色卡牌

不带任何角色标签的卡牌可以被所有角色使用，作为通用卡池的一部分。

### 龙牌体系

龙标签独立于角色标签，任何角色都可以使用龙牌。龙牌数量影响[龙威](./dragon-majesty)能力的开局属性加成。
