# 唤雨裂空

<img src="/images/relics/orobos_sky_fist_rain.png" alt="唤雨裂空" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 先古

## 描述

拾起时，将[辉·沧天逆流拳](/cards/character/sky_fist.md)和[大雨滂沱](/cards/character/heavy_rain.md)各一张加入牌组。

- **双卡入组**：两张卡均为新建（未升级），直接加入牌组主牌堆。
- **加入位置**：直接进牌组（不是抽牌堆），永久保留至打出或被消耗。

## 小贴士

- **双卡天造地设的联动**：[大雨滂沱](/cards/character/heavy_rain.md)2 费给 9 格挡 + 全敌人全属性 -1 + 全体[冰封](/powers/freeze_power.md) 2 回合；[辉·沧天逆流拳](/cards/character/sky_fist.md) 7 费吃[消耗牌堆](/mechanics/exhaust_pile.md)数量降费/放大伤害（每张消耗堆牌：费 -1、全体伤害 +7），再按"所有 PP 牌的 最大PP − 当前PP 差值总和"附加[固定伤害](/powers/fixed_damage_power.md)。
- **沧天拳的费效奇迹**：基础 7 费看似天价，但费随消耗堆递减（最低 0 费），主伤害按消耗堆张数线性放大（7×N 打全体）。消耗堆 5 张时就是 2 费打 35 点全体 + 差值固伤，堆满 7 张更是 0 费 49 点——核弹级收尾。注意它是"后期超模、前期废物"：主伤害严格等于 7×消耗堆张数，堆里没东西时打出就是 7 费 0 伤害（仅剩固伤部分）的废铁，需要先养消耗体系。
- **大雨的冰封失败惩罚与沧天拳的微妙关系**：冰封施加失败时（敌方免疫/拦截），自身所有 PP 卡 PP -2。沧天拳的固伤口径正是 Σ(最大PP − 当前PP)——PP 被扣掉后差值拉大，固伤随之提高，惩罚在数值上"喂"了沧天拳一手。但这**不是白赚**：PP 是单场可打出次数，PP 被扣意味着这些牌本场剩余可打出次数变少（扣到 0 直接报废），是"牺牲 PP 牌的续航换沧天拳一发固伤"的置换，多个免疫敌人失败还会重复叠加（3 个敌人 = PP -6），代价可能远超收益。
- **全属性 -1 的收益面**：力量 -1 让敌人攻击伤害 -1；防御 -1 让敌人受到的攻击伤害 +1；命中 -1 让敌人出现 5% 落空率（仅当敌人命中被削到负值）；速度 -1 累积到 -2 时**所有玩家多抽 1 张**（敌方负速度反哺玩家抽牌）。
- **冰封失败的判定边界**：冰封层数没增加才算失败（敌方免疫或拦截）；对已带冰封的敌人重复施加（2→4 层）判定为成功，不触发惩罚。普通敌群吃冰封时这张牌是纯赚。
- **性价比**：先古稀有度合理——一张洗控场、一张吃消耗堆收割，主题咬合度极高的完整 combo 包；缺消耗体系支撑时沧天拳价值打折，整体强度上限取决于牌组配合。
