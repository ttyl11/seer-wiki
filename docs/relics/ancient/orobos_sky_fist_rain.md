# 唤雨裂空

<img src="/images/relics/orobos_sky_fist_rain.png" alt="唤雨裂空" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 先古

## 描述

拾起时，将[辉·沧天逆流拳](/cards/character/sky_fist.md)和[大雨滂沱](/cards/character/heavy_rain.md)各一张加入牌组。

- **双卡入组**：两张卡均为新建（未升级），直接加入牌组主牌堆。
- **加入位置**：直接进牌组（不是抽牌堆），永久保留至打出或被消耗。

## 小贴士

- **双卡天造地设的联动**：[大雨滂沱](/cards/character/heavy_rain.md)2 费给 9 格挡 + 全敌人全属性 -1 + [冰封](/powers/freeze_power.md)2 回合（失败则自身 PP 牌 -2，反向养 PP 消耗）；[辉·沧天逆流拳](/cards/character/sky_fist.md)7 费吃消耗堆数量放大攻击伤害（每张消耗堆 -1 费 + 7 点伤害），再附等量已消耗 PP 总值的[固定伤害](/powers/fixed_damage_power.md)。两卡天然咬合——大雨洗 PP、消耗堆累积，沧天拳收割输出。
- **沧天拳的费效奇迹**：基础 7 费看着天价，但每张消耗堆牌让费 -1（最低 0 费）。配合多消耗堆的牌组（如消耗型/诅咒消耗型牌组）能轻松打到 0-3 费。消耗堆 5 张时就是 35 点全屏伤害 + 已消耗 PP 总值固定伤害——核弹级输出。
- **大雨滂沱的副作用是养沧天拳**：冰封失败时自身所有 PP 卡 -2 PP，看似惩罚实则是给沧天拳积攒"已消耗 PP 总值"——PP 消耗越多，沧天拳附加的固定伤害越高。所以大雨的"失败"反而是沧天拳的"养料"。
- **全属性 -1 的微妙效果**：力量 -1 让敌人攻击伤害 -1，防御 -1 让敌人受到攻击伤害 +1，命中 -1 让敌人 5% 概率攻击未命中，速度 -1 需累积到 -2 才让敌人少抽。单次大雨全敌人减全属性是不错的全方位削弱。
- **大雨的冰封失败判定**：冰封层数没增加才算失败（即敌人有冰封免疫或反弹）。普通敌人吃冰封不会触发惩罚，遇到冰封免疫/反弹型 BOSS 时才会触发——但这种 BOSS 也常常依赖异常状态，反而能用沧天拳的高伤直接绕过。
- **性价比**：先古稀有度合理——双卡主题咬合度极高，一张洗 PP/消耗堆+控场，一张吃 PP/消耗堆收割，完整 combo 包。
