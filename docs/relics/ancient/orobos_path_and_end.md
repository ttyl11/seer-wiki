# 诅咒传说

<img src="/images/relics/orobos_path_and_end.png" alt="诅咒传说" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 先古

## 描述

拾起时，获得1个随机<span style="color:#d4a017;font-weight:600">传说遗物</span>，将1张随机<span style="color:#d44;font-weight:600">赛尔诅咒牌</span>加入牌组。

- **传说遗物池**：从传说稀有度的非塔罗遗物中排除已拥有项后随机发放一个。
- **代价**：从赛尔诅咒牌池（17 张）随机取一张加入牌组。
- **多端一致**：传说遗物和诅咒牌均用同步随机源选取，多人模式两端结果一致。

## 风味文字

<span style="color:#d44;font-weight:600">传说的代价。</span>

## 小贴士

- **白送一个传说遗物**：拾起瞬间直接发放一个传说稀有度遗物（排除已拥有的），等同免费抽一次传说池。传说遗物都是高强度核弹级效果，单这一项就值回票价。
- **诅咒牌的代价是真伤脑筋**：17 张赛尔诅咒牌代价各不相同——[懒惰](/cards/curse/sloth.md)让攻击伤害变 0、[云玩家](/cards/curse/cloud_gamer.md)封锁所有 PP 卡、[傲慢](/cards/curse/pride.md)回合结束自伤、[暴怒](/cards/curse/wrath.md)强制先打且对全图伤害、[氪金](/cards/curse/pay_to_win.md)抽到直接扣金币。能不能消化代价全看抽到哪张。
- **诅咒牌是永久牌组负担**：诅咒牌进牌组后持续影响每场战斗，不是一次性消耗。除非有消耗诅咒牌的手段（如某些遗物/事件），否则会拖累整个跑图。建议配合能消耗诅咒的遗物或事件使用。
- **理想情况是提前备好消化手段**：若跑图中能拿到消耗诅咒牌的手段（如某些事件/遗物效果），再拾起这个遗物能把代价完全消化。无消化手段时建议谨慎拾起——传说遗物虽强但诅咒牌代价可能反向拖垮牌组。
- **性价比**：先古稀有度合理——一换一是核弹换核弹的等价交换，价值取决于能否消化诅咒牌代价。
