# 宝象龛

<img src="/images/relics/orobos_elephant_blessing.png" alt="宝象龛" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 先古

## 描述

拾起时，将[御象灵尊](/cards/colorless/elephant_spirit_lord.md)和[福泽聚宝象](/cards/character/treasure_elephant.md)各一张加入牌组。

- **双卡入组**：两张卡均为新建（未升级），直接加入牌组主牌堆。
- **加入位置**：直接进牌组（不是抽牌堆），永久保留至打出或被消耗。

## 风味文字

<span style="color:#d44;font-weight:600">象。</span>

## 小贴士

- **蓄力体系的完整启动器**：[御象灵尊](/cards/colorless/elephant_spirit_lord.md)每回合 -2 费 + 自身累积[蓄力](/powers/accumulate_power.md)（最多 6 层），[福泽聚宝象](/cards/character/treasure_elephant.md)消耗所有蓄力层数把 70 点伤害 ×蓄力层数。这遗物等于直接送你一套"养蓄力→爆伤"的核心组合。
- **御象灵尊的成长曲线**：9 费看似天价，但每回合 -2 费——1 回合后 7 费、2 回合后 5 费、3 回合后 3 费、4 回合后 1 费。配合保留关键词可以等降到 0 费再打出。蓄力随回合数累积（封顶 6 层），越后期打出蓄力越多。
- **福泽聚宝象是双刃核弹**：2 费 70 点伤害（炼狱关键词无视防御），消耗蓄力层数放大伤害——6 层蓄力下 420 点伤害。代价是失去当前生命值一半（不可格挡的非攻击伤害，**不是固定伤害**），并附加等量 ×250% 的[固定伤害](/powers/fixed_damage_power.md)给目标。
- **自伤机制的高风险高回报**：满血打出福泽聚宝象自伤一半生命，但等量 ×2.5 的固定伤害附加到目标——血越厚越值。满血 60+ 血量时打出相当于把 90+ 点固定伤害甩到敌人头上。注意自伤是不可格挡的非攻击伤害，不会被防御挡掉。
- **理想配合链**：御象灵尊养 5-6 层蓄力 → 福泽聚宝象消耗蓄力放大伤害 → 配合回血牌（如[真龙吐息](/cards/character/true_dragon_breath.md)未格挡回血）补偿自伤。两卡主题天然咬合。
- **性价比**：先古稀有度合理——直接送一套主题咬合的双卡核心，省去跑图搜寻时间。
