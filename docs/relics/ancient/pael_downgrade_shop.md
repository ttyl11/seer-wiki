# 佩尔之鳞

<img src="/images/relics/pael_downgrade_shop.png" alt="佩尔之鳞" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 先古

### 数值参数

| 参数 | 数值 |
|---|---|
| 金币数 | 288 |

## 描述

拾起时，获得<span style="color:#3aa675;font-weight:600">288</span><span style="color:#d4a017;font-weight:600">金币</span>，将牌组中所有已升级的卡牌降级。之后商店中出现的卡牌都会被升级。

- **降级范围**：拾起时遍历牌组中所有已升级的卡牌逐张降级。
- **商店升级**：只要持有此遗物，后续所有商店刷出的可升级卡牌都会自动以升级态出现。

## 风味文字

<span style="color:#d44;font-weight:600">降级。</span>

## 小贴士

- **前期拾起血赚、后期拾起肉痛**：拾起时把所有已升级卡全部打回原形换 288 金币——前期牌组没几张升级的牌，损失几乎可忽略；后期牌组十几张升级核心卡全部降级，痛感完全不同。
- **商店升级是常驻被动**：只要这件遗物在身上，之后每次进商店刷出的可升级卡都自动是升级版，不可升级的卡（衍生/状态牌）不受影响。
- **金币与升级卡形成正反馈**：288 金币够早期买 2-3 张商店卡，配合升级效果相当于"白嫖"了升级服务，商店流派收益翻倍。
- **性价比**：先古稀有度合理——一次性 288 金币 + 终局商店升级，价值看拾起时机。
