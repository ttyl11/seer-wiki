# 佩尔之鳞

<img src="/images/relics/pael_downgrade_shop.png" alt="佩尔之鳞" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 先古

### 数值参数

| 参数 | 数值 |
|---|---|
| 金币数 | 288 |

## 描述

拾起时，获得<span style="color:#3aa675;font-weight:600">288</span><span style="color:#d4a017;font-weight:600">金币</span>，将牌组中所有已升级的卡牌降级。之后商店中出现的卡牌都会被升级。

- **降级范围**：拾起时遍历牌组中所有已升级的卡牌逐张降级。
- **商店升级**：只要持有此遗物，后续所有商店刷出的可升级卡牌都会自动以升级态出现。

## 风味文字

<span style="color:#d44;font-weight:600">降级。</span>

## 小贴士

- **前期拾起血赚、后期拾起肉痛**：拾起时把所有已升级卡全部打回原形换 288 金币——前期牌组没几张升级的牌，损失几乎可忽略；后期牌组十几张升级核心卡全部降级，痛感完全不同。判断标准很简单：数一数牌组里有几张升级牌，每张升级牌约值一次篝火，掂量 288 金币买不买得回来。
- **⚠️ 与全量升级类遗物有先后顺序陷阱**：[无相蜕变皿](/relics/ancient/vaku_upgrade_and_aberration.md)（升级全牌组）和[佩尔之脊](/relics/ancient/pael_upgrade_curse.md)（每场战后随机升级）都是升级来源——先拿之鳞再拿它们没冲突；但若已靠蜕变皿把全牌组升了级，再拾起之鳞等于把整副升级牌组亲手打回原形，血亏。反过来先之鳞后蜕变皿，降级的牌又被全量升回来，等于白赚 288 金。
- **商店升级是常驻被动**：只要这件遗物在身上，之后每次进商店刷出的可升级卡都自动是升级版（不可升级的衍生/状态牌不受影响）——商店买卡从此自带"免费篝火"，一张省一次升级服务的钱和时间。
- **金币与升级卡形成正反馈**：288 金币在早期够买 2-3 张商店卡，配合升级效果相当于每张都是强化版入手，商店流派收益直接翻倍。对比[骄奢金阙](/relics/ancient/ancient_neow_golden_palace.md)（888 金但附带两张诅咒），之鳞的金币少但有持续价值、零诅咒代价。
- **走商店路线的构筑核心**：拿到之鳞后路线规划优先串商店——每逛一家店都是一次"升级卡自选超市"。多幕长线跑图中商店密度可观，累积的免费升级次数远超一次性 288 金的价值。
- **注意升级的是"可升级"卡**：商店里刷出的卡只有 `IsUpgradable` 才会被升级——天生满级或不可升级的特殊牌照常以白板出售，买之前看清商品状态。
