# 太虚忘机磐

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 先古

## 描述

拾起时，获得遗物<span style="color:#d4a017;font-weight:600">[无为觉者](/relics/legendary/inaction_awakener.md)</span>。

- **容器型遗物**：自身无任何战斗效果，仅作为发放载体；拾取后立即转化为<span style="color:#d4a017;font-weight:600">[无为觉者](/relics/legendary/inaction_awakener.md)</span>。

## 风味文字

<span style="color:#d44;font-weight:600">无为而治。</span>

## 小贴士

- **拾起即得传说遗物**：自身无战斗效果，捡起来就转化为[无为觉者](/relics/legendary/inaction_awakener.md)——无代价白拿一件传说品质遗物，鼠标悬停可直接预览完整效果。
- **到手的是"反向构筑"引擎**：无为觉者把最大生命绑到牌组张数、全属性加成绑到牌组数/8，PP 牌打出后剩余/已消耗对调形成永动循环，打 0 PP 牌叠[万相乖离](/powers/universal_divergence_power.md)（最高 5 层含复活）——一件遗物改写整局的构筑逻辑。
- **拾起瞬间最大生命降为 1**：转化为无为觉者的当下血量上限直接砸到 1，直到下一场战斗开始才恢复为牌组数——拿到后**立刻赶往最近的战斗/事件房**，别在地图上闲逛踩坑；这也是所有容器型先古奖励里唯一带即时风险的。
- **开局拿它 = 整局走大牌组**：最大生命 = 牌组数意味着删牌是**负收益**（删一张少一血上限），加牌反而涨血涨属性——与[正义大裁决](/cards/character/justice_judgment.md)（能耗随牌组数下降，60 张 0 费）天然绝配；万相乖离还会消耗 PP 牌当燃料，牌组大才有得烧。详细机制（PP 对调循环、乖离代价、复活移除半数 PP 牌）见[无为觉者页面](/relics/legendary/inaction_awakener.md)。
- **先古开局奖励中的极端选项**：同为开局赠礼，[覆世天平](/relics/ancient/nonupeipe_apocalypse_and_worlds.md)给泛用的天启帝君、[龙骸樽](/relics/ancient/nonupeipe_dragon_feast_and_jortrud.md)绑定龙卡流派，太虚忘机磐则是**彻底反转构筑理念**的大牌组引擎——上限极高（80 张牌组 = 80 血 + 10 全属性）但完全锁死发育方向，还要承受拾起瞬间 1 血的空窗期。
