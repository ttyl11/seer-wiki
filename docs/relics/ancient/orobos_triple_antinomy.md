## 描述

拾起时，将<span style="color:#3aa675;font-weight:600">3</span>张[二律背反](/cards/character/antinomy.md)加入牌组。

- **批量入组**：循环创建 3 张新建（未升级）二律背反卡牌，直接加入牌组主牌堆。
- **加入位置**：直接进牌组（不是抽牌堆），永久保留至打出或被消耗。

## 小贴士

- **3 张 0 费反转型核弹**：[二律背反](/cards/character/antinomy.md)是 0 费 PP 卡——造成 5 点伤害，反转对手全属性（正数翻负，让力量/防御/命中/速度变成等量负面），免疫下一次非暴击攻击（[二律背反能力](/powers/antinomy_power.md)）。3 张等于开局白送 3 个反制核弹。
- **反转只对正数生效**：反转逻辑只把对手当前的正数属性翻成等量负数，对已经是负数的不动。所以面对已经叠了 +3 力量的 BOSS，一张就把他的 +3 力量翻成 -3（攻击伤害 -3）；面对 0 属性的敌人则无效。
- **3 张的连锁压制**：3 张二律背反可以连打 3 次反转，对单体 BOSS 每次都把当前正属性翻负——3 张合计等于 9 点伤害 + 3 次全属性反转 + 3 次非暴击免疫。配合升级版（先制 +1）还能进一步压缩对手节奏。
- **0 费 + 反转 + 免疫是反制核心**：免疫下一次非暴击攻击意味着吃一次攻击免伤，但暴击仍能穿透。配合能强化暴击或无视免伤的手段时，对手的暴击牌能破解这套连招。
- **基础版没先制，升级才给**：二律背反基础版先制为 0，升级后才 +1。这个遗物送的是未升级版，所以是 0 先制——必须靠其它手段升级才能拿到先制减费效果。
- **性价比**：先古稀有度合理——3 张 0 费反制核弹，能彻底改变 BOSS 战的属性博弈节奏。
