# 破晓提灯

<img src="/images/relics/neow_dawn_gift.png" alt="破晓提灯" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 先古

## 描述

拾起时，将<span style="color:#3aa675;font-weight:600">1</span>张<span style="color:#d4a017;font-weight:600">[曙光普照](/cards/character/shining_light.md)</span>加入牌组。

- **悬浮提示**：悬浮提示注册了曙光普照，鼠标悬停可查看该卡效果。

## 风味文字

<span style="color:#d44;font-weight:600">奥丁的赠礼。</span>

## 小贴士

- **拾起即得 1 张曙光普照**：一次性触发，卡牌永久加入牌组。曙光普照是 Seer 角色牌，具体效果见[卡牌页面](/cards/character/shining_light.md)。
- **价值取决于流派契合度**：如果牌组能围绕曙光普照的机制构筑，这张遗物等于白送一张组件；如果牌组方向不搭，进来的这张牌反而是累赘。
- **性价比**：先古稀有度合理——白送一张角色牌，强度看曙光普照在你牌组中的定位。
