# 探骊司南

<img src="/images/relics/darv_relic_drop_bonus.png" alt="探骊司南" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 先古

### 数值参数

| 参数 | 数值 |
|---|---|
| 稀有遗物概率(%) | 5 |
| 罕见遗物概率(%) | 15 |
| 普通遗物概率(%) | 35 |

## 描述

战斗胜利后：<span style="color:#3aa675;font-weight:600">5</span>%概率获得<span style="color:#d4a017;font-weight:600">稀有遗物</span>，<span style="color:#3aa675;font-weight:600">15</span>%概率获得<span style="color:#d4a017;font-weight:600">罕见遗物</span>，<span style="color:#3aa675;font-weight:600">35</span>%概率获得<span style="color:#d4a017;font-weight:600">普通遗物</span>。

- **判定顺序**：按稀有 → 罕见 → 普通顺序依次判定，命中其一即止，最多掉一件。
- **奖励选取**：掉落的遗物推入奖励选择界面，需主动选取。
- **不重复**：掉落的遗物从共享遗物池移除，多人模式不会重复发放。

## 风味文字

<span style="color:#d44;font-weight:600">遗物掉落，概率提升。</span>

## 小贴士

- **每场战斗约 47.5% 概率额外掉遗物**：5% 稀有 + 约 14.25% 罕见 + 约 28.26% 普通，合计约 47.5%。等于近一半战斗会额外送一件遗物，长局累计收益极可观。
- **判定是互斥的，最多一件**：按稀有→罕见→普通顺序判定，命中其一就停（罕见/普通的实际概率要扣除前面命中后的剩余概率）。所以不会一场掉多件，但稀有没中还有机会掉罕见/普通。
- **稀有度越高越难触发**：5% 稀有是核弹级惊喜，15% 罕见是稳定收益，35% 普通是保底。大部分时候掉的是普通/罕见，稀有是锦上添花。
- **这是额外掉落，与正常奖励并存**：额外掉落不影响战斗胜利的常规奖励（金币、卡牌选择等）——它是在正常奖励之外多送一件遗物。而且掉的是遗物袋里**你还没有的**遗物（已拥有的不会重复掉），等于加速集齐全遗物池。
- **需主动选取，不是直接进背包**：掉落的遗物推入奖励选择界面，你要手动选。所以不会自动占背包位，但忘了选就没了。
- **拥有者死亡不触发**：战斗胜利时如果遗物拥有者已死，不掉落。所以这遗物要保命才能持续收益。
- **性价比**：先古稀有度合理——近半战斗额外掉遗物的收益远超一个遗物位，长局累计的遗物数量是质变级。跑线越长（楼层越多、战斗越多）收益越大，是先古遗物里最吃"长线"的一件。
