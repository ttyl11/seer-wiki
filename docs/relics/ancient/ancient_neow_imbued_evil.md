# 华彩邪印

<img src="/images/relics/ancient_neow_imbued_evil.png" alt="华彩邪印" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 先古

## 描述

拾起时，牌组中所有牌附魔<span style="color:#9b59b6;font-weight:600">[华彩](/enchantments/glam.md)</span>，并获得<span style="color:#d4a017;font-weight:600">[邪恶](/mechanics/evil.md)</span>关键词。

- **华彩附魔 + 邪恶关键词**：拾起时牌组所有牌附加华彩附魔和[邪恶](/mechanics/evil.md)关键词。
- **新牌自动获得邪恶**：通过邪恶关键词复制机制产生的新牌会自动注册并获得邪恶关键词；商店购买、事件奖励等途径获得的新牌不会获得邪恶。所有新牌都不会获得华彩附魔。

## 风味文字

<span style="color:#d44;font-weight:600">华彩。</span>

## 小贴士

- **全牌组附魔华彩**：拾起时牌组中每一张牌都附魔[华彩](/enchantments/glam.md)。华彩是随机附魔，每张牌获得不同的附魔效果，相当于全牌组免费强化一轮。
- **全牌组获得邪恶关键词**：每张牌获得[邪恶](/mechanics/evil.md)关键词，效果参见邪恶机制说明。
- **邪恶复制的新牌也获得邪恶**：邪恶关键词的复制机制产生的新牌会自动注册到遗物列表中，获得邪恶关键词。但商店购买、事件奖励等途径获得的新牌不会自动获得邪恶。
- **一次性附魔，永久关键词**：华彩附魔在拾起时一次性施加，邪恶关键词则持续对新牌生效。
