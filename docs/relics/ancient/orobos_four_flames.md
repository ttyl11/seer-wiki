# 四象琉璃盏

<img src="/images/relics/orobos_four_flames.png" alt="四象琉璃盏" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 先古

## 描述

每场战斗开始时，获得<span style="color:#9b59b6;font-weight:600">[金火](/powers/gold_fire_power.md)</span>、<span style="color:#9b59b6;font-weight:600">[蓝火](/powers/blue_fire_power.md)</span>、<span style="color:#9b59b6;font-weight:600">[绿火](/powers/green_fire_power.md)</span>、<span style="color:#9b59b6;font-weight:600">[紫火](/powers/purple_fire_power.md)</span>各 1 层。

- **触发时机**：每场战斗开始前自动施加，整场战斗持续。
- **金火与紫火是双刃**：金火让"双方受到的攻击伤害"都减少 25%（自己受伤降，自己打人也降）；紫火让"双方造成的伤害"都提升 25%（自己打人增，敌人打自己也增）。

## 小贴士

- **四火联动是稳态加成包**：金火 25% 减攻伤 + 蓝火每回合回 2 体力 + 绿火每 3 回合全属性 +1 + 紫火 25% 增攻伤——四种能力覆盖减伤/续航/成长/输出全维度，每场战斗开局自动启用，无需任何操作。
- **金火紫火是双刃剑**：金火让**双方**受到的攻击伤害都降 25%——自己受伤减少，但自己打敌人的攻击伤害也减少；紫火让**双方**造成伤害都增 25%——自己攻击增伤，但敌人攻击自己也增伤。净效果是"换血加速"：自己打敌人 ×0.75×1.25≈0.9375（轻微降低），敌人打自己 ×0.75×1.25≈0.9375（也轻微降低）。实际上金紫火**互相抵消**，对攻击伤害的净影响接近零，剩下蓝火回血 + 绿火成长才是真实收益。
- **金紫火对非攻击伤害无效**：金火只对攻击伤害减免，紫火只对攻击伤害增伤。烧伤/中毒/固定伤害等非攻击伤害**完全不受影响**。所以遇到依赖异常状态伤害的敌人，金火紫火的"双向抵消"会让玩家更亏——自己的非攻击伤害减免/增伤都没有，但敌人造成的非攻击伤害还是全额。
- **绿火的全属性 +1 含义**：每 3 回合给自身力量+1（攻击伤害+1）、命中+1（用于抵消负命中）、防御+1（受到攻击伤害-1）、速度+1（每 2 层回合开始多抽 1 张）。注意命中 +1 自身无直接增益，速度 +1 需累积到 2 层才生效——所以单次绿火主要受益是力量和防御。
- **性价比**：先古稀有度合理——四种能力持续整场战斗，蓝火和绿火是稳定正收益，金紫火对攻伤互抵后净影响微弱。
