# 匠心錾刻锤

<img src="/images/relics/orobos_craftsman_double.png" alt="匠心錾刻锤" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 先古

## 描述

拾起时，将牌组中所有未结算的[匠心](/cards/quest/craftsman_heart.md)卡牌已累积伤害值翻倍。

- **触发时机**：仅在获得遗物瞬间触发一次，非每回合持续。
- **目标筛选**：只处理尚未达到 8000 累积阈值、未发放奖励的匠心卡牌，已结算的不受影响。
- **同步范围**：翻倍结果同时写入卡牌本体和牌组版本，多端进度一致。

## 小贴士

- **一次性翻倍已累积伤害**：[匠心](/cards/quest/craftsman_heart.md)卡牌会记录你造成的伤害平方之和除以 8 的累积值，达到 8000 时给 8000 金币。这个遗物拾起的瞬间直接把当前累积值 ×2，等同跳过大半个跑图期的累积进度。
- **拾起时机决定收益**：越晚拾起翻倍基数越大。早期拾起时匠心卡牌还没累积多少伤害，翻倍几近无效；中后期拾起可能直接帮一张已累积 4000+ 的匠心卡牌瞬间冲过阈值领奖。
- **配合匠心卡组核心**：牌组里若有多张匠心卡牌，每张都独立翻倍——多卡并行收益翻番。配合提升伤害输出的牌（如增伤/暴击/多段攻击类）能让累积阶段也加速。
- **性价比**：先古稀有度合理——一次性帮匠心卡牌翻倍跨过半数累积量，价值取决于拾起时机。
