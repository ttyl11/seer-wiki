# 大暗黑天

<img src="/images/relics/darv_dark_sky_relics_and_curses.png" alt="大暗黑天" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 先古

### 数值参数

| 参数 | 数值 |
|---|---|
| 加入诅咒数 | 3 |

## 描述

拾起时，获得所有大暗黑天系列遗物，将<span style="color:#3aa675;font-weight:600">3</span>张<span style="color:#d44;font-weight:600">赛尔诅咒</span>加入牌组。

- **大暗黑天系列遗物**：共 8 件，包括 [艾夏拉](/relics/rare/constancy.md)、[混沌天蛇太祖](/relics/rare/chaotic_snake.md)、[幽冥帝尊·修罗](/relics/rare/nether_emperor.md)、[终末之灭·天邪龙王](/relics/rare/dragon_of_doom.md)、[厉魇魔王·咤克斯](/relics/rare/demon_king.md)、[邪冥·兽皇](/relics/rare/evil_beast_emperor.md)、[万古邪皇·威斯克](/relics/rare/ancient_evil_emperor.md)、[风殇影翼·飞镰](/relics/rare/flying_scythe.md)。已拥有的不再重复发放。
- **赛尔诅咒**：从当前解锁的赛尔诅咒中随机不重复抽取 3 张加入牌组。

## 风味文字

<span style="color:#d44;font-weight:600">诅咒降临。</span>

## 小贴士

- **8 件稀有遗物一次拿全**：大暗黑天系列共 8 件稀有遗物，拾起时一次全部获得（已经拥有的不重复发放，不会浪费在重复件上）。等于一个遗物位装 8 个遗物。
- **3 张赛尔诅咒是代价**：拿 8 件遗物的同时从赛尔诅咒牌池随机不重复抽 3 张塞进牌组。赛尔诅咒多数可以主动打出（付出代价消除），但七宗罪系列（懒惰/渺小/开龟等）里不少是纯负资产——抽到就占手牌位。3 张诅咒整局都在，会在长战斗中卡手。这不是白拿——你要用 3 张诅咒换 8 件遗物。
- **8 件遗物覆盖攻防控场**：[艾夏拉](/relics/rare/constancy.md)（敌方回合开始消除其全属性强化、成功则睡眠 2 回合）、[混沌天蛇太祖](/relics/rare/chaotic_snake.md)（挨打变强）、[幽冥帝尊·修罗](/relics/rare/nether_emperor.md)（高血先制/低血必暴+击杀传导伤害回血）、[终末之灭·天邪龙王](/relics/rare/dragon_of_doom.md)（血量对比切攻防模式+邪龙之噬+受击回血/全体固伤反击）、[厉魇魔王·咤克斯](/relics/rare/demon_king.md)（增伤+概率秒杀）、[邪冥·兽皇](/relics/rare/evil_beast_emperor.md)（意图无效化）、[万古邪皇·威斯克](/relics/rare/ancient_evil_emperor.md)（诅咒联动+固定伤害）、[风殇影翼·飞镰](/relics/rare/flying_scythe.md)（全敌人力量/命中-1+挨打重则无实体/轻则先制）。8 件覆盖攻防控场续航，拿到后基本全能。
- **8 件遗物间的联动**：不少遗物效果互相配合——飞镰每回合削敌方力量命中，艾夏拉消除敌方属性强化，两者叠加让敌人越打越弱；威斯克的诅咒联动喜欢多诅咒牌组，正好把代价（3 张赛尔诅咒）变成燃料；幽冥帝尊和天邪龙王都是"血量高低切换模式"型，高血量进攻低血量防守自动互补。
- **核心矛盾：8 件遗物的强度 vs 3 张诅咒的污染**：8 件遗物给的强度是核弹级，但 3 张赛尔诅咒会持续污染牌组整局。诅咒牌抽到就是废牌（或要付代价打出），长战斗中可能卡手。拿之前要评估牌组能否扛住 3 张诅咒。
- **先古稀有度名副其实**：先古遗物本身是 Boss 掉落级别的稀有度，一件先古换 8 件稀有 + 3 诅咒，是改变整局构筑的选择。
- **性价比**：先古稀有度合理——8 件稀有遗物的强度远超 3 张诅咒的代价，但诅咒污染需要牌组有应对手段（如消耗/移除诅咒的牌、或配合威斯克把诅咒转化为收益）。
