# 大暗黑天

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 先古

### 数值参数

| 参数 | 数值 |
|---|---|
| 加入诅咒数 | 3 |

## 描述

拾起时，获得所有大暗黑天系列遗物，将<span style="color:#3aa675;font-weight:600">3</span>张<span style="color:#d44;font-weight:600">赛尔诅咒</span>加入牌组。

- **大暗黑天系列遗物**：共 8 件，包括 [艾夏拉](/relics/rare/constancy.md)、[混沌天蛇太祖](/relics/rare/chaotic_snake.md)、[幽冥帝尊·修罗](/relics/rare/nether_emperor.md)、[终末之灭·天邪龙王](/relics/rare/dragon_of_doom.md)、[厉魇魔王·咤克斯](/relics/rare/demon_king.md)、[邪冥·兽皇](/relics/rare/evil_beast_emperor.md)、[万古邪皇·威斯克](/relics/rare/ancient_evil_emperor.md)、[风殇影翼·飞镰](/relics/rare/flying_scythe.md)。已拥有的不再重复发放。
- **赛尔诅咒**：从当前解锁的赛尔诅咒中随机不重复抽取 3 张加入牌组。

## 风味文字

<span style="color:#d44;font-weight:600">诅咒降临。</span>

## 小贴士

- **8 件稀有遗物一次拿全**：大暗黑天系列共 8 件稀有遗物，拾起时一次全部获得。已拥有的不重复发放。8 件遗物各自有强力效果，等于一个遗物位装 8 个遗物。
- **3 张赛尔诅咒是代价**：拿 8 件遗物的同时往牌组塞 3 张赛尔诅咒。赛尔诅咒是污染牌组的负面牌，会拖累抽牌节奏。所以这不是白拿——你要用 3 张诅咒的代价换 8 件遗物。
- **8 件遗物覆盖攻防控场**：艾夏拉（清属性+睡眠）、混沌天蛇（挨打变强）、幽冥帝尊（先制/暴击）、天邪龙王、咤克斯（增伤+秒杀）、兽皇（意图无效化）、威斯克（诅咒+固定伤害）、飞镰（减属性+无实体/先制）。8 件覆盖攻防控场续航，拿到后基本全能。
- **核心矛盾：8 件遗物的强度 vs 3 张诅咒的污染**：8 件遗物给的强度是核弹级，但 3 张赛尔诅咒会持续污染牌组整局。诅咒牌抽到就是废牌，长战斗中可能卡手。所以拿之前要想清楚你的牌组能不能扛住 3 张诅咒。
- **先古稀有度名副其实**：先古遗物本身是 Boss 掉落级别的稀有度，一件先古换 8 件稀有 + 3 诅咒，是改变整局构筑的选择。
- **性价比**：先古稀有度合理——8 件稀有遗物的强度远超 3 张诅咒的代价，但诅咒污染需要牌组有应对手段（如消耗/移除诅咒的牌）。
