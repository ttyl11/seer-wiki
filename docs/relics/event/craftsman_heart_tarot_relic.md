# 匠心塔罗

<img src="/images/relics/craftsman_heart_tarot_relic.png" alt="匠心塔罗" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 事件遗物
- **稀有度**: 事件
- **获取途径**: ⚠️ **当前无法获取**（源码仍在，但无任何事件/途径发放此遗物；原版与 Mod 均无随机事件遗物池）

## 描述

每进入一个房间，随机获得1件尚未拥有的<span style="color:#d4a017;font-weight:600">[塔罗遗物](/relics/tarot_relic_base.md)</span>。

- **触发时机**：进入任意房间即触发——战斗、商店、火堆、事件等所有房间类型都算。
- **不重复**：只发放你尚未拥有的塔罗遗物。已拥有的不会重复获取。
- **空池保护**：所有可发放的塔罗遗物都已集齐后，本房间不再发放。

## 风味文字

<span style="color:#d44;font-weight:600">匠心独运，塔罗无穷。</span>

## 小贴士

- **每房间白嫖一件塔罗**：可发放的候选共 25 件——22 件正统塔罗（对应大阿卡纳 22 张牌，如[愚者](/relics/common/tarot_fool.md)、[世界](/relics/common/tarot_world.md)等）+ 3 件名字带"塔罗"的同类遗物（[涅奥的猩红牌盒](/relics/ancient/neow_blood_tarot.md)、[诡宴占星盘](/relics/ancient/neow_tarot_feast.md)、[殉道者占卜盘](/relics/ancient/tezcatara_tarot_holy_passing.md)——判定逻辑按类名含"Tarot"匹配，这 3 件也被收进候选池）。一个楼层通常有 10+ 个房间，拿到此遗物后两三层就能集齐全套。
- **占卜盘类遗物会连锁开箱**：候选池里的 3 件占卜盘/牌盒类遗物，本身效果就是"拾起时获得 N 个随机塔罗"（猩红牌盒 +2、诡宴占星盘 +5 附带 1 张赛尔诅咒、殉道者占卜盘 +6 附带每回合圣逝）。从匠心塔罗手里拿到它们时会立刻连锁触发——一个房间实际进账可能远超 1 件，全套塔罗的集齐速度比表面看起来更快。
- **所有房间都触发**：不只是战斗房间——商店、火堆、事件、宝箱房等进入即触发。路过非战斗房间也能白拿遗物。
- **塔罗遗物本身就不弱**：22 件正统塔罗各有强力效果（如愚者随机获取塔罗、世界每回合稳定格挡等），每房间免费拿一件等于指数级膨胀遗物数量。如果此遗物可获取，将是全游戏最强遗物之一。
- **⚠️ 当前无法获取**：源码完整但没有任何事件或途径发放此遗物，正常游戏中无法获得。可能是开发中或预留内容。
- **性价比**：事件稀有度——如果可获取，事件稀有度严重偏低，效果远超任何先古/传说遗物。每房间免费一件遗物的机制级强度是全游戏独一无二的。
