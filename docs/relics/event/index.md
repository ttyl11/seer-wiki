## 小贴士

- 标注 ⚠️ 的遗物（匠心塔罗、龙魂附魔、龙魂宝珠、龙魂药水）源码仍在，但当前无任何事件/途径发放。原版与 Mod 均无随机事件遗物池，这些遗物不会在游戏中出现。
- 降级诅咒、虚无诅咒、状态牌诅咒为一次性战斗遗物，战斗结束后自动移除。
