# 属性加成

<img src="/images/relics/attribute_bonus_relic.png" alt="属性加成" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 事件
- **获取途径**: 「属性内卷的路边争论」事件（免费试用=2个、小额付费=3个、全额梭哈=6个）

### 数值参数

| 参数 | 数值 |
|---|---|
| 事件选项基数 | 2/3/6（由事件选项决定） |
| 每场实际属性总数 | 基数+1（3/4/7，含群星的礼赠保底 1 个） |
| 战后金币 | 基数+1（3/4/7） |

## 描述

在每场战斗开始时，获得 <span style="color:#3aa675;font-weight:600">2/3/6</span> 个随机[属性](/mechanics/element-affinity.md)加成。每场战斗结束后，获得 <span style="color:#3aa675;font-weight:600">2/3/6</span> [金币](/mechanics/money_pouch.md)。

- **⚠️ 本地化与源码不一致**：本地化描述为"获得若干个随机属性加成"（默认 0 个），但实际每场战斗开始时施加的属性总数 = 事件选项基数 + 1——[群星的礼赠](/relics/starter/elemental_core.md)（开局自带的初始遗物）会保底分配 1 个元素属性，本遗物再补基数个，无论遗物执行顺序如何总数恒定为基数+1。战后金币也按基数+1 结算（3/4/7），本地化未提及金币部分。实际效果以实际效果为准。
- **属性种类**：从 26 种元素属性（草/水/火/飞/电/机械/地/普通/冰/超能/格斗/光/暗/神秘/龙/圣/次元/远古/邪/自然/王/混沌/神/轮回/虫/虚）中随机施加。

## 小贴士

- **每场战斗获得随机元素属性**：战斗开始时从 26 种元素属性中随机抽取若干个施加，总数 = 事件选项基数+1（免费试用 3 个、小额付费 4 个、全额梭哈 7 个，含群星的礼赠保底的 1 个）。元素属性决定[克制倍率](/mechanics/element-affinity.md)——克制敌方元素 ×1.5、被敌方克 ×0.75、无关系 ×1.0，只作用于攻击伤害。
- **多属性是连乘，方差极大**：你身上的每个元素属性独立参与倍率计算后**连乘**——梭哈 7 个属性若 3 克制 3 被克 1 中性 = 1.5³×0.75³ ≈ 0.95，几乎白干；但 5 克制 2 中性 = 1.5⁵ ≈ 7.6 倍伤害，直接起飞。属性越多上限越高、下限也越低，纯属看脸。
- **重复抽到同一元素没有额外收益**：同一元素叠加层数不改变倍率（克制关系固定）——抽 7 次全出同一元素等于只有 1 个属性的乘区。重复元素是随机性的"隐性浪费"。
- **属性打的是双向牌**：你的元素既决定你打敌人的倍率，也决定有元素的敌人打你的倍率——抽到被敌人克的属性，敌方攻击对你 ×1.5、你的攻击对敌 ×0.75，双重劣势。面对无元素的敌人（部分怪物没有属性分配）时属性完全无效，只剩金币收益。
- **战后额外金币是稳定底线**：每场战斗结束后额外获得等量金币（3/4/7），本地化未提及。长期跑线可以累积一笔金币——全程梭哈选项（7 金币/场）跑 30 场战斗就是 210 金币。属性随缘、金币保底，这是本遗物的真实定价：金币收入是确定性收益，元素是彩票。
- **获取途径决定强度**：事件中选择"免费试用"基数 2，"小额付费"基数 3，"全额梭哈"基数 6。投入越多收益越高，梭哈选项的每场金币是免费试用的 2 倍多，属性乘区上限也更高（同时方差更大）。
- **属性数量固定不升级**：事件选择后属性数量就固定了，没有后续升级途径。选择时需要权衡当前金币储备和长期收益——短跑线（快打 Boss）免费试用够用，长跑线梭哈的累计金币更划算。
