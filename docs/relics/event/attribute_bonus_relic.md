# 属性加成

<img src="/images/relics/attribute_bonus_relic.png" alt="属性加成" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 事件
- **获取途径**: 「属性内卷的路边争论」事件（免费试用=2个、小额付费=3个、全额梭哈=6个）

### 数值参数

| 参数 | 数值 |
|---|---|
| 属性加成数量 | 2/3/6（由事件选项决定） |
| 战后金币 | 同属性加成数量 |

## 描述

在每场战斗开始时，获得 <span style="color:#3aa675;font-weight:600">2/3/6</span> 个随机[属性](/mechanics/element-affinity.md)加成。每场战斗结束后，获得 <span style="color:#3aa675;font-weight:600">2/3/6</span> [金币](/mechanics/money_pouch.md)。

- **⚠️ 本地化与源码不一致**：本地化描述为"获得若干个随机属性加成"（默认 0 个），但实际每场战斗开始时施加的属性加成数量始终为属性数值+1（即至少 1 个），具体数量由事件选项决定（2/3/6）。此外源码在每场战斗结束后额外获得同等数量的[金币](/mechanics/money_pouch.md)，本地化未提及。实际效果以实际效果为准。
- **属性种类**：从 26 种元素属性（草/水/火/飞/电/机械/地/普通/冰/超能/格斗/光/暗/神秘/龙/圣/次元/远古/邪/自然/王/混沌/神/轮回/虫/虚）中随机施加。

## 小贴士

- **每场战斗获得随机元素属性**：战斗开始时从 26 种元素属性中随机抽取若干个施加，数量取决于事件选项（2/3/6）。元素属性提供对应的元素克制关系，影响战斗中的伤害倍率。
- **战后额外金币**：每场战斗结束后额外获得同等数量的金币（2/3/6），本地化未提及。长期跑线可以累积一笔金币——全程梭哈选项（6 金币/场）跑 30 场战斗就是 180 金币。
- **随机性的局限**：属性是随机抽取的，无法指定想要哪种元素。同种元素可能重复施加（叠加层数），但也可能歪到不克制当前敌人的属性上。属性的价值完全取决于敌人元素类型。
- **获取途径决定强度**：事件中选择"免费试用"获得 2 个属性加成，"小额付费"获得 3 个，"全额梭哈"获得 6 个。投入越多收益越高，梭哈选项的每场收益是免费试用的 3 倍。
- **属性数量固定不升级**：事件选择后属性数量就固定了，没有后续升级途径。选择时需要权衡当前金币储备和长期收益。
- **性价比**：事件稀有度——免费试用白嫖 2 属性 + 2 金币/场已是稳赚；小额付费和全额梭哈需要投入金币，但长期跑线回报可观（每场固定金币 + 元素属性增益）。真正定价点在"每场固定金币收入"上，元素属性作为附加收益锦上添花。梭哈选项适合长跑线，免费试用适合短跑线或金币紧张时。
