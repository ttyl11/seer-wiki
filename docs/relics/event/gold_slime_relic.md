## 描述

每场战斗开始时，恢复等量于牌组中“黏液”牌数量的生命。打出[暴政统治者](/cards/event/tyrant_ruler.md)<span style="color:#3aa675;font-weight:600">20</span>次后，变为[暴君史莱姆](/relics/event/tyrant_slime_relic.md)。

- **黏液回复**：战斗开始时按牌组中黏液牌数量回复等量生命。
- **形态切换**：每打出1次暴政统治者计数+1（跨战斗累计），打满20次后变为暴君史莱姆。
- **⚠️ 本地化与源码不一致**：源码在每场战斗胜利后还会向牌组加入1张黏液卡，但本地化描述未提及此效果。实际效果以实际为准。
- **注意区分两种牌**："黏液"（原版状态牌，打出抽1张牌）负责计数回血；"史莱姆"系列牌（[史莱姆](/cards/character/slime.md)、[体力史莱姆](/cards/colorless/slime_stamina.md)、[攻击史莱姆](/cards/colorless/slime_attack.md)、[防御史莱姆](/cards/colorless/slime_defense.md)、[速度史莱姆](/cards/colorless/slime_speed.md)）是另一套牌，只与暴政统治者的自动打出联动。两者名字相近但互不掺和。

## 小贴士

- **每场战斗开局的免费回血**：战斗开始时按牌组中黏液牌数量回血。事件初始给5张黏液，即每场战斗回5血；之后每打赢一场+1张黏液，回血持续递增（第10场时每场回14血）。
- **黏液越攒越多的双刃剑**：每场胜利后自动加入1张黏液（本地化未提及此效果，以实际为准）。回血更多了，但牌组也越来越臃肿——黏液是状态牌，会占抽牌位和手牌位。
- **暴政统治者是变形钥匙**：打出暴政统治者20次后，本遗物变为暴君史莱姆。暴政统治者 PP5（单场最多打5次），20次计数**最快也要4场战斗**（每场打满5次 PP），实际一般需要5-8场。它的效果是：1费对所有敌人6伤+1层易伤、自身先制+1、获得1层缓冲、弃掉手牌中最多3张牌，并自动随机免费打出本场战斗中所有"史莱姆"系列牌。
- **⚠️ 自动打出的不包括黏液**：暴政统治者自动打出的是**史莱姆系列牌**（史莱姆/体力/攻击/防御/速度史莱姆，且只扫本场战斗的手牌+抽牌堆+弃牌堆）。黏液（Slimed）不在自动打出范围内——靠事件选项二拿到的5张黏液只能手动打。想让自动打出有货，需要额外补充史莱姆牌（同一事件的选项一/选项四，或其他获取途径）。
- **变形目标：暴君史莱姆**：变形后每回合开始消耗所有黏液、每张对随机敌人施加1层凝滞；受击时令敌方速度和命中降低；造成伤害时概率翻倍，否则施加固定伤害；战斗结束时移除牌组中1张黏液清理牌组。变形越早牌组越早净化，变形越晚累积的黏液越多但回血也越多。
- **核心矛盾：拖还是冲**：拖得越久回血越多，但牌组污染越严重。牌组运转能力强、能消化黏液时可以多拖几场攒回血；牌组已臃肿时应尽快打满20次变形。
- **黏液不是纯废牌**：黏液打出后抽1张牌，等于换一张手牌，能自我循环，不会完全卡死在手里。
- **事件成套获取**：通过[史莱姆的加冕](/events/slime_coronation.md)事件「加冕为王」选项获得，同时获得暴政统治者和5张黏液。注意同一事件的「听不懂，思密达」（100金币+2张史莱姆）和「集结勇士」（2张升级史莱姆）能给暴政统治者提供自动打出的弹药——先后遇到时可以互补。
