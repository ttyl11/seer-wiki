# 咤克斯的诅咒

<img src="/images/relics/zhakes_curse_relic.png" alt="咤克斯的诅咒" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 事件

## 描述

每场战斗结束后，将1张随机<span style="color:#d44;font-weight:600">赛尔诅咒牌</span>加入你的牌组。

- **牌池限定**：仅从赛尔诅咒牌池中随机选取1张。
- **永久加入**：诅咒牌永久加入牌组，持续整局游戏。

## 风味文字

<span style="color:#d44;font-weight:600">诅咒永不停歇。</span>

## 小贴士

- **每场战斗+1随机诅咒**：每场战斗结束后，从赛尔诅咒牌池随机选取1张永久加入牌组。战斗越多，牌组污染越严重，长线运营负担极大。
- **永久加入**：诅咒牌永久加入牌组，不会自动移除。需要通过火堆移除牌、转化等手段清理，否则越积越多拖垮卡组。
- **赛尔诅咒牌池**：从mod专属的赛尔诅咒牌池中随机选取，包含多种诅咒牌效果。无法预知会拿到哪种诅咒，不确定性高。
- **性价比**：事件稀有度——纯负面遗物，每场战斗+1诅咒是持续负担。除非配合诅咒流遗物能将诅咒转化为收益，否则尽量避免获取。
