# 虚无诅咒

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 事件
- **获取途径**: [「莱达长老的电车难题考验」](/events/leda_elder_trolley_problem.md) 事件，选择「指认大长老」

## 描述

本场战斗所有卡牌附带<span style="color:#d4a017;font-weight:600">[虚无](/mechanics/ethereal.md)</span>。战斗结束后移除此遗物。

- **本场战斗所有牌获得虚无**：拥有者第一个回合开始时，给抽牌堆、手牌、弃牌堆里所有卡牌加上虚无关键词。
- **虚无的真实规则**：虚无牌**打出后正常进弃牌堆**，下回合还能抽回再用；只有**回合结束时还留在手里**的虚无牌才会被消耗。
- **一次性，战斗后消失**：只在拥有者首个回合触发一次，战斗结束后遗物自动消失。

## 小贴士

- **⚠️ 虚无不烧打出去的牌，只烧留在手里的牌**：虚无牌打出后正常进弃牌堆，下回合照样抽回；只有回合结束时**还攥在手里**的虚无牌才被消耗。所以这件遗物的真实惩罚是"每回合没打完的手牌数"——每剩一张就蒸发一张，牌组并不是匀速缩水。
- **惩罚的是手牌利用率，不是牌组总量**：快攻/低费流每回合把手牌打空，几乎零损失；高费慢速流每回合剩 2-3 张打不出去的牌，等于每回合白烧 2-3 张，几回合后牌组就见底。拿到它后的正确打法是宁可打 1 费小牌也别让手牌留到回合结束。
- **保留救不了虚无牌**：保留牌回合结束时会留在手里而不弃掉——但虚无消耗检查的恰恰是"回合结束时在手牌里"，保留牌正中枪口照样被烧。想保关键牌别指望保留，趁早打出去才是正解。
- **三牌堆全部加虚无**：不只手牌，抽牌堆和弃牌堆里的牌也一起获得虚无。无法通过"先打光手牌"让后续抽到的牌幸免——这场战斗里你抽到的每一张都是虚无牌，规则全程有效。
- **可配合消耗联动**：虚无触发的移除走的是"消耗"结算，凡是"每当有牌被消耗"类的联动（回血、加格挡、叠层等）都能吃到收益。有这类体系时，这件遗物反而能变成资源引擎，把负面惩罚变成正向收益。
- **只持续一场战斗**：战斗结束后遗物自动消失，不会带入下一场。拿到后只需要熬过一场战斗，不用永久承受负面效果。牌组也不会真的受损——下场战斗牌组原样都在。
- **三选一的代价之一**：来自[「莱达长老的电车难题考验」](/events/leda_elder_trolley_problem.md)——三个选项分别获得"本场全卡虚无"、"本场全牌降级"、"本场开始时塞 10 张随机状态牌"三件一次性负面遗物。手牌利用率高的快攻流选虚无几乎白板；升级多的牌组怕降级；小牌组怕状态牌。按自己的构筑挑伤害最小的那个。
