# 虚无诅咒

<img src="/images/relics/ethereal_next_combat_relic.png" alt="虚无诅咒" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 事件

## 描述

本场战斗所有卡牌附带<span style="color:#d4a017;font-weight:600">[虚无](/mechanics/ethereal.md)</span>。战斗结束后移除此遗物。

- **本场战斗所有牌获得虚无**：拥有者回合开始时，给抽牌堆、手牌、弃牌堆里所有卡牌加上虚无关键词。虚无牌在打出后的回合结束时会被消耗（除非有保留）。
- **一次性，战斗后消失**：只在拥有者首个回合触发一次，战斗结束后遗物自动消失。

## 小贴士

- **负面遗物，加速卡牌消耗**：虚无牌在打出后回合结束时会消耗，不再回到弃牌堆。所以这件遗物会让你的牌组越打越少，手牌资源快速枯竭，是典型的负面事件遗物。
- **三牌堆全部加虚无**：不只手牌，抽牌堆和弃牌堆里的牌也一起获得虚无。所以无法通过"先打出手牌再抽新牌"来规避——新抽的牌一样是虚无牌。
- **保留牌不受虚无影响**：虚无牌只在"不保留"时才消耗。所以带保留关键词的牌、或者有保留能力的遗物可以保住关键牌不被消耗，是对抗这件遗物的主要手段。
- **可配合消耗联动**：虚无会让牌被消耗，而有些卡牌/遗物在牌被消耗时有额外效果。如果你有这类联动，虚无反而能变成正向收益，把负面遗物变成资源。
- **只持续一场战斗**：战斗结束后遗物自动消失，不会带入下一场。所以拿到后只需要熬过一场战斗，不用永久承受负面效果。
- **只有拥有者触发**：只影响拥有这件遗物的玩家一方的卡牌，不影响队友的牌组（多人游戏）。
