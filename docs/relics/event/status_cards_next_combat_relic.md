# 状态牌诅咒

<img src="/images/relics/status_cards_next_combat_relic.png" alt="状态牌诅咒" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 事件

## 描述

本场战斗首回合开始时，向牌堆添加<span style="color:#d4a017;font-weight:600">状态牌</span>。每场战斗结束后移除。

- **触发时机**：首回合开始时触发一次，之后不再触发。
- **状态牌池**：合并原版状态牌池与 8 张 mod 状态牌（枯竭、侵蚀、心魔、凋萎、灼烧状态、余温之星、神圣流逝、荒芜）。
- **数量来源**：状态牌数量由外部（事件、卡牌效果）创建遗物时设置，遗物自身不定义默认值。
- **加入位置**：随机选牌加入抽牌堆。

*（无）*

## 小贴士

- **首回合塞状态牌污染抽牌**：战斗首回合把状态牌塞进抽牌堆，污染你的抽牌节奏。状态牌是废牌，会卡手牌、影响关键回合的输出。
- **状态牌池很杂**：状态牌池包含原版状态牌+8张mod状态牌（枯竭、侵蚀、心魔、凋萎、灼烧状态、余温之星、神圣流逝、荒芜），每张效果不同但都是负面，抽到哪张都难受。
- **一次性诅咒**：战斗结束后自动移除，只影响当前这场战斗。拿到后扛过这场战斗就没事了，不需要专门处理。
- **应对策略**：配合消耗手牌、抽牌堆操作类卡牌可以缓解——优先消耗掉塞进来的状态牌，或者用洗牌/抽牌类卡牌快速过掉。
