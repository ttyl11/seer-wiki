## 描述

①在每场战斗开始时，移除你的现有属性，转为<span style="color:#9b59b6;font-weight:600">[混沌属性](/powers/chaos_power.md)</span>，获得<span style="color:#d4a017;font-weight:600">守护者</span>卡牌。<br/>②在你的回合开始时，<span style="color:#d4a017;font-weight:600">召唤</span><span style="color:#3aa675;font-weight:600">X</span>。<br/>③每击杀1个敌人X+<span style="color:#3aa675;font-weight:600">2</span>（精英+<span style="color:#3aa675;font-weight:600">5</span>，Boss+<span style="color:#3aa675;font-weight:600">10</span>），X当前值为<span style="color:#3aa675;font-weight:600">X</span>（跨战斗保留）。<br/>④每受到1次未被格挡的攻击伤害X-<span style="color:#3aa675;font-weight:600">2</span>，X<0时直接死亡。

- **混沌属性替换**：战斗开始时移除你身上所有元素属性，再施加 1 层混沌属性。混沌属性对飞行/冰/神秘/次元/邪灵/自然/圣灵 7 种元素造成 1.5 倍伤害，对电/机械/格斗/轮回/虚空 5 种元素造成 0.75 倍伤害。
- **守护者卡牌**：每场战斗开始时把 1 张守护者加入抽牌堆。守护者是原版奥斯提联动卡——造成伤害并额外造成等量于奥斯提最大生命值的伤害。X 越高，召唤的奥斯提最大生命越高，守护者伤害也越高。
- **召唤奥斯提**：回合开始时召唤数量等于 X 的奥斯提。若已有奥斯提则增加其最大生命值，而非重复召唤。
- **击杀加分**：你击杀敌人后 X 增加——普通敌人 +2、精英 +5、Boss +10。房间类型决定加值档次。
- **受伤扣分**：受到未被格挡的攻击伤害后 X -2。非攻击伤害（如能力伤害）不扣 X。X 降至 0 以下时直接处决自身。

## 小贴士

- **X 是跨战斗滚雪球的核心资源**：X 值在存档中持久化，不会因战斗结束而重置。开局 4，随着击杀敌人不断累积，越往后越强。一局下来 X 可以堆到几十，每回合召唤几十 HP 的奥斯提，配合守护者卡伤害极其恐怖。
- **守护者卡与奥斯提形成联动闭环**：每场战斗白送 1 张守护者，守护者的额外伤害等于奥斯提最大生命值。X 高 = 奥斯提血厚 = 守护者伤害高。所以 X 不仅决定召唤量，还直接放大守护者卡的爆发力，是一鱼两吃。
- **击杀增益 vs 受伤惩罚的拉锯**：杀敌加 X（普通 +2 / 精英 +5 / Boss +10），但每次挨未格挡的攻击伤害扣 2。这意味着防得好（不挨打）X 只涨不跌，防不好（频繁挨打）X 会被慢慢磨掉。防守压力直接影响滚雪球速度。
- **X < 0 直接死亡是致命风险**：X 掉到负数会立即处决自身，没有回旋余地。如果当前 X 很低（比如刚开局 4），连续挨两三次未格挡攻击就可能暴毙。低 X 时必须优先防守，不能贪输出。
- **只扣攻击伤害，非攻击伤害不扣**：能力伤害等非攻击伤害不会扣 X。所以面对靠攻击打伤害的敌人要格外小心，面对靠能力/异常打伤害的敌人则相对安全。
- **Boss 战是滚雪球最快途径**：击杀 Boss 一次 +10，是普通敌人的 5 倍。一局里 Boss 数量有限，每次 Boss 击杀都是 X 的大幅跳升。尽量保证 Boss 战中不挨打，把 +10 全额吃下。
- **混沌属性改变元素克制关系**：战斗开始移除所有元素属性换成混沌，意味着你原来的元素构筑（如纯电、纯冰）会被完全覆盖。混沌对 7 种元素 1.5x、5 种元素 0.75x，打弱克制的敌人更强，打强克制的敌人更弱。如果你牌组依赖特定元素属性，这件遗物会打乱你的元素体系。
- **核心矛盾：进攻滚雪球 vs 防守保命**：杀敌加 X 让奥斯提和守护者更强，鼓励你积极进攻快速清场。但受伤扣 X 甚至致死，又要求你严防死守。攻防节奏的把控是玩好这件遗物的关键——前期 X 低时偏防守，X 堆起来后转进攻收割。
