## 描述

①在每场战斗开始时，移除你的现有属性，转为<span style="color:#9b59b6;font-weight:600">[混沌属性](/powers/chaos_power.md)</span>，获得<span style="color:#d4a017;font-weight:600">守护者</span>卡牌。<br/>②在你的回合开始时，以<span style="color:#3aa675;font-weight:600">X</span>点生命<span style="color:#d4a017;font-weight:600">召唤</span>奥斯提。<br/>③每击杀1个敌人X+<span style="color:#3aa675;font-weight:600">2</span>（精英+<span style="color:#3aa675;font-weight:600">5</span>，Boss+<span style="color:#3aa675;font-weight:600">10</span>），X当前值为<span style="color:#3aa675;font-weight:600">X</span>（跨战斗保留）。<br/>④每受到1次未被格挡的攻击伤害X-<span style="color:#3aa675;font-weight:600">2</span>，X<0时直接死亡。

- **混沌属性替换**：战斗开始时移除你身上所有元素属性，再施加 1 层混沌属性。你攻击持有飞行/冰/神秘/次元/邪灵/自然/圣灵 7 种元素的敌人时伤害 ×1.5，攻击持有电/机械/格斗/轮回/虚空 5 种元素的敌人时伤害 ×0.75。
- **守护者卡牌**：每场战斗开始时把 1 张守护者加入手牌底部。守护者是原版奥斯提联动卡——1 费攻击牌，由奥斯提造成 10 点伤害并额外造成等量于奥斯提最大生命值的伤害（升级后 0 费、基础伤害 15）。奥斯提不在场时守护者打不出伤害（卡牌会红光警示）。
- **召唤奥斯提**：回合开始时以 X 点生命召唤奥斯提。若奥斯提已存活，则改为最大生命 +X 并回复 X 点生命——奥斯提是越养越厚的成长型坦克。若奥斯提阵亡，下回合会以 X 点生命复活（最大生命重置为 X，本场的累积清零）。
- **击杀加分**：**必须由你亲手击杀**（你本体打出的攻击伤害）——X 增加。普通敌人 +2、精英 +5、Boss +10，按击杀发生时的房间类型决定加值档次。
- **受伤扣分**：受到未被格挡的攻击伤害后 X -2。非攻击伤害（如能力伤害）不扣 X。X 降至 0 以下时直接处决自身。

## 小贴士

- **X 是跨战斗滚雪球的核心资源**：X 值在存档中持久化，不会因战斗结束而重置。开局 4，随着击杀敌人不断累积，越往后越强。一局下来 X 可以堆到几十，奥斯提每回合涨几十点最大生命，守护者的伤害也跟着水涨船高。
- **守护者与奥斯提形成联动闭环**：每场战斗白送 1 张守护者，守护者的总伤害 = 基础 10 + 奥斯提当前最大生命。X=20 时：第 1 回合召唤 20 血奥斯提、守护者打 30；第 2 回合奥斯提最大生命 40、守护者打 50；第 3 回合打 70……只要奥斯提活着，守护者伤害每回合递增 X。X 不仅决定奥斯提的血量厚度，还直接放大守护者的爆发力，是一鱼两吃。
- **奥斯提阵亡会清空本场累积**：奥斯提被打死后，下回合复活是以 X 点生命**重置**（不是在原最大生命基础上加）——之前养的几十点最大生命全部归零。敌人集火奥斯提就是 counter 你的手段，X 高时务必保护好奥斯提（或接受它死后从 X 血重新滚起）。
- **击杀归属有讲究——必须你亲手补刀**：加分只认**你本体打出的攻击伤害**击杀。毒杀、灼烧烧死（这类伤害没有来源归属）、奥斯提用守护者补刀、队友击杀统统不加 X。异常流构筑拿它要特别注意：把敌人磨到残血后，最后一下要留给自己的攻击牌。
- **AOE 团灭是加分大户**：一张 AOE 牌同时打死多只敌人时，每只敌人独立结算加分——一次团灭 3 只普通怪就是 +6。多怪战斗（尤其会召唤小怪的 Boss 房）里 X 涨得最快。
- **击杀增益 vs 受伤惩罚的拉锯**：杀敌加 X（普通 +2 / 精英 +5 / Boss +10），但每次挨未格挡的攻击伤害扣 2。防得好（不挨打）X 只涨不跌，防不好 X 会被慢慢磨掉。防守压力直接影响滚雪球速度。
- **X < 0 直接死亡是致命风险**：X 掉到负数会立即处决自身，没有回旋余地。如果当前 X 很低（比如刚开局 4），连续挨两三次未格挡攻击就可能暴毙。低 X 时必须优先防守，不能贪输出。
- **只扣攻击伤害，非攻击伤害不扣**：能力伤害等非攻击伤害不会扣 X。面对靠攻击打伤害的敌人要格外小心，面对靠能力/异常打伤害的敌人则相对安全。
- **Boss 战是滚雪球最快途径**：击杀 Boss 一次 +10，是普通敌人的 5 倍。一局里 Boss 数量有限，每次 Boss 击杀都是 X 的大幅跳升。尽量保证 Boss 战中不挨打，把 +10 全额吃下。
- **混沌属性改变元素克制关系**：战斗开始移除所有元素属性换成混沌，意味着你原来的元素构筑（如纯电、纯冰）会被完全覆盖。混沌打 7 种元素 ×1.5、5 种元素 ×0.75，且只影响你的攻击伤害（不影响敌人打你）。如果你牌组依赖特定元素属性，这件遗物会打乱你的元素体系。
- **核心矛盾：进攻滚雪球 vs 防守保命**：杀敌加 X 让奥斯提和守护者更强，鼓励你积极进攻快速清场。但受伤扣 X 甚至致死，又要求你严防死守。攻防节奏的把控是玩好这件遗物的关键——前期 X 低时偏防守，X 堆起来后转进攻收割。
