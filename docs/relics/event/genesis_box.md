# 创世魔盒

<img src="/images/relics/genesis_box.png" alt="创世魔盒" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 事件遗物
- **稀有度**: 事件
- **获取途径**: [「莱达宇宙：缺失的愚者塔罗」](/events/missing_fool_tarot.md) 事件，选择「小心翼翼，伸手触碰魔盒」

## 描述

每场精英战斗胜利后，随机获得1件<span style="color:#d4a017;font-weight:600">塔罗主题遗物</span>。

- **精英战斗胜利送塔罗**：每场精英战斗胜利后，从 21 件塔罗遗物（魔术师到世界，不含愚者）中随机获得 1 件。
- **优先未拥有**：优先选择你尚未拥有的塔罗遗物；全部拥有后才允许重复。

## 风味文字

<span style="color:#d44;font-weight:600">魔盒之中，藏着宇宙的终极秘密。</span>

## 小贴士

- **精英战斗的塔罗稳定来源**：每打赢一场精英战斗就送 1 件塔罗遗物，是塔罗遗物的稳定获取渠道。一局打几场精英战就能集齐多件塔罗，比随机掉落靠谱得多。
- **21 件塔罗不重复优先**：优先送你没有的塔罗，所以前期每场精英战都能拿到新塔罗，不用担心重复。直到 21 件全集齐后才开始重复。
- **不含愚者，呼应事件主题**：塔罗池是魔术师到世界共 21 件，永远不含[愚者](/relics/common/tarot_fool.md)——正对应获取事件「**缺失的**愚者塔罗」的标题：魔盒里装的是大阿卡纳的后 21 张，愚者这张牌本身是缺失的。想要愚者得去别的事件找。
- **只精英战斗触发**：普通战斗、Boss 战不触发，只有精英战斗胜利后才送。拿到它之后主动多走精英房间，每场精英战 = 常规奖励 + 一件塔罗，收益翻倍。
- **塔罗遗物普遍强力**：塔罗主题遗物通常效果较强（如[恋人](/relics/common/tarot_lovers.md)、[死神](/relics/common/tarot_death.md)、[世界](/relics/common/tarot_world.md)等），每场精英战额外送一件等于额外奖励。
- **集齐后重复价值有限**：21 件塔罗全集齐后，再打精英只会重复获得已有塔罗，价值大减。所以前期是黄金期，后期收益递减。
- **获取事件的另外两个选项都是垫底**：同事件里「当场砸碎」是删牌+掉血的代价选项，「按兵不动」只 +18 最大生命。除非正好想删废牌或急需血量上限，正常都选触碰魔盒。
