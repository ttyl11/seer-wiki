# 降级诅咒

<img src="/images/relics/downgrade_next_combat_relic.png" alt="降级诅咒" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 事件

## 描述

本场战斗所有已升级的卡牌被降级。战斗结束后移除此遗物。

- **降级范围**：首回合开始时扫描[抽牌堆](/mechanics/draw_pile.md)、[手牌](/mechanics/hand.md)、[弃牌堆](/mechanics/discard_pile.md)三处所有卡牌，已升级的全部降级回未升级状态。
- **只触发一次**：首回合触发后不再重复，整场战斗只降级一次。
- **战斗后消失**：战斗结束后遗物自动移除，是一次性负面遗物。

## 小贴士

- **一次性负面遗物，全牌组降级**：首回合开始时把你抽牌堆、手牌、弃牌堆里所有已升级的卡牌全部降级回未升级状态。如果你花了很多篝火升级卡牌，这件遗物会让这些升级本场战斗全部失效。
- **三处卡牌全覆盖**：不只是手牌，抽牌堆和弃牌堆里已升级的卡牌也会被降级。所以没有任何已升级的卡牌能幸免，无论它在哪个牌堆。
- **只影响已升级的卡牌**：未升级的卡牌不受影响（没有降级空间）。所以如果你牌组里大部分卡牌都没升级，这件遗物的影响较小。
- **战斗后自动消失**：战斗结束后遗物自动移除，不会占据遗物位。但本场战斗中降级的卡牌已经受到了影响，这场战斗的战力会下降。
- **首回合触发，无法规避**：在你第一回合开始时立即触发降级，没有反应时间。拿到这件遗物就意味着下一场战斗必定全牌组降级，不能选不打。
- **升级多的牌组受害最大**：如果你有 10+ 张已升级卡牌，这场战斗的战力会大幅下降。升级少的牌组（如刚开局）几乎不受影响。
- **核心定位：事件惩罚**：这是一件事件发放的负面遗物，通常作为事件的"代价"出现。拿到后需要硬扛一场降级战斗，之后自动消失。
