# 降级诅咒

<img src="/images/relics/downgrade_next_combat_relic.png" alt="降级诅咒" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 事件
- **获取途径**: [「莱达长老的电车难题考验」](/events/leda_elder_trolley_problem.md) 事件，选择「指认二长老」

## 描述

本场战斗所有已升级的卡牌被降级。战斗结束后移除此遗物。

- **降级范围**：你的第一个回合开始时扫描[抽牌堆](/mechanics/draw_pile.md)、[手牌](/mechanics/hand.md)、[弃牌堆](/mechanics/discard_pile.md)三处所有卡牌，已升级的全部降级回未升级状态。
- **只触发一次**：首个回合触发后不再重复，整场战斗只降级一次。
- **战斗后消失**：战斗结束后遗物自动移除，是一次性负面遗物。
- **只影响本场战斗**：战斗开始时牌组里的卡会被克隆进战斗牌堆，降级只作用于这些战斗内的克隆体——战斗结束后，局外牌组里的升级原封不动，篝火升级的投入不会真的损失。

## 小贴士

- **一次性负面遗物，全牌组临时降级**：你的第一个回合开始时，抽牌堆、手牌、弃牌堆里所有已升级的卡牌全部退回未升级状态。如果花了很多篝火升级卡牌，这件遗物会让这些升级本场战斗全部失效。
- **⚠️ 只是临时生效，升级不会真丢**：战斗里的卡是从局外牌组克隆出来的，降级只改克隆体。战斗结束后翻开牌组——升级还在，篝火投入分毫不少。真正的代价只有"这一场战斗变弱"，不是永久损毁。
- **降级=回到基础版，不会更差**：降级只是把卡重置回未升级形态（数值、耗能都回基础值），不会变成比基础版更烂的版本。
- **三处卡牌全覆盖**：不只是手牌，抽牌堆和弃牌堆里已升级的卡牌也会被降级。没有任何已升级的卡能幸免，无论它在哪个牌堆。
- **只影响已升级的卡牌**：未升级的卡牌不受影响（没有降级空间）。所以牌组里大部分卡都没升级时（如刚开局、或全靠事件加成），这件遗物几乎白板。
- **首回合触发，无法规避**：在你第一回合开始时立即触发降级，没有反应时间。拿到这件遗物就意味着下一场战斗必定全牌组降级，不能选不打。
- **升级多的牌组受害最大**：如果你有 10+ 张已升级卡牌，这场战斗的战力会大幅下降。升级少的牌组（如刚开局）几乎不受影响。
- **三选一的代价之一**：来自[「莱达长老的电车难题考验」](/events/leda_elder_trolley_problem.md)——三个选项分别获得"本场降级"、"本场全卡附带虚无"、"本场开始时塞 10 张随机状态牌"三件一次性负面遗物。三者都是只影响下一场战斗的临时惩罚，战斗结束遗物消失。牌组升级多时降级最伤；依赖留牌连击/打光手牌的构筑更怕虚无；小牌组最怕 10 张状态牌稀释抽牌。按自己的构筑挑伤害最小的那个。
