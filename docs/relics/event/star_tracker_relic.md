# 星辰之录

<img src="/images/relics/star_tracker_relic.png" alt="星辰之录" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 事件

## 描述

记录你在泰坦之灵房间获得的所有永久增益。

- **纯记录遗物**：无任何被动效果，仅展示玩家在泰坦之灵房间金蛋抽奖的累计次数和已获得的永久增益。
- **获取方式**：首次进入泰坦之灵房间时自动发放，不进入正常掉落池。
- **实时读取**：所有数值实时读取，遗物本身不存储计数器——每次抽完金蛋，悬浮提示里的数字立刻刷新。
- **右下角计数器**：遗物图标右下角的计数实时显示累计抽奖总次数。

### 显示内容

- **抽奖统计**：已累计抽奖总次数、各星级（1★-6★）分别的抽取次数。
- **当前所有永久效果**（按星级分组）：
  - **1★**：增伤、减伤、活力、辉星、召唤、铸造
  - **2★**：力量、防御、速度、先制、命中、再生
  - **3★**：敏捷、荆棘、集中、覆甲、仪式、狂暴
  - **4★**：复制、熵、随机充能球、充能球栏位、人工制品、缓冲、无实体、四类唱词、龙胆、神耀能量、魔王咒怨
  - **5★附带**：改善、禁忌魔典、神羽、永昌玺

## 小贴士

- **泰坦之灵房间专属记录器**：首次进入泰坦之灵房间自动获得，记录你在那里金蛋抽奖的累计次数和已获得的所有永久增益。纯记录用途，无战斗效果，相当于一本永久增益账本。
- **按星级分组看增益结构**：1★给增伤/减伤/活力/辉星/召唤/铸造，2★给四维属性+先制/命中/再生，3★给敏捷/荆棘/集中/覆甲/仪式/狂暴，4★给复制/熵/充能球/人工制品/缓冲/无实体/唱词/龙胆/神耀能量/魔王咒怨等机制类增益，5★附带改善/禁忌魔典/神羽/永昌玺等特殊奖励——星级越高，抽到的增益越机制化、越难被普通手段替代。
- **抽奖统计**：按星级（1★-6★）分别统计抽取次数，帮你判断抽奖运气和规划后续投入——比如 1★ 已经攒了不少增伤，同样的泰坦之灵继续砸 1★ 的边际收益如何，看一眼账本就有数。
- **自动获取不占掉落**：注册到事件遗物池不进入正常掉落池，不会挤占其他遗物的掉落位。
