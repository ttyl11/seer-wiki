## 描述

战斗开始时，随机升级牌组中 <span style="color:#3aa675;font-weight:600">3</span> 张卡牌。<br/>回合开始时，将1张<span style="color:#9b59b6;font-weight:600">[米咔](/cards/event/mika.md)</span>加入[手牌](/mechanics/hand.md)。

- **临时升级**：升级作用于战斗中的抽牌堆卡牌，战斗结束后自动销毁，无需手动降级。
- **米咔入手**：拥有者每回合开始向[手牌](/mechanics/hand.md)加入1张[米咔](/cards/event/mika.md)衍生牌。

## 小贴士

- **战斗开始随机升级3张牌**：临时升级抽牌堆中 3 张可升级的卡牌（战斗克隆，不碰局外牌组），战斗结束后销毁。每场战斗重新随机选取——注意是**抽牌堆**随机，改不了你起手固有牌的初始质量，但抽到升级牌的概率整体提升。
- **每回合1张米咔，留到回合末免费自动打出**：米咔主动打出要花 3 费，但**回合结束时在手牌中会免费自动打出**（不耗能量、不占你的出牌操作）——正确用法就是每回合把它攥到回合结束白嫖。米咔每张 PP 5 点，每回合生成的是全新一张（独立 PP），正常节奏根本用不完。
- **米咔自动输出+控场**：自动打出时获得 3 点[格挡](/mechanics/block.md)、对所有敌人造成 3 点攻击伤害、附加 1 种随机[异常状态](/mechanics/abnormal-status.md) 3 回合（全体敌人同一种）、再造成 3 点[固定伤害](/powers/fixed_damage_power.md)（不可格挡）。每回合白嫖一层攻防+异常+固伤，长战斗累计收益可观。
- **超3张牌米咔被弃置**：一回合内打出**第 4 张牌**的瞬间，手牌中所有米咔立刻移入弃牌堆（打出米咔本身不计数触发）。弃牌堆里的米咔不会再自动打出（只在手牌中才触发），等于这回合的米咔收益作废。多段出牌/低费连击流每回合轻松超 3 张，与米咔机制天然冲突——这类构筑拿它前要掂量；慢速高费构筑则几乎每回合都能吃到完整收益。
- **米咔的异常是全池随机**：从全部异常状态里随机抽 1 种（不分好坏——可能抽到睡眠也可能抽到无关痛痒的），对全体敌人统一施加。打群体怪时"全体异常"价值最高，单体 Boss 时异常种类看脸。
- **事件选项的横向对比**：同一事件的另一个选项「当主角」是升级 2 张牌 + 附魔 2 张（一次性即时强化）。「躺平认怂」拿我们仨换长期每回合收益——收益随战斗场次增长，跑线越长越划算，短局或牌组已成型时不如直接升级+附魔。
