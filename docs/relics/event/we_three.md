## 描述

战斗开始时，随机升级牌组中 <span style="color:#3aa675;font-weight:600">3</span> 张卡牌。<br/>回合开始时，将1张<span style="color:#9b59b6;font-weight:600">[米咔](/cards/event/mika.md)</span>加入[手牌](/mechanics/hand.md)。

- **临时升级**：升级作用于战斗中的抽牌堆卡牌，战斗结束后自动销毁，无需手动降级。
- **米咔入手**：拥有者每回合开始向[手牌](/mechanics/hand.md)加入1张[米咔](/cards/event/mika.md)衍生牌。

## 小贴士

- **战斗开始随机升级3张牌**：临时升级抽牌堆中3张可升级的卡牌，战斗结束后销毁，无需手动降级。每场战斗重新随机选取，提升开局手牌质量。
- **每回合1张米咔**：每回合开始向[手牌](/mechanics/hand.md)加入1张[米咔](/cards/event/mika.md)。米咔是衍生攻击牌，回合结束时若在手牌中自动打出，无需主动操作。
- **米咔自动输出+控场**：米咔自动打出时获得3点格挡、对所有敌人造成3点伤害、附加1种随机[异常状态](/mechanics/abnormal-status.md)3回合、造成3点非攻击伤害。每回合自动覆盖格挡、伤害、异常与非攻击伤害。
- **超3张牌米咔弃置**：一回合打出超过3张牌时，手牌中所有米咔移入弃牌堆。大抽牌流派要小心米咔被弃置，影响自动输出节奏。
- **性价比**：事件稀有度合理——每回合自动输出+异常+非攻击伤害是稳定收益，战斗开始升级3张牌是额外福利。米咔自动打出适合辅助型卡组，无需操作即可每回合覆盖攻防。
