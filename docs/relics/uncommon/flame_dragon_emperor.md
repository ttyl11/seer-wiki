# 炎龙圣帝

<img src="/images/relics/flame_dragon_emperor.png" alt="炎龙圣帝" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 罕见

### 数值参数

| 参数 | 数值 |
|---|---|
| 烧伤回合 | 999 |
| 回复生命 | 5 |

## 描述

战斗开始时，令自身和所有敌人<span style="color:#d44;font-weight:600">[烧伤](/powers/burn_power.md)</span><span style="color:#3aa675;font-weight:600">999</span>回合。<br/>回合结束时，若自身处于<span style="color:#d44;font-weight:600">[烧伤](/powers/burn_power.md)</span>状态，回复<span style="color:#3aa675;font-weight:600">5</span>点生命。

- **自身和敌人一起烧伤**：战斗开始同时对自身和所有敌人施加 999 回合烧伤。烧伤每回合造成 3 点不可格挡伤害，并让拥有者的攻击牌伤害 -1。
- **自身烧伤换回复**：自身回合结束时，如果自身仍有烧伤，回复 5 点生命。烧伤扣 3 血、回复 5 血，每回合净 +2 血。

## 小贴士

- **双向烧伤，群体削敌**：战斗开始自身和所有敌人都烧伤 999 回合。烧伤每回合造成 3 点不可格挡伤害，且让拥有者的攻击牌伤害 -1。敌人既掉血又减攻，双重削弱。
- **自身烧伤是赚的**：自身每回合烧伤扣 3 血，回合结束回 5 血，净 +2 血/回合。所以自身的烧伤不是惩罚，反而是持续回血来源——只要烧伤不被清除，每回合都在回血。
- **999 回合等于永久**：999 层烧伤每回合 -1，正常战斗打不完，等于永久烧伤。除非被驱散/免疫类效果清除，否则整场战斗都在生效。
- **烧伤被清除则回复失效**：回合结束的回复需要自身有烧伤才触发。如果自身烧伤被清除（如驱散、免疫类能力），回复也会失效，只剩敌人烧伤在发挥作用。
- **自身攻击牌伤害 -1 是代价**：因为自身也有烧伤，攻击牌伤害 -1。所以这件遗物和纯攻击流有一定冲突——你的攻击牌会变弱。更适合靠烧伤削敌 + 回复续航的消耗流。
- **多敌人战斗收益爆炸**：所有敌人都烧伤，敌人越多总伤害越高。面对 3 个敌人，每回合烧伤就造成 9 点群体伤害，还让所有敌人攻击牌伤害 -1，是群战的强力遗物。
