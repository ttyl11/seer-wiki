# 流萤·雪

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 罕见

### 数值参数

| 参数 | 数值 |
|---|---|
| 计算下注数量 | 1 |
| 奇巧手牌数 | 3 |

## 描述

战斗开始时，将<span style="color:#3aa675;font-weight:600">1</span>张<span style="color:#d4a017;font-weight:600">计算下注</span>加入手牌。<br/>首回合开始时，随机<span style="color:#3aa675;font-weight:600">3</span>张手牌附加<span style="color:#9b59b6;font-weight:600">[奇巧](/mechanics/sly.md)</span>。

- **战斗开始送计算下注**：战斗开始时生成 1 张计算下注到手牌。0 费技能，打出时弃掉其余全部手牌并抽等量牌，之后消耗。
- **首回合随机加奇巧**：首回合开始时，从手牌随机选 3 张附加[奇巧](/mechanics/sly.md)关键词。手牌不足 3 张时全部附加。

## 小贴士

- **这两个效果是设计好的一套组合**：计算下注打出时会弃掉其余全部手牌——而[奇巧](/mechanics/sly.md)的触发条件正是"回合结束前从手牌被丢弃时免费打出"。先送你 3 张奇巧牌、再送你一张能弃掉它们的 0 费牌，等于明示你：第一回合打出计算下注，手里的奇巧牌就会被免费自动打出。一次操作白嫖 3 张牌的效果，还顺手洗一次手牌。
- **计算下注的完整结算顺序**：打出后先弃掉其余全部手牌（奇巧牌暂入弃牌堆并做标记），再抽等量新牌，最后奇巧牌从弃牌堆**免费自动打出**。结算完手牌数不变，但额外执行了 3 张牌的效果——0 费换来一整轮倾泻。
- **奇巧附加是整场战斗有效的**：首回合附上的奇巧关键词在那 3 张牌上**持续整场战斗**，不是只管第一回合。这些牌被打出、进弃牌堆、洗回手牌后，只要再被任何弃牌效果弃置（计算下注、其他弃牌卡），依然会免费自动打出。牌局拖得越久，反复触发的机会越多。
- **想让奇巧触发必须"弃"，正常打出和回合结束弃牌都不算**：奇巧只在回合中主动弃牌时触发——回合结束的常规弃牌不触发。手里捏着奇巧牌却没弃牌手段时，它们只是普通牌，别指望白嫖。
- **PP 牌被奇巧自动打出时照常扣 PP**：免费指的是不花能量，PP 次数照扣。手牌里既有 PP 牌又被附上奇巧时，想清楚要不要让它们被自动打出。
- **随机 3 张无法指定，有误伤风险**：奇巧随机附在 3 张手牌上。如果附到需要择机使用的牌（比如留到 Boss 阶段的爆发牌、需要精确选目标的牌），打出计算下注会把它们强制免费打出，时机不由你定。手牌里有"必须留给关键时刻的牌"时，先手动打出或保留它们再考虑弃牌。
