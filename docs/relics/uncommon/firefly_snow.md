# 流萤·雪

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 罕见

### 数值参数

| 参数 | 数值 |
|---|---|
| 计算下注数量 | 1 |
| 奇巧手牌数 | 3 |

## 描述

战斗开始时，将<span style="color:#3aa675;font-weight:600">1</span>张<span style="color:#d4a017;font-weight:600">计算下注</span>加入手牌。<br/>首回合开始时，随机<span style="color:#3aa675;font-weight:600">3</span>张手牌附加<span style="color:#9b59b6;font-weight:600">[奇巧](/mechanics/sly.md)</span>。

- **战斗开始送计算下注**：战斗开始时生成 1 张计算下注到手牌。计算下注丢弃所有手牌并抽等量牌，是换牌工具。
- **首回合随机加奇巧**：首回合开始时，从手牌随机抽 3 张附加奇巧关键词。手牌不足 3 张时全部附加。

## 小贴士

- **计算下注是免费换牌工具**：战斗开始送 1 张计算下注到手牌。计算下注丢弃所有手牌并抽等量牌，等于免费洗一次手牌。手牌质量差时用它换牌，每场战斗白嫖一次换牌机会。
- **首回合 3 张手牌变奇巧**：首回合开始时，随机 3 张手牌获得奇巧关键词。奇巧牌在使用时有额外效果，让普通牌变成奇巧牌，提升手牌整体价值。
- **只首回合触发**：奇巧只在首回合附加，第二回合及以后不再附加。所以这件遗物的价值集中在前期的爆发和建立优势。
- **手牌不足 3 张全部附加**：如果首回合手牌不到 3 张，所有手牌都会获得奇巧，不会浪费。所以即使手牌少也能吃满收益。
- **奇巧随机分配，无法指定**：3 张奇巧是随机选的，无法指定给特定卡牌。所以无法保证关键牌一定获得奇巧，有一定的随机性。
- **计算下注配合奇巧有联动**：计算下注会丢弃手牌再抽等量，如果丢弃的奇巧牌换成了新牌，新抽的牌不带奇巧。所以要想清楚是先打奇巧牌再用计算下注，还是先用计算下注再等下回合——不过奇巧只首回合加，用了计算下注后新抽的牌不会有奇巧。
