# 圣甲盖亚

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 罕见

## 描述

每次受到未被格挡的伤害后，反弹等量的<span style="color:#d4a017;font-weight:600">不可格挡伤害</span>给攻击者。

- **反弹伤害**：受到伤害后，当目标为拥有者且未格挡伤害大于 0 时，对攻击者造成等量非攻击伤害。
- **⚠️ 本地化与源码不一致**：本地化描述为"不可格挡伤害"，但实际造成的是非攻击伤害（可被格挡）。实际效果以实际效果为准。

## 小贴士

- **反弹量等于实际受伤量**：反弹的伤害等于你未被格挡的部分。格挡越多反弹越少，完全格挡则不触发——所以这张遗物和高格挡牌组有天然矛盾。
- **核心矛盾：越能挡越不反弹**：你想格挡保命，但格挡掉了伤害就不触发反弹。需要在"保命"和"反弹输出"之间找平衡，故意少格挡一点来触发反弹也是一种策略。
- **面对多段攻击效率最高**：多段攻击的每一段只要未被格挡都会触发反弹，每次都反弹等量伤害。敌人多段攻击打你5下，你就反弹5次。
- **只反弹别人的攻击**：不会反弹自己的伤害（自伤不触发），也不会在反弹伤害时再次触发自身（防止无限循环）。
- **反弹伤害可被攻击者格挡**：反弹的是非攻击伤害，攻击者如果有格挡可以挡掉一部分。所以面对高格挡敌人时反弹效果会打折扣。
- **不需要主动出牌**：被动触发，只要你被攻击且受了伤就反弹。适合作为防御型牌组的额外输出来源。
