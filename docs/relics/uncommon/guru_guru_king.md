# 咕噜咕王

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 罕见

### 数值参数

| 参数 | 数值 |
|---|---|
| 召唤生命 | 3 |

## 描述

每次生成<span style="color:#d4a017;font-weight:600">[充能球](/mechanics/orb.md)</span>时，<span style="color:#d4a017;font-weight:600">[召唤](/mechanics/summon.md)</span>奥斯提（增加<span style="color:#3aa675;font-weight:600">3</span>点最大生命）。

- **召唤奥斯提**：每次生成充能球时召唤奥斯提。若奥斯提存活，增加 3 点最大生命**并同时回复 3 点当前生命**；若奥斯提已死亡或不存在，以 3 点最大生命复活或重新召唤（首次召唤自带"为你而死"）。

## 小贴士

- **每颗充能球让奥斯提"上限+3、当前+3"**：奥斯提存活时，每颗充能球在提升 3 点最大生命的同时**回复 3 点当前生命**——3/3 成长到 6/6、9/9，又肉又奶。这不是纸面血量，是实打实的双重成长，不需要额外治疗手段跟上。
- **对残血奥斯提也是急救**：奥斯提受伤后（比如 4/9），下一颗充能球让它变成 7/12——边升上限边补血。充能球生成频率越高，奥斯提的续航越稳。
- **⚠️ 奥斯提只挡攻击伤害**："为你而死"只把你受到的**攻击伤害**的未格挡部分转移给奥斯提。异常状态扣血、[固定伤害](/powers/fixed_damage_power.md)等非攻击伤害**照常砸在你身上**，奥斯提再肉也替你挡不了这些。
- **奥斯提阵亡 = 成长清零**：复活时最大生命重置为 3 并回满 3/3，之前累积的全部清零。保住奥斯提就是保住成长进度——它血量告急时优先喂充能球回血，别让积累白费。
- **复活机制是安全网**：阵亡后下一颗充能球立刻以 3/3 复活并重新挂上"为你而死"。不必过分保守，让奥斯提主动吃伤害换血量差是合理战术。
- **与奥斯提攻击牌联动**：戳击、取回、重压等卡牌需要奥斯提在场才能发挥效果。本遗物提供免费的稳定召唤来源，把卡牌资源省下来。
- **充能球频率就是成长速度**：每颗球都喂 3 点成长，Boss 战拖得越久奥斯提越肉。配合高频生成充能球的卡牌与遗物（以及部分能提升召唤量的效果），长战斗中能养出高血量肉盾。
