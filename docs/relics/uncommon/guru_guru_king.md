# 咕噜咕王

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 罕见

### 数值参数

| 参数 | 数值 |
|---|---|
| 召唤生命 | 3 |

## 描述

每次生成<span style="color:#d4a017;font-weight:600">[充能球](/mechanics/orb.md)</span>时，<span style="color:#d4a017;font-weight:600">[召唤](/mechanics/summon.md)</span>奥斯提（增加<span style="color:#3aa675;font-weight:600">3</span>点最大生命）。

- **召唤奥斯提**：每次生成充能球时召唤奥斯提。若奥斯提存活，增加3点最大生命；若奥斯提已死亡或不存在，以3点最大生命复活或召唤。

## 小贴士

- **每颗充能球都是免费召唤**：每次生成充能球时自动召唤奥斯提。奥斯提存活时每次+3最大生命，死亡时以3点最大生命复活。频繁生成充能球能让奥斯提最大生命越来越高。
- **核心陷阱：最大生命涨了，当前生命不涨**：奥斯提存活时，每颗充能球只增加最大生命，不恢复当前生命。第1颗充能球召唤时当前生命为3，之后无论叠多少颗充能球，当前生命都不变（除非有其他治疗手段）。5颗充能球后奥斯提最大生命15但当前生命仍可能只有3——纸面很肉，实际很脆。
- **奥斯提是你的伤害护盾**：奥斯提拥有"为你而死"能力，会自动吸收所有未被格挡的攻击伤害。奥斯提越肉，你越安全。
- **奥斯提死亡后最大生命重置**：奥斯提死后复活时最大生命重置为3，之前累积的全部清零。保护好奥斯提、避免它轻易阵亡是最大化收益的关键。
- **与奥斯提攻击牌联动**：戳击、取回、重压等卡牌需要奥斯提存活才能发挥效果。本遗物提供稳定的奥斯提来源，不用消耗卡牌资源去手动召唤。
- **充能球流派的核心遗物**：充能球生成频率越高，奥斯提最大生命越高。配合大量生成充能球的卡牌和遗物，能让奥斯提在Boss战中成长为高血量的肉盾——但记得配合治疗手段让当前生命跟上。
- **复活机制是安全网**：即使奥斯提阵亡，下一颗充能球就能将其复活。不必过于保守，让奥斯提主动承担伤害也是合理的战术。
