# 奥利贡

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 罕见

### 数值参数

| 参数 | 数值 |
|---|---|
| 最大选择数 | 3 |

## 描述

战斗开始时，从抽牌堆选择最多<span style="color:#3aa675;font-weight:600">3</span>张牌，清空PP并<span style="color:#d4a017;font-weight:600">[消耗](/mechanics/exhaust.md)</span>。

- **选牌来源**：从抽牌堆选牌，上限为 3 张。
- **PP 清空**：仅对 PP 牌清空 PP 值，非 PP 牌直接消耗不受影响。

## 小贴士

- **开局筛牌消耗**：战斗开始时从抽牌堆选最多 3 张牌直接消耗，相当于开局就能移除牌组里的诅咒/状态/废牌，精简牌组。
- **PP 牌消耗前清空 PP**：选中的 PP 卡在消耗前会清空其 PP 值，防止消耗后 PP 残留。非 PP 卡直接消耗不受影响。
- **精简牌组的核心工具**：配合牌组里的诅咒/状态牌或多余基础牌，每场战斗开局免费消耗 3 张，长期跑图牌组越来越干净。
- **性价比**：罕见稀有度合理——免费消耗 + PP 清空是精简流核心，强度看牌组有多少废牌可筛。
