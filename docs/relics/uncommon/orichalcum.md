# 奥利贡

<img src="/images/relics/orichalcum.png" alt="奥利贡" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 罕见

### 数值参数

| 参数 | 数值 |
|---|---|
| 最大选择数 | 3 |

## 描述

战斗开始时，从抽牌堆选择最多<span style="color:#3aa675;font-weight:600">3</span>张牌，清空PP并<span style="color:#d4a017;font-weight:600">[消耗](/mechanics/exhaust.md)</span>。

- **选牌来源**：从抽牌堆选牌，上限为 3 张（可以一张都不选）。
- **PP 清空**：仅对 PP 牌清空 PP 值再消耗，非 PP 牌直接消耗。

## 小贴士

- **这是"每场战斗"的筛牌，不是永久删牌**：战斗内的消耗不改变局外牌组——战斗结束后所有牌复原，下一场战斗重新选 3 张。它不是删牌工具，而是**每场战斗开局免费优化的抽牌质量**：把最不想在这场抽到的牌从抽牌堆移走，价值远高于一次性删 3 张。
- **最佳目标是诅咒/状态/废牌**：诅咒牌、状态牌、对当前敌人完全无用的牌都是首选——本场抽牌堆干净一截，等于提高每一次抽牌的期望质量。
- **千万别选 PP 核心牌**：选中的 PP 牌会被清空 PP 并消耗——本场这张牌直接作废、一次都打不出。筛牌时避开你的 PP 引擎。
- **发生在起手抽牌之前**：选牌和消耗都结算于抽起手牌之前，3 张被移走的牌不会出现在本场任何一次抽牌里。
- **可以一张不选**：牌组干净或没有值得移的牌时，选 0 张直接开打，没有强制代价。
- **顺手喂消耗堆**：开局就往消耗堆垫 3 张——[沙罗希瓦](/relics/common/sala_xiva.md)（按消耗堆牌数给所有敌人施加等量[固定伤害](/powers/fixed_damage_power.md)）这类消耗堆计数效果从第一回合就满额启动。
