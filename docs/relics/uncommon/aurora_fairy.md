# 极光仙子

<img src="/images/relics/aurora_fairy.png" alt="极光仙子" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 罕见

### 数值参数

| 参数 | 数值 |
|---|---|
| 增伤百分比 | 0（动态） |

## 描述

战斗开始时获得<span style="color:#9b59b6;font-weight:600">[回合增伤](/powers/turn_damage_boost_power.md)</span>（增伤百分比=敌方最大生命之和-自身最大生命）。<br/>击败敌人时，为所有手牌附加<span style="color:#d4a017;font-weight:600">[奇巧](/mechanics/sly.md)</span>，然后丢弃所有手牌。

- **增伤公式**：增伤百分比 = max(0, 敌方所有敌人最大生命之和 − 自身最大生命)，写入[回合增伤](/powers/turn_damage_boost_power.md)能力；差距为 0 或负数时不获得增伤。
- **击杀触发**：仅**攻击牌**击杀敌人时触发（技能牌、能力牌、反伤等其它来源的击杀不算）。
- **奇巧后弃牌**：先给所有手牌永久附加[奇巧](/mechanics/sly.md)，再全部丢弃——**丢弃会触发奇巧，全部手牌免费自动打出**。

## 小贴士

- **敌方血越多你增伤越高**：战斗开始时获得[回合增伤](/powers/turn_damage_boost_power.md)，百分比 = 所有敌方最大生命之和 − 自身最大生命（不小于 0）。敌方总血 300、自身 100 = +200% 增伤，第一刀就是三倍伤害。血量差距越大增伤越恐怖，打多敌人精英战和高血量 Boss 时收益极高。
- **增伤只持续你的第一回合**：回合增伤只施加 1 层，在你自己的回合结束时自动消失。所有增伤收益集中在战斗首轮，开局就是爆发窗口，起手尽量多打攻击牌。
- **增伤只对攻击伤害生效**：回合增伤位于乘法区（与[易伤](/powers/vulnerable_power.md)、暴击相乘），但只提升攻击伤害——灼烧、中毒等异常结算不吃增伤。
- **击杀=全手牌免费打光，这是爆发引擎不是惩罚**：攻击牌击杀敌人后，所有手牌附加[奇巧](/mechanics/sly.md)再弃置，而奇巧的效果正是"回合结束前从手牌被丢弃时免费打出"——等于**把整只手免费全部打出**。第一回合高增伤 + 击杀触发全手牌连打，正是这套遗物的完整combo：先用增伤攻击牌收掉一只残血敌人，剩下的手牌立刻全部免费倾泻出去。
- **连锁击杀**：自动打出的牌若又是攻击牌并再次击杀敌人，会再一次触发（给当时手里的牌附奇巧并弃置）。若自动打出的牌中途抽了新牌，新抽的牌也能吃到新一轮触发。
- **奇巧是永久附加**：附加的奇巧持续整场战斗，这些牌之后若再被其它弃牌效果弃掉（在回合结束前），仍会免费打出；只有回合结束的正常清手牌不触发。
- **目标选择注意**：自动打出时目标由系统自动选择，需要精确指定目标的解场牌（单体控制、指向性移除）可能打不到你想要的目标。手牌里有这类牌时，优先在自己主动打出关键牌**之后**再完成击杀。
- **零增伤场景**：如果自身最大生命 ≥ 敌方总血量（如打弱小敌人），不获得增伤，遗物只剩击杀触发部分——这类速杀局里它基本是白板。
- **性价比**：罕见稀有度合理——首回合高倍率增伤 + 击杀附奇巧是双重收益，且二者互相成全（增伤帮你完成击杀、击杀引爆全手牌）。真正定价点在"血量差越大增伤越高"这个独有公式上，打高血量 Boss 时收益极高。
