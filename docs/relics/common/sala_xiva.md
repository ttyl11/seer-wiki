# 沙罗希瓦

<img src="/images/relics/sala_xiva.png" alt="沙罗希瓦" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 普通

## 描述

每回合开始时，为所有对手附加等同于<span style="color:#d4a017;font-weight:600">[消耗牌堆](/mechanics/exhaust_pile.md)</span>牌数的<span style="color:#d4a017;font-weight:600">[固定伤害](/powers/fixed_damage_power.md)</span>。

- **触发时机**：拥有者自己回合开始时触发（读取当时消耗牌堆的数量，施加后堆不变）。
- **层数来源**：实时读取消耗牌堆的卡牌数，消耗牌堆为空时不触发。
- **结算时序**：你回合开始施加 → 敌人在**它的回合开始**受到等量伤害（固伤结算后整个能力移除，下回合你再施加新的）。伤害为不可格挡的非攻击伤害（见[固定伤害](/powers/fixed_damage_power.md)）。

## 小贴士

- **消耗越多伤害越疼**：每回合开始把消耗牌堆的牌数变成固定伤害施加给所有对手。消耗5张牌就是每回合5点固伤，消耗10张就是每回合10点——注意是**每回合持续结算**，不是一次性：固伤在敌人回合开始扣血后移除，下回合你按新的堆数再施加。消耗流派的核心输出遗物，越往后打越疼。
- **和 PP 牌循环是天然搭配**：[群星的礼赠](/relics/starter/elemental_core.md)（初始遗物）的 PP 牌自动循环机制——PP 耗尽的 PP 牌会自动进消耗堆（不回收）——开局就往消耗堆里攒牌。打 PP 牌越多的牌组，消耗堆涨得越快，沙罗希瓦的固伤基数跟着水涨船高，**人人都能白吃一层收益**。
- **与毁灭的冲突要算清楚**：[毁灭](/mechanics/destruction.md)关键词会把牌"移动到销毁牌堆"——销毁牌堆**不计入**消耗牌堆计数。毁灭系卡牌把消耗堆清空的同时，沙罗希瓦的固伤基数也跟着清零。两套体系一个吃"囤消耗"一个吃"清消耗"，同时持有时互相打架，二选一。
- **固伤无视格挡、不吃力量**：结算的是不可格挡的非攻击伤害——敌人的格挡和减伤对它无效。能挡它的是三类：固伤免疫类能力（施加后直接作废）、免疫异常状态类效果（固定伤害属于异常，施加不上去）、以及会增减固定伤害层数的能力（在施加瞬间按比例增减层数）。
- **对怪物"决心"能力是负反馈**：若对手带[决心](/powers/resolve_power.md)（群星礼赠的怪物能力池之一），你施加的固伤会在它回合开始**反弹给包括你在内的全部它的对手**——给带决心的怪堆固伤等于给自己人上刑，看到怪物带决心就别指望这条输出线。
- **空消耗牌堆不触发**：消耗牌堆为空时不施加固定伤害，第一回合通常没效果。需要先铺几个回合的消耗才能看到收益，是中后期发力的遗物。
- **对所有敌人生效**：固定伤害施加给所有对手，多敌人战斗收益翻倍。
- **性价比**：普通稀有度合理——消耗流派的稳定固伤输出，强度看牌组消耗频率。
