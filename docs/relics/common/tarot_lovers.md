# 恋人

<img src="/images/relics/tarot_lovers.png" alt="恋人" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 塔罗遗物
- **稀有度**: 普通

## 描述

回合结束时，若手中剩余牌数为奇数，对随机敌人施加1层[烧伤](/powers/burn_power.md)和1层[冻伤](/powers/frostbite_power.md)；若为偶数，随机生成1个[充能球](/mechanics/orb.md)。

- 自身回合结束前结算（早于充能球回合被动和弃牌），手牌数为 0 时不触发任何效果。
- 手牌数为奇数时：随机 1 个敌人同时吃到 [烧伤](/powers/burn_power.md) 1 层 + [冻伤](/powers/frostbite_power.md) 1 层——两种异常落在同一个敌人身上。
- 手牌数为偶数时：随机生成 1 个[充能球](/mechanics/orb.md)。候选共 13 种：原版的闪电、冰霜、黑暗、等离子，加上本 Mod 的[圣杯](/orbs/holy_grail_orb.md)、[PP](/orbs/pp_orb.md)、[多用](/orbs/multi_orb.md)、[火山](/orbs/volcano_orb.md)、[海洋](/orbs/ocean_orb.md)、[森林](/orbs/forest_orb.md)、[高塔](/orbs/tower_orb.md)、[星星](/orbs/star_orb.md)、[神谕](/orbs/oracle_orb.md)。玻璃球不在候选之列——它只能由玻璃工艺、旋转工艺、折射这类特定卡牌定向生成。

## 小贴士

- **奇偶手牌就是开关**：留奇数张手牌结束回合就上异常，留偶数张就生成[充能球](/mechanics/orb.md)。这是少数能让玩家主动选择效果的塔罗，规划出牌节奏就能精准切换两种收益。
- **奇数分支是异常流引信**：1 层[烧伤](/powers/burn_power.md) + 1 层[冻伤](/powers/frostbite_power.md)同时挂上，既能配合[女祭司](tarot_high_priestess.md)（冻伤敌人回合空过）又能配合[魔术师](tarot_magician.md)（异常敌人全属性 -1）。只要每回合留奇数张手牌，就等于白送一次异常铺垫。
- **偶数分支是充能球轮盘**：13 种候选随机出一个，涵盖回血（圣杯）、回能（等离子）、增伤（黑暗）、控场（海洋/森林）等全方位效果。轮盘明显偏向 Mod 球——9 种 Mod 球合计约 82% 概率，每种原版球只有约 4.5%。连没有充能球栏位的角色也能靠它白开 1 个栏位。上限很高但不可控，想要稳定收益的卡组会更倾向奇数分支。
- **落地当回合就能干活**：偶数分支的结算时机在充能球回合被动之前——抽到闪电、冰霜、黑暗、森林、海洋、火山、多用这类回合结束被动的球，进场当回合就白触发一次被动（比如森林球刚生成就给随机敌人挂 3 层中毒）。等离子、星星、高塔、神谕、PP、圣杯是回合开始被动，要等下回合才开始产出。
- **空手直接跳过**：手牌为 0 时不触发任何效果。完全打空手牌的回合等于浪费一次触发，记得至少留 1 张牌在手里。
- **手牌规划是新玩法**：传统卡组追求"打空手牌"或"留防御牌"，恋人却要求玩家在回合结束前精确控制手牌奇偶。这会改变出牌顺序的决策逻辑，喜欢操控型卡组的玩家会上瘾。
- **价值锚点**：普通稀有度却能每回合白送异常或充能球，上限远超普通遗物；唯一代价是需要主动规划手牌奇偶，对出牌节奏有要求，纯爆发流卡组可能没余力兼顾。
