# 恋人

<img src="/images/relics/tarot_lovers.png" alt="恋人" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 塔罗遗物
- **稀有度**: 普通

## 描述

回合结束时，若手中剩余牌数为奇数，对随机敌人施加1层[烧伤](/powers/burn_power.md)和1层[冻伤](/powers/frostbite_power.md)；若为偶数，随机生成1个[充能球](/mechanics/orb.md)。

- 自身回合结束前结算，手牌数为 0 时不触发任何效果。
- 手牌数为奇数时：对随机 1 个敌人施加 [烧伤](/powers/burn_power.md) 1 层 + [冻伤](/powers/frostbite_power.md) 1 层。
- 手牌数为偶数时：从全部[充能球](/mechanics/orb.md)池（原版 5 种 + 圣杯、PP、多用、火山、海洋、森林、高塔、星星、神谕）中随机生成 1 个。

## 小贴士

- **奇偶手牌就是开关**：留奇数张手牌结束回合就上异常，留偶数张就生成[充能球](/mechanics/orb.md)。这是少数能让玩家主动选择效果的塔罗，规划出牌节奏就能精准切换两种收益。
- **奇数分支是异常流引信**：1 层[烧伤](/powers/burn_power.md) + 1 层[冻伤](/powers/frostbite_power.md)同时挂上，既能配合[女祭司](tarot_high_priestess.md)（冻伤敌人回合空过）又能配合[魔术师](tarot_magician.md)（异常敌人全属性 -1）。只要每回合留奇数张手牌，就等于白送一次异常铺垫。
- **偶数分支是充能球轮盘**：14 种充能球随机出一个，涵盖回血（圣杯）、回能（等离子）、增伤（黑暗）、控场（海洋/森林）等全方位效果。上限很高但不可控，想要稳定收益的卡组会更倾向奇数分支。
- **空手直接跳过**：手牌为 0 时不触发任何效果。完全打空手牌的回合等于浪费一次触发，记得至少留 1 张牌在手里。
- **手牌规划是新玩法**：传统卡组追求"打空手牌"或"留防御牌"，恋人却要求玩家在回合结束前精确控制手牌奇偶。这会改变出牌顺序的决策逻辑，喜欢操控型卡组的玩家会上瘾。
- **价值锚点**：普通稀有度却能每回合白送异常或充能球，上限远超普通遗物；唯一代价是需要主动规划手牌奇偶，对出牌节奏有要求，纯爆发流卡组可能没余力兼顾。
