# 恶魔

<img src="/images/relics/tarot_devil.png" alt="恶魔" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 塔罗遗物
- **稀有度**: 普通

### 数值参数

| 参数 | 数值 |
|---|---|
| 伤害阈值 | 40 |
| 回合阈值 | 3 |

## 描述

从第三回合起，回合开始时，若上回合造成的总伤害≥<span style="color:#3aa675;font-weight:600">40</span>，将所有敌人攻击[意图](/mechanics/intent.md)无效。

- **三回合启动**：第3回合起才检测，检测的是上一回合你造成的总伤害；前两回合不检测，第1回合的伤害也永远不会被计入。
- **伤害统计**：你造成伤害时累加本回合总伤害，攻击伤害与非攻击伤害都算。
- **意图压制**：触发后所有敌人的攻击[意图](/mechanics/intent.md)变为无效，加增益、上减益等非攻击意图照常执行。
- **每回合清零**：每次回合开始处理完后清空本回合伤害统计，未到检测回合也会清空。

## 小贴士

- **三回合启动期**：遗物第3回合才上线，且检测的是"上一回合"的总伤害。想在第3回合就拿到保护，第2回合必须打出40+伤害；前两回合整体是预热，速攻战往往来不及发力，更适合拉锯战。
- **40伤害线怎么凑**：统计的是你本回合造成的全部伤害，攻击和非攻击都算。早期没成型的build凑40偏吃力，但有了力量堆叠或多段攻击后很轻松，配合[战车](/relics/common/tarot_chariot.md)这类连击流几乎稳触。
- **只废攻击意图**：触发后所有敌人攻击意图变无效，但加增益、上减益等非攻击意图照常执行。对纯输出型boss是硬克制，对爱叠增益的敌人收效有限。
- **稳触发即滚雪球**：每回合都能突破40线时，敌人每回合都打不出攻击，拖得越久优势越大，天然契合慢速成长流。

**性价比**：普通稀有度却能给到全敌攻击意图压制的力度，触发后相当于该回合免受所有敌人攻击，性价比极高。其代价是40伤害门槛加3回合启动期，逼着你往中后期成长流靠，这也算合理的强度约束。
