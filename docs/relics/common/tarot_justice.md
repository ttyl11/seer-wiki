## 基本信息

- **分类**: 塔罗遗物
- **稀有度**: 普通

### 数值参数

| 参数 | 数值 |
|---|---|
| 每2%生命损失增伤(%) | 2 |
| 每2%生命损失减伤(%) | 1 |
| 当前增伤(%) | 0（动态显示） |
| 当前减伤(%) | 0（动态显示） |

## 描述

每损失2%生命值：造成的伤害+<span style="color:#3aa675;font-weight:600">2</span>%，受到的伤害-<span style="color:#3aa675;font-weight:600">1</span>%。<br/>当前增伤：<span style="color:#3aa675;font-weight:600">0</span>%<br/>当前减伤：<span style="color:#3aa675;font-weight:600">0</span>%

- **实时显示**：当前增伤和当前减伤随损失生命值实时变化，战斗开始、自己回合开始、受到伤害时刷新。
- **计算方式**：损失生命百分比÷2后向下取整得到档位，每档+2%增伤、-1%减伤。如损失 <span style="color:#3aa675;font-weight:600">50</span>% 生命 → 25 档 → +<span style="color:#3aa675;font-weight:600">50</span>% 增伤 / -<span style="color:#3aa675;font-weight:600">25</span>% 减伤。
- **生效范围**：仅对受力量加成的攻击伤害生效——自己打出的攻击吃增伤，敌人打过来的攻击吃减伤；非攻击伤害两边都不受影响。

## 小贴士

- **血越少越强**：每损失2%生命，造成伤害+2%、受到伤害-1%。半血时+50%增伤/-25%减伤，残血时接近翻倍输出还自带减伤。
- **只放大攻击伤害**：增伤与减伤都只作用于受[力量](/powers/strength_power.md)加成的攻击伤害，[灾厄](/powers/doom_power.md)、真实伤害等非攻击伤害两边都不受影响。
- **档次计算**：损失百分比÷2后向下取整，损失3%生命只算1档（+2%增伤）。自残压血时尽量凑到2的倍数百分比，多出的1%零头不折算成档位。
- **联动思路**：和[倒吊人](tarot_hanged_man.md)是天生组合——倒吊人每回合自损5点压低血量，正好喂养正义的增伤；再配合护盾/格挡在低血量保命，能把高风险转化为高回报。
- **性价比**：普通遗物里上限最高的增伤件之一，残血状态接近翻倍输出还自带减伤。需要配合自残或保命手段才能安全压血，无脑压血容易暴毙。
