# 科德布鲁

<img src="/images/relics/codblru.png" alt="科德布鲁" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 普通

### 数值参数

| 参数 | 数值 |
|---|---|
| 覆甲层数 | 3 |

## 描述

回合结束时：<br/>若本回合未受到伤害，获得1层<span style="color:#d4a017;font-weight:600">[爆发](/powers/burst_power.md)</span>。<br/>若本回合受到了伤害，获得<span style="color:#3aa675;font-weight:600">3</span>层<span style="color:#d4a017;font-weight:600">[覆甲](/powers/plating_power.md)</span>。

- **伤害判定**：只看未格挡伤害是否大于 0。完全格挡掉的伤害不算"受到伤害"，依然走爆发分支。每回合开始时重置受伤标记。
- **二选一**：回合结束时根据本回合是否受伤分支：未受伤 → [爆发](/powers/burst_power.md) 1 层；受伤 → [覆甲](/powers/plating_power.md) 3 层。

## 小贴士

- **二选一的核心张力**：没受伤给爆发（进攻），受伤给覆甲（防守）。遗物会根据你的场面形势自动切换模式——防得好就奖励你打得更狠，防不住就帮你续命。这是一个自我调节的遗物，不会因为你打得差就完全没用。
- **爆发让下一张技能牌打两次**：1 层爆发 = 下回合打出的下一张技能牌自动重复一次。等于白嫖一次技能效果——配合高价值技能牌（抽牌、加 buff、群伤）收益翻倍。普通遗物给这个效果已经很强了。
- **完全格挡 = 爆发**：判定只看未格挡伤害。只要把敌人打过来的伤害全部格挡掉，就算"未受伤"，照样拿爆发。所以高格挡牌组可以每回合稳定拿爆发，等于每回合白嫖一次技能重复。
- **覆甲是延迟且衰减的防御**：覆甲每回合结束时按当前层数产出等量[格挡](/mechanics/block.md)（层数不清零，下回合开始才 -1），是持续产出而非一次性转化。但科德布鲁的覆甲在回合结束流程的末尾才施加，错过了当回合的产出窗口，还要先挨一次下回合开始的衰减——3 层覆甲下回合结束时只剩 2 层（给 2 点格挡），再下回合给 1 点，全周期总共只产出 3 点格挡，只有理想值（3+2+1=6 点）的一半。防御来得慢且越用越少。
- **连续受伤时覆甲会叠加**：如果连续几回合都受伤，每回合都加 3 层覆甲，覆甲会越叠越厚——第 2 回合结束时就有 5 层（上回合 3 减 1 + 这回合 3），第 3 回合 7 层。越挨打越硬，形成自动续命机制。
- **爆发不跨回合保留**：爆发如果当回合没用掉（没打技能牌），回合结束时自动消失。科德布鲁在回合结束时给爆发，所以爆发只能在下回合使用——下回合记得先打一张高价值技能牌把它用掉。
- **核心矛盾：想拿爆发就不能挨打，想不挨打就要花费用格挡**：为了拿爆发你需要把费用花在格挡牌上，但爆发奖励的是打技能牌——你的费用要同时兼顾格挡和打牌。这个矛盾让遗物不会无脑强，需要你在防守和进攻之间分配资源。
- **性价比**：普通稀有度合理——爆发（技能重复）本身就有不亚于罕见遗物的进攻价值，覆甲提供了防守兜底。攻守兼备且自动切换，普通稀有度偏便宜。
