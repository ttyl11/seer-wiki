# 隐者

<img src="/images/relics/tarot_hermit.png" alt="隐者" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 塔罗遗物
- **稀有度**: 普通

## 描述

如果本回合未出牌，则自身和所有敌人都获得1层[无实体](/powers/intangible_power.md)。

- **触发时机**：自己回合结束时，检查本回合是否出过牌。
- **范围**：自身和所有敌人都获得1层[无实体](/powers/intangible_power.md)。

## 风味文字

<span style="color:#d44;font-weight:600">隐者。</span>

## 小贴士

- **以静制动的双刃剑**：整回合不出牌时，自身和所有敌人都获得1层[无实体](/powers/intangible_power.md)。你换来了生存，但敌人也变得难以打动。
- **无实体只挡攻击**：无实体把攻击伤害降为1点，但[灾厄](/powers/doom_power.md)、能力伤害、真实伤害等全部绕过。想趁隐身输出，得靠非攻击手段。
- **最佳时机**：手里没好牌、敌人意图凶猛时主动空过一回合，等于用一回合换一层无实体保命，比起硬扛更划算。
- **联动思路**：和[死神](tarot_death.md)天然契合——空过回合后手牌全留到回合结束，[灾厄](/powers/doom_power.md)层数等于手牌数，而灾厄绕过无实体直接斩杀。
- **性价比**：普通遗物里偏冷门的保命件，能否发挥作用取决于卡组是否扛得住空过一回合。控制流和灾厄流能把它玩成神技，纯进攻卡组则基本无用。
