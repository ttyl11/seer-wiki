# 月亮

## 基本信息

- **分类**: 塔罗遗物
- **稀有度**: 普通

### 数值参数

| 参数 | 数值 |
|---|---|
| 加成伤害 | 3 |

## 描述

连续打出同类型牌时，对随机敌人造成<span style="color:#3aa675;font-weight:600">3</span>点伤害。

- **触发时机**：打出牌后，仅响应你自己打出的牌。
- **连续同类型**：上一张牌的类型与当前牌相同时触发，每回合第一张牌只记录类型、不触发。
- **伤害类型**：非攻击伤害（不受[力量](/powers/strength_power.md)加成、不会未命中），可被[格挡](/mechanics/block.md)。
- **回合重置**：每回合开始清空上一张牌的类型记录，第一张牌不触发。

## 小贴士

- **连击流的小甜点**：连续打两张同类型牌就白送3点伤害，攻击/技能/能力牌各自算同类型。多段攻击流、技能连发流容易触发，每回合能多次蹭血。
- **不吃加成的3点伤害**：这3点是非攻击伤害，不受[力量](/powers/strength_power.md)加成，也不会因[命中](/powers/accuracy_power.md)降低而未命中，无法靠堆属性养大，只能当个稳定补刀。
- **别为它牺牲节奏**：3点伤害偏低，若手牌类型本来就杂，不必为了触发它硬连两张同类型牌而打乱更优的出牌顺序。

**性价比**：普通稀有度给个免费补刀，稳定无副作用，几乎不挑卡组。3点非攻击伤害在长线战斗里能累积成可观的蹭血量，作为过渡件完全合格。
