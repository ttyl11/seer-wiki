# 战车

## 基本信息

- **分类**: 塔罗遗物
- **稀有度**: 普通

### 数值参数

| 参数 | 数值 |
|---|---|
| 每层伤害加成 | 20 |
| 最大伤害加成 | 100 |

## 描述

连续打出攻击牌时伤害递增，每连续1张增加<span style="color:#3aa675;font-weight:600">20</span>%，最高增加<span style="color:#3aa675;font-weight:600">100</span>%。

- **连击计数**：打出攻击牌时，若上一张也是攻击牌则连击数+1；若上一张非攻击牌则连击数重置为1；打出非攻击牌则连击数归零。
- **伤害加成**：连击数大于1时，攻击伤害提升（连击数-1）×20%，最高+100%（第6张连击攻击封顶）。仅对受力量加成的攻击伤害生效，能力伤害、充能球伤害等不吃加成。
- **回合重置**：自己回合开始时连击数归零，无法跨回合累积。

## 小贴士

- **滚雪球式爆发**：第1张攻击牌没有加成，从第2张起每多连打1张攻击牌伤害+20%，第6张达到+100%上限。想把伤害拉满就得一口气铺出6张攻击牌。
- **技能牌会断链**：穿插任何非攻击牌都会让连击数归零，技能牌要么在攻击链打完后再出，要么留到下回合。
- **只放大攻击伤害**：加成只作用于受[力量](/powers/strength_power.md)影响的攻击伤害，[灾厄](/powers/doom_power.md)、充能球等非攻击伤害完全不吃。
- **联动思路**：多段攻击牌是最佳载体——同一张牌的多段伤害共享当前连击加成，一张多段攻击就能把加成吃满。搭配低费攻击牌连打可快速堆到上限。
- **性价比**：普通遗物中偏进攻的选项，攻击牌密度高的卡组能稳定吃到+40%以上加成。技能牌为主的卡组几乎吃不到加成，按卡组结构决定取舍。
