# 星太白

<img src="/images/relics/xing_tai_bai.png" alt="星太白" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 商店

## 描述

在火堆选择休息时，获得一层1血[复活](/mechanics/revive.md)机会（可叠加，全局通用）。

- **可叠加**：每次休息回复时复活充能递增，可累积多次复活机会。
- **1血复活**：触发复活时回复 1 点生命，消耗一层充能。

## 小贴士

- **火堆休息充能**：在火堆选择休息时获得1层[复活](/mechanics/revive.md)充能，可叠加累积多次。每次休息+1层，多次休息可攒出多次复活机会。剩余充能数显示在遗物图标上（0 时不显示）。注意只有"休息"给充能——升级牌、挖遗物等其他火堆选项不给。
- **1血复活保命**：死亡时消耗1层充能复活，回复1点生命。1血复活极其脆弱，需要配合回血手段才能在复活后存活。
- **充能全局通用**：复活充能全局累积，不限于单场战斗。整局游戏所有火堆休息都能攒充能，适合长线运营。
- **休息本身就是双重收益**：休息回血+攒复活充能一次拿两份价值，让"休息"从纯回复选项变成攻守兼备的战略选择。血量健康时也可以为了攒充能而休息。
- **性价比**：商店稀有度合理——1血复活是最后保命手段，多次累积能防多次致命伤害。但1血复活后需要立即回血，否则下回合仍可能阵亡。
