## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 商店

## 描述

每经过一个精英房间，获得一层可以跳地图的机会。

- **跳跃机制**：当剩余跳跃次数大于 0 时允许非相邻移动（跳跃到非子节点房间）；每次非相邻移动消耗一层。
- **计数器显示**：计数器仅在剩余跳跃次数大于 0 时显示，显示当前剩余次数。

## 小贴士

- **跳跃检测**：进入房间时参照原版飞靴逻辑——比较上一个房间的子节点是否包含当前房间，不包含即判定为非相邻移动并消耗一层。
- **存档兼容**：已弃用的旧字段保留以防止旧存档反序列化失败，运行时仅使用单一剩余跳跃次数计数器。
- **触发过滤**：进入房间时若房间计数大于 1 则直接返回，仅在进入房间首帧检测跳跃。
