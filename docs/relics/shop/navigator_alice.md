## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 商店

## 描述

每经过一个精英房间，获得一层可以跳地图的机会。

- **跳跃机制**：当剩余跳跃次数大于 0 时允许非相邻移动（跳跃到非子节点房间）；每次非相邻移动消耗一层。
- **计数器显示**：计数器仅在剩余跳跃次数大于 0 时显示，显示当前剩余次数。

## 小贴士

- **精英房换跳跃次数**：每进入一个精英房间就攒 1 次跳跃机会（进门即计入）。跳跃机会可以累积，打 3 个精英就有 3 次跳图权。
- **跳跃=移动到不相邻房间**：有跳跃次数时，你可以移动到不与当前房间相连的房间——等于无视地图路线，跳过中间所有房间直达目标。每跳一次消耗 1 层。与原版飞靴（Winged Boots）同类机制。
- **跳跃的三大用途**：①跳过不想打的房间（精英后残血时跳过下一个精英）②直达关键房间（火堆/商店优先访问）③跨越断路（地图路线被堵时绕过去）。地图规划的自由度大幅提升。
- **不打精英就没得跳**：跳跃次数完全来自精英房，回避精英的保守玩法会让这件遗物变成摆设。买它就意味着要主动打精英换机动性——攻防节奏要自己掌握。
- **跳跃不会白给**：注意跳跃是"消耗品"不是"无限飞"，每次非相邻移动都扣 1 层，跳到没有次数就只能沿地图正常走了。剩余次数显示在遗物图标上，规划路线前先看清楚。
- **后期价值上升**：后期楼层精英密度高，跳跃次数越攒越多；配合大牌组或回复能力，用跳跃直达火堆/商店滚雪球很强。
- **性价比**：商店稀有度合理——机动性是杀戮尖塔里隐形的巨大收益，但前提是你敢打精英。攻守兼备的牌组买它血赚，怕精英的怂流买它亏本。
