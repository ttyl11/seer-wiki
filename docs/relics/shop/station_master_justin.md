## 描述

接下来<span style="color:#3aa675;font-weight:600">3</span>场精英战或Boss战首回合开始时，获得卡牌<span style="color:#d4a017;font-weight:600">六翼光剑</span>。

- **触发条件**：精英战或Boss战首回合开始时触发，普通战不触发。
- **次数扣减**：每次触发后剩余次数递减，右下角计数器实时显示剩余次数。
- **卡牌位置**：生成的六翼光剑加入手牌顶部。

## 小贴士

- **精英/Boss战专属启动**：只在精英战和Boss战触发（进入战斗时判定），普通战不消耗次数。3 次机会正好覆盖一局的硬仗，每次开局白拿一张[六翼光剑](/cards/event/six_wing_light_sword.md)到手牌顶，首回合就在手里。
- **六翼光剑是要养的大炮**：这张牌默认**不可打出**，要等你本场**首次洗牌后**才能打出（洗牌自动解锁）。它带"保留"关键词——留在手里不会被回合结束弃掉，可以安心攒到解锁。配合抽牌、洗牌类卡牌能提前激活。
- **0 费 66 伤还带 PP3**：六翼光剑 0 费、单次 66 点伤害（不吃力量加成的固定数值）、PP 3——**本场最多可打 3 次，累计 198 点伤害**，对精英和 Boss 都是实打实的重火力。注意它不可升级。
- **洗牌前是死牌**：开局到首次洗牌之间它只是占手牌的摆设（保留着不掉），且不能主动弃掉换触发——好在"保留"保证它一定会等到解锁那一刻。
- **次数跨战斗保留**：3 次次数跨战斗保留（存档保存），拾起时初始化为 3。用完后遗物变空壳，不影响后续。
- **性价比**：商店稀有度合理——3 张免费六翼光剑全数喂给硬仗，精英/Boss 战开局就有重火力打底，推图稳定性大幅提升。
