# 派克博士

<img src="/images/relics/dr_pike.png" alt="派克博士" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 商店

### 数值参数

| 参数 | 数值 |
|---|---|
| 强制事件次数 | 3 |

## 描述

下<span style="color:#3aa675;font-weight:600">3</span>个问号房间必然为<span style="color:#d4a017;font-weight:600">疯狂科学</span>事件。

- **问号房间强制为事件房**：剩余次数大于 0 时，问号房间不会变成商店/战斗/宝藏等其他类型，必定是事件房。
- **事件强制为疯狂科学**：剩余次数大于 0 时，进入的事件必定是疯狂科学（即原版"打造时间"事件），不会随机到其他事件。
- **计数递减**：每次进入事件房后剩余次数 -1，显示在遗物图标上。3 次用完后不再强制。

## 小贴士

- **下 3 个问号房间必定是疯狂科学事件**：买下后接下来遇到的 3 个问号房间全部变成疯狂科学事件，不会随机到其他事件。等于花一次钱锁定 3 次高价值事件。
- **疯狂科学（打造时间）是定制卡牌事件**：这个事件让你选择卡牌类型（攻击/能力/技能）+ 附加效果（混沌/扼杀/好奇/充能/专长/精进/削弱/暴力/智慧等），获得一张定制卡牌。3 次事件 = 3 张定制卡牌，是补强牌组的绝佳机会。
- **问号房间被强制为事件房，不会变其他类型**：不只是事件类型被替换，问号房间本身也被强制为事件房。所以不会出现"问号变成商店"的情况，3 次问号必定是 3 次事件。
- **计数器显示在遗物图标上**：遗物图标上显示剩余次数（3→2→1→0），让你清楚知道还剩几次强制事件。
- **3 次用完后变为空遗物**：3 次强制事件全部用完后，遗物不再有任何效果，但仍然占据一个遗物位。所以这件遗物的价值集中在前 3 次问号房间。
- **核心价值：锁定高价值事件**：疯狂科学（打造时间）是原版最好的事件之一——免费定制卡牌且无负面代价。锁定 3 次等于保底 3 张定制卡牌，对牌组补强极大。
- **适合在问号多的楼层买**：如果你当前楼层或后续楼层有很多问号房间，买这件遗物收益最大。如果后续问号很少，3 次强制事件可能要跨好几层才能用完。
