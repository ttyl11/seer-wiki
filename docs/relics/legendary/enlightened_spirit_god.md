# 启灵元神

<img src="/images/relics/enlightened_spirit_god.png" alt="启灵元神" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 传奇（自定义稀有度）

### 数值参数

| 参数 | 数值 |
|---|---|
| 放逐怪物数量阈值 | 3 |
| 神印伤害分母 | 8 |
| 神谕阈值百分比 | 50 |
| 免疫回合数 | 1 |

## 描述

①神殇：战斗开始时，若对面怪物大于 <span style="color:#3aa675;font-weight:600">2</span>，随机放逐对面一个血量最低的怪物。（直接秒杀）<br/>②神印：每当出现了与开场不同的怪物，每有一只，给予所有怪物一层<span style="color:#9b59b6;font-weight:600">[神印](/powers/divine_seal_power.md)</span>。（神印：每有一层，回合开始时，造成 <span style="color:#3aa675;font-weight:600">1</span>/<span style="color:#3aa675;font-weight:600">8</span> 其当前生命的<span style="color:#d4a017;font-weight:600">[固定伤害](/mechanics/fixed-damage.md)</span>）<br/>③神谕：每场战斗限一次，自身体力首次降低到 <span style="color:#3aa675;font-weight:600">1</span>/<span style="color:#3aa675;font-weight:600">2</span> 以下时，恢复到 <span style="color:#3aa675;font-weight:600">1</span>/<span style="color:#3aa675;font-weight:600">2</span>。<br/>④神照：第一回合开始时，获得等于遗物数量的[格挡](/mechanics/block.md)。<br/>⑤神启：回合开始时，自身体力大于 <span style="color:#3aa675;font-weight:600">1</span>/<span style="color:#3aa675;font-weight:600">2</span> 时免疫[异常状态](/mechanics/abnormal-status.md)和能力下降。自身体力低于 <span style="color:#3aa675;font-weight:600">1</span>/<span style="color:#3aa675;font-weight:600">2</span> 时，生成一个<span style="color:#9b59b6;font-weight:600">[神谕充能球](/orbs/oracle_orb.md)</span>。

- **神殇秒杀**：①战斗开始时如果对面怪物达到 3 只（≥3 即触发），直接秒杀血量最低的那只。多只并列最低时随机选一只。
- **神印的施加与结算分两个时点**：②的检测/施加发生在**你的回合开始**（战斗中出现新怪物时，每只给所有当前怪物 1 层神印——两只新怪同时出现就是全体 +2 层）；而神印的伤害结算发生在**怪物自己的回合开始**（每只怪各自按身上层数受伤）。伤害公式 = 层数 × 当前生命 ÷ 8（向下取整），3 层神印 = 每回合吃 3/8 当前生命。新增怪物越多，神印叠得越深。
- **神谕保命**：③每场战斗首次生命值降到 50% 以下时，自动恢复到 50%。每场战斗限一次。
- **神照护盾**：④第一回合开始时获得[格挡](/mechanics/block.md)，数值等于当前拥有的遗物数量。遗物越多护盾越厚。
- **神启双模式**：⑤每回合开始时根据生命值切换模式：生命值**高于** 50% 时免疫异常状态和能力下降；生命值**不高于** 50% 时（含恰好一半）改为主动清除这些免疫，并生成一个[神谕充能球](/orbs/oracle_orb.md)（随机提升属性和附魔）。

## 小贴士

- **多敌人战秒杀最弱**：①对面达到 3 只怪物时开局直接秒杀血量最低的一个，瞬间减员降低敌方输出压力。注意是"血量最低"而非"威胁最大"，秒杀的通常是杂兵而非核心敌人；精英战/Boss 战（1~2 只）完全吃不到这条效果，它的价值全在普通群怪战。
- **神印克制召唤流**：②敌方中途召唤的新怪物，要等到**你的回合开始**才叠上神印（检测发生在你这边回合开始时），伤害则在**怪物自己的回合开始**结算——召唤物召唤出来的当回合可以先白嫖一刀，之后每回合开始都按"层数 × 当前生命 ÷ 8"掉血。敌人越召唤，全场神印越深；伤害按"当前生命"算，高血量召唤母体吃到的伤害远比杂兵疼，召唤流 boss 越招越崩盘。
- **神印对开场怪不生效**：神印只由"新怪物出现"触发——开场就站着的 3 只怪永远不会有神印（除非中途有新怪加入才连它们一起叠）。别指望它对普通固定阵容战斗有任何输出贡献。
- **神谕保命**：③每场战斗限一次，HP 首次跌破 50% 时自动回血到 50%。这是稳定的容错底线，可以放心在半血以上激进输出，不用担心被一波带走。
- **神照护盾随遗物数成长**：④首回合获得等于遗物数量的[格挡](/mechanics/block.md)。后期遗物累积到 15+ 个时，开局等于白穿一件重甲，配合⑤的高血量免疫，开局非常稳。注意它只在第一回合给一次，不是每回合。
- **神启的 HP 阈值双模式，掉线瞬间切换**：⑤HP 高于 50% 时每回合刷新免疫（异常状态+能力下降），HP 掉到 50% 及以下的瞬间，免疫被**主动清除**（不是等它自然过期）并改发神谕充能球。配合③的神谕保底（首次跌破 50% 自动回血拉回线上方），大部分时间能保持高血量享受免疫；如果敌人持续压血线，你就反复在"免疫↔充能球"之间切换。想稳就拉血线吃免疫，想输出就故意压线吃充能球——[神谕充能球](/orbs/oracle_orb.md)随机提升属性和附魔，长期压线反而能攒出一身随机强化。
