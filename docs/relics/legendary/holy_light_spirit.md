# 圣光灵神

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 传说（自定义稀有度）

### 数值参数

| 参数 | 数值 |
|---|---|
| 已损失生命伤害百分比 | 5 |
| 永久增伤百分比 | 50 |

## 描述

①每次使用牌，附加对方已损失生命 <span style="color:#3aa675;font-weight:600">5</span>% 的<span style="color:#d4a017;font-weight:600">[固定伤害](/mechanics/fixed-damage.md)</span>。<br/>②整局游戏限一次自身死亡后，满血重生一次。<br/>③重生后获得永久增伤 <span style="color:#3aa675;font-weight:600">50</span>%（全局通用）。<br/>④每回合开始前，净化抽牌堆的所有诅咒牌和状态牌。净化：将诅咒牌和状态牌变为"圣光"。

- **失血固伤**：①每次打出牌时，对这张牌指定的目标敌人施加固定伤害，数值为目标敌人已损失生命的 5%。敌人血越残固伤越高。只对牌指定的目标生效，不是所有敌人都吃。
- **限一次复活**：②整局游戏只有一次。首次死亡时满血复活，复活期间免疫所有伤害和异常状态。
- **永久增伤**：③复活后永久获得 50% 增伤，之后每场战斗开始时自动获得此增伤，整局游戏持续生效。
- **抽牌堆净化**：④每回合抽牌前，将抽牌堆中所有诅咒牌和状态牌转化为圣光牌。净化只作用于抽牌堆，不作用手牌和弃牌堆。

## 小贴士

- **固定伤害随敌人失血成长，是斩杀引擎**：①每次打牌都对牌指定的目标敌人附加其已损失生命的 5%（向下取整）——敌人血越残，附加伤害越高。一个掉了一半血的 200 血 boss，每张牌白赚 5 点固定伤害。配合多段攻击牌或低费高频牌，一回合打 5 张牌就是 25+ 点固伤跳字。注意满血敌人吃不到收益（已损失=0），适合补刀而非起手。
- **复活是过程全免伤的**：②死亡触发复活时，复活瞬间免疫所有伤害、免疫一切能力施加（不止异常状态）、敌人也无法选中你——不会出现"复活瞬间又被补一刀打死"的尴尬。复活回满血（100% 最大生命）。
- **复活奖励当场结算**：③+50% 永久增伤在复活**当场**立即施加，不是下场战斗才生效——复活那场战斗剩下的时间就在享受增伤。之后每场战斗开始时自动重新挂上，整局游戏有效。
- **复活限一次整局游戏**：②死亡后满血重生，但整局游戏只有一次机会。这是终极保命底牌，建议留到 boss 战或必死局面再触发，平时不要依赖复活去扛伤害，别浪费在简单战斗。
- **复活越早，增伤红利越大**：③复活后永久 +50% 增伤——早死一次（比如中期某场精英战）换后续全程增伤，收益反而可能更高；但复活只有一次，需要权衡"早复活早享受增伤"与"留到关键时刻保命"。真正的抉择是：这 50% 增伤打算用几层来换。
- **净化抽牌堆 = 白送圣光**：④每回合抽牌前把抽牌堆的诅咒牌和状态牌转化为[圣光](/cards/ancient/holy_light.md)（1 费技能：本回合所有牌耗能 -1，抽 2 张牌）——净化掉的不是"废牌变没了"，而是变成一张能润滑当回合爆发的优质牌。对带大量诅咒牌的牌组或面对塞诅咒/状态牌的敌人时，既保证每回合抽到的都是可用牌，还能顺手打出一波 0 费爆发。
- **净化只管抽牌堆，手牌和弃牌堆不管**：塞进手牌的诅咒不会被净化（要靠打出或其它手段处理），弃牌堆里的诅咒也只有洗回抽牌堆后才会被净化。敌人往你牌组里塞的诅咒/状态，最终都会在进入抽牌堆的那一刻被转化为圣光。
