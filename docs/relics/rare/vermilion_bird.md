# 炽羽炎凤·朱雀

<img src="/images/relics/vermilion_bird.png" alt="炽羽炎凤·朱雀" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 稀有

### 数值参数

| 参数 | 数值 |
|---|---|
| 缓冲层数 | 3 |
| 重生生命百分比 | 50 |

## 描述

①自身死亡时[重生](/mechanics/revive.md)一次（每场游戏只触发一次），重生后回复 <span style="color:#3aa675;font-weight:600">50</span>% 最大生命并获得 <span style="color:#3aa675;font-weight:600">3</span> 层<span style="color:#d4a017;font-weight:600">[缓冲](/powers/buffer_power.md)</span>。<br/>②触发重生的每一次战斗结束后，将一张<span style="color:#9b59b6;font-weight:600">狱火</span>加入牌组。

- **整局一次**：复活标记持久化保存，触发后整局游戏不再复活。
- **复活后诅咒**：触发复活后，本场及之后每场战斗胜利都会向牌组永久加入1张狱火。

## 小贴士

- **整局一次的复活保险**：自身死亡时复活，回复50%最大生命并获得3层[缓冲](/powers/buffer_power.md)（每次抵消1次伤害）。复活标记持久化保存，整局游戏只能触发1次，是最后保命手段。
- **复活过程完全无敌**：复活结算期间受到的伤害乘0、能力施加量拦截为0、不可被击中、阻止战斗提前结束。复活过程不会被任何效果打断，安心等回血。
- **复活后每场+1狱火**：触发复活后，本场及之后每场战斗胜利都会向牌组永久加入1张狱火。复活是双刃剑——保命但持续污染牌组，越早复活负担越重。
- **狱火是自残型能力牌**：狱火（原版能力牌）打出后永久生效——回合开始时失去1点生命，本回合内每次失去生命时对所有敌人造成6点伤害（升级后9点）。配合自残流或高血量流派能转化为持续输出，但对普通卡组是每回合自残1点的持续负担。
- **性价比**：稀有度合理——一次复活保命+3层缓冲是顶级保险，但复活后每场+1狱火的代价不可忽视。适合高风险卡组或最终决战兜底，不建议轻易触发。
