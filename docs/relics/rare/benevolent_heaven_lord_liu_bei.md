# 仁天之君·刘备

<img src="/images/relics/benevolent_heaven_lord_liu_bei.png" alt="仁天之君·刘备" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 稀有

## 描述

回合开始时，自身每处于一种<span style="color:#d44;font-weight:600">[异常状态](/mechanics/abnormal-status.md)</span>，则随机无效化敌人一个意图。

- **触发条件**：仅在我方回合开始时触发，统计自身当前处于的异常状态种类数（不累计层数，仅按种类计数）。
- **目标范围**：每个异常状态对应一次随机敌人意图无效化，目标敌人随机抽取，可能多次命中同一敌人。
- **无效化效果**：被无效化的敌人该回合的整个行动被阻止——不仅仅是被替换的那一个意图，而是该回合所有意图都不执行。

## 风味文字

<span style="color:#d44;font-weight:600">仁天之君·刘备。</span>

## 小贴士

- **无效化 = 敌人整个回合不行动**：一次无效化直接封死该敌人本回合的**全部**行动——原理是把整个行动的执行入口替换为空操作（意图列表只是 UI 显示）。敌人本回合排了"攻击 + 增益 + 召唤"三个意图，一次无效化全部落空。
- **按种类计数，不按层数**：统计的是异常状态**种类数**——凝滞 3 层 + 失明 2 层只算 2 种。只需要种类多样，不需要叠层数，1 层就顶 1 个名额。
- **每种异常状态换一次随机点名**：N 种异常状态 = N 次独立随机选择敌人并无效化其行动。**选择可能重复命中同一敌人**——重复点同一个敌人时不会叠加额外效果（它的行动已经被封死了），属于浪费。敌人数量越接近异常状态种类数，点名越不浪费。
- **单体 Boss 时 1 种就够**：Boss 一回合只有一个行动，第一次无效化就已完全封死，额外的异常状态种类在单体战斗中是冗余——它们的价值在多敌人场景兑现。
- **异常状态是"燃料"，越多越好**：通常挨异常状态是坏事，在这件遗物手里是控制弹药。主动让自己进入多种不同异常状态（自施加类效果、敌方施加的异常都可以吃），把负面转化为每回合的群体封行动。
- **触发时序在我方回合开始**：无效化发生在你回合开始的那一刻——封掉的是敌人**即将执行**的本轮行动，正好护住你这一整个回合的输出环境。
