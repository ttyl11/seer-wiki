# 裁罪魔剪·塞泽斯

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 稀有

## 描述

①你每损失<span style="color:#3aa675;font-weight:600">1</span>生命，造成伤害提升<span style="color:#3aa675;font-weight:600">0.5</span>%，受到伤害和固定伤害减少<span style="color:#3aa675;font-weight:600">0.1</span>%。低于半血的部分翻倍。<br/>②战斗结束时，你可以删去一张牌，若如此做，你损失<span style="color:#3aa675;font-weight:600">50</span>%当前生命值。

- **损失计算**：损失生命 = 最大生命 - 当前生命。以半血为界，半血以上的损失按正常倍率计算，半血以下的损失倍率翻倍。
- **增伤**：你造成的攻击伤害提升（正常损失×0.5% + 翻倍损失×1%）。
- **减伤**：你受到的攻击伤害和固定伤害减少（正常损失×0.1% + 翻倍损失×0.2%）。
- **删牌扣血条件**：只有在奖励界面真正选择删去一张牌后，才会损失50%当前生命值；若取消删牌则不扣血（符合"若如此做"的语义）。

## 小贴士

- **核心矛盾：越残血越强，但越残血越容易死**：损失的生命越多，造成伤害越高、受到伤害越低。满血时无加成，半血时+25%伤害/-5%减伤，残血时加成可达+75%伤害/-15%减伤（100血角色）。但残血时一次失误就可能被秒杀——高收益和高风险绑在一起。
- **半血是质变临界点**：低于半血的部分增减伤效果翻倍。半血以上每损失1血+0.5%伤害/-0.1%减伤；半血以下每损失1血+1%伤害/-0.2%减伤。主动压到半血以下收益显著。
- **高血量角色收益更大**：加成按损失生命的绝对值计算，最大生命越高，可损失的量越多，加成上限越高。200血角色残血可达+150%伤害，100血角色只有+75%。
- **增伤只加成攻击伤害**：增伤仅作用于你造成的攻击伤害（受力量影响的攻击牌伤害），不影响毒、焚烧等非攻击伤害。减伤则同时覆盖攻击伤害和固定伤害，残血时连固定伤害都能大幅减免。
- **每场战斗免费删牌**：战斗胜利后获得一次删牌机会，代价是损失50%当前生命。删牌是永久强化牌组的核心资源，这个代价在长线收益面前非常划算。
- **不删牌则不扣血**：玩家可以取消删牌，取消时不会扣除50%当前生命。但删牌是稀缺资源，通常应当总是删牌。
- **残血时删牌代价更低**：50%生命损失按当前生命计算，残血时绝对损失更少。而且本遗物的减伤效果会降低这笔生命损失（残血时减伤更强），形成正反馈循环。
- **配合自伤/压血手段**：主动压血（自伤卡牌、卖血遗物）能快速进入高加成区间。配合回血手段在战斗中调整血线，战斗结束前压低血量可减少50%损失。
