# 幽冥帝尊·修罗

<img src="/images/relics/nether_emperor.png" alt="幽冥帝尊·修罗" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 稀有

### 数值参数

| 参数 | 数值 |
|---|---|
| 生命阈值 | 70（%） |
| 先制层数 | 1 |
| 最大生命伤害百分比 | 15（%） |
| 暴击倍率 | 150（即 1.5×） |

## 描述

在你的回合开始时，若生命值><span style="color:#3aa675;font-weight:600">70</span>%，获得<span style="color:#3aa675;font-weight:600">1</span>层<span style="color:#d4a017;font-weight:600">[先制](/powers/first_strike_power.md)</span>；若生命值≤<span style="color:#3aa675;font-weight:600">70</span>%，本回合所有攻击必定[暴击](/powers/critical_strike_power.md)（伤害×<span style="color:#3aa675;font-weight:600">1.5</span>）。
击败敌人时，对随机存活敌人造成其最大生命<span style="color:#3aa675;font-weight:600">15</span>%的伤害，并回复等量生命。

- **触发边界**：生命百分比严格大于阈值（70%）时给先制，小于等于阈值时改为本回合必暴击，二者每回合二选一。
- **暴击只加成攻击伤害**：必暴击仅对攻击牌造成的伤害生效（×1.5），烧伤、中毒等非攻击伤害不受影响。

## 小贴士

- **血量自适应切换模式**：血量 >70% 时给 1 层先制（下张牌耗能 -1），≤70% 时本回合所有攻击必暴击。高血量抢节奏减费，低血量爆发输出——遗物自己根据血量选模式，不用手动切。
- **先制是减费不是增伤**：1 层先制 = 下一张牌耗能 -1，打出后移除。想用先制减费就得高血量开局，适合配合高费牌打出 0 费爆发。
- **暴击只对攻击牌生效**：必暴击 ×1.5 只加成攻击牌的伤害，非攻击伤害（烧伤结算、中毒等）不暴击。低血量回合集中打攻击牌收益最大，别指望靠烧伤蹭暴击。
- **击杀连锁不可格挡**：击杀敌人后对随机存活敌人造成其最大生命 15% 伤害（不可格挡的非攻击伤害，不是[固定伤害](/powers/fixed_damage_power.md)），并等量回血。多敌人场景越杀越强，残局收割利器。
- **血量管理是核心矛盾**：想触发暴击就得压血到 70% 以下，但血太低有暴毙风险。适合有回血或护盾支撑的牌组主动控血换爆发，脆皮牌组慎用。
- **性价比**：稀有稀有度合理——自适应减费/暴击 + 击杀回血连锁三合一，强度取决于血量管理能力，操作空间大。
