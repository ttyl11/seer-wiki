# 群星的礼赠

<img src="/images/relics/elemental_core.png" alt="群星的礼赠" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 初始

### 数值参数

| 参数 | 数值 |
|---|---|
| 赛尔牌出现概率 | 45% |
| 稀有遗物掉落概率 | 1% |
| 罕见遗物掉落概率 | 3% |
| 普通遗物掉落概率 | 6% |

## 描述

局外<span style="color:#d4a017;font-weight:600">右键点击</span>使用一次：从30个遗物中选择1个。<br/>选择<span style="color:#d4a017;font-weight:600">普通</span>遗物：敌人最大生命-20%。<br/>选择<span style="color:#d4a017;font-weight:600">罕见</span>遗物：敌人最大生命不变。<br/>选择<span style="color:#d4a017;font-weight:600">稀有</span>遗物：敌人最大生命+20%。<br/>选择<span style="color:#9b59b6;font-weight:600">史诗</span>遗物：敌人最大生命+40%。<br/>选择<span style="color:#9b59b6;font-weight:600">传说</span>遗物：敌人最大生命+80%。

- **遗物宝库（局外右键，30 选 1）**：局外右键打开 30 选 1 遗物网格（14 普通 + 8 罕见 + 5 稀有 + 2 史诗 + 1 传奇），含角色彩蛋遗物；必须选一个，不能跳过。选择后按所选稀有度调整下场战斗所有敌人的最大生命。
- **HP 倍率**：普通 ×0.8（-20%）、罕见 ×1.0（不变）、稀有 ×1.2（+20%）、史诗 ×1.4（+40%）、传奇 ×1.8（+80%）。
- **每回合注入属性与暴击**：每回合开始时，为所有玩家和敌人中尚未拥有者补齐随机[属性](/mechanics/element-affinity.md)（26 选 1）和 1 层[暴击](/powers/critical_strike_power.md)。
- **怪物能力随机化**：随探索房间数累积概率，为敌人附加 60+ 种额外能力（强体、侵蚀、暗滞、神话、复活、要害、绝律等），概率受设置项控制。
- **赛尔牌注入**：卡牌奖励与商人卡池按概率混入赛尔卡池的卡牌，战斗奖励选项补齐到 4 张。
- **战斗胜利额外掉落**：每场胜利后按概率额外掉落一件遗物（稀有 1% / 罕见 3% / 普通 6%）。
- **PP 牌循环**：回合开始从消耗堆回收 PP>0 的 PP 牌到弃牌堆（虚无牌、能力牌除外）；回合结束消耗手牌/抽牌/弃牌中 PP=0 的 PP 牌（受[无为觉者](/relics/legendary/inaction_awakener.md)抑制）。
- **首事件强制**：跑局第一幕开局，首个未知房间强制为事件，且首个事件被替换为志旭之战（除 Neow 外）；起始点后的路径节点同步开放，确保能走到该事件。

## 小贴士

- **宝库稀有度与敌人强度的核心权衡**：选普通遗物敌人血量 -20%，选传奇遗物敌人血量 +80%。所以宝库不是"越稀有越好"——选传奇遗物虽然本身强力，但所有敌人血量近乎翻倍，整局都会更难。要根据牌组强度权衡：牌组强选高稀有度滚雪球，牌组弱选普通降难度保命。注意血量倍率是**整局持续**（每场战斗开始前都按倍率调整所有敌人最大生命），不是只影响下一场。
- **彩蛋遗物按角色出现**：宝库的 30 格里会优先塞入当前角色的专属彩蛋（已拥有的不占位）：铁甲战士能看到[典韦](/relics/uncommon/dian_wei.md)、[邪灵魔龙王](/relics/uncommon/evil_nether_dragon_emperor.md)、[超算鲁比克](/relics/rare/rubik_supercomputer.md)、[塔罗·正义](/relics/common/tarot_justice.md)；沉默猎手能看到[萤火雪](/relics/uncommon/firefly_snow.md)、超算鲁比克、[塔罗·恋人](/relics/common/tarot_lovers.md)、[塔罗·隐士](/relics/common/tarot_hermit.md)；观者能看到[天隐圣剑](/relics/uncommon/divine_sword_tianyin.md)、超算鲁比克、[圣辉王](/relics/common/star_holy_king.md)；缺陷者能看到[东海龙王](/relics/common/east_sea_dragon_king.md)、[圣王萨格罗斯](/relics/rare/holy_king_sargeros.md)、超算鲁比克、[塔罗·塔](/relics/common/tarot_tower.md)；缚灵师能看到[罗刹鬼剑](/relics/common/ghost_sword_rakshasa.md)、超算鲁比克、[塔罗·死神](/relics/common/tarot_death.md)。彩蛋会挤占对应稀有度的名额（如铁甲战士的 4 个彩蛋里普通/罕见/稀有的格子会相应减少）。**选角色就是在选宝库候选池**——想拿塔罗·正义就选铁甲战士开局。
- **每场战斗都有额外遗物掉落**：每场胜利后 1% 稀有 / 3% 罕见 / 6% 普通概率额外掉一件遗物。一局打几十场战斗，累积下来额外遗物相当可观，是 mod 里重要的遗物来源。
- **每回合自动补属性和暴击**：每回合开始，全场（玩家和敌人）**尚未持有**属性的单位补 1 个随机属性、**尚未持有**暴击的单位补挂暴击（不是每回合叠加——属性和暴击都是"缺了才补"）。属性带来克制关系，暴击带来爆发，让每场战斗都有随机性。注意敌人也会拿到属性和暴击，不是单方面增益。若某角色已持有属性（如谱尼的[起源流转](/relics/starter/origin_shift.md)给的神灵），则不会被随机属性覆盖。
- **怪物能力随探索深度越来越凶**：敌人附加额外能力的概率随探索房间数累积增长（约 60+ 种，每种能力独立掷骰，一个怪可能同时挂上好几种）。开局时几乎所有概率都是 0，越往后威胁越大——第三层的精英可能同时带"强体+复活+绝律"这类组合。已经拥有任意怪物能力的怪不会再次掷骰，所以威胁是"开局定型"的：进场时看一眼挂了什么，本场不会再追加。
- **赛尔牌混入卡池**：卡牌奖励和商店卡池会按概率混入赛尔卡池的卡牌，且战斗奖励补齐到 4 张选项。所以即使选了原版角色，也能拿到赛尔卡的卡牌，丰富了牌组构筑。
- **PP 牌的自动循环**：PP 牌用完 PP 后会自动消耗，PP>0 的 PP 牌会从消耗堆回到弃牌堆循环使用（虚无牌和能力牌除外——这两类不会回收）。这个机制让 PP 牌成为可循环资源，而非一次性消耗品。[无为觉者](/relics/legendary/inaction_awakener.md)会抑制这个循环，让 PP=0 的牌留在手里不消耗。
- **首场必遇志旭之战**：跑局第一个问号房间必然是志旭之战事件，提供匠心/龙魂阵营任务牌或从 100 张赛尔卡选 7 张的选项。这是 mod 给的早期定向选择，决定本局大致走向。
- **商店 Seer 遗物加价**：商店里的 Seer 遗物会比原版贵（加价幅度受设置项控制）。所以买 Seer 遗物要预留更多金币，别按原版价格规划经济。
