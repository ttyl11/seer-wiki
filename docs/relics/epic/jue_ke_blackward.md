# 爵刻·黑沃德

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 史诗（自定义稀有度）

## 描述

在每场战斗开始时，获得<span style="color:#9b59b6;font-weight:600">[爵刻](/powers/jue_ke_power.md)</span>，层数等于牌组中<span style="color:#d4a017;font-weight:600">[PP牌](/mechanics/pp-system.md)</span>的数量。

- **PP牌计数**：战斗开始时统计牌组中PP牌的数量，作为爵刻的施加层数。
- **零牌保护**：若牌组中无PP牌，则不施加爵刻。

## 风味文字

<span style="color:#d44;font-weight:600">黑沃德。</span>

## 小贴士

- **PP牌越多爵刻越强**：爵刻层数 = 牌组中PP牌数量。10张PP牌就获得10层爵刻，20张就20层。每层爵刻提供"回合开始+1先制"+"造成伤害时附加4点固定伤害并回2血"。PP牌越多，先制叠得越多，固定伤害和回血触发次数也越多。
- **爵刻是攻防一体的能力**：每层爵刻在回合开始给1层先制（减费），造成伤害时附加4点固定伤害并回2血，然后消耗1层。所以10层爵刻 = 10回合先制+10次4点固定伤害+10次2点回血——攻防两端都有收益。
- **核心矛盾：PP牌占牌组位但效果弱**：PP牌越多爵刻越强，但PP牌本身通常效果较弱（主要靠PP系统消耗PP触发效果）。牌组里塞太多PP牌会挤占强力卡牌的位置——需要在"爵刻层数"和"牌组质量"之间平衡。
- **配合高频攻击牌组**：爵刻的固定伤害和回血在"造成伤害时"触发，攻击牌越多触发越频繁。配合多段攻击牌，一次攻击就能触发多次爵刻效果。
- **爵刻消耗后需要重新积累**：爵刻每次造成伤害消耗1层，打完就没了。一场战斗中爵刻层数是固定的（=牌组PP牌数），用完就不再有先制和固定伤害加成。长线战斗中需要控制出牌节奏。
- **先制是额外减费收益**：爵刻每层在回合开始给1层先制，先制每层让下一张牌耗能-1。10层爵刻意味着每回合开始有10层先制——第一张牌直接减10费（相当于免费），是极强的减费来源。
