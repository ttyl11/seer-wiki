# 诅咒之神·狄修

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 史诗（自定义稀有度）

### 数值参数

| 参数 | 数值 |
|---|---|
| 基础属性加成 | 0 |
| 每诅咒属性加成 | 1 |
| 每诅咒格挡 | 6 |
| 每诅咒固定伤害 | 10 |

## 描述

①战斗开始时，[全属性](/mechanics/all_attributes.md)+（牌组中<span style="color:#d44;font-weight:600">诅咒牌</span>数×<span style="color:#3aa675;font-weight:600">1</span>）。<br/>②回合开始时，[手牌](/mechanics/hand.md)中每有1张<span style="color:#d44;font-weight:600">诅咒牌</span>获得<span style="color:#3aa675;font-weight:600">6</span>点<span style="color:#d4a017;font-weight:600">[格挡](/mechanics/block.md)</span>。<br/>③[抽牌堆](/mechanics/draw_pile.md)中每有1张<span style="color:#d44;font-weight:600">诅咒牌</span>对随机敌人造成<span style="color:#3aa675;font-weight:600">10</span>点<span style="color:#d4a017;font-weight:600">[固定伤害](/powers/fixed_damage_power.md)</span>。<br/>④[弃牌堆](/mechanics/discard_pile.md)中每有1张<span style="color:#d44;font-weight:600">诅咒牌</span>获得1张<span style="color:#d4a017;font-weight:600">燃料</span>。<br/>⑤[消耗牌堆](/mechanics/exhaust_pile.md)中每有1张<span style="color:#d44;font-weight:600">诅咒牌</span>自动打出[抽牌堆](/mechanics/draw_pile.md)顶1张牌。

- **全属性加成**：战斗开始时一次性施加[力量](/powers/strength_power.md)、[防御](/powers/defense_power.md)、[命中](/powers/accuracy_power.md)、[速度](/powers/speed_power.md)，每项层数 = 牌组诅咒数 × 1，整场战斗有效。
- **回合开始四效齐发**：②③④⑤均在自身回合开始时触发，分别扫描手牌/抽牌堆/弃牌堆/消耗牌堆中的诅咒牌数量。
- **燃料**：原版 0 费技能牌，获得 1 点能量 + 抽 1 张牌，消耗。等于把弃牌堆的诅咒转化为免费过牌。
- **自动打出**：每张消耗牌堆的诅咒触发一次自动打出抽牌堆顶牌（不消耗费用和 PP）。需指定目标的牌随机选敌人，无合法目标则跳过。

## 小贴士

- **诅咒全面翻身变资源**：这张遗物把诅咒牌的惩罚完全反转——牌组里的诅咒给全属性，手牌里的诅咒给格挡，抽牌堆里的诅咒给固定伤害，弃牌堆里的诅咒给燃料，消耗堆里的诅咒给自动出牌。每个牌堆的诅咒都有对应收益，诅咒越多越强。
- **全属性加成是永久质变**：①在战斗开始时按牌组诅咒数给全属性。5 张诅咒 = 力量+5（每次攻击多打 5 点）+ 防御+5（每次受击少 5 点）+ 命中+5 + 速度+5（回合多抽 2 张）。这是一次性的整场战斗永久 buff，不需要每回合维持。诅咒越多，起手属性越恐怖。
- **抽牌堆诅咒 = 每回合免费输出**：③每回合对随机敌人造成 10 点固定伤害 × 抽牌堆诅咒数。诅咒只要还在抽牌堆里，每回合都会触发。5 张诅咒在抽牌堆 = 每回合 50 点固定伤害，全程自动白嫖。
- **弃牌堆诅咒 = 免费能量和过牌**：④每张弃牌堆的诅咒给一张燃料（原版 0 费技能牌：+1 能量、抽 1 牌、消耗）。等于每张弃牌堆诅咒白送一次免费过牌——既补能量又过牌，弃牌堆的诅咒越多，你的资源越充裕。
- **消耗堆诅咒 = 免费自动出牌**：⑤每张消耗堆的诅咒自动打出抽牌堆顶的一张牌（不花费用和 PP）。消耗 5 张诅咒 = 每回合免费打 5 张牌。但自动出牌不可控——可能歪到不需要的牌上，也可能浪费关键牌的时机。
- **核心矛盾：诅咒越多越强，但诅咒仍然占手牌**：虽然手牌诅咒给格挡，但诅咒本身打不出去（或打出有负面效果），会挤占手牌空间。需要消耗或弃掉诅咒来腾手牌——但消耗和弃牌又会把诅咒移到其他牌堆触发其他效果。所以诅咒在不同牌堆间流转的过程本身就是在不断产生收益。
- **与诅咒生成卡完美配合**：牌组中能生成诅咒牌的卡能大幅提升全属性加成。生成越多诅咒，①的加成越高，②③④⑤的触发量也越大。这张遗物让诅咒生成从惩罚变成核心 build。
- **与消耗诅咒的卡配合**：能消耗诅咒牌的卡能把诅咒从手牌移到消耗堆，既腾出手牌空间又触发⑤的自动出牌。一石二鸟。
- **性价比**：史诗稀有度偏便宜——5 个效果全面转化诅咒惩罚为收益，全属性永久 buff + 每回合免费输出 + 免费资源 + 免费出牌，机制级强度。前提是牌组有足够诅咒数，诅咒少的牌组收益有限。
