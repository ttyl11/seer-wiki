# 孙权

<img src="/images/relics/sun_quan.png" alt="孙权" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 史诗

### 数值参数

| 参数 | 数值 |
|---|---|
| 制衡抽牌阈值 | 7 张/回合 |
| 制衡触发次数 | 1 次/回合 |
| 奇巧附加数 | 1 张/技能牌 |
| 下回合多抽 | 1 张/攻击牌 |

## 描述

①每回合累计抽到 <span style="color:#3aa675;font-weight:600">7</span> 张牌时，可以选择丢弃任意数量的手牌，然后摸等量的牌（每回合 <span style="color:#3aa675;font-weight:600">1</span> 次）。<br/>②你每使用一张<span style="color:#d4a017;font-weight:600">技能牌</span>，随机一张牌（抽牌堆/手牌/弃牌堆）获得<span style="color:#d4a017;font-weight:600">[奇巧](/mechanics/sly.md)</span>。<br/>③你每使用一张<span style="color:#d4a017;font-weight:600">攻击牌</span>，下回合多抽 <span style="color:#3aa675;font-weight:600">1</span> 张牌。

## 详细机制

- **"抽到 7 张"的计数口径**：只统计**自己抽到的牌**——回合开始的常规抽牌、卡牌效果的额外抽牌、制衡摸回来的牌全部计入；跨回合清零重算，必须**单回合内**累计到 7。手牌达到上限时抽牌中断，计数停在当前值。
- **触发时机与操作**：第 7 张牌抽到手里的瞬间弹出弃牌选牌界面（后续抽牌暂挂等待）。可选择丢弃 **0 张到全部**手牌中的任意数量并摸回等量，选 0 张等于跳过。每回合限 1 次，之后继续计数但本回合不再弹出。
- **①与②的联动——弃牌即免费打出**：制衡的弃牌属于"回合中从手牌被丢弃"，恰好是[奇巧](/mechanics/sly.md)的触发条件——被弃的奇巧牌会**免费自动打出**。选牌界面里带奇巧的牌会金色高亮，一眼可辨哪些是"免费弹药"。免费打出的牌照常结算②③效果。
- **②的撒牌范围**：从抽牌堆、手牌、弃牌堆**三堆合集**里随机选 1 张（三堆所有牌等概率，不是每堆各选一张）。附加的奇巧是持久的卡牌关键词，不随回合切换消失，弃掉它之前随时可能触发。
- **③叠的是牌数不是回合**：每打出 1 张攻击牌获得 1 层"下回合抽牌"，3 层 = 下回合**一次性**多抽 3 张（抽完后清空），不是"连续 3 回合各多抽 1 张"。与原版卡牌"猎杀者"同机制。
- **③反过来给①加速**：下回合多抽的牌同样计入当回合的 7 张计数——常规 5 张 + 攻击牌换来的多抽，往往只差 1~2 张就够触发制衡。
- **多人模式**：只响应**你自己**打出和抽到的牌，队友的操作不会替你触发任何一条。

## 小贴士

- **三条效果是一个自洽引擎，不是三个孤立奖励**：②往三堆牌里撒奇巧 → ①制衡弃牌时手上的奇巧牌免费打出 → 免费打出的技能牌又触发②（再撒一个奇巧）、攻击牌触发③ → ③下回合多抽的牌又给①的 7 张计数加速。转起来之后每回合都是"抽满 7 → 弃几张家奇巧 → 免费连环出牌 → 下回合更多牌"的滚雪球。
- **7 张是设计门槛，不是白送的平均值**：回合开始常规抽 5 张，距离 7 还差 2——牌组里得有抽牌检索（"抽 2 张"类技能、0 费过牌）才能稳定吃满制衡。纯大费慢速牌组一回合挤不出额外抽牌，制衡就处于哑火状态。拿到孙权后抓牌优先级：抽牌检索 > 一切。
- **制衡的真正用途是"免费打出"而不是"换牌"**：表面是弃 N 摸 N 的手牌过滤，实际弃掉的奇巧牌会免费自动执行——等于用选牌界面"点菜"：想免费放哪张就弃哪张（前提是它带奇巧）。手上没有奇巧牌时，制衡才退化成纯过滤，价值大打折扣。
- **③是下回合的燃料，顺带给①垫计数**：多抽的牌要等下回合才到手，但每 1 张都给制衡的 7 张计数打底。攻击牌打得越密集，制衡触发越勤——攻击与过牌在这条遗物上是同一个方向。
- **③的原型与对照**：原版"猎杀者"（打出攻击牌下回合多抽 2 张）是一次性卡牌效果，孙权把它做成了常驻引擎；①的原型是原版遗物"赌博筹码"（战斗开始时弃任意张摸等量），孙权把它搬进了每回合且用抽牌数做门槛；②的原型是原版能力牌"谋划专家"（打技能牌给**该牌自己**附奇巧），孙权改成随机撒向三堆，配合①的弃牌才有引爆点。
- **性价比**：史诗合理——单拆任何一条都只是罕见级效果（换牌/撒奇巧/多抽 1），定价的依据是三条互为齿轮的引擎联动，转起来后每回合白嫖数次免费出牌加持续过牌。
