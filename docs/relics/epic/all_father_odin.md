# 天父奥丁

<img src="/images/relics/all_father_odin.png" alt="天父奥丁" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 史诗（自定义稀有度）

### 数值参数

| 参数 | 数值 |
|---|---|
| 减益概率(%) | 50 |
| 减益回合 | 2 |
| 调整回合 | 3 |

## 描述

①回合开始时，<span style="color:#3aa675;font-weight:600">50</span>%概率令所有对手进入随机1种<span style="color:#d44;font-weight:600">[异常状态](/mechanics/abnormal-status.md)</span><span style="color:#3aa675;font-weight:600">2</span>回合。<br/>②回合结束时，令所有敌人的<span style="color:#d44;font-weight:600">[异常状态](/mechanics/abnormal-status.md)</span>回合数调整为<span style="color:#3aa675;font-weight:600">3</span>。<br/>③自身打出<span style="color:#d4a017;font-weight:600">攻击牌</span>时，为随机敌人附加等于所有敌人<span style="color:#d44;font-weight:600">[异常状态](/mechanics/abnormal-status.md)</span>总回合数的<span style="color:#d4a017;font-weight:600">[固定伤害](/powers/fixed_damage_power.md)</span>。

- **每个敌人独立随机**：效果①为每个敌人分别独立抽取一种异常状态，敌人之间可能中不同的异常状态。
- **回合数双向拉平**：效果②把每个敌人已有异常状态的回合数统一拉到 <span style="color:#3aa675;font-weight:600">3</span>——不足 3 的补到 3，超过 3 的也削到 3。
- **固定伤害结算**：效果③统计所有敌人所有异常状态的回合数总和，作为<span style="color:#d4a017;font-weight:600">[固定伤害](/powers/fixed_damage_power.md)</span>施加给随机一个敌人（下回合开始结算）。

## 小贴士

- **三效果形成异常状态闭环**：①回合开始随机施加异常状态 → ②回合结束把回合数拉平到 3 → ③打攻击牌把异常状态总回合数转化为固定伤害。三个效果环环相扣，②既补足①给的 2 回合到 3 回合，又为③提供稳定的伤害基数。
- **50% 概率一次判定影响所有敌人**：每回合开始进行一次50%判定，判定通过则所有敌人都中异常状态（各自独立随机种类），判定失败则全部空过。长期看大约隔一回合施加一次。③的固定伤害完全依赖异常状态存量，空过回合会导致伤害断档。
- **固定伤害量级举例**：3 个敌人各中 1 种异常状态 3 回合 = 总 9 回合 = 9 点固定伤害给随机 1 个敌人。配合其他施加异常状态的能力把种类和回合数堆高，单次固定伤害可轻松突破 20+。
- **②是双向锁定也是上限**：回合数拉到 3 意味着不足 3 会补足（增益），但超过 3 也会被削减（限制）。如果用其他能力给敌人叠了 10 回合异常状态，回合结束会被砍到 3，反而亏了。适合搭配"种类多、回合少"的异常状态策略，不适合"单一种类高回合"的叠法。
- **固定伤害下回合结算**：③施加的是固定伤害能力，目标在下回合开始时才受到伤害，且可被免疫固定伤害效果挡掉。面对有固定伤害免疫的敌人时，③会失效。
- **配合攻击牌密集的卡组**：③每次打攻击牌都触发，多打几张攻击牌就能多次施加固定伤害。低费攻击牌连打是最佳触发方式。
- **②只维护不创造**：回合结束的拉平只对敌人**已有**的异常状态生效，不会无中生有。如果①的 50% 没中、也没有其他异常状态来源，②就是空过。所以这件遗物最怕连续空判——一旦断档，③的固定伤害也会跟着断。
- **性价比**：史诗稀有度给三效果闭环——自动施加 + 自动维护 + 自动转化伤害，一件遗物自成异常状态体系。拿到即用，不依赖其他配合就能持续输出固定伤害，强度配得上史诗。
