## 描述

①首次获得<span style="color:#d44;font-weight:600">[异常状态](/mechanics/abnormal-status.md)</span>时，转化为<span style="color:#3aa675;font-weight:600">3</span>回合<span style="color:#9b59b6;font-weight:600">[星赐](/powers/star_blessing_power.md)</span>，<span style="color:#d4a017;font-weight:600">[召唤](/mechanics/summon.md)</span>奥斯提（<span style="color:#3aa675;font-weight:600">10</span>HP）。<br/>②奥斯提存活时，所受异常状态转为<span style="color:#3aa675;font-weight:600">1</span>回合<span style="color:#9b59b6;font-weight:600">[星赐](/powers/star_blessing_power.md)</span>，<span style="color:#d4a017;font-weight:600">[召唤](/mechanics/summon.md)</span>奥斯提（<span style="color:#3aa675;font-weight:600">1</span>HP）。<br/>③奥斯提死亡时，以死前最大生命<span style="color:#3aa675;font-weight:600">20</span>%复活。<br/>④我方回合结束时，消耗奥斯提<span style="color:#3aa675;font-weight:600">25</span>%当前生命，恢复自身等量生命，对敌方造成等量<span style="color:#d4a017;font-weight:600">固定伤害</span>。

- **异常转化**：①②将自身受到的异常状态层数清零（不生效），转化为星赐并召唤/强化奥斯提。首次转化给3回合星赐+10HP奥斯提；后续转化需奥斯提存活，给1回合星赐并增加奥斯提1点最大生命（上限与当前生命同步+1）。若首次转化时奥斯提已经存活（如[宿主岩](/relics/common/host_rock.md)先召唤过），10HP 变为给现有奥斯提上限+10，不会重复召唤。
- **复活机制**：③奥斯提死亡时立即复活，复活后最大生命=死前最大生命×20%（向下取整，至少1）。
- **④伤害链**：对奥斯提造成非攻击伤害→恢复自身等量生命→对每个可击中敌人造成等量非攻击伤害。非攻击伤害不受力量/防御加成，但可被格挡。

## 小贴士

- **奥斯提存活时完全免疫异常状态**：核心机制。奥斯提存活期间，自身受到的所有24种异常状态都被转化为星赐，异常状态不生效。敌人的异常状态攻击反而是在给你送星赐——越打你越强。
- **星赐攻防双收益**：每次转化获得星赐（首次3回合，后续1回合）。星赐提供两项效果：攻击伤害 +10%、己方回合结束随机恢复一张 PP 未满的卡牌 2 点 PP（从手牌/抽牌堆/弃牌堆中选，全满则落空）。注意星赐的层数是**持续时间**而不是强度——+10% 增伤固定不变，叠层只是延长回合数。异常状态施加越频繁，星赐覆盖的回合越密集，攻防两端持续受益。
- **奥斯提随异常状态成长**：②每次转化不仅获得星赐，还让奥斯提上限与当前生命各+1。战斗中受到的异常状态越多，奥斯提最大生命越高，④的吸血和伤害量也越大。敌人密集施加异常状态时，奥斯提会迅速成长。
- **奥斯提死亡的连锁惩罚**：③复活将奥斯提最大生命设为死前的20%（向下取整，至少1）。10最大生命→死亡→复活为2最大生命→再死亡→复活为1最大生命。反复死亡后奥斯提只剩1点最大生命，④的吸血量降至0（25%×1向下取整为0，不触发），需要靠②重新慢慢叠最大生命。保护好奥斯提是使用此遗物的关键。
- **⚠️ "固定伤害"实际是非攻击伤害**：本地化描述④写"对敌方造成等量固定伤害"，但实际使用非攻击伤害（可被格挡），与"固定伤害"能力（下回合开始才结算、可被免疫固定伤害挡掉）是不同机制。④的伤害立即结算，且可被敌人格挡减少——面对有格挡的敌人时伤害会打折扣。
- **每回合被动收益**：④每回合结束自动触发，不需要打牌。消耗奥斯提25%当前生命→恢复自身等量生命→对每个敌人造成等量非攻击伤害。奥斯提HP越高，每回合的恢复和伤害越大。这是稳定的被动输出和治疗来源。注意④消耗的是**当前生命**的25%——奥斯提满血时抽得最多，残血时收益缩水，尽量让奥斯提保持健康。
- **首次转化是最大收益点**：①首次转化给3回合星赐+10HP奥斯提，远超后续的1回合星赐+1HP。每场战斗的第一次异常状态转化价值最高，尽量在战斗早期触发以尽早开始被动收益循环。
