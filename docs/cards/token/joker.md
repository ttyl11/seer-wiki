# 小丑

## 基本信息

- **分类**: 衍生牌
- **最大PP**: 5
- **能量消耗**: 0
- **类型**: 技能
- **稀有度**: 衍生
- **目标**: 自身
- **可升级**: 否

### 数值参数

| 参数 | 数值 |
|---|---|
| PP | 5 |
| 最大PP | 5 |

## 描述

PP: 5/5 选择1张手牌置入弃牌堆。

## 小贴士

- **手牌弃置**：选择1张[手牌](/mechanics/hand.md)（不包括小丑自身）置入[弃牌堆](/mechanics/discard_pile.md)。
- **戏法关键词**：带有[戏法](/mechanics/trick.md)关键词，打出后若[弃牌堆](/mechanics/discard_pile.md)有牌，随机抽一张到[手牌](/mechanics/hand.md)。与小丑的弃牌效果配合，可实现近似换牌。
- **不可生成**：战斗中不可被生成。
- **衍生卡牌**：属于衍生卡牌。
