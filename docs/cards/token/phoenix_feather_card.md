# 烬翎

## 基本信息

- **分类**: 衍生牌
- **最大PP**: 1
- **能量消耗**: 0
- **类型**: 技能
- **稀有度**: 衍生
- **目标**: 无
- **可升级**: 否
- **关键词**: [毁灭](/mechanics/destruction.md)

### 数值参数

| 参数 | 数值 |
|---|---|
| 平局数值 | 1 |
| 能量获取 | 2 |
| PP | 1 |
| 最大PP | 1 |

## 描述

PP: 1/1 抽<span style="color:#3aa675;font-weight:600">1</span>张牌，获得<span style="color:#3aa675;font-weight:600">2</span>点[<span style="color:#d4a017;font-weight:600">能量</span>](/mechanics/energy.md)。

## 小贴士

- **目标选取**：无目标。
- **抽牌**：从[抽牌堆](/mechanics/draw_pile.md)抽 <span style="color:#3aa675;font-weight:600">1</span> 张牌至[手牌](/mechanics/hand.md)。
- **能量获取**：获得 <span style="color:#3aa675;font-weight:600">2</span> 点[能量](/mechanics/energy.md)。配合 <span style="color:#3aa675;font-weight:600">0</span> 费打出可净赚 2 点能量。
- **毁灭关键词**：打出时自动清空[消耗堆](/mechanics/exhaust_pile.md)。
- **不可升级**：本卡无法升级。
- **衍生牌**：由菲尼克斯向敌人抽牌堆中加入。
- **胜利条件**：累计存在 <span style="color:#3aa675;font-weight:600">20</span> 片烬翎（抽牌+弃牌+手牌）时玩家获得本局战斗胜利。
