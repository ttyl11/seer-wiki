# 暴怒

<img src="/images/cards/wrath.png" alt="暴怒" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 诅咒牌
- **能量消耗**: 1
- **类型**: 诅咒
- **稀有度**: 诅咒
- **目标**: 无
- **可升级**: 否

### 数值参数

| 参数 | 数值 |
|---|---|
| 伤害 | 8 |

## 描述

此牌在[<span style="color:#d4a017;font-weight:600">手牌</span>](/mechanics/hand.md)中时必须先打出。打出后对所有生物造成<span style="color:#3aa675;font-weight:600">8</span>点伤害。

## 小贴士

- **诅咒牌**：本卡为[诅咒牌](/mechanics/curse-system.md)中少见的**可打出**类型——能量消耗 1，需主动打出结算效果，而非像[羞耻](/cards/curse/shame.md)那样"无法打出"滞留手牌。在[手牌](/mechanics/hand.md)中以红色高亮警示。
- **必须先打出**（强制优先）：当此牌在自己[手牌](/mechanics/hand.md)中时，**其他牌一律无法打出**，玩家被强制先打出暴怒。只有四种例外能让其他牌通过：①该牌本身也是暴怒；②该牌不为自己拥有（如队友的牌）；③该牌不在手牌堆（如抽牌堆/弃牌堆的自动效果）；④由系统自动打出（如回合结束自动结算）。
- **目标选取**：无目标，但伤害作用于战斗中所有生物。
- **伤害结算**：分两段结算，均以本牌为伤害来源——
  - 第一段：对所有**敌方生物**造成 <span style="color:#3aa675;font-weight:600">8</span> 点攻击伤害。
  - 第二段：对所有**玩家方生物**（包括打出者自己）造成 <span style="color:#3aa675;font-weight:600">8</span> 点攻击伤害。
  - 两段均附带斩击特效。
- **自身伤害**：由于第二段也会作用于打出者本人，暴怒实际等同于"全场 8 点 + 自伤 8 点"，是双刃剑。在残血时打出可能直接致死，需谨慎选择时机。
- **升级效果**：本卡不可升级。
