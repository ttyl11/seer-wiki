# 老鼠药

## 基本信息

- **分类**: 诅咒牌
- **能量消耗**: 3
- **类型**: 诅咒
- **稀有度**: 诅咒
- **关键词**: [<span style="color:#d4a017;font-weight:600">消耗</span>](/mechanics/exhaust.md)、[<span style="color:#d4a017;font-weight:600">固有</span>](/mechanics/innate.md)、[<span style="color:#d4a017;font-weight:600">保留</span>](/mechanics/retain.md)、[<span style="color:#d4a017;font-weight:600">永恒</span>](/mechanics/eternal.md)
- **可升级**: 否

### 数值参数

| 参数 | 数值 |
|---|---|
| 最大生命损失 | 4 |

## 描述

此牌在[<span style="color:#d4a017;font-weight:600">手牌</span>](/mechanics/hand.md)中时，使用药水失去<span style="color:#3aa675;font-weight:600">4</span>点最大生命值。

## 小贴士

- **触发时机**：使用药水后触发。
- **触发条件**：此牌必须在[手牌](/mechanics/hand.md)中。
- **效果**：失去 <span style="color:#3aa675;font-weight:600">4</span> 点最大生命值（可致死）。
- **关键词**：
 - [固有](/mechanics/innate.md)：每场战斗开始时必定在手牌中。
 - [保留](/mechanics/retain.md)：回合结束时不被弃置。
 - [永恒](/mechanics/eternal.md)：无法从牌组中移除或变化。
 - [消耗](/mechanics/exhaust.md)：若被打出则消耗（但作为诅咒牌无法正常打出）。
- **不可升级**：此牌无法升级。

## 相关机制

- [手牌](/mechanics/hand.md)：使用药水时若此牌在手牌中则触发效果
- [消耗](/mechanics/exhaust.md)、[固有](/mechanics/innate.md)、[保留](/mechanics/retain.md)、[永恒](/mechanics/eternal.md)：携带的四个原版关键词
