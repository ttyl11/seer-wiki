# 羞耻

## 基本信息

- **分类**: 诅咒牌
- **类型**: 诅咒
- **稀有度**: 诅咒
- **可升级**: 否

## 小贴士

- **无法打出**（[<span style="color:#d4a017;font-weight:600">查看机制页</span>](/mechanics/unplayable.md)，原版关键词 Unplayable）：此牌无法被打出，会一直留在手牌中占据空间，除非通过消耗/弃牌等效果主动移除。
- **诅咒牌**：作为手牌负担存在，本卡无额外效果。注意与"虚无"（Ethereal，回合结束自动消耗）不同——羞耻**不会**在回合结束时自动消耗，需主动处理。
