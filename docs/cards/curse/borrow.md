# 借鉴

<img src="/images/cards/borrow.png" alt="借鉴" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 诅咒牌
- **能量消耗**: 0
- **类型**: 诅咒
- **稀有度**: 诅咒
- **可升级**: 否

## 描述

回合结束时若在<span style="color:#d4a017;font-weight:600">手牌</span>中，下回合加入一张随机其他角色的牌（费用<span style="color:#3aa675;font-weight:600">+1</span>），且必须先打出该牌。

## 小贴士

- **触发链是"回合结束生成→下回合开始加入手牌"**：借鉴进入手牌时给自身施加一个不可见的状态，回合结束时检查借鉴是否还在手牌——是则从原版 5 个角色牌池（铁甲/静默/缺陷/亡缚/摄政）随机抽 1 张牌，费用 +1，暂存起来；下回合开始时这张牌才真正加入手牌底部。**所以借鉴的"惩罚"不是当回合生效，而是下回合多一张外来牌占用出牌位**。
- **⚠️ 描述与实际效果不符**：描述写"必须先打出该牌"，但实际没有强制打出的逻辑。实际效果只是"下回合多一张费用+1 的外来牌"，你完全可以不打它、正常出别的牌。如果出现"必须先打出"的行为，是其它机制在起作用，不是借鉴本身。
- **费用 +1 是关键代价**：原版牌池里有 0 费的（如打击、防御），+1 后变 1 费；也有 3 费的（如恶魔形态），+1 后变 4 费。**所以借鉴的惩罚方差很大**——抽到 0 费牌几乎无痛，抽到高费牌可能直接卡死当回合节奏。
- **应对策略**：借鉴只在手牌里才触发，所以**消耗它、洗回抽牌堆、或当回合结束前打出去**（但它无法主动打出）都能规避。实际可行的解法是带消耗类卡牌或洗牌类遗物，把借鉴从手牌移走。
