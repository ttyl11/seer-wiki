# 借鉴

<img src="/images/cards/borrow.png" alt="借鉴" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 诅咒牌
- **能量消耗**: 0
- **类型**: 诅咒
- **稀有度**: 诅咒
- **关键词**: [保留](/mechanics/retain.md)、[不可打出](/mechanics/unplayable.md)
- **可升级**: 否

## 描述

回合结束时若在<span style="color:#d4a017;font-weight:600">手牌</span>中，下回合加入一张随机其他角色的牌（费用<span style="color:#3aa675;font-weight:600">+1</span>），且必须先打出该牌。

## 小贴士

- **触发链是"回合结束生成→下回合开始加入手牌"**：借鉴进入手牌时给自身施加一个不可见的状态，回合结束时检查借鉴是否还在手牌——是则从原版 5 个角色牌池（铁甲/静默/缺陷/亡缚/摄政）随机抽 1 张牌暂存；下回合开始时这张牌才加入[手牌](/mechanics/hand.md)底部。**所以借鉴的"惩罚"不是当回合生效，而是下回合多一张外来牌占用出牌位**。
- **⚠️ 描述与实际效果不符**：描述写"必须先打出该牌"，但实际没有强制打出的逻辑。实际效果只是"下回合多一张费用+1 的外来牌"，你完全可以不打它、正常出别的牌。如果出现"必须先打出"的行为，是其它机制在起作用，不是借鉴本身。
- **保留=惩罚每回合滚动累积**：借鉴带[保留](/mechanics/retain.md)关键词，回合结束不弃牌、一直赖在手上——只要它还在手，**每个回合结束都会再生成一张**外来牌。不处理它，外来牌会一回合一张地持续挤占你的手牌位和抽牌空间。
- **费用 +1 真实有效、只维持一回合**：生成发生在回合结束的清理流程之后，+1 的临时费率因此完整覆盖下回合——外来牌加入手牌时确实显示 +1 费；再下个回合结束才会清除。原版牌池里 0 费牌（打击、防御）+1 后变 1 费尚可接受，3 费牌（恶魔形态级别）+1 后变 4 费可能直接卡死当回合节奏——**惩罚方差很大**。
- **外来牌是临时的**：生成的牌属于本场战斗临时生成，战斗结束消失，不会污染卡组。
- **应对策略**：借鉴[不可打出](/mechanics/unplayable.md)且保留在手，常规弃牌对它无效——实际可行的解法是用消耗类卡牌效果（如"消耗手牌中一张牌"）或变牌效果把它从手牌移走，移走后惩罚即刻停止。
