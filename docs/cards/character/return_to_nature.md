## 小贴士

- **1 费力量 + 格挡 + 抽牌三合一**：[力量](/powers/strength_power.md)+<span style="color:#3aa675;font-weight:600">1</span>、<span style="color:#3aa675;font-weight:600">8</span> 点[格挡](/mechanics/block.md)、抽 <span style="color:#3aa675;font-weight:600">1</span> 张——攻防资源一体的多功能牌。
- **抽 1 不亏手牌位**：打出它自己消耗一张手牌、立刻抽回一张，手牌净数量不变。这意味着它几乎可以无脑塞进任何回合的出牌计划里，不像纯增益牌那样挤占手牌位。
- **升级变 0 费后是成长引擎**：费用 <span style="color:#3aa675;font-weight:600">1</span>→<span style="color:#3aa675;font-weight:600">0</span> 后单场最多白嫖 5 次（PP5），累计 <span style="color:#3aa675;font-weight:600">+5</span> 力量、<span style="color:#3aa675;font-weight:600">40</span> 格挡、<span style="color:#3aa675;font-weight:600">5</span> 张抽牌——长 Boss 战里力量逐回合滚起来，后续每一张攻击牌都吃加成。抽到即升的高优先级对象。
- **力量吃重放/连打放大**：+1 力量加成的是"每一次攻击伤害"——配[重放](/mechanics/replay.md)（如[飞翼连击](/cards/colorless/wing_combo.md)赋予手牌重放）或一回合连打多张攻击牌时，这张牌攒的力量在每一下上都生效。先升它、再铺重放，是力量流的标准节奏。
- **性价比**：<span style="color:#3aa675;font-weight:600">1</span> 费力量 + <span style="color:#3aa675;font-weight:600">8</span> 格挡 + <span style="color:#3aa675;font-weight:600">1</span> 抽，三效合一；升级 <span style="color:#3aa675;font-weight:600">0</span> 费纯赚。
