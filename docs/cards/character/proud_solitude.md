## 小贴士

- **先制几乎稳定触发**：触发条件是任意存活敌人的[力量](/powers/strength_power.md)、[防御](/powers/defense_power.md)、[命中](/powers/accuracy_power.md)、[速度](/powers/speed_power.md)有一项大于 <span style="color:#3aa675;font-weight:600">0</span>。绝大多数敌人在战斗中都会带正属性，所以[先制](/powers/first_strike_power.md)+<span style="color:#3aa675;font-weight:600">1</span> 基本等于白送——下一张牌耗能 -<span style="color:#3aa675;font-weight:600">1</span>。
- **全属性加成是双刃剑**：力量、防御、命中、速度各 +<span style="color:#3aa675;font-weight:600">2</span> 同时施加给所有存活生物（多人模式下队友的生物也吃到）。敌人[力量](/powers/strength_power.md)+<span style="color:#3aa675;font-weight:600">2</span> 后下次攻击多打 <span style="color:#3aa675;font-weight:600">2</span> 点；敌人[防御](/powers/defense_power.md)+<span style="color:#3aa675;font-weight:600">2</span> 后你打他少 <span style="color:#3aa675;font-weight:600">2</span> 点。[命中](/powers/accuracy_power.md)正层数无实际效果，[速度](/powers/speed_power.md)正层数影响抽牌。整体属性增益双方对等，谁更依赖属性谁就更受益。
- **格挡也送给敌人**：所有存活生物获得 <span style="color:#3aa675;font-weight:600">15</span> 点（升级后 <span style="color:#3aa675;font-weight:600">30</span> 点）[格挡](/mechanics/block.md)。你的格挡吸收敌方攻击，敌人的格挡也吸收你的攻击。适合在敌人即将爆发高伤害时打出，用格挡吸收；不适合在你准备当回合斩杀时打出，因为敌人也获得了格挡。
- **多抽牌只给自己**：下 <span style="color:#3aa675;font-weight:600">2</span> 回合每回合开始多抽 <span style="color:#3aa675;font-weight:600">1</span> 张牌，这个增益只施加给自身。层数在自身回合结束时减 <span style="color:#3aa675;font-weight:600">1</span>，<span style="color:#3aa675;font-weight:600">2</span> 层刚好对应 <span style="color:#3aa675;font-weight:600">2</span> 个回合。这是这张牌的核心隐性收益——稳定的过牌优势。
- **速度增益相互抵消**：你获得 +<span style="color:#3aa675;font-weight:600">2</span> [速度](/powers/speed_power.md)（每 <span style="color:#3aa675;font-weight:600">2</span> 层多抽 <span style="color:#3aa675;font-weight:600">1</span> 张），敌人也获得 +<span style="color:#3aa675;font-weight:600">2</span> 速度（敌人正速度使所有玩家少抽 <span style="color:#3aa675;font-weight:600">1</span> 张）。单敌人场景下两者正好抵消，多敌人场景下敌方速度叠加会进一步压缩你的抽牌数。实际过牌收益主要来自多抽牌增益本身。
- **升级只翻倍格挡**：升级后[格挡](/mechanics/block.md) <span style="color:#3aa675;font-weight:600">15</span> → <span style="color:#3aa675;font-weight:600">30</span>，翻倍。其他参数（全属性 +<span style="color:#3aa675;font-weight:600">2</span>、<span style="color:#3aa675;font-weight:600">2</span> 回合多抽、先制 +<span style="color:#3aa675;font-weight:600">1</span>）均不变。升级适合需要硬抗高频攻击的场景，纯输出流派升级价值有限。
- **性价比**：<span style="color:#3aa675;font-weight:600">1</span> 费打出 = 全场 +<span style="color:#3aa675;font-weight:600">2</span> 全属性 + <span style="color:#3aa675;font-weight:600">15</span>/<span style="color:#3aa675;font-weight:600">30</span> 格挡 + <span style="color:#3aa675;font-weight:600">2</span> 回合多抽 <span style="color:#3aa675;font-weight:600">1</span> 张 + 条件先制 +<span style="color:#3aa675;font-weight:600">1</span>。虽然增益双方对等，但你额外获得多抽牌和先制——节奏优势完全在自己手里。罕见稀有度合理。
