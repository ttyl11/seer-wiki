## 小贴士

- **鲲鹏互生是无限循环**：这张牌未击杀就衍生[鹏·万里遨游](/cards/character/peng_thousand_miles_soar.md)放抽牌堆顶，鹏·万里遨游未击杀又衍生鲲·千里击涛回抽牌堆顶——两张牌互为衍生对象，只要一直没击杀就永远循环下去，不会断链。
- **衍生牌带本能，伤害翻倍是核心**：衍生的牌附带[本能](/enchantments/instinct.md)附魔，攻击伤害直接翻倍——基础 <span style="color:#3aa675;font-weight:600">36</span> 伤变 <span style="color:#3aa675;font-weight:600">72</span>，升级 <span style="color:#3aa675;font-weight:600">54</span> 伤变 <span style="color:#3aa675;font-weight:600">108</span>。所以循环越往后伤害越高，第一张没杀掉，第二张（翻倍）更容易杀掉。
- **击杀才回手 + 先制 3 层**：击杀敌人时这张牌回手，并获得 <span style="color:#3aa675;font-weight:600">3</span> 层[先制](/powers/first_strike_power.md)（每层让下张牌减 <span style="color:#3aa675;font-weight:600">1</span> 费）。<span style="color:#3aa675;font-weight:600">3</span> 层先制正好抵消 <span style="color:#3aa675;font-weight:600">3</span> 费——回手后 0 费再打一次，形成"击杀→回手→0费→再击杀"的收割链。
- **溢出伤害也算击杀**：用 <span style="color:#3aa675;font-weight:600">36</span> 伤打 <span style="color:#3aa675;font-weight:600">1</span> 血敌人照样触发回手+先制，不需要精准控血。所以残血敌人就是回手触发器。
- **悼会接管下回合**：带[悼](/mechanics/mourning.md)关键词，打出后下回合由瓦库代替你行动——自动从手牌打出所有可打的牌。瓦库会自动把衍生的鹏/鲲打出去继续循环，不需要你手动操作。但要规划好悼触发时的手牌内容，别让瓦库乱打。
- **核心矛盾：想击杀回手 vs 未击杀衍生翻倍**：击杀回手拿先制（即时收割，回手牌保持当前状态——带本能就带回带本能的），未击杀衍生翻倍牌（延迟强化，但放抽牌堆顶要等下回合）。两条路都赚——击杀是即时收益，未击杀是延迟强化。实战中通常第一发没杀掉反而不可怕，因为下回合抽到的是 <span style="color:#3aa675;font-weight:600">72</span>/<span style="color:#3aa675;font-weight:600">108</span> 伤的翻倍牌。
- **升级 +18 伤提升击杀率**：升级 <span style="color:#3aa675;font-weight:600">36</span>→<span style="color:#3aa675;font-weight:600">54</span>，翻倍后 <span style="color:#3aa675;font-weight:600">72</span>→<span style="color:#3aa675;font-weight:600">108</span>。+<span style="color:#3aa675;font-weight:600">18</span> 伤显著扩大击杀线，让循环更易进入"击杀回手"的正循环。
- **性价比**：<span style="color:#3aa675;font-weight:600">3</span> 费 <span style="color:#3aa675;font-weight:600">36</span>（升级 <span style="color:#3aa675;font-weight:600">54</span>）伤已接近 1 费换 12-<span style="color:#3aa675;font-weight:600">18</span> 伤的常规价，加上击杀回手 + 鲲鹏循环 + 翻倍衍生，收割收益明显偏强，但需要击杀或循环条件触发。
