## 小贴士

- **格挡转三重输出是核心**：这张牌把"格挡"这个防御属性变成三重攻击——①全场格挡总和的攻击伤害 ②自身格挡 <span style="color:#3aa675;font-weight:600">200</span>%（升级 <span style="color:#3aa675;font-weight:600">300</span>%）的固定伤害 ③倒映反弹。防御姿态反而是最佳输出时机，"防御即进攻"做到极致。
- **敌人格挡反成你的输出**：攻击伤害 = 自身格挡 + **所有敌人格挡**的总和。敌人叠格挡通常让你头疼，但这张牌让敌人格挡变成你的伤害来源——敌人格挡越高，这张牌打出的攻击伤害也越高，面对高格挡敌人收益翻倍。
- **格挡减费，30 格挡 = 0 费**：自身每有 <span style="color:#3aa675;font-weight:600">5</span> 点[格挡](/mechanics/block.md)耗能 <span style="color:#3aa675;font-weight:600">-1</span>。<span style="color:#3aa675;font-weight:600">30</span> 格挡直接 <span style="color:#3aa675;font-weight:600">0</span> 费打出——配合防御流派叠格挡后，这张牌从 <span style="color:#3aa675;font-weight:600">6</span> 费降到免费。
- **固定伤害只取自身格挡，不含敌人**：固定伤害 = 自身格挡 × <span style="color:#3aa675;font-weight:600">200</span>%（升级 <span style="color:#3aa675;font-weight:600">300</span>%），只算自身格挡不算敌人。所以自身 <span style="color:#3aa675;font-weight:600">30</span> 格挡时，每个敌人吃 <span style="color:#3aa675;font-weight:600">60</span> 固定伤害（升级 <span style="color:#3aa675;font-weight:600">90</span>），下回合开始结算不可格挡。
- **倒映补足反击**：获得 <span style="color:#3aa675;font-weight:600">1</span> 层倒映（原版能力），被格挡的伤害会反弹给攻击者。打完这张牌后敌人若反击，倒映触发形成"格挡转伤 + 反弹"的双重防御反击。
- **保留让蓄格挡成为可能**：拥有[保留](/mechanics/retain.md)关键词，回合结束不弃置。可以前期用防御牌蓄格挡，等格挡叠高后一次性打出——格挡越高，伤害越高、减费越多、固定伤害越高，三重收益同步放大。
- **核心矛盾：格挡是防御资源也是输出资源**：格挡既能挡伤害又能转伤害，两个用途争抢同一资源。想保高格挡防御就别急着打这张牌，想打这张牌输出就要把格挡消耗掉（打出后格挡还在，但下回合可能被敌人打掉）。最佳时机是回合末格挡还没被打掉时爆发。
- **升级固定伤害 +50%**：升级固定伤害百分比 <span style="color:#3aa675;font-weight:600">200</span>%→<span style="color:#3aa675;font-weight:600">300</span>%，即自身格挡 <span style="color:#3aa675;font-weight:600">30</span> 时固定伤害从 <span style="color:#3aa675;font-weight:600">60</span>→<span style="color:#3aa675;font-weight:600">90</span>。攻击伤害和倒映不变，升级只强化固定伤害这一项。
- **性价比**：<span style="color:#3aa675;font-weight:600">6</span> 费换全场格挡伤害 + 倒映 + 固定伤害三效合一，格挡减费机制让实际费用可能远低于 <span style="color:#3aa675;font-weight:600">6</span>，配合格挡流派是"防御即进攻"的核心定价。
