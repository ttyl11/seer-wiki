## 小贴士

- **0 费核弹：清增益 + 回牌 + 增伤三合一**：这张牌一次打出做了三件事——<span style="color:#3aa675;font-weight:600">14</span> 点全体伤害打底，然后清空所有敌人的增益，最后把整个[消耗牌堆](/mechanics/exhaust_pile.md)捞回[手牌](/mechanics/hand.md)并给下一张攻击牌叠增伤。0 费换这么多事，是 mod 里少有的"翻盘按钮"级单卡。
- **清增益是双向收益**：每清掉敌人一个增益，自身[力量](/powers/strength_power.md)/[防御](/powers/defense_power.md)/[命中](/powers/accuracy_power.md)/[速度](/powers/speed_power.md)各 +<span style="color:#3aa675;font-weight:600">1</span>（即[全属性](/mechanics/all_attributes.md)+1）。注意按**种类**计数、不按层数——敌人力量堆到 5 层也只算 1 个增益。面对爱铺增益的精英或 Boss，一刀下去既剥夺对面的加成又给自己叠全属性——敌人越多、增益种类越杂，你赚得越多。多人遭遇战里收益尤其爆炸。
- **消耗牌堆全捞回 + PP 回满**：消耗堆里所有牌全部返回手牌，PP 牌还回满 PP。意味着你之前消耗掉的高价值牌（包括其它 PP 大招）可以立刻再打一次。配合大量消耗自身牌的卡能一波捞回一整手资源。
- **增伤只给下一张攻击牌**：每捞回 <span style="color:#3aa675;font-weight:600">1</span> 张牌，下一张攻击牌伤害 +<span style="color:#3aa675;font-weight:600">50</span>%（可叠加）。捞回 <span style="color:#3aa675;font-weight:600">4</span> 张就是 +<span style="color:#3aa675;font-weight:600">200</span>%（<span style="color:#3aa675;font-weight:600">3</span> 倍伤害）。注意此增伤只作用于**下一张攻击牌**——用掉就没了，所以打完这张立刻接你最狠的攻击牌。本牌自身的 <span style="color:#3aa675;font-weight:600">14</span> 点伤害在增伤施加之前结算，不吃这个加成。
- **[寂灭](/mechanics/nirvana.md)：一场战斗用一次，用完从牌组消失**：本场战斗打完后此牌从牌组移除。这意味着它是一张"战略储备"——不到关键时刻别乱交。最好的时机是消耗堆积累了一定牌量、且下一张攻击牌能配合增伤打出巨额伤害时。
- **[固有](/mechanics/innate.md)（升级后）让核弹随时待命**：升级后每场战斗起手必有此牌。但别因为起手有就急着打——起手消耗堆通常是空的，增伤收益为零。固有保证的是"想用的时候一定在手"，不是"起手就要用"。
- **性价比**：0 费合理——清增益 + 全属性成长 + 消耗堆全捞 + 下次攻击增伤四合一，再加寂灭的一次性代价，这个价精准。
