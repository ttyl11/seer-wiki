# 欢梦芳逝

<img src="/images/cards/phantom_dream_fade.png" alt="欢梦芳逝" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 角色牌
- **最大PP**: 1
- **能量消耗**: 1
- **类型**: 攻击
- **稀有度**: 稀有
- **目标**: 所有敌人
- **可升级**: 是（1 级）

### 数值参数

| 参数 | 数值 |
|---|---|
| 自损生命 | 13 |
| 伤害 | 13 |
| 舞台持续回合 | 99 |

## 描述

PP: 1/1 自损13点生命，对所有敌人造成等量伤害。下场战斗开启灵籁泳馆和星璨舞台99回合。

## 升级后

PP: 1/1 自损13点生命，对所有敌人造成等量伤害。下场战斗开启灵籁泳馆和星璨舞台99回合。（耗能降为0）

## 小贴士

- **自损换AOE的爆发件**：自损13生命对全体敌人造成13点攻击伤害。PP1低消耗即可触发，是低PP高伤害的AOE选择。升级后0费更是无成本启动。
- **跨战斗舞台是核心价值**：打出后下场战斗自动开启[灵籁泳馆](/powers/ling_lai_swim_hall_power.md)（免疫属性下降+每回合回3血）和[星璨舞台](/powers/star_stage_power.md)（伤害+25%+每回合恢复3张牌1PP）99回合。等于用一张牌换下场战斗99回合的双重增益。
- **自损13血的代价**：需要13点生命作为代价，低血量时使用风险极大。配合回血手段或高血量流派才能安全使用。
- **跨战斗预热**：舞台效果在下场战斗才开始，所以这张牌适合在当前战斗快结束时打出（最后一回合），为下场战斗铺路。
