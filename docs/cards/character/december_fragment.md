## 基本信息

- **分类**: 角色（圣灵谱尼）牌
- **最大PP**: 1

- **类型**: 能力

| 参数 | 数值 | 升级后 |
|---|---|---|
| 抽牌数量 | 1 | 2 |

## 描述

PP: 1/1 获得等于回合数乘怪物数的[<span style="color:#d4a017;font-weight:600">格挡</span>](/mechanics/block.md)。抽<span style="color:#3aa675;font-weight:600">1</span>张牌。

## 升级后

PP: 1/1 获得等于回合数乘怪物数的[<span style="color:#d4a017;font-weight:600">格挡</span>](/mechanics/block.md)。抽<span style="color:#3aa675;font-weight:600">2</span>张牌。

## 小贴士

- **⚠️ 本地化与实际行为不一致**：本地化描述为"回合数**乘**怪物数"，但实际效果是**加法**：格挡 = 当前回合数 + 敌人数。本地化文案未同步更新，实际行为以加法为准。
- **格挡递增示例**（按实际加法行为）：
 - 第 1 回合，1 个敌人 → 格挡 2（1+1）
 - 第 3 回合，2 个敌人 → 格挡 5（3+2）
 - 第 5 回合，3 个敌人 → 格挡 8（5+3）
 - 第 10 回合，3 个敌人 → 格挡 13（10+3）
- **越后期越强**：格挡量随回合数和敌人数线性增长——长战斗和多敌人遭遇战中价值极高。Boss 战打到 10+ 回合时，一张牌获得 10+ 格挡 + 抽牌，远超普通防御牌。
- **0 费抽牌的保底价值**：即使格挡量不高（如第 1 回合仅 2 格挡），0 费抽 1 张牌本身就有循环价值——等于不占能耗地替换手牌。升级后抽 2 张更是质变，0 费抽 2 张是极强的过牌。
- **格挡加成**：该牌获得的[格挡](/mechanics/block.md)受[敏捷](/powers/dexterity_power.md)等格挡加成能力影响。配合敏捷体系可以进一步放大格挡量。
- **配合建议**：适合长战斗拖回合格挡流——配合[宇宙胎动](./cosmic_movement.md)（敏捷+1）可以让每张此牌多 1 格挡。多敌人遭遇战中优先打出，格挡收益翻倍。升级后 0 费抽 2 张配合手牌消耗型卡组可以快速补充手牌。
- **升级的价值**：抽牌从 1 提升到 2。格挡量不变（仍为回合数+敌人数），但 0 费抽 2 张的过牌能力是质变——从"防御+替换"升级为"防御+强力过牌"。升级优先级高。
- **性价比**：0 费能力牌，格挡 + 抽牌，随战斗进程递增的超值卡。前 2 回合格挡偏低（2-3），第 3 回合后开始体现价值。
