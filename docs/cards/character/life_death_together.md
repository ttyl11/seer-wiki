# 同生共死

## 基本信息

- **分类**: 角色（圣灵谱尼）牌
- **最大PP**: 1
- **能量消耗**: 1
- **类型**: 技能
- **稀有度**: 普通
- **目标**: 敌方单体
- **可升级**: 是（1 级）

### 数值参数

| 参数 | 数值 | 升级后 |
|---|---|---|
| 能量消耗 | 1 | 0 |
| PP | 1 | 1 |
| 最大PP | 1 | 1 |

## 描述

PP: <span style="color:#3aa675;font-weight:600">1</span>/<span style="color:#3aa675;font-weight:600">1</span> 将此敌人的生命值变为与自身最大生命值相同（对boss无效）。

## 升级后

PP: <span style="color:#3aa675;font-weight:600">1</span>/<span style="color:#3aa675;font-weight:600">1</span> 将此敌人的生命值变为与自身最大生命值相同（对boss无效）。

## 小贴士

- **双向效果是核心张力**：这张牌把敌人当前血量强制对齐到玩家最大血量——敌人血**高于**你最大血时，差额直接扣掉（不可格挡的非攻击伤害，无视格挡）；敌人血**低于**你最大血时，差额反而**治疗敌人**补足。选对目标是斩杀核弹，选错目标直接奶满敌人。一张牌能斩杀也能自杀式救援敌人，全看你对目标血量的判断。
- **斩杀线 = 自身最大血量**：扣血量 = 敌人当前血 − 自身最大血。所以你最大血量越高，斩杀线越高——配合增加最大血量的遗物/能力（如九死未悔扣 9 上限要谨慎，反而降低斩杀线）。这张牌和最大血量流派天然配合，最大血堆到 <span style="color:#3aa675;font-weight:600">80</span> 时，任何血量高于 <span style="color:#3aa675;font-weight:600">80</span> 的敌人都能被一刀斩到 <span style="color:#3aa675;font-weight:600">80</span>。
- **反向治疗的陷阱**：敌人残血时千万别用——比如敌人只剩 <span style="color:#3aa675;font-weight:600">10</span> 血，你最大血 <span style="color:#3aa675;font-weight:600">80</span>，这张牌会奶他 <span style="color:#3aa675;font-weight:600">70</span> 血。所以这张牌只能对**血量明显高于你最大血**的敌人用（高血量精英怪、多血普通怪），残血敌人用其它手段收割。
- **Boss 房整张牌跳过**：Boss 房间下整张牌效果直接不生效——不是 Boss 免疫，是整张牌在 Boss 战完全不触发。所以 Boss 战别留这张牌在手牌浪费位置。
- **伤害不可格挡**：造成的差额伤害是不可格挡的非攻击伤害，无视格挡/护甲/任何减伤。对高格挡敌人尤其有效——它叠再多格挡也挡不住这个差额。
- **升级 0 费是质变**：耗能 <span style="color:#3aa675;font-weight:600">1</span>→<span style="color:#3aa675;font-weight:600">0</span>，0 费即可斩杀，灵活性大增。0 费让它可以随时穿插在出牌序列里收割高血敌人，不必专门留能量。
- **性价比**：1 费（升级 0 费）换"差额不可格挡伤害"，斩杀收益极高，但双向效果让实际价值完全取决于目标选择——这是一张考验判断力的牌，不是无脑强的牌。
