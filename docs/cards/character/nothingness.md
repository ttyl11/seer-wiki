## 小贴士

- **0 费遗物驱动核弹**：基础只有 <span style="color:#3aa675;font-weight:600">1</span> 点伤害，但遗物越多触发越多档——5 档递进，每一档都是质变。遗物流成型后这张 0 费牌能打出远超高费牌的效果。
- **5 档递进效果**：遗物数 &gt; <span style="color:#3aa675;font-weight:600">4</span> 额外 <span style="color:#3aa675;font-weight:600">4</span> 伤（总 <span style="color:#3aa675;font-weight:600">5</span>）；&gt; <span style="color:#3aa675;font-weight:600">8</span> 生成 1 个 [PP 充能球](/orbs/pp_orb.md)；&gt; <span style="color:#3aa675;font-weight:600">16</span> 获得 [先制](/powers/first_strike_power.md)+<span style="color:#3aa675;font-weight:600">1</span>；&gt; <span style="color:#3aa675;font-weight:600">32</span> 所有敌人 [臣服](/powers/subjugation_power.md)；&gt; <span style="color:#3aa675;font-weight:600">64</span> 直接秒杀目标。档位是"&gt;"不是"&gt;="，所以正好 <span style="color:#3aa675;font-weight:600">4</span> 个遗物不触发第一档，需要 <span style="color:#3aa675;font-weight:600">5</span> 个起。
- **秒杀是真秒杀，但 Boss 无效**：&gt; <span style="color:#3aa675;font-weight:600">64</span> 个遗物时直接击杀目标，不是造成伤害，无视格挡/护甲/任何减伤。但 Boss 房间下秒杀档跳过——所以别指望用它秒 Boss，它是普通战和精英战的清场核弹。
- **万相乖离是双刃剑**：[万相乖离](/powers/universal_divergence_power.md)每层会把遗物数**除以其层数**计算（上限 <span style="color:#3aa675;font-weight:600">5</span> 层），削弱遗物档位触发；但每层给所有攻击牌 **+<span style="color:#3aa675;font-weight:600">3</span> 伤害**。这是核心权衡——叠 <span style="color:#3aa675;font-weight:600">5</span> 层万相乖离时，<span style="color:#3aa675;font-weight:600">64</span> 个遗物被除成 <span style="color:#3aa675;font-weight:600">12</span> 个，秒杀档（&gt;64）和臣服档（&gt;32）都触发不了，但每张攻击牌多 <span style="color:#3aa675;font-weight:600">15</span> 点伤害。要遗物档位效果还是要直接伤害增幅，得看流派走向。万相乖离本身还有更多强力效果（防死回满血、清敌属性、群体异常等），详见其能力页面。
- **999 次升级独一无二**：可升级 <span style="color:#3aa675;font-weight:600">999</span> 次，每次 +<span style="color:#3aa675;font-weight:600">1</span> 抽牌。是 mod 里升级次数最多的卡——长期投资后一张 0 费牌能抽一大把牌，配合遗物档位效果是遗物流的终极引擎。但升级机会有限，999 次只是理论上限。
- **性价比**：<span style="color:#3aa675;font-weight:600">0</span> 费换遗物驱动的 5 档成长效果，遗物流成型后是核弹级免费触发器。万相乖离的双刃剑设计让它在不同流派里有不同价值，不是无脑强。
