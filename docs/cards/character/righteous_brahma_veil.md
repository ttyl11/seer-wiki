## 小贴士

- **下 3 回合每回合回 2/3 血——持续续航**：打出后下 <span style="color:#3aa675;font-weight:600">3</span> 回合每回合结束恢复 <span style="color:#3aa675;font-weight:600">2</span> 点生命（升级 <span style="color:#3aa675;font-weight:600">3</span> 点），共 <span style="color:#3aa675;font-weight:600">6</span>/<span style="color:#3aa675;font-weight:600">9</span> 点回血。
- **怀生菩怜态时给所有对手疲惫 5 回合**：若处于[怀生菩怜态](/powers/compassionate_bodhi_power.md)，所有对手获得[疲惫](/powers/fatigue_power.md) <span style="color:#3aa675;font-weight:600">5</span> 回合。
- **拒赦怒威态时给所有对手害怕 5 回合**：若处于[拒赦怒威态](/powers/wrathful_judgment_power.md)，所有对手获得[害怕](/powers/fear_power.md) <span style="color:#3aa675;font-weight:600">5</span> 回合。
- **两种状态可同时触发**：怀生菩怜态和拒赦怒威态的检查是独立的——如果同时处于两种状态，疲惫和害怕同时施加给所有对手。
- **升级回血 2→3**：升级后每回合回血从 <span style="color:#3aa675;font-weight:600">2</span> 提升到 <span style="color:#3aa675;font-weight:600">3</span>，总回血从 <span style="color:#3aa675;font-weight:600">6</span> 提升到 <span style="color:#3aa675;font-weight:600">9</span>。
- **性价比**：<span style="color:#3aa675;font-weight:600">1</span> 费换 <span style="color:#3aa675;font-weight:600">3</span> 回合续航 + 条件群体控制，配合三态切换收益更高。
