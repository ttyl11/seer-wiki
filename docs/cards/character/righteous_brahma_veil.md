## 小贴士

- **下 3 回合每回合回 2/3 血——己方回合结束结算**：打出后挂回血能力，己方回合结束时恢复 <span style="color:#3aa675;font-weight:600">2</span> 点生命（升级 <span style="color:#3aa675;font-weight:600">3</span> 点）并减 <span style="color:#3aa675;font-weight:600">1</span> 层，共 <span style="color:#3aa675;font-weight:600">6</span>/<span style="color:#3aa675;font-weight:600">9</span> 点回血——打出当回合结束就回第一口。
- **怀生菩怜态时群体疲惫——降攻伤 + 反伤**：若处于[怀生菩怜态](/powers/compassionate_bodhi_power.md)，所有对手获得 <span style="color:#3aa675;font-weight:600">5</span> 层[疲惫](/powers/fatigue_power.md)：攻击伤害降低，且每次造成伤害时自身受到等于层数的不可[格挡](/mechanics/block.md)伤害——敌人打人越狠，反噬越痛，是群体压制 + 反伤的双重防御。
- **拒赦怒威态时群体害怕——纯降攻伤**：若处于[拒赦怒威态](/powers/wrathful_judgment_power.md)，所有对手获得 <span style="color:#3aa675;font-weight:600">5</span> 层[害怕](/powers/fear_power.md)：攻击伤害降低，回合结束 <span style="color:#3aa675;font-weight:600">-1</span> 层，持续 <span style="color:#3aa675;font-weight:600">5</span> 回合的群体减攻。
- **三态互斥——同一时间最多触发一种效果**：怀生菩怜态与拒赦怒威态互相排斥（切换状态时旧状态先被移除），不可能同时持有——疲惫与害怕不会同时施加。处于百天浮世络或无状态时打出，只有回血效果。
- **升级回血 2→3**：升级后每回合回血从 <span style="color:#3aa675;font-weight:600">2</span> 提升到 <span style="color:#3aa675;font-weight:600">3</span>，总回血从 <span style="color:#3aa675;font-weight:600">6</span> 提升到 <span style="color:#3aa675;font-weight:600">9</span>。
- **性价比**：<span style="color:#3aa675;font-weight:600">1</span> 费换 <span style="color:#3aa675;font-weight:600">3</span> 回合续航 + 条件群体压制；PP9 支持多次打出刷新群体减益，配合三态切换（如[妙时天女](/relics/epic/maiden_of_wondrous_time.md)）收益更高。
