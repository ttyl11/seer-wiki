## 描述

PP: <span style="color:#3aa675;font-weight:600">5</span>/<span style="color:#3aa675;font-weight:600">5</span> 每安装一个mod，场上所有生物获得1回合<span style="color:#d4a017;font-weight:600">狂暴</span>。对所有敌人造成<span style="color:#3aa675;font-weight:600">6</span>点伤害。

## 升级后

PP: <span style="color:#3aa675;font-weight:600">5</span>/<span style="color:#3aa675;font-weight:600">5</span> 每安装一个mod，场上所有生物获得1回合<span style="color:#d4a017;font-weight:600">狂暴</span>。对所有敌人造成<span style="color:#3aa675;font-weight:600">10</span>点伤害。

## 小贴士

- **mod 联动全体狂暴**：打出时按已安装 mod 数量（seer 本体也算一个，所以最少 1 层），给场上**所有生物**施加等量层数的[狂暴](/powers/fury_power.md)——包括自己、双人房的队友、以及全部敌人。每层狂暴使该生物造成的攻击伤害 +25%，在其自己回合结束时 -1 层。
- **先挂狂暴、后结算伤害**：结算顺序是先施加狂暴、再打出全体攻击——这张牌自己的 6（升级 10）点伤害**已经吃满刚挂上的狂暴加成**。装 3 个 mod 时实际一击是 6×175%≈10，装得越多首击越痛。
- **双刃剑设计**：你和敌人（以及队友）拿到的是同一份额度的狂暴——你加多少攻击伤害，敌人也加多少。装 3 个 mod → 双方 +75% 攻击伤害。打出后要趁狂暴层数还在的同回合全力输出，同时留意敌人的下回合增强攻击；狂暴只加成攻击伤害，敌人的灼烧/固伤类不受影响。
- **0 费全体攻击**：0 费对所有敌人造成 6 点攻击伤害（升级后 10），即使不算狂暴，作为 0 费 AOE 本身就有清小怪的价值。
- **PP 5 可反复铺**：单场最多打 5 次，每次都重新按 mod 数施加狂暴——狂暴逐回合 -1，但只要持续重打就能维持高层数；对玩家而言是常驻增幅引擎，对敌人而言则是持续为对手"充值"，打之前想清楚自己的爆发窗口在哪。
- **配合建议**：先手打出找茬，紧接高伤害多段攻击牌吃满 +25%×mod 数的乘区；狂暴对攻击伤害是乘法加成，与力量（加法）叠加良好。防守回合少打——给敌人白挂狂暴纯亏。
- **升级的关键性**：伤害 6→10（+67%）。0 费牌升级不占能量节奏，且升级后首击在狂暴加成下提升更明显（mod 越多差距越大），优先级高。
- **性价比**：0 费全体攻击 + 全场狂暴，多 mod 玩家的收益和风险同步放大；单 mod（只有 seer）时也有 1 层狂暴可用，保底不亏。
