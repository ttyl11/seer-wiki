## 小贴士

- **Boss 战核弹，伤害翻倍是核心**：Boss 房间下基础伤害 ×<span style="color:#3aa675;font-weight:600">2</span>——<span style="color:#3aa675;font-weight:600">35</span> 伤变 <span style="color:#3aa675;font-weight:600">70</span>，升级 <span style="color:#3aa675;font-weight:600">50</span> 伤变 <span style="color:#3aa675;font-weight:600">100</span>。这张牌就是为 Boss 战设计的终结卡，与[王·联盟审判](/cards/character/king_alliance_judgment.md)是对称设计——两张都是 Boss 翻倍卡，区别在附带效果（联盟审判走麻痹/害怕稳定控，这张走吸血/免疫/随机异常的全能向）。
- **伤害按攻击结算，吃增伤乘区**：本牌伤害是普通攻击伤害——[力量](/powers/strength_power.md)/[易伤](/powers/vulnerable_power.md)加成、[暴击](/powers/critical_strike_power.md)全部生效，也会被目标[格挡](/mechanics/block.md)抵扣。基础 <span style="color:#3aa675;font-weight:600">35</span> 伤（Boss <span style="color:#3aa675;font-weight:600">70</span>）只是面板起点，配合增伤手段能打出更高爆发；吸血也跟着实际结算的乘区走。
- **六效合一是"全套服务"**：伤害 + 吸血 + 异常免疫 + 先制 + 异常施加 + 减费，一张牌把输出、续航、保命、加速、控制、降本全包了。Boss 战打一张等于开了六个增益，是爆发回合的核心。
- **吸血按总伤害算，被格挡也不亏**：回复量 = 本次攻击**总伤害**（含被格挡吸收的部分）的 <span style="color:#3aa675;font-weight:600">25</span>%——<span style="color:#3aa675;font-weight:600">70</span> 伤即使全打在格挡上也按 <span style="color:#3aa675;font-weight:600">70</span> 计算，稳定回 <span style="color:#3aa675;font-weight:600">17</span> 血。只有回血量不足 <span style="color:#3aa675;font-weight:600">1</span>（总伤害 <span style="color:#3aa675;font-weight:600">4</span> 以下）才不触发，正常打出必有吸血。
- **异常免疫 2 回合保命窗口**：自身获得 <span style="color:#3aa675;font-weight:600">2</span> 回合[异常状态](/mechanics/abnormal-status.md)免疫，期间不受任何异常影响。Boss 战中这 <span style="color:#3aa675;font-weight:600">2</span> 回合就是安全输出窗口——不用担心被上烧伤/中毒/瘫痪等异常打断节奏。
- **先制 2 层加速后续**：自身获得 <span style="color:#3aa675;font-weight:600">2</span> 层[先制](/powers/first_strike_power.md)——下一张打出的牌耗能 <span style="color:#3aa675;font-weight:600">-2</span>（先制按层数全额减在下一张牌上，打出后整个先制消失）。所以接一张高费牌最赚：接 <span style="color:#3aa675;font-weight:600">5</span> 费牌变 <span style="color:#3aa675;font-weight:600">3</span> 费，等于变相补回 <span style="color:#3aa675;font-weight:600">2</span> 费——本牌实际净消耗约 <span style="color:#3aa675;font-weight:600">3</span> 费换六效，不算贵。
- **随机 2 种异常不重复**：从全部异常状态中随机选 <span style="color:#3aa675;font-weight:600">2</span> 种不重复的，对目标各施加 <span style="color:#3aa675;font-weight:600">2</span> 层（层在不同异常里的含义不同——灼烧类是 DoT 量、麻痹类是持续时间，详见各异常页面）。随机性意味着效果不稳定——可能抽到瘫痪+害怕这种强控，也可能抽到较弱的异常。但 <span style="color:#3aa675;font-weight:600">2</span> 种叠加总有压制效果。
- **同名牌减费，越打越便宜**：打出后获得减费能力，同名牌每次打出费用 <span style="color:#3aa675;font-weight:600">-1</span>（最低 <span style="color:#3aa675;font-weight:600">0</span>）。首次 <span style="color:#3aa675;font-weight:600">5</span> 费，第二次 <span style="color:#3aa675;font-weight:600">4</span> 费……长线 Boss 战多次打出后实际成本递减。
- **核心矛盾：六效都很强但都偏一次性**：异常免疫只 <span style="color:#3aa675;font-weight:600">2</span> 回合，先制只作用下一张牌，异常施加只 <span style="color:#3aa675;font-weight:600">2</span> 回合。所以这张牌是"爆发窗口"而非"持续增益"，打出后要立即在这 <span style="color:#3aa675;font-weight:600">2</span> 回合窗口内最大化输出。
- **升级 +15 伤，Boss 战相当于 +30**：升级 <span style="color:#3aa675;font-weight:600">35</span>→<span style="color:#3aa675;font-weight:600">50</span>，Boss 战翻倍后相当于 +<span style="color:#3aa675;font-weight:600">30</span> 伤（<span style="color:#3aa675;font-weight:600">70</span>→<span style="color:#3aa675;font-weight:600">100</span>）。其它效果不变，升级只强化伤害这一项。
- **性价比**：<span style="color:#3aa675;font-weight:600">5</span> 费换 <span style="color:#3aa675;font-weight:600">35</span> 伤（Boss <span style="color:#3aa675;font-weight:600">70</span>）+ 吸血 + 免疫 + 先制 + 异常施加 + 减费六效合一，Boss 战价值爆炸，减费机制让多次打出后实际成本递减。
