## 小贴士

- **Boss 战核弹，伤害翻倍是核心**：Boss 房间下基础伤害 ×<span style="color:#3aa675;font-weight:600">2</span>——<span style="color:#3aa675;font-weight:600">35</span> 伤变 <span style="color:#3aa675;font-weight:600">70</span>，升级 <span style="color:#3aa675;font-weight:600">50</span> 伤变 <span style="color:#3aa675;font-weight:600">100</span>。这张牌就是为 Boss 战设计的终结卡，与[王·联盟审判](/cards/character/king_alliance_judgment.md)（精英战核弹）是对称设计——一个打精英一个打 Boss。
- **六效合一是"全套服务"**：伤害 + 吸血 + 异常免疫 + 先制 + 异常施加 + 减费，一张牌把输出、续航、保命、加速、控制、降本全包了。Boss 战打一张等于开了六个增益，是爆发回合的核心。
- **吸血需造成伤害，被格挡不回血**：按实际造成伤害的 <span style="color:#3aa675;font-weight:600">25</span>% 回血，且回血量需 ≥<span style="color:#3aa675;font-weight:600">1</span> 才生效。Boss 格挡高时回血会大打折扣——<span style="color:#3aa675;font-weight:600">70</span> 伤被格挡到只剩 <span style="color:#3aa675;font-weight:600">20</span>，只能回 <span style="color:#3aa675;font-weight:600">5</span> 血。所以这张牌要在 Boss 没格挡或格挡低时打才回血多。
- **异常免疫 2 回合保命窗口**：自身获得 <span style="color:#3aa675;font-weight:600">2</span> 回合[异常状态](/mechanics/abnormal-status.md)免疫，期间不受任何异常影响。Boss 战中这 <span style="color:#3aa675;font-weight:600">2</span> 回合就是安全输出窗口——不用担心被上烧伤/中毒/瘫痪等异常打断节奏。
- **先制 2 层加速后续**：自身获得 <span style="color:#3aa675;font-weight:600">2</span> 层[先制](/powers/first_strike_power.md)，下两张牌各减 <span style="color:#3aa675;font-weight:600">1</span> 费。打出这张 <span style="color:#3aa675;font-weight:600">5</span> 费牌后，紧接的两张牌变相补回 <span style="color:#3aa675;font-weight:600">2</span> 费——所以实际净消耗是 <span style="color:#3aa675;font-weight:600">3</span> 费换六效，不算贵。
- **随机 2 种异常不重复**：从所有异常状态中随机选 <span style="color:#3aa675;font-weight:600">2</span> 种不重复的，对目标各施加 <span style="color:#3aa675;font-weight:600">2</span> 回合。随机性意味着效果不稳定——可能抽到瘫痪+害怕这种强控，也可能抽到较弱的异常。但 <span style="color:#3aa675;font-weight:600">2</span> 种叠加总有压制效果。
- **同名牌减费，越打越便宜**：打出后获得减费能力，同名牌每次打出费用 <span style="color:#3aa675;font-weight:600">-1</span>（最低 <span style="color:#3aa675;font-weight:600">0</span>）。首次 <span style="color:#3aa675;font-weight:600">5</span> 费，第二次 <span style="color:#3aa675;font-weight:600">4</span> 费……长线 Boss 战多次打出后实际成本递减。
- **核心矛盾：六效都很强但都偏一次性**：异常免疫只 <span style="color:#3aa675;font-weight:600">2</span> 回合，先制只下两张牌，异常施加只 <span style="color:#3aa675;font-weight:600">2</span> 回合。所以这张牌是"爆发窗口"而非"持续增益"，打出后要立即在这 <span style="color:#3aa675;font-weight:600">2</span> 回合窗口内最大化输出。
- **升级 +15 伤，Boss 战相当于 +30**：升级 <span style="color:#3aa675;font-weight:600">35</span>→<span style="color:#3aa675;font-weight:600">50</span>，Boss 战翻倍后相当于 +<span style="color:#3aa675;font-weight:600">30</span> 伤（<span style="color:#3aa675;font-weight:600">70</span>→<span style="color:#3aa675;font-weight:600">100</span>）。其它效果不变，升级只强化伤害这一项。
- **性价比**：<span style="color:#3aa675;font-weight:600">5</span> 费换 <span style="color:#3aa675;font-weight:600">35</span> 伤（Boss <span style="color:#3aa675;font-weight:600">70</span>）+ 吸血 + 免疫 + 先制 + 异常施加 + 减费六效合一，Boss 战价值爆炸，减费机制让多次打出后实际成本递减。
