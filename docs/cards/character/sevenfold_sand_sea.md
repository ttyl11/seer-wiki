## 小贴士

- **1 费四维增益 + 唱词铺设**：一张牌同时给[力量](/powers/strength_power.md)、[防御](/powers/defense_power.md)、[命中](/powers/accuracy_power.md)、[速度](/powers/speed_power.md)各 +<span style="color:#3aa675;font-weight:600">1</span>（即[全属性](/mechanics/all_attributes.md)+1），还附加[唱词：拉](/powers/chant_ra_power.md)。<span style="color:#3aa675;font-weight:600">1</span> 费换四维增益本身已合格，唱词是额外收益。
- **无唱词时效果翻倍**：翻倍判定在施加前快照——若自身当前**没有任何唱词**（舍麦什/霍尔希德/拉/莎木斯四种任一都没有），四维增益变为各 +<span style="color:#3aa675;font-weight:600">2</span>。所以第一张打出时收益最大——首次打出 +2 四维，之后因身上常驻唱词：拉，再打只 +1。想让后续打出也翻倍，得先把唱词洗掉或用消耗唱词的机制。
- **速度是最实在的长线收益**：速度每 <span style="color:#3aa675;font-weight:600">2</span> 层 = 每回合多抽 <span style="color:#3aa675;font-weight:600">1</span> 张牌。翻倍时速度 +2 意味着**之后每回合都多抽 1 张**——这是四维里唯一产生持续资源流的一项，首次打出的真实价值远超表面上的 +2 四维。
- **唱词：拉的反制效果**：[唱词：拉](/powers/chant_ra_power.md)不是直接给增益，而是"自身生命减少后，每有一层令所有对手[先制](/powers/first_strike_power.md)−<span style="color:#3aa675;font-weight:600">1</span>"——任何来源的掉血都触发（攻击、固定伤害、自损），你挨打得越频繁，对手先制被削得越狠。配合受击向打法能持续压制对手出牌节奏。唱词本身是增益（Buff）且不衰减，挂上就是整场生效。
- **升级只加抽牌**：升级让抽牌数从 <span style="color:#3aa675;font-weight:600">0</span> 增至 <span style="color:#3aa675;font-weight:600">1</span>，让这张牌从"纯增益"变成"增益 + 过牌"。1 费 +1 四维 + 1 抽 + 唱词铺设，升级后是合格的工具牌。
- **性价比**：1 费合理——四维增益 + 唱词铺设，首次打出翻倍更赚。升级后加抽 1 张让灵活性大增。
