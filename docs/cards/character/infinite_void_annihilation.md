## 描述

PP: <span style="color:#3aa675;font-weight:600">3</span>/<span style="color:#3aa675;font-weight:600">3</span> 将所有敌人非攻击意图无效化。抽<span style="color:#3aa675;font-weight:600">1</span>张牌。

## 升级后

耗能<span style="color:#3aa675;font-weight:600">-1</span>。PP: <span style="color:#3aa675;font-weight:600">3</span>/<span style="color:#3aa675;font-weight:600">3</span> 将所有敌人非攻击意图无效化。抽<span style="color:#3aa675;font-weight:600">1</span>张牌。

## 小贴士

- **只无效化非攻击意图**：将所有敌人的非攻击意图（如格挡、增益、召唤等）变为无效化。被无效化的敌人整回合不行动，即使同回合还有攻击意图也不会执行。
- **抽牌补充手牌**：抽 <span style="color:#3aa675;font-weight:600">1</span> 张牌，弥补打出此牌的卡位，不亏手牌数。
- **全敌人覆盖**：对所有敌人生效，多敌人遭遇战中价值放大。面对单个敌人时，有非攻击意图则整回合被取消，纯攻击意图则无效。
- **2 费合理**：2 费换全敌人非攻击意图无效化 + 1 抽牌。意图控制类效果稀有，1 抽牌弥补手牌，性价比合理。
- **升级降费**：耗能 <span style="color:#3aa675;font-weight:600">2</span> → <span style="color:#3aa675;font-weight:600">1</span>，1 费打出意图控制 + 抽牌，灵活性大幅提升。
