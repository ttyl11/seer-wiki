## 小贴士

- **六效合一的终极核弹——一张牌把输出/控制/续航/资源全包了**：①对所有敌人 <span style="color:#3aa675;font-weight:600">22</span> 伤 ②移除所有敌人增益 + [击晕](/mechanics/stun.md) ③所有 PP 牌回满 PP ④消耗牌堆全部回流抽牌堆 ⑤获得 <span style="color:#3aa675;font-weight:600">6</span> 层[永昌玺](/powers/eternal_seal_power.md)（直接满层）⑥施加[八方债](/powers/octagon_debt_power.md)倒计时。打出这一张等于同时完成输出、控场、续航、资源回收四件事。
- **永昌玺直接满 6 层——跳过累积立即享受全部效果**：正常永昌玺要逐层累积，这张牌直接给 <span style="color:#3aa675;font-weight:600">6</span> 层（上限），立即解锁：攻击伤害 +<span style="color:#3aa675;font-weight:600">48</span>%、每次攻击后附加 <span style="color:#3aa675;font-weight:600">5</span> 点[固定伤害](/powers/fixed_damage_power.md)、回合结束回 <span style="color:#3aa675;font-weight:600">3</span> 血 + 从弃牌堆随机选一张 PP 牌 PP 设为 <span style="color:#3aa675;font-weight:600">1</span>、免疫[异常状态](/mechanics/abnormal-status.md)、对手获先制时自己也获先制、每隔 <span style="color:#3aa675;font-weight:600">2</span> 回合击晕一次对手。
- **八方债是死亡倒计时——3 回合后毁灭性结算**：打出后开始 <span style="color:#3aa675;font-weight:600">3</span> 回合倒计时（每次**自己回合结束**递减，打出当回合结束就减 <span style="color:#3aa675;font-weight:600">1</span>），归零时：生命值直接设为 <span style="color:#3aa675;font-weight:600">1</span>（非伤害、无视格挡）、所有 PP 牌 PP 清零、所有不在消耗堆的牌全部消耗。基本等于死亡——除非你在倒计时内结束战斗（战斗结束 Power 直接消失，不结算）。
- **人工制品可以吞掉八方债——"非赢即死"变"白嫖"**：八方债是挂在**自己身上的减益**，而[人工制品](/powers/artifact_power.md)会拦截一切落到自己身上的可见减益（不分敌我来源）。先拿到 <span style="color:#3aa675;font-weight:600">1</span> 层人工制品（如[大数回廊](/cards/character/great_number_corridor.md)、[冰天花葬](/cards/character/ice_sky_flower_burial.md)、[沦·亡灵天灾](/cards/character/undead_catastrophe.md)都能给），再打出八方——八方债被人工制品挡掉根本不落地，倒计时不存在，<span style="color:#3aa675;font-weight:600">6</span> 层永昌玺 + 全部资源效果白拿。这是这张牌最强的隐藏配合，直接抹掉代价面。
- **核心矛盾：6 层永昌玺的核弹增益 vs 3 回合后的毁灭**：这张牌最精妙也最极端的设计——给你最强增益和最丰富资源，但 <span style="color:#3aa675;font-weight:600">3</span> 回合后一切归零。打出后必须全力输出在 <span style="color:#3aa675;font-weight:600">3</span> 回合内赢，否则就是自杀（除非用人工制品吞债抹掉代价）。是 mod 里最极端的"非赢即死"型核弹。
- **消耗牌堆回流 + PP 回满是启动资源**：打出这张牌的同时帮你把消耗堆的牌全部回流抽牌堆、所有 PP 牌回满——配合永昌玺的增伤和固定伤害，<span style="color:#3aa675;font-weight:600">3</span> 回合内的输出窗口被最大化。
- **陨关键词——打出后变圣逝不能复用**：此牌带[陨](/mechanics/fallen.md)关键词，打出后转化为[圣逝](/cards/status/holy_passing.md)，整局 run 内不能再次获得或使用。
- **升级多 1 回合缓冲**：升级后倒计时从 <span style="color:#3aa675;font-weight:600">3</span> 延长至 <span style="color:#3aa675;font-weight:600">4</span> 回合，多 <span style="color:#3aa675;font-weight:600">1</span> 回合输出窗口——对于"非赢即死"的牌来说，多 <span style="color:#3aa675;font-weight:600">1</span> 回合往往是生与死的区别。
- **性价比**：<span style="color:#3aa675;font-weight:600">3</span> 费换六效合一 + 6 层永昌玺，mod 里最极端的核弹牌——代价是 <span style="color:#3aa675;font-weight:600">3</span> 回合后毁灭性结算，必须在窗口内结束战斗。
