## 小贴士

- **9 费是表象，三态减费才是真面目**：三种态（[百天浮世络](/powers/hundred_day_floating_world_power.md)/[怀生菩怜态](/powers/compassionate_bodhi_power.md)/[拒赦怒威态](/powers/wrathful_judgment_power.md)任一）每层各减 <span style="color:#3aa675;font-weight:600">3</span> 费，三种态层数相加满 <span style="color:#3aa675;font-weight:600">3</span> 层直接 <span style="color:#3aa675;font-weight:600">0</span> 费打出。裸打 <span style="color:#3aa675;font-weight:600">9</span> 费等于自杀——这张牌只配在三态体系里玩，没三态别拿。
- **9 点伤害是添头，两个态的效果才是核弹**：基础 <span style="color:#3aa675;font-weight:600">9</span> 伤只是顺带挠痒，真正价值在两个态触发的额外效果——一个保命一个输出，威力都是"按血量百分比计算"的级别。
- **怀生菩怜态 = 反比格挡，敌人越硬你越硬**：处于[怀生菩怜态](/powers/compassionate_bodhi_power.md)时，获得等同于**敌人当前生命** <span style="color:#3aa675;font-weight:600">99</span>% 的[格挡](/mechanics/block.md)（向下取整）。Boss <span style="color:#3aa675;font-weight:600">200</span> 血时打出直接拿 <span style="color:#3aa675;font-weight:600">198</span> 格挡，<span style="color:#3aa675;font-weight:600">199</span> 血拿 <span style="color:#3aa675;font-weight:600">197</span>——敌人血越厚你越肉，专门用来硬扛高血精英/Boss 的爆发回合。
- **拒赦怒威态 = 正比固定伤害，自己越满血越疼**：处于[拒赦怒威态](/powers/wrathful_judgment_power.md)时，附加等同**自身当前生命** <span style="color:#3aa675;font-weight:600">99</span>% 的[固定伤害](/powers/fixed_damage_power.md)。自己 <span style="color:#3aa675;font-weight:600">80</span> 满血打出附加 <span style="color:#3aa675;font-weight:600">79</span> 固定伤害（下回合开始结算，不可格挡）。所以这张牌要在血量健康时打才疼，残血打出来固定伤害也残。
- **两个态的最佳时机正好相反**：怀生菩怜态要敌人高血（格挡多），拒赦怒威态要自己高血（固定伤害高）。敌人满血 + 自己满血时两个态都触发最理想——既拿大额格挡又附加大额固定伤害，但这种情况实战中不多见，通常只能二选一。
- **消属性是额外保底**：消除敌人的力量/防御/命中/速度四种正层数（整项移除，不是减层；负层数不算），每消除 <span style="color:#3aa675;font-weight:600">1</span> 种获得 <span style="color:#3aa675;font-weight:600">1</span> 层[缓冲](/powers/buffer_power.md)。最理想消除 <span style="color:#3aa675;font-weight:600">4</span> 种 = <span style="color:#3aa675;font-weight:600">4</span> 层缓冲，每层挡一整次生命值损失。对叠力量的精英怪尤其赚——既清了对方力量又拿了缓冲。
- **升级保留是质变**：三态回合结束减 <span style="color:#3aa675;font-weight:600">1</span> 层，不升级的话这牌可能还没等到三态叠满就被迫打出。[保留](/mechanics/retain.md)让它能留在手里等到三态到位再爆发，是这张牌能用的前提。
- **性价比**：三态减费后实际 <span style="color:#3aa675;font-weight:600">0</span>-<span style="color:#3aa675;font-weight:600">3</span> 费换"百分比格挡 + 百分比固定伤害 + 消属性 + 缓冲"四效合一，三态流派的收尾核弹定价合理。
