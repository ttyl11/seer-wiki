## 小贴士

- **三段连锁——宝剑→铸造君王之剑→自动打出君王之剑**：打出万剑归一后获得 3 张 0 费[宝剑](/cards/colorless/sword.md)；宝剑打出时[铸造](/mechanics/forge.md) 10 产生君王之剑并立即将其消耗进消耗堆；之后每回合开始，万剑归一能力自动从消耗堆打出一张君王之剑——形成"铸造→消耗→自动打出"的永动输出链。
- **君王之剑自带 20 伤害**：君王之剑基础伤害 10，但宝剑每次铸造 10 会给**所有**君王之剑（含消耗堆里的）加伤害——新建的君王之剑 = 基础 10 + 铸造 10 = **自带 20 伤害**，且后续每一次铸造都会让它继续变大。
- **铸造会强化所有已消耗的剑——伤害滚雪球**：这是连锁的核心：每次铸造 +10 会加到**包括消耗堆里**的每一把君王之剑上。单张宝剑（打出 1 次 + [重放](/mechanics/replay.md) 3 次 = 4 次铸造）产生 4 把剑，最终伤害为 50/40/30/20——**一张 0 费宝剑 = 140 点伤害储备**。
- **3 张宝剑齐发 ≈ 900 点伤害储备**：3 张宝剑共执行 12 次铸造，产生 12 把君王之剑，每把都被后续铸造反复强化（越早生成的剑越肥，最早的一把可达 130 伤害）。之后每回合自动打出一张，12 回合的白嫖输出——真正的"万剑归一"。
- **PP1——一场战斗一次的启动器**：PP 仅 1 点，基本每场战斗只能启动一次（除非配合 PP 恢复手段）。好在启动后连锁全自动运转，不占用后续回合的出牌。注意授予的能力是增益类型——被敌人消除增益会停止"每回合自动打出"，但已进消耗堆的剑不受影响，之后抽到宝剑仍可手动重启动。
- **自动打出的剑免费且随机选目标**：每回合开始自动从消耗堆打出一张君王之剑——自动打出**不消耗能量**（2 费的君王之剑白嫖打出），目标从存活敌人中随机选取（多人模式两端随机同步），无法指定——Boss 单挑时无所谓，多敌人时听天由命。
- **消耗堆打完就停**：君王之剑打出后进入弃牌堆，不会自动回消耗堆。储备多少把就能自动打多少回合；弃牌堆洗回抽牌堆后若有幸再抽到君王之剑，可再被宝剑重新消耗进堆，形成第二轮循环。抽到手里不打也不亏——君王之剑自带[保留](/mechanics/retain.md)，回合结束不弃、一直留在手牌，随时等宝剑回收。
- **升级加固有——保证关键回合启动**：升级后获得[固有](/mechanics/innate.md)，战斗起手必在手牌，第一回合就能规划能量启动连锁。对 3 费能力牌来说价值极高。
- **配合方向**：额外获得宝剑或额外铸造的手段都能扩大剑池；[圣剑三](/cards/token/holy_sword_three.md)可让所有君王之剑伤害变为 3 倍，与庞大的剑池联动收益爆炸。
- **性价比**：3 费 + PP1 换 3 张 0 费宝剑 + 每回合自动输出的永久能力——启动当回合就把 3 费赚回（3 张 0 费宝剑本身价值 3 费以上），之后每回合的白嫖伤害全是净赚，稀有度定价超值。
