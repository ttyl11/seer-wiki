## 升级后

PP: <span style="color:#3aa675;font-weight:600">3</span>/<span style="color:#3aa675;font-weight:600">3</span> 造成<span style="color:#3aa675;font-weight:600">50</span>点伤害。对Boss伤害<span style="color:#3aa675;font-weight:600">+100%</span>。令对手[<span style="color:#d44;font-weight:600">麻痹</span>](/powers/ma_power.md)、[<span style="color:#d44;font-weight:600">害怕</span>](/powers/fear_power.md)<span style="color:#3aa675;font-weight:600">2</span>回合。同名牌每打出一次费用<span style="color:#3aa675;font-weight:600">-1</span>（最低0）。下次受到伤害减半，下次造成伤害翻倍。

## 小贴士

- **Boss战核弹，伤害翻倍是核心**：在 Boss 房间（按房间类型判定）基础伤害 ×<span style="color:#3aa675;font-weight:600">2</span>——<span style="color:#3aa675;font-weight:600">35</span> 伤变 <span style="color:#3aa675;font-weight:600">70</span>，升级 <span style="color:#3aa675;font-weight:600">50</span> 伤变 <span style="color:#3aa675;font-weight:600">100</span>。这张牌就是为 Boss 战准备的终结卡，普通战斗和精英战不享受翻倍，尽量留给 Boss。
- **双异常压制——麻痹 + 害怕叠出 63% 减攻**：同时施加[麻痹](/powers/ma_power.md) + [害怕](/powers/fear_power.md)各 <span style="color:#3aa675;font-weight:600">2</span> 回合。麻痹令其攻击伤害 -10% 且每回合开始获得 1 层[易伤](/powers/vulnerable_power.md)，害怕再令攻击伤害 -30%——两者相乘，Boss 的攻击输出直接打到 **63%**（0.9 × 0.7）。Boss 挂着易伤挨打，攻防两端都被这张牌接管。
- **麻痹的易伤会持续累积**：麻痹存续期间目标每回合开始自动 +1 层易伤，2 回合内叠 2 层——后续攻击伤害被放大的收益相当可观，配合增伤窗口更痛。
- **减伤增伤都是"下次"，一次性消耗**：自身获得[减伤](/powers/next_damage_reduction_power.md)（下次受到的攻击伤害减半）+ [增伤](/powers/next_damage_boost_power.md)（下次攻击伤害翻倍）。两者都只对**攻击伤害**生效——非攻击伤害（如灼烧、固定伤害）不受影响——且触发一次就消耗。打出后下一手要立即用增伤打输出，或靠减伤硬吃 Boss 反击。
- **同名牌减费，越打越便宜**：打出后获得减费能力，同名牌每次打出费用 <span style="color:#3aa675;font-weight:600">-1</span>（最低 <span style="color:#3aa675;font-weight:600">0</span>）。首次 <span style="color:#3aa675;font-weight:600">5</span> 费，第二次 <span style="color:#3aa675;font-weight:600">4</span> 费，第三次 <span style="color:#3aa675;font-weight:600">3</span> 费……第六次开始 <span style="color:#3aa675;font-weight:600">0</span> 费。多张同名卡在长战斗中反复打出后实际成本极低。
- **升级 +15 伤，Boss 战相当于 +30**：升级 <span style="color:#3aa675;font-weight:600">35</span>→<span style="color:#3aa675;font-weight:600">50</span>，Boss 战翻倍后相当于 +<span style="color:#3aa675;font-weight:600">30</span> 伤（<span style="color:#3aa675;font-weight:600">70</span>→<span style="color:#3aa675;font-weight:600">100</span>）。其它效果不变，升级只强化伤害。
- **爆发回合的"全套服务"**：伤害 + 双异常 + 减伤 + 增伤 + 减费五效合一，但增伤减伤只下次生效、双异常只 2 回合——打出后要立即跟进输出牌利用增伤窗口，别浪费那 100% 增伤。
- **性价比**：<span style="color:#3aa675;font-weight:600">5</span> 费换 <span style="color:#3aa675;font-weight:600">35</span> 伤（Boss <span style="color:#3aa675;font-weight:600">70</span>）+ 攻防双向异常 + 减伤增伤 + 减费。普通战斗性价比一般，**Boss 战价值爆炸**——是值得为 Boss 战专门留着的终端卡。
