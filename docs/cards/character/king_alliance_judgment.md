## 描述

PP: <span style="color:#3aa675;font-weight:600">3</span>/<span style="color:#3aa675;font-weight:600">3</span> 造成<span style="color:#3aa675;font-weight:600">35</span>点伤害。对精英敌人伤害<span style="color:#3aa675;font-weight:600">+100%</span>。令对手[<span style="color:#d44;font-weight:600">瘫痪</span>](/powers/paralysis_power.md)、[<span style="color:#d44;font-weight:600">害怕</span>](/powers/fear_power.md)<span style="color:#3aa675;font-weight:600">2</span>回合。同名牌每打出一次费用<span style="color:#3aa675;font-weight:600">-1</span>（最低0）。下次受到的攻击伤害减半，下次攻击伤害翻倍。

## 升级后

PP: <span style="color:#3aa675;font-weight:600">3</span>/<span style="color:#3aa675;font-weight:600">3</span> 造成<span style="color:#3aa675;font-weight:600">50</span>点伤害。对精英敌人伤害<span style="color:#3aa675;font-weight:600">+100%</span>。令对手[<span style="color:#d44;font-weight:600">瘫痪</span>](/powers/paralysis_power.md)、[<span style="color:#d44;font-weight:600">害怕</span>](/powers/fear_power.md)<span style="color:#3aa675;font-weight:600">2</span>回合。同名牌每打出一次费用<span style="color:#3aa675;font-weight:600">-1</span>（最低0）。下次受到的攻击伤害减半，下次攻击伤害翻倍。

## 小贴士

- ⚠️ **本地化三处错误，以实际效果为准**：游戏内描述写"对 Boss 伤害 +100%""麻痹""下次受到/造成伤害"，但实际是——①判定**精英房间**（不是 Boss 房间）伤害翻倍 ②施加的是[瘫痪](/powers/paralysis_power.md)（不是[麻痹](/powers/ma_power.md)，两者是不同异常状态）③减伤增伤只对**攻击伤害**生效（非攻击伤害如烧伤自伤、固定伤害不受影响）。
- **精英战核弹，伤害翻倍是核心**：精英房间下基础伤害 ×<span style="color:#3aa675;font-weight:600">2</span>——<span style="color:#3aa675;font-weight:600">35</span> 伤变 <span style="color:#3aa675;font-weight:600">70</span>，升级 <span style="color:#3aa675;font-weight:600">50</span> 伤变 <span style="color:#3aa675;font-weight:600">100</span>。这张牌就是为精英战设计的终结卡，Boss 房间不享受翻倍所以别指望它打 Boss。
- **双异常压制把敌人输出压到极低**：同时施加[瘫痪](/powers/paralysis_power.md) + [害怕](/powers/fear_power.md)各 <span style="color:#3aa675;font-weight:600">2</span> 回合。两个都降低攻击伤害，叠加后敌方普攻输出大幅缩水；瘫痪还有额外惩罚——敌人若一回合没造成伤害，下回合开局直接吃虚弱 + 易伤 + 缩小各 <span style="color:#3aa675;font-weight:600">1</span> 层。
- **减伤增伤都是"下次"，一次性消耗**：自身获得[减伤](/powers/next_damage_reduction_power.md)（下次受到的攻击伤害减半）+ [增伤](/powers/next_damage_boost_power.md)（下次攻击伤害翻倍）。两者都只对**攻击伤害**生效，且触发一次就消耗——打出这张牌后下一手要立即利用增伤打输出，或靠减伤挡敌人反击。
- **同名牌减费，越打越便宜**：打出后获得减费能力，同名牌每次打出费用 <span style="color:#3aa675;font-weight:600">-1</span>（最低 <span style="color:#3aa675;font-weight:600">0</span>）。首次 <span style="color:#3aa675;font-weight:600">5</span> 费，第二次 <span style="color:#3aa675;font-weight:600">4</span> 费，第三次 <span style="color:#3aa675;font-weight:600">3</span> 费……第六次开始 <span style="color:#3aa675;font-weight:600">0</span> 费。长线精英战多次打出后实际成本递减。
- **六效合一的矛盾：什么都想做但只能做一次**：伤害 + 双异常 + 减伤 + 增伤 + 减费，效果多但都是"一次性"——增伤减伤只下次生效，双异常只 2 回合。所以这张牌是爆发回合的"全套服务"，打出后要立即跟进利用增伤，别浪费那 100% 增伤窗口。
- **升级 +15 伤，精英战相当于 +30**：升级 <span style="color:#3aa675;font-weight:600">35</span>→<span style="color:#3aa675;font-weight:600">50</span>，精英战翻倍后相当于 +<span style="color:#3aa675;font-weight:600">30</span> 伤（<span style="color:#3aa675;font-weight:600">70</span>→<span style="color:#3aa675;font-weight:600">100</span>）。其它效果不变，升级只强化伤害这一项。
- **性价比**：<span style="color:#3aa675;font-weight:600">5</span> 费换 <span style="color:#3aa675;font-weight:600">35</span> 伤（精英 <span style="color:#3aa675;font-weight:600">70</span>）+ 双异常 + 减伤增伤 + 减费六效合一，精英战价值爆炸，减费机制让多次打出后实际成本递减，典型"前期贵后期便宜"定价。
