# 五芒星

<img src="/images/cards/pentagram.png" alt="五芒星" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 角色牌
- **最大PP**: 5
- **能量消耗**: 0
- **辉星消耗**: 5
- **类型**: 攻击
- **稀有度**: 普通
- **目标**: 任意敌方
- **可升级**: 是（1 级）

### 数值参数

| 参数 | 数值 |
|---|---|
| 伤害 | 12 |
| 升级后伤害 | 20 |
| 神谕充能球数 | 3 |

## 描述

PP: 5/5 造成12点伤害。生成3个神谕充能球。

## 升级后

PP: 5/5 造成20点伤害。生成3个神谕充能球。

## 小贴士

- **0费5辉星的高性价比输出**：0费即可打出，但消耗5点辉星。12点伤害+3个神谕充能球，是辉星流派的爆发件——有辉星时无成本爆发，无辉星则打不出。
- **神谕充能球持续收益**：[神谕](/mechanics/orb)充能球被动随机提升属性，激发时随机附魔手牌。3个球等于每回合3次随机属性提升+附魔机会，长期收益可观。
- **PP5双重消耗**：PP5+5辉星的双重消耗，需要配合PP恢复和辉星生成（如[星光仙气](/cards/character/starlight_aura.md)）才能稳定使用。
- **升级伤害提升明显**：12→20伤害提升67%，升级后单卡输出接近高费攻击牌水平，0费打出性价比极高。
