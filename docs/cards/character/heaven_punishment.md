# 天谴

<img src="/images/cards/heaven_punishment.png" alt="天谴" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 角色牌
- **最大PP**: 1
- **能量消耗**: 3
- **类型**: 攻击
- **稀有度**: 普通
- **目标**: 单体敌方
- **可升级**: 是（1 级）

### 数值参数

| 参数 | 数值 |
|---|---|
| 伤害范围 | 敌人当前生命的1/6~1/3 |
| 选牌数量 | 3 |
| 升级后耗能 | 2 |

## 描述

PP: 1/1 随机造成等于敌人1/6~1/3当前生命的伤害。从3张带「天」的牌中选择一张获得。

## 升级后

PP: 1/1 随机造成等于敌人1/6~1/3当前生命的伤害。从3张带「天」的牌中选择一张获得。（耗能降为2）

## 小贴士

- **百分比伤害克高血敌人**：伤害 = 敌人当前生命 × 1/6~1/3（随机）。敌人300血时造成50-100点伤害，是少有的百分比伤害攻击牌，专克高血量Boss。
- **选牌补充手牌**：打完伤害后从3张带「天」的牌中选一张加入手牌，等于打一张牌还能再获得一张「天」牌。牌组中「天」字牌越多，选牌池越丰富。
- **3费高耗能**：3费攻击牌较高，PP1低消耗部分弥补。升级后2费更合理，适合作为中期输出件。
- **低血敌人收益降低**：百分比伤害的弱点是敌人低血时伤害也低——20血敌人只能造成3-6点伤害。适合开局打高血敌人，后期收割残血换其他牌。
