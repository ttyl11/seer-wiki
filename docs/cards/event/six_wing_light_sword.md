# 六翼光剑

<img src="/images/cards/six_wing_light_sword.png" alt="六翼光剑" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 事件牌
- **最大PP**: 3
- **能量消耗**: 0
- **类型**: 攻击
- **稀有度**: 衍生
- **目标**: 敌方单体
- **可升级**: 否

### 数值参数

| 参数 | 数值 |
|---|---|
| PP | 3 |
| 最大PP | 3 |
| 伤害 | 66 |

## 描述

PP: 3/3 造成<span style="color:#3aa675;font-weight:600">66</span>点伤害。当你首次洗牌后可用。

## 小贴士

- **分类**：事件牌，战斗中不可被生成，无法升级。
- **关键词**：自带 [<span style="color:#d4a017;font-weight:600">保留</span>](/mechanics/retain.md) 与"不可打出"。初始状态下此牌无法打出。
- **首次洗牌解锁**：当拥有者首次洗牌后，移除"不可打出"限制，此后此牌才可打出。
- **打出效果**：对指定敌方目标造成 <span style="color:#3aa675;font-weight:600">66</span> 点攻击伤害（基值 66）。
- **目标选取**：敌方单体。
