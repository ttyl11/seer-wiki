# 六翼光剑

## 基本信息

- **分类**: 事件牌
- **最大PP**: 3
- **能量消耗**: 0
- **类型**: 攻击
- **稀有度**: 衍生
- **目标**: 敌方单体
- **可升级**: 否
- **关键词**: [保留](/mechanics/retain.md)、[不能被打出](/mechanics/unplayable.md)（首次洗牌后移除）

### 数值参数

| 参数 | 数值 |
|---|---|
| 伤害 | 66 |
| PP | 3 |
| 最大PP | 3 |

## 描述

PP: 3/3 造成<span style="color:#3aa675;font-weight:600">66</span>点伤害。当你首次洗牌后可用。

## 小贴士

- **开局是块砖，洗完牌才是剑**：初始带[不能被打出](/mechanics/unplayable.md)，抽到也只能攥着（好在带[保留](/mechanics/retain.md)，回合结束不弃、一直躺在手牌里等解锁）。**你自己第一次洗牌**的瞬间，"不可打出"被移除——从此变成 0 费 66 伤的可打出攻击牌。
- **66 是"白板"伤害：不吃力量，也不吃易伤**：伤害类型为 Unpowered——**不受[力量](/powers/strength_power.md)加成**（正负都不吃）、**不受[易伤](/powers/vulnerable_power.md)增伤**、也不吃锋锐/活力类攻击附魔增伤和[防御](/powers/defense_power.md)类减伤；但**可被[格挡](/mechanics/block.md)正常削减**。增伤 buff 一律无效，打谁都是实打实的 66——对高[防御](/powers/defense_power.md)叠层的坦克敌人相对更痛，对易伤目标的收割则毫无加成。
- **PP 3 = 一场三次 66**：0 费无成本打出，单场最多 <span style="color:#3aa675;font-weight:600">3</span> 次，总计 <span style="color:#3aa675;font-weight:600">198</span> 点伤害——洗牌后每个回合都是白嫖的爆发窗口。配合[保留](/mechanics/retain.md)，解锁前不占弃牌循环、解锁后想留到哪回合打都行。
- **解锁条件是"你洗牌"，不是"战斗过了几回合"**：故意快速抽干[抽牌堆](/mechanics/draw_pile.md)（抽牌加速、滤牌效果）能提前解锁；反过来刻意少抽牌会一直锁着。拿到这张牌的战斗，第一优先级就是尽快触发首次洗牌。
- **无法升级、不可战斗生成**：数值固定 66，由特定事件获得；强度全靠"洗牌后 0 费白打"这个时机价值。
