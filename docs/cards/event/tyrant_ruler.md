## 小贴士

- **🔑 结算顺序：伤害 → 先制 → 缓冲 → 弃牌 → 易伤 → 免费放史莱姆**：先把 <span style="color:#3aa675;font-weight:600">6</span> 点伤害砸向全体，再给**自己**加[先制](/powers/first_strike_power.md)+<span style="color:#3aa675;font-weight:600">1</span> 和 <span style="color:#3aa675;font-weight:600">1</span> 层[缓冲](/powers/buffer_power.md)（这两个增益都是给自己，不是给敌人），然后弃牌、施加全体[易伤](/powers/vulnerable_power.md)，最后自动打出史莱姆。
- **易伤在伤害之后才施加**：本牌自己的 <span style="color:#3aa675;font-weight:600">6</span> 点伤害吃不到自己挂的易伤增伤——但后面自动打出的史莱姆攻击牌**能吃到**，结算顺序对它非常有利。
- **弃牌可以一张都不弃**："最多 3 张"意味着 0～3 张随意——没垃圾牌时直接跳过；有弃牌触发效果（弃牌收益类能力）时，这张牌等于白送一次弃 3 的触发机会。弃牌选择会排除此牌自身。
- **"牌组中所有的史莱姆牌"实际是战斗中三堆**：收集范围是[手牌](/mechanics/hand.md) + [抽牌堆](/mechanics/draw_pile.md) + [弃牌堆](/mechanics/discard_pile.md)（**不含**[消耗堆](/mechanics/exhaust_pile.md)），包括[攻击史莱姆](/cards/colorless/slime_attack.md)、[防御史莱姆](/cards/colorless/slime_defense.md)、[速度史莱姆](/cards/colorless/slime_speed.md)、[体力史莱姆](/cards/colorless/slime_stamina.md)；[黏液？](/cards/status/slime_quest.md)不算史莱姆牌，不会被自动打出。
- **史莱姆全部免费自动打出，一张不费能量**：洗乱顺序后依次自动打出（不消耗能量，仅打出当前可打出的牌），指定敌方目标的史莱姆会随机选一个敌人。手牌、抽牌堆、弃牌堆里囤的史莱姆越多，这一下的爆发越恐怖——先囤后放是正确用法。
- **PP 5/5 + 1 费，可以反复收割**：一场最多打 <span style="color:#3aa675;font-weight:600">5</span> 次，每次都是"群伤 + 全体易伤 + 放生全部史莱姆"的完整循环；配合能生成史莱姆的手段，中后期一轮清场不是梦。
- **升级只加伤害**：6→9（+50%），其余全部不变——先制、缓冲、弃牌、易伤、放史莱姆一段不少，纯数值升级。
