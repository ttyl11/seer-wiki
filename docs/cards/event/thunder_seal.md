## 小贴士

- **触发时机**：打出时对所有对手施加<span style="color:#9b59b6;font-weight:600">疲惫</span><span style="color:#3aa675;font-weight:600">2</span> 回合，然后为召唤奥斯提增加最大生命，最后将此牌回到[<span style="color:#d4a017;font-weight:600">手牌</span>](/mechanics/hand.md)。
- **保留**：此牌带有[<span style="color:#d4a017;font-weight:600">保留</span>](/mechanics/retain.md)关键词，打出后回到手牌。
- **疲惫**：减益。攻击伤害降低 <span style="color:#3aa675;font-weight:600">20</span>%，每次造成伤害时自身受到等于层数的不可格挡伤害，回合结束时减少 <span style="color:#3aa675;font-weight:600">1</span> 层。
- **目标选取**：所有敌方。
- **升级效果**：奥斯提最大生命获取从 <span style="color:#3aa675;font-weight:600">3</span> 提升至 <span style="color:#3aa675;font-weight:600">5</span>。
