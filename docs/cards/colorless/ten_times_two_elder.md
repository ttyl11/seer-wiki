# 十倍二长老？

<img src="/images/cards/ten_times_two_elder.png" alt="十倍二长老？" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 无色牌
- **能量消耗**: 0
- **类型**: 能力
- **稀有度**: 普通
- **目标**: 自身
- **可升级**: 是（1 级）

## 描述

每回合开始时，向[<span style="color:#d4a017;font-weight:600">手牌</span>](/mechanics/hand.md)加入一张随机其他角色卡。

## 升级后

每回合开始时，向[<span style="color:#d4a017;font-weight:600">手牌</span>](/mechanics/hand.md)加入一张随机<span style="color:#d4a017;font-weight:600">升级</span>其他角色卡。打出后立即加入一张。

## 小贴士

- **触发时机**：打出时对自身施加<span style="color:#3aa675;font-weight:600">1</span> 层。该能力在每回合开始时触发，向[<span style="color:#d4a017;font-weight:600">手牌</span>](/mechanics/hand.md)加入一张随机其他角色卡。
- **角色卡池**：从铁血战士（Ironclad）、静默（Silent）、缺陷（Defect）、亡灵法师（Necrobinder）、统治者（Regent）五个角色卡池中随机抽取一张未锁定卡。
- **升级效果**：升级后，打出时额外立即加入一张随机角色卡，且所有生成的卡牌都会自动升级。
