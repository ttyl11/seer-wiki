# 元神启动

<img src="/images/cards/spirit_activation.png" alt="元神启动" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 无色牌
- **能量消耗**: 1
- **类型**: 能力
- **稀有度**: 罕见
- **目标**: 自身
- **可升级**: 是（1 级）

## 描述

每回合开始时，<span style="color:#d4a017;font-weight:600">生成</span>一个[<span style="color:#d4a017;font-weight:600">神谕充能球</span>](/orbs/oracle_orb.md)。

## 升级后

每回合开始时，<span style="color:#d4a017;font-weight:600">生成</span>一个[<span style="color:#d4a017;font-weight:600">神谕充能球</span>](/orbs/oracle_orb.md)。

## 小贴士

- **分类**：无色牌，能力牌，耗能 <span style="color:#3aa675;font-weight:600">1</span>，稀有度罕见。默认 <span style="color:#3aa675;font-weight:600">1</span> 级。
- **关键词**：自带[虚无](/mechanics/ethereal.md)，若回合结束时仍在手牌则消耗。
- **打出效果**：获得相应能力，使每回合开始时生成一个[神谕充能球](/orbs/oracle_orb.md)。
- **升级效果**：移除虚无关键词，使此牌不再在回合结束时消耗。
- **目标选取**：自身。
