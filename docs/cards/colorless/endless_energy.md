# 无尽能源

## 基本信息

- **分类**: 无色牌
- **能量消耗**: 0
- **类型**: 技能
- **稀有度**: 稀有
- **目标**: 无
- **可升级**: 是（1 级）

## 描述

获得<span style="color:#3aa675;font-weight:600">999</span>点[<span style="color:#d4a017;font-weight:600">能量</span>](/mechanics/energy.md)。本回合每打出一张牌，向[<span style="color:#d4a017;font-weight:600">手牌</span>](/mechanics/hand.md)加入1张随机赛尔诅咒。

## 升级后

获得<span style="color:#3aa675;font-weight:600">999</span>点[<span style="color:#d4a017;font-weight:600">能量</span>](/mechanics/energy.md)。本回合每打出一张牌，向[<span style="color:#d4a017;font-weight:600">手牌</span>](/mechanics/hand.md)加入1张随机赛尔诅咒。

> 升级后获得[保留](/mechanics/retain.md)关键词。

## 小贴士

- **无尽能源**（[<span style="color:#d4a017;font-weight:600">查看能力页</span>](/powers/endless_energy_power.md)，mod 能力，不可见）：本回合中你每打出一张牌，从赛尔诅咒牌池中随机选取一张诅咒牌加入[手牌](/mechanics/hand.md)。回合结束时自动移除此能力。
- **能量获取**：获得 <span style="color:#3aa675;font-weight:600">999</span> 点[能量](/mechanics/energy.md)。
- **升级效果**：添加[保留](/mechanics/retain.md)关键词（原版关键词），使此牌在回合结束时不会被弃置。
