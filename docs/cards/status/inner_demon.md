# 心魔

<img src="/images/cards/inner_demon.png" alt="心魔" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 状态牌
- **能量消耗**: 2
- **类型**: 状态
- **稀有度**: 状态
- **目标**: 无
- **可升级**: 否

## 描述

抽到此牌时，你必须先打出此牌。

## 小贴士

- **强制打出**：此牌在[<span style="color:#d4a017;font-weight:600">手牌</span>](/mechanics/hand.md)中时，必须先打出此牌才能打出其他牌。当手牌中存在此牌时，其他卡牌（非心魔、非自动打出）都无法打出。
- **状态牌**：此牌为状态牌，不可在战斗中生成，不可升级。
- **耗能**：打出此牌需消耗 <span style="color:#3aa675;font-weight:600">2</span> 点[<span style="color:#d4a017;font-weight:600">能量</span>](/mechanics/energy.md)。
