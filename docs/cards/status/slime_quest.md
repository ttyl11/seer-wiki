# 黏液？

<img src="/images/cards/slime_quest.png" alt="黏液？" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 状态牌
- **最大PP**: 1
- **能量消耗**: 0
- **类型**: 状态
- **稀有度**: 状态
- **目标**: 无
- **可升级**: 是（无限级）

### 数值参数

| 参数 | 数值 |
|---|---|
| PP | 1 |
| 最大PP | 1 |
| 抽牌数量 | 2 |
| Slime数量 | 1 |

## 描述

抽<span style="color:#3aa675;font-weight:600">2</span>张牌。向你的[<span style="color:#d4a017;font-weight:600">手牌</span>](/mechanics/hand.md)加入<span style="color:#3aa675;font-weight:600">1</span>张黏液。

## 升级后

抽<span style="color:#3aa675;font-weight:600">2</span>张牌。向你的[<span style="color:#d4a017;font-weight:600">手牌</span>](/mechanics/hand.md)加入<span style="color:#3aa675;font-weight:600">2</span>张黏液。

## 小贴士

- **卡牌类型**：属于状态牌（可无限升级）。耗能 <span style="color:#3aa675;font-weight:600">0</span>，PP <span style="color:#3aa675;font-weight:600">1</span>。
- **关键词**：自带[<span style="color:#d4a017;font-weight:600">保留</span>](/mechanics/retain.md)与[<span style="color:#d4a017;font-weight:600">消耗</span>](/mechanics/exhaust.md)。
- **打出效果**：先抽 <span style="color:#3aa675;font-weight:600">2</span> 张牌，然后向[手牌](/mechanics/hand.md)加入 <span style="color:#3aa675;font-weight:600">1</span> 张黏液。
- **可重复升级**：每次升级多加入 <span style="color:#3aa675;font-weight:600">1</span> 张黏液（可无限升级，每升一级黏液 +1）。
- **目标选取**：无目标。
