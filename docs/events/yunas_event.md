# 尤纳斯

天空一角已被浓稠的黑夜吞噬，无数扭曲的影子在云层中蠕动——那是尤纳斯的领域，异空间影魔。空洞而冰冷的声音从黑暗中传来："闯入者……准备好迎接黑暗了吗？"

## 小贴士

- **单体线是标准事件战**：打赢一只尤纳斯换一件专属遗物，难度可控，血量健康时的稳妥选择。
- **四体线是给"成型牌组"准备的试炼**：同时面对 4 个尤纳斯，火力不足会被轮番侵蚀——但奖励[原始黑洞尤纳斯](/relics/epic/primordial_black_hole_yunas.md)是升级版专属遗物，效果强度对应它的史诗定位。AoE（全场伤害）成型、或有强力控制（眩晕/瘫痪）的牌组再去挑战。
- **逃跑是纯惩罚，没有收益**：不是"无损离开"，而是被黑暗**随机吞掉 <span style="color:#d44;font-weight:600">3</span> 张牌**——随机意味着可能吃掉你的核心卡！看到这个事件请务必做好战斗准备，逃跑只在"牌组全是废牌、随机删也不心疼"的极端情况下才算止损。
- **先看牌组再选难度**：能稳定打过精英 → 四体；血量/牌组一般 → 单体；两种都打不动且牌组恰好需要"强制瘦身" → 才考虑逃跑。
