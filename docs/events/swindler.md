# 奸商

破旧招牌上写着"包你满意"四个歪歪扭扭的字。尖嘴猴腮的奸商见到你便露出狡黠的笑容："哟——客官！抽奖吗？大奖丰厚，童叟无欺！看见没？这三张，全是大奖牌！"

## 小贴士

- **"四十张大奖"是话术，实际只有 3 种变体**：豪华抽奖是从上表 3 张里随机给 1 张（走 Niche 随机，多端结果一致）。大奖牌本身是可用的功能性卡牌，不是废牌，但 <span style="color:#3aa675;font-weight:600">200</span> 金币买一张随机变体的价格并不便宜——两件普通遗物的钱了。
- **单抽是彻底的骗局**：<span style="color:#3aa675;font-weight:600">5</span> 金币打水漂，什么都不会发生——剧情文本里奸商把牌"晃了晃又塞回去"把你赶出来。这 <span style="color:#3aa675;font-weight:600">5</span> 金币唯一的用途是看一段被骗的剧情。
- **抽老板的战斗是纸老虎**：四只[史莱姆](/monsters/normal/slime_monster.md)血条写着 <span style="color:#3aa675;font-weight:600">114512~114517</span>（玩梗数字），但**你永远不需要打穿它**——本体两个技能都不攻击：第 1 回合「弹力无限」把每位玩家抽牌堆里随机 <span style="color:#3aa675;font-weight:600">2</span> 张可变化的牌变成黏液（单人最多 <span style="color:#d44;font-weight:600">8</span> 张）；第 2 回合「史莱姆意志」**直接自杀变身**成四种小史莱姆之一（血量仅 <span style="color:#3aa675;font-weight:600">32~37</span>，[体力史莱姆](/monsters/normal/hp_slime_monster.md)为 <span style="color:#3aa675;font-weight:600">95~105</span>）。11 万血量在第 2 回合自动清零，变身只发生一次。
- **前两回合是白给的准备期**：变身前它们完全不输出，尽情叠格挡、铺场面、攒能量。真正的压力在变身后：[攻击史莱姆](/monsters/normal/attack_slime_monster.md)登场自带 <span style="color:#3aa675;font-weight:600">5</span> 层力量（20 伤重击+力量翻倍）；[防御史莱姆](/monsters/normal/defense_slime_monster.md)的盾击带<span style="color:#d44;font-weight:600">固定伤害</span>（无视格挡）；[体力史莱姆](/monsters/normal/hp_slime_monster.md)血厚还会回血；[速度史莱姆](/monsters/normal/speed_slime_monster.md)自带先制加成。变身当回合集中爆发逐个点名，压力远小于表面。
- **战斗奖励就是三张牌，别指望金币**：这场战斗被设置为**不给任何常规奖励**——没有金币、药水、也没有卡牌奖励，三张大奖牌（各 1 张）就是全部战利品。即便如此，免费三张全套仍碾压 <span style="color:#3aa675;font-weight:600">200</span> 金币一张随机的豪华抽奖。
- **黏液不是死牌，但代价真实存在**：被塞进抽牌堆的黏液是 <span style="color:#3aa675;font-weight:600">1</span> 费状态牌，打出即消耗并**抽 1 张牌**——它不卡死手牌，只是每次 <span style="color:#3aa675;font-weight:600">1</span> 点能量的过路费。真正的损失是被变化掉的那些真卡：本场战斗再也抽不回来，核心牌被变走会明显拖慢节奏。
- **大奖牌的战术价值**：两张本 mod 大奖牌都是 <span style="color:#3aa675;font-weight:600">0</span> 费技能，等于白嫖三张 3 费核心牌（3 费位通常是职业大招）——配合吃牌组数量或吃生成牌的构筑（如[保底](/cards/curse/guaranteed.md)流、能量引擎）能形成奇怪的滚雪球；对普通牌组则是锦上添花的填充牌。注意生成的牌只在本场战斗有效。
- **决策树**：能打赢中型战斗 → 抽老板（三张全套，前两回合还白送准备期）；打不过且金币充裕 → 豪华抽奖赌一张；任何情况下都不要单抽。
