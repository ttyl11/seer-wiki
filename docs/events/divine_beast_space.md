# 神兽空间

云雾缭绕的圣域，四尊巨大的神兽雕像环绕四周——玄武、凤凰（朱雀）、白虎、青龙。空气中传来古老的回响，似乎每尊神兽都在等待你的挑战。

## 基本信息

- **类型**：剧情抉择事件
- **战斗**：是
- **机制**：四选一挑战，胜利奖励均为**永久加成**（整局所有战斗生效，详见[永久属性](/mechanics/permanent-bonus.md)）

## 选项一览

事件为两页结构：第一页选择「进入空间」或「离开」（离开无事发生），进入后第二页四选一挑战神兽。

| 神兽 | 战斗 | 永久加成 |
|---|---|---|
| 玄武巴斯特（帕诺星系守护神） | 是 | 受到伤害减少 <span style="color:#3aa675;font-weight:600">10%</span> |
| 凤凰菲尼克斯 / 朱雀（裂空星系守护神） | 是 | 每回合获得 <span style="color:#3aa675;font-weight:600">10</span> 点[再生](/mechanics/abnormal-status.md) |
| 白虎泰格尔（罗格星系守护神） | 是 | 造成伤害提高 <span style="color:#3aa675;font-weight:600">20%</span> |
| 青龙朵拉格（卡兰星系守护神） | 是 | 最大生命值 +<span style="color:#3aa675;font-weight:600">20</span> |

## 小贴士

- **只能四选一，选错没法重来**：进入空间后挑战一尊神兽，其余加成本轮再也拿不到。选择前想清楚你的牌组最缺哪一维。
- **白虎 20% 增伤是最泛用的输出投资**：所有伤害（攻击、固定伤害等）整体乘算 <span style="color:#3aa675;font-weight:600">1.2</span>，输出流的公认首选——越早拿到，整局累计收益越高。
- **玄武 10% 减伤是生存流的保险**：受伤恒定打九折，配合格挡体系收益会被格挡稀释一部分（减伤在格挡之前的结算顺序会降低"破防伤害"），更适合没有成型格挡的牌组。
- **朱雀 10 点再生是续航引擎**：每回合稳定回 <span style="color:#3aa675;font-weight:600">10</span> 血，长战斗/消耗战里等于每回合白拿一张小回血牌；速攻流则基本用不上。
- **青龙 +20 上限最保守**：一次性提高容错，但没有伤害/回复的成长性。适合血量吃紧、想要纯容错的跑法。
- **战斗难度四尊相近，按需选择即可**：真正需要权衡的是奖励方向——输出选白虎、防御选玄武、续航选朱雀、容错选青龙。大后期（第三幕）遇到时，增伤/减伤的累计价值已经变薄，加最大生命的即时收益反而更实在。
