## 小贴士

- **合作路线 = 四次免费锻造**：从牌组中随机升级 <span style="color:#3aa675;font-weight:600">4</span> 张**可升级**的牌。注意是随机而非指定——平均下来总有一两张升在你不太想升的牌上，期望价值约等于 <span style="color:#3aa675;font-weight:600">2.5</span>~<span style="color:#3aa675;font-weight:600">3</span> 次指定升级。牌组里废牌越少（已精简过），随机升级的命中率越高。
- **威胁路线 = 普通商店全场 <span style="color:#3aa675;font-weight:600">5</span> 折**：会员卡是原版商店遗物，对走商人价格系统的普通商店（原版商店房间）全部商品半价。注意 mod 自定义的[！？商店？！](/events/weird_shop.md)（金币直扣）、[赛尔豆商店](/events/elite_shop.md)（赛尔豆结算）、[泰坦之灵商店](/events/boss_shop.md)（泰坦之灵结算）都不走该系统，**不受会员卡影响**。长跑局逛普通商店累计能省下可观金币；但它是"省钱的卡"而非"变强的卡"，对战斗没有直接帮助。
- **怎么选看牌组阶段**：还在成长期（有大量值得升级的核心牌）→ 选合作，把战力立刻顶上去；已经成型、且后续规划要走多商店路线（买遗物/删牌）→ 会员卡的累计折扣更划算。
- **赛罗居然真信了**：虚张声势的剧情文本相当欢乐——堂堂光之国战士被你一句狠话吓得慌慌张张交出物资，算是对话框彩蛋。
