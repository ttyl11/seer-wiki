# 决战回响：混沌深渊的宿命对决

雷光与裂地拳风交织——雷伊、盖亚以全新形态并肩而立，对面是连黑暗都在扭曲的湮灭之主·咤克斯。战场角落，琉梦已被混沌之力缠满全身，再晚一步就要被彻底侵蚀同化。生死一瞬，你必须做出抉择。

## 小贴士

- **守护线：卖上限换保命遗物**：[琉梦](/relics/epic/liu_meng.md)是史诗级专属遗物，<span style="color:#d44;font-weight:600">8</span> 点最大生命的永久代价换一件高价值遗物，血量充裕时是笔好买卖；血牛流（吃最大生命的体系）要三思。
- **驰援线：一诅咒换永动机**：[雷盖之交](/cards/event/thunder_gaia_bond.md)打出后获得"打攻击牌补技能牌、打技能牌补攻击牌"的整场循环能力，长战斗收益指数级放大——只要 <span style="color:#3aa675;font-weight:600">1</span> 张随机诅咒的代价，是三选一里风险收益比最均衡的。诅咒可以后续用删牌服务处理。
- **投靠线：力量最强，代价也最长线**：一次性拿两件遗物 + 一张高稀有卡，但[咤克斯的诅咒](/relics/event/zhakes_curse_relic.md)会**每场战斗结束后**往牌组里塞 <span style="color:#3aa675;font-weight:600">1</span> 张随机赛尔诅咒——打到第 <span style="color:#3aa675;font-weight:600">15</span> 场就是 <span style="color:#3aa675;font-weight:600">15</span> 张诅咒，牌组会被持续污染。除非你的牌组能消化诅咒（诅咒流、有批量删牌手段），否则后期抽牌质量会崩盘。
- **投靠线的正确打开方式**：湮灭流/诅咒流成型时，每场一张诅咒反而是燃料——配合吃诅咒数量的遗物或"诅咒越多越强"的卡，负面代价直接变正面引擎，那时这套奖励就是三选一里的天花板。
- **选完即离场**：本事件没有战斗，三条线都是拿奖励走人，不必担心卷入雷伊盖亚与咤克斯的战斗。
