# 莱达长老的电车难题考验

莱达宇宙的三位长老又在开会，但他们之间已察觉到不对劲——据说被混沌侵蚀的长老，会在经典的电车难题上暴露本心。大长老双手合十："我不入地狱，谁入地狱。"二长老拂尘一甩："人为造业，干预天道。"三长老眼睛一亮："我可以用业火逼停列车，然后烧死所有人！？"你需要指出你认为被混沌侵蚀的长老。

## 小贴士

- **没有正确答案，只有"伤害最小"**：三长老确实是真凶（指认他的结局文案明说"你的判断完全正确"），但"答对"的奖励是被他一掌打飞＋塞 10 张状态牌；指认另外两位则会各吃一个"小惩戒"。本题考的不是推理，是**按自己的构筑挑惩罚**。
- **虚无（指认大长老）——惩罚手牌利用率**：虚无牌**打出后正常进弃牌堆**，只有回合结束时**还留在手里**才被消耗。每回合把手牌打空的快攻/低费流几乎零损失；每回合剩 2-3 张打不出的高费慢速流则每回合白烧牌，几回合后牌组见底。手牌利用率高就选它。
- **降级（指认二长老）——惩罚升级投入**：本场战斗开始时，三处牌堆里所有已升级卡全部退回基础版。刚开局、篝火升级少的牌组近乎白板；升级多的牌组这场战力会明显缩水。注意升级**不会真丢**——降级只作用于战斗内的克隆体，战后局外牌组原封不动，只弱这一场。
- **状态牌（指认三长老）——惩罚抽牌质量**：首回合开始时 10 张随机状态牌插入抽牌堆随机位置。小牌组被稀释得最狠（20 张牌组抽到状态牌的概率接近一半），且池子里有[芜](/cards/status/barren.md)（累积处决）、[心魔](/cards/status/inner_demon.md)（锁死出牌）等危险货；大牌组反而扛得住。牌组厚就选它。
- **选完先看路线再打**：负面遗物到手后下一场战斗自动生效——尽量安排先打个普通小怪消化惩罚，别带着它硬闯精英或 Boss 房。
- **三条惩罚都只持续一场战斗**：战斗结束遗物自动消失，牌组、升级、抽牌质量全部恢复原状。决策口诀：**手牌打空流选虚无、升级少选降级、大牌组选状态牌**。
