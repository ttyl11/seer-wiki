## 小贴士

- **挑拨线是全 mod 最肥的事件战之一**：赢了直接拿 <span style="color:#3aa675;font-weight:600">1200</span> 万赛尔豆（约等于[赛尔豆商店](/events/elite_shop.md)普通卡 <span style="color:#3aa675;font-weight:600">4</span> 张或删牌服务 <span style="color:#3aa675;font-weight:600">3</span> 次的购买力）+ <span style="color:#3aa675;font-weight:600">10</span> 泰坦之灵（[泰坦之灵商店](/events/boss_shop.md)整整 <span style="color:#3aa675;font-weight:600">10</span> 抽，正好一轮 2 星保底周期）+ <span style="color:#3aa675;font-weight:600">5</span> 颗刻印水晶。但代价是同时面对两位战神——双人房强度接近精英 Boss 战，前期误选可能直接团灭。
- **刻印水晶的用途**：[通用刻印激活水晶](/relics/event/universal_engraving_gem_relic.md)用于激活刻印系统，5 颗是很大一笔储备，足够点亮多条刻印路线。
- **请教线 = 温和的锻造包**：升级 <span style="color:#3aa675;font-weight:600">2</span> + 移除 <span style="color:#3aa675;font-weight:600">1</span>，全部指定选牌，零风险。不想打架时的优质保底。
- **欺骗线 = 卖 8 血换史诗遗物**：<span style="color:#d44;font-weight:600">8</span> 点直接伤害换一件随机赛尔史诗遗物，交换比公道。血量健康时是"白嫖"级收益；残血时 8 点伤害也有致死风险，需谨慎。
- **决策树**：战力成型（能打精英）→ 挑拨离间，巨额资源直接改变整局节奏；中期稳健 → 虚心请教；缺遗物且血量充足 → 欺骗。
