# 罗开

> 事件文案自称卖「通用刻印宝石」、能「强化你的刻印」，实际获得的遗物是[通用刻印激活水晶](/relics/event/universal_engraving_gem_relic.md)——效果是每颗手牌上限 +1，与"刻印"无关（游戏中也不存在独立的刻印系统）。听罗开吹不如看遗物描述。

## 小贴士

- **水晶的真实价值是手牌上限**：每颗[通用刻印激活水晶](/relics/event/universal_engraving_gem_relic.md)让手牌上限永久 +1，且效果可叠加——手牌上限越大，每回合能攥住的牌越多，抽到关键牌不用被迫弃掉，大过牌、连击链构筑的强度天花板直接由它抬高。三颗一组拿满就是 +3，相当可观。
- **两种货币两个价，泰坦档单价碾压**：<span style="color:#3aa675;font-weight:600">500</span> 万赛尔豆 1 颗 vs <span style="color:#3aa675;font-weight:600">3</span> 泰坦之灵 3 颗——泰坦之灵档折合 1 泰坦/颗。赛尔豆面值大但获取渠道多（日常战斗、商店找零），泰坦之灵稀缺且是[泰坦之灵商店](/events/boss_shop.md)金蛋抽卡的唯一资金：手里泰坦 ≥5 且不急着抽卡时才值得走批发档，否则老老实实付赛尔豆。
- **离开也有小礼物**：不买东西直接走，罗开会塞给你 <span style="color:#3aa675;font-weight:600">1</span> 泰坦之灵当"交个朋友"——遇到本事件至少保底 +1 泰坦，血赚不亏。买了宝石就没有这 1 泰坦，两档奖励互斥。
- **买不起不会白跑**：赛尔豆或泰坦之灵不够时选项点了只会触发"钱不够"对话，货币分文不扣、事件直接结束——不用怕误点。
- **决策树**：大过牌/手牌上限流 → 按富余货币买 1 颗或 3 颗；普通构筑手牌上限边际价值低 → 直接离开白拿 1 泰坦之灵，留给金蛋抽卡。
