# 克洛斯星

降落在美丽的克洛斯星——茂密的丛林、奇异的生物。前方有几只毛茸茸的皮皮在跳跃，更深处似乎有巨大的蘑菇状生物在活动，空气中弥漫着青草与花蜜的香气。

## 选项一览

|---|---|---|

## 小贴士

- **打皮皮 = 最温和的删牌服务**：六只皮皮的低威胁战斗，赢了换 <span style="color:#3aa675;font-weight:600">1</span> 张指定移除。前中期想精简牌组、又舍不得花钱删牌时的免费窗口。
- **两场战斗都没有战败保护**：与[梅赫维特](/events/mehvet.md)的试炼不同，这里的战斗打输就是正常死亡、结束跑局——评估战力后再动手。
- **拜皮神 = 白拿史诗遗物**：一句口号直接换[皮神](/relics/epic/pi_shen.md)，零风险零代价——三选一里唯一的"无本买卖"，不想战斗时闭眼选。
- **深入丛林 = 两件罕见遗物**：蘑菇怪 ×2 的战斗压力明显高于六只皮皮，但两件随机罕见遗物的期望收益也最厚。注意游戏内文本写作"稀有遗物"，实际掉落稀有度为**罕见**（Uncommon）。
- **决策树**：牌组需要精简 → 打皮皮；缺一件稳定增益 → 拜皮神；战力充裕想要更多遗物 → 深入丛林。血量不健康时优先拜皮神，避免无谓战斗损耗。
