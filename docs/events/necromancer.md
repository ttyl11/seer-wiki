## 小贴士

- **召唤体系与 mod 卡有联动**：奥斯提是原版亡灵契约师的左手召唤物，mod 卡（如[核威强袭](/cards/event/nuclear_assault.md)）也会召唤奥斯提作战——亡灵契约师的召唤/奥斯提卡能直接混编进赛尔牌组，是与 mod 卡联动最直接的一池。
- **虚无卡是把双刃剑**：[虚无](/mechanics/ethereal.md)卡如果**留在手里**到回合结束会被消耗掉；打出去则正常进弃牌堆不受影响。它考验的是出牌规划——手里攥着没打出去就等于白丢一张牌。若牌组有吃消耗堆的配合（如[毁灭](/mechanics/destruction.md)），故意留虚无牌到回合结束也能变废为宝。
- **灾厄是高阶关键词**：灾厄相关卡普遍强度高但理解成本也高，新手建议优先抓召唤/奥斯提这类直观组件。
- **遗物双件各有取向**：大帽子（每场战斗第 <span style="color:#3aa675;font-weight:600">1</span> 回合开始时，从你**职业卡池**的[虚无](/mechanics/ethereal.md)牌中随机生成 <span style="color:#3aa675;font-weight:600">2</span> 张加入手牌——是临时生成牌，不是从牌组里抽）正好呼应虚无主题；象牙麻将牌（打出 <span style="color:#3aa675;font-weight:600">3</span> 费及以上的牌时获得 <span style="color:#3aa675;font-weight:600">1</span> 能量）适配高费重卡。泛用性不错，牌组不缺召唤组件时是稳妥之选。
- **决策树**：玩召唤/奥斯提流 → 请求法术（一次补 5 张）；要泛用增益 → 索取遗物；牌组要瘦身 → 请她舍弃。
