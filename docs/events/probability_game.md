# 派克博士的概率博弈

"嗨赛尔，看看我研发的新东西吧，自动变牌机！！！"指示牌写着：50 金币变化一张牌！第一次 100% 成功！之后每次概率减半：50%、25%、12.5%……直到你满意为止。（最终解释权归本机器所有）

## 基本信息

- **类型**：功能事件
- **战斗**：否
- **机制**：可重复使用的[变化](/mechanics/transform.md)服务，成功率从 100% 开始，**每尝试一次减半**（无论成败）

## 选项一览

| 选项 | 代价 | 收益 |
|---|---|---|
| 变化卡牌 | <span style="color:#3aa675;font-weight:600">50</span> 金币/次 | 选择 1 张牌进行变化（变成同卡池中随机另一张普通/罕见/稀有牌，不保证同稀有度） |
| 离开（未变过牌） | — | 获得 <span style="color:#3aa675;font-weight:600">150</span> 金币 |
| 离开（变过牌后） | — | 无奖励 |

> ℹ️ 点「变化卡牌」的瞬间，<span style="color:#d44;font-weight:600">50</span> 金币立即扣除、且"未变牌离开"的 <span style="color:#3aa675;font-weight:600">150</span> 金币安慰奖资格同时作废——之后才弹出选牌界面。此时取消选牌：成功率**不会**减半，但 50 金币和安慰奖都已回不来。想保住 150 金币，就一次都别点。

## 概率与期望

| 尝试次数 | 第 1 次 | 第 2 次 | 第 3 次 | 第 4 次 | 第 5 次 |
|---|---|---|---|---|---|
| 成功率 | <span style="color:#3aa675;font-weight:600">100%</span> | <span style="color:#3aa675;font-weight:600">50%</span> | <span style="color:#3aa675;font-weight:600">25%</span> | <span style="color:#3aa675;font-weight:600">12.5%</span> | <span style="color:#3aa675;font-weight:600">6.25%</span> |
| 每次成功的期望成本 | <span style="color:#3aa675;font-weight:600">50</span> 金币 | <span style="color:#3aa675;font-weight:600">100</span> 金币 | <span style="color:#3aa675;font-weight:600">200</span> 金币 | <span style="color:#3aa675;font-weight:600">400</span> 金币 | <span style="color:#3aa675;font-weight:600">800</span> 金币 |

## 小贴士

- **概率按"尝试次数"衰减，不按成功次数**：即使失败，下一次成功率照样减半——连续尝试的边际成本是指数上升的（每次成功的期望成本逐次翻倍）。无限续杯的期望总成功次数收敛于 <span style="color:#3aa675;font-weight:600">2</span> 次（1 + 0.5 + 0.25 + … = 2），再多赌就是给机器送钱。
- **失败不毁牌，但钱和概率都没了**：摇奖失败时选中的那张牌原样保留、什么都不会发生——但 50 金币照扣、概率照样减半。好在每次尝试都是重新选牌，失败后完全可以换一张"更不怕浪费"的牌再试。
- **变化的候选池不保证同稀有度**：变出来的牌从原卡所属卡池中已解锁的牌里随机抽，稀有度限定在普通/罕见/稀有三档——普通卡可能直接变出稀有卡，稀有卡也可能跌回普通。状态牌/诅咒牌则只在各自同类的池子里换（诅咒换诅咒、状态换状态），先古/事件/衍生稀有度的牌会转去无色卡池的普通/罕见/稀有候选。不可变化的牌（如永恒牌）在选牌界面里根本选不到。
- **第一次 100% 成功是稳定收益**：<span style="color:#3aa675;font-weight:600">50</span> 金币换一次必定成功的变牌，是本事件确定性最高的交易。有废牌就先变一张，之后看钱包和心情决定是否续杯。
- **白拿 150 金币是默认解**：不碰机器直接离开 = 净赚 <span style="color:#3aa675;font-weight:600">150</span> 金币（比三次变牌的花费 150 金币还多，够商店买半件遗物）。只要付过一次钱（哪怕取消了选牌），这笔安慰奖就没了——没想清楚要变什么之前，别手痒点第一次。
- **金币不足 50 时机器自动歇业**：钱包低于 <span style="color:#3aa675;font-weight:600">50</span> 金币时「变化」选项直接不显示，只剩离开一条路——好在这时如果一次都没赌过，150 金币安慰奖照拿。
- **推荐流程**：①有废牌 → 变第 1 张（100% 稳）；②第 2 张半价概率，钱包宽裕可赌；③第 3 次起期望成本 200 金币/次，见好就收。没废牌 → 直接离开拿钱走人。
