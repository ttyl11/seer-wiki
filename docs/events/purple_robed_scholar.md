## 小贴士

- **《日月前事》是纯彩蛋**：选项没有任何实际收益——你刚开口她就吓得转身逃走。这个书名是联动剧情梗，好奇的话可以点一次看看文本，但别指望拿东西。
- **请教技巧是"强制塞牌"**：从五个原版职业（铁甲战士/静默猎手/故障机器人/储君/亡灵契约师）的卡池随机生成 <span style="color:#3aa675;font-weight:600">5</span> 张，但**至少要选 3 张**才能离开。随机 5 张里挑 3 张，质量完全看脸——牌组已经很精炼时，硬塞 3 张杂牌反而是负收益；牌组尚在早期扩容期时则基本稳赚。
- **塞的牌可以跨职业**：生成池包含全部五个原版职业，有机会白嫖其他职业的核心牌来补强短板（比如缺 AoE 抓全场攻击、缺过牌抓抽牌引擎）。
- **索要遗物的代价是羞耻**：随机罕见遗物 + <span style="color:#3aa675;font-weight:600">1</span> 张[羞耻](/cards/curse/shame.md)（不可打出、回合结束触发负面效果的诅咒）。有删牌手段或诅咒流（能利用诅咒）时是净赚；一个诅咒换一件遗物的基础交换比也还算公道。
- **性价比排序**：早期缺卡 → 请教技巧（拿 3 张补强）；中后期牌组成型 → 索要遗物（诅咒可后续删）；《日月前事》只在你想看彩蛋时点。
